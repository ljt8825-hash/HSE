## P0 - Critical 修复

### P0-1: JWT_SECRET 硬编码移除 fallback 值

| 属性     | 内容                                        |
|----------|---------------------------------------------|
| 问题描述  | JWT_SECRET 在 3 个文件中存在硬编码 fallback 值 |
| 严重程度  | Critical                                    |
| 影响文件  | server/middleware/auth.js:10                  |
|          | server/middleware/auth.js:11 (REFRESH_SECRET)|
|          | server/services/wsServer.js:15              |
|          | server/routes/auth.js:226                   |
| 修复方式  | 移除 fallback 值，启动时强制检查环境变量      |
| 修复补丁  | [fix-jwt-secret-hardcode.js](patches/fix-jwt-secret-hardcode.js) |
| 预估工时  | 0.5 天                                      |

**修复后必须执行**:
- 生成新的 JWT_SECRET（64+ 字符随机）
- 生成新的 JWT_REFRESH_SECRET（64+ 字符随机）
- 更新 .env 配置
- 重启服务（所有现有 Token 失效）
- 通知所有用户重新登录

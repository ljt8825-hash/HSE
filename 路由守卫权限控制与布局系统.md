## 一、架构总览

### 1.1 路由-权限-布局协作图

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户访问页面                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    全局前置守卫 (beforeEach)                     │
│  1. Token 检查（getAccessToken 纯函数）                         │
│  2. 白名单放行（/login, /404 等）                               │
│  3. 未登录 → 跳转登录页（携带 redirect 参数）                    │
│  4. 已登录 → 加载用户信息（authStore.fetchUserInfo）             │
│  5. 权限未加载 → 获取权限树（permissionStore.fetchPermissions）  │
│  6. 生成动态路由（permissionStore.generateRoutes）               │
│  7. 添加动态路由（router.addRoute）                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    路由解析与组件匹配                            │
│  - 静态路由：直接匹配（login, 404, redirect）                    │
│  - 动态路由：根据 permissionStore.dynamicRoutes 匹配             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      布局组件渲染                                │
│  LayoutDefault.vue → 侧边栏 / Header / 面包屑 / 标签页          │
│  LayoutBlank.vue   → 登录页等无布局页面                         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    页面组件（features/*/views）                  │
│  - 按钮级权限：v-permission 指令控制显隐                        │
│  - 服务端数据：TanStack Query useQuery / useMutation            │
│  - 客户端状态：Pinia Store（表单草稿、筛选条件等）               │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 路由分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 静态常量路由 | 无需权限，所有用户可访问 | /login, /404, /redirect |
| 动态异步路由 | 根据权限动态生成 | /dashboard, /user/list, /system/role |
| 嵌套路由 | 在 Layout 内部渲染 | 所有业务页面均为 / 的子路由 |

## 二、路由核心配置

### 2.1 `src/router/index.ts` — 路由实例

```typescript
// src/router/index.ts

import { createRouter, createWebHistory, type RouteRecordRaw } from 'vue-router'
import type { App } from 'vue'
import { constantRoutes } from './routes'
import { setupRouterGuards } from './guards'

/**
 * 创建 Vue Router 实例
 * - 初始只挂载常量路由（登录页、404 等）
 * - 动态路由在导航守卫中根据权限动态添加
 */
export const router = createRouter({
  history: createWebHistory(import.meta.env.VITE_PUBLIC_PATH || '/'),
  routes: constantRoutes as RouteRecordRaw[],
  scrollBehavior() {
    // 路由切换后滚动到顶部
    return { top: 0, left: 0 }
  },
})

/**
 * 初始化路由（在 main.ts 中调用）
 * @param app — Vue 应用实例
 */
export function setupRouter(app: App): void {
  // 设置导航守卫
  setupRouterGuards(router)

  app.use(router)
}

/**
 * 重置路由（登出时调用）
 * 移除所有动态添加的路由，恢复为常量路由
 */
export function resetRouter(): void {
  // 获取当前所有路由名称
  const routes = router.getRoutes()

  // 移除所有非常量路由
  routes.forEach((route) => {
    const name = route.name
    if (name && !constantRoutes.some((r) => r.name === name)) {
      router.removeRoute(name)
    }
  })
}

export default router
```

## 三、导航守卫完整实现

```typescript
// src/router/guards.ts

import type { Router, NavigationGuardNext, RouteLocationNormalized } from 'vue-router'
import { getAccessToken } from '@/utils/token'
import { useAuthStore } from '@/stores/auth'
import { usePermissionStore } from '@/stores/permission'
import { useAppStore } from '@/stores/app'
import { asyncRoutes } from './routes'
import NProgress from 'nprogress' // npm install nprogress @types/nprogress
import 'nprogress/nprogress.css'

// 关闭 NProgress 加载圆圈
NProgress.configure({ showSpinner: false })

/** 白名单路由（无需登录即可访问） */
const whiteList = ['/auth/login', '/auth/register', '/auth/forget-password', '/404', '/403']

/**
 * 设置路由导航守卫
 * @param router — Vue Router 实例
 */
export function setupRouterGuards(router: Router): void {
  // ==================== 全局前置守卫 ====================
  router.beforeEach(
    async (
      to: RouteLocationNormalized,
      _from: RouteLocationNormalized,
      next: NavigationGuardNext
    ) => {
      // 开始进度条
      NProgress.start()

      // 设置页面标题
      document.title = to.meta?.title
        ? `${to.meta.title as string} — Vue3 Admin Pro`
        : 'Vue3 Admin Pro'

      // 使用纯函数检查 Token（避免 Pinia 未初始化问题）
      const hasToken = getAccessToken()

      // 已登录状态
      if (hasToken) {
        if (to.path === '/auth/login') {
          // 已登录用户访问登录页 → 重定向到首页
          next({ path: '/', replace: true })
          NProgress.done()
          return
        }

        const authStore = useAuthStore()
        const permStore = usePermissionStore()

        // 步骤 1：获取用户信息（若未加载）
        if (!authStore.userInfo) {
          try {
            await authStore.fetchUserInfo()
          } catch {
            // Token 失效，执行登出并跳转登录页
            await authStore.logoutAction()
            next(`/auth/login?redirect=${encodeURIComponent(to.fullPath)}`)
            NProgress.done()
            return
          }
        }

        // 步骤 2：获取权限并生成动态路由（若未生成）
        if (!permStore.isRoutesGenerated) {
          try {
            // 获取菜单树和权限编码
            await permStore.fetchPermissions()

            // 生成可访问的动态路由
            const accessedRoutes = permStore.generateRoutes(asyncRoutes)

            // 动态添加路由到 router
            accessedRoutes.forEach((route) => {
              router.addRoute(route)
            })

            // 重新导航（确保新添加的路由生效）
            next({ ...to, replace: true })
            return
          } catch (error) {
            console.error('动态路由生成失败:', error)
            await authStore.logoutAction()
            next(`/auth/login?redirect=${encodeURIComponent(to.fullPath)}`)
            NProgress.done()
            return
          }
        }

        // 步骤 3：设置面包屑
        setBreadcrumbs(to)

        // 步骤 4：添加到已访问标签页
        addVisitedView(to)

        next()
        return
      }

      // 未登录状态
      if (whiteList.includes(to.path)) {
        // 白名单路由直接放行
        next()
      } else {
        // 非白名单路由 → 跳转登录页，携带原始目标路径
        next(`/auth/login?redirect=${encodeURIComponent(to.fullPath)}`)
        NProgress.done()
      }
    }
  )

  // ==================== 全局后置守卫 ====================
  router.afterEach(() => {
    // 结束进度条
    NProgress.done()

    // 关闭全局 Loading（若由路由守卫开启）
    const appStore = useAppStore()
    appStore.setGlobalLoading(false)
  })

  // ==================== 全局错误处理 ====================
  router.onError((error) => {
    console.error('路由错误:', error)
    NProgress.done()
  })
}

// ==================== 辅助函数 ====================

/**
 * 根据当前路由生成面包屑
 */
function setBreadcrumbs(to: RouteLocationNormalized): void {
  const appStore = useAppStore()
  const breadcrumbs: Array<{ title: string; path?: string }> = []

  // 添加首页
  breadcrumbs.push({ title: '首页', path: '/' })

  // 遍历匹配的路由记录
  to.matched.forEach((route) => {
    if (route.meta?.title && route.path !== '/') {
      breadcrumbs.push({
        title: route.meta.title as string,
        path: route.path,
      })
    }
  })

  appStore.setBreadcrumbs(breadcrumbs)
}

/**
 * 添加到已访问标签页
 */
function addVisitedView(to: RouteLocationNormalized): void {
  const appStore = useAppStore()

  // 隐藏的路由不添加到标签页
  if (to.meta.hidden) return

  appStore.addVisitedView({
    name: to.name as string,
    path: to.path,
    title: (to.meta.title as string) || '未命名',
  })
}
```

## 四、动态路由与权限过滤

### 4.1 权限过滤核心逻辑（已在 `src/stores/permission.ts` 中定义，此处补充说明）

```typescript
// src/stores/permission.ts 中的关键逻辑回顾

/**
 * 生成动态路由的核心流程：
 *
 * 1. 后端返回当前用户的权限编码列表：['dashboard:view', 'user:list', 'system:role', ...]
 * 2. 遍历 asyncRoutes，检查每个路由的 meta.permission 是否在权限列表中
 * 3. 递归处理子路由
 * 4. 返回过滤后的路由数组
 * 5. 使用 router.addRoute() 动态添加到路由表
 */

/**
 * 权限匹配规则：
 * - 超级管理员（拥有 '*:*:*'）→ 放行所有路由
 * - 路由未设置 meta.permission → 默认放行
 * - 路由设置了 meta.permission → 检查用户权限列表
 * - 父路由无权限 → 整个子树被过滤
 */
```

### 4.2 动态路由注册流程

```
用户访问 /system/role
       │
       ▼
 beforeEach 触发
       │
       ├── getAccessToken() → 有 Token
       │
       ├── authStore.fetchUserInfo() → 加载用户信息
       │
       ├── permissionStore.fetchPermissions() → 请求后端
       │   └── GET /api/permissions/menu-tree
       │   └── GET /api/permissions/role-permissions
       │
       ├── permissionStore.generateRoutes(asyncRoutes)
       │   └── filterAsyncRoutes(asyncRoutes, ['dashboard:view', 'system:role', ...])
       │       └── 遍历递归，过滤无权限路由
       │
       ├── accessedRoutes.forEach(route => router.addRoute(route))
       │   └── 动态注册到 Vue Router
       │
       └── next({ ...to, replace: true }) → 重新匹配路由
                   │
                   ▼
           匹配成功 → 渲染 LayoutDefault → 渲染 RoleManageView
```

### 4.3 登出时重置路由

```typescript
// src/stores/auth.ts 中 logoutAction 的整合

async function logoutAction(): Promise<void> {
  // ... 清理 Token 和状态

  // 重置路由（移除所有动态路由）
  const { resetRouter } = await import('@/router')
  resetRouter()

  // 重置权限状态
  const permStore = usePermissionStore()
  permStore.resetPermissions()

  // 清空标签页
  const appStore = useAppStore()
  appStore.visitedViews = []

  // 跳转登录页
  await router.replace('/auth/login')
}
```

## 五、布局组件系统

### 5.1 `LayoutDefault.vue` — 默认布局

```vue
<!-- src/components/layout/LayoutDefault.vue -->

<template>
  <div class="layout-default" :class="{ collapsed: sidebarCollapsed, dark: isDark }">
    <!-- 侧边栏 -->
    <aside class="layout-sidebar">
      <div class="sidebar-logo">
        <img src="@/assets/images/logo.svg" alt="logo" />
        <span v-show="!sidebarCollapsed" class="logo-text">Admin Pro</span>
      </div>
      <LayoutSidebar
        :menus="menuTree"
        :collapsed="sidebarCollapsed"
        :active-key="activeMenu"
        @select="handleMenuSelect"
      />
    </aside>

    <!-- 主内容区 -->
    <div class="layout-main">
      <!-- 顶部导航 -->
      <LayoutHeader
        :user-info="userInfo"
        :avatar="avatar"
        :display-name="displayName"
        :sidebar-collapsed="sidebarCollapsed"
        :visited-views="visitedViews"
        @toggle-sidebar="toggleSidebar"
        @close-view="removeVisitedView"
        @logout="handleLogout"
      />

      <!-- 面包屑 -->
      <LayoutBreadcrumb :items="breadcrumbs" />

      <!-- 标签页 -->
      <LayoutTabs
        :views="visitedViews"
        :active-path="$route.path"
        @switch="handleTabSwitch"
        @close="removeVisitedView"
        @close-others="closeOtherViews"
        @close-all="closeAllViews"
      />

      <!-- 页面内容 -->
      <main class="layout-content" v-loading="globalLoading">
        <router-view v-slot="{ Component, route }">
          <transition name="fade-transform" mode="out-in">
            <keep-alive :include="cachedViews">
              <component :is="Component" :key="route.path" />
            </keep-alive>
          </transition>
        </router-view>
      </main>
    </div>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { useAuthStore } from '@/stores/auth'
import { useAppStore } from '@/stores/app'
import { usePermissionStore } from '@/stores/permission'
import LayoutSidebar from './LayoutSidebar.vue'
import LayoutHeader from './LayoutHeader.vue'
import LayoutBreadcrumb from './LayoutBreadcrumb.vue'
import LayoutTabs from './LayoutTabs.vue'

const route = useRoute()
const router = useRouter()

const authStore = useAuthStore()
const appStore = useAppStore()
const permStore = usePermissionStore()

// 状态映射
const sidebarCollapsed = computed(() => appStore.sidebarCollapsed)
const isDark = computed(() => appStore.isDark)
const userInfo = computed(() => authStore.userInfo)
const avatar = computed(() => authStore.avatar)
const displayName = computed(() => authStore.displayName)
const menuTree = computed(() => permStore.menuTree)
const breadcrumbs = computed(() => appStore.breadcrumbs)
const visitedViews = computed(() => appStore.visitedViews)
const globalLoading = computed(() => appStore.globalLoading)

// 当前激活菜单
const activeMenu = computed(() => route.path)

// 缓存的页面（keep-alive include）
const cachedViews = computed(() =>
  visitedViews.value
    .filter((v) => {
      const matchedRoute = router.resolve(v.path)
      return matchedRoute.meta?.keepAlive
    })
    .map((v) => v.name)
)

// 菜单选择
function handleMenuSelect(path: string): void {
  router.push(path)
}

// 切换侧边栏
function toggleSidebar(): void {
  appStore.toggleSidebar()
}

// 登出
async function handleLogout(): Promise<void> {
  await authStore.logoutAction()
}

// 标签页切换
function handleTabSwitch(path: string): void {
  router.push(path)
}

// 关闭其他标签页
function closeOtherViews(path: string): void {
  appStore.visitedViews = appStore.visitedViews.filter(
    (v) => v.path === path || v.path === '/dashboard'
  )
}

// 关闭所有标签页
function closeAllViews(): void {
  appStore.visitedViews = appStore.visitedViews.filter((v) => v.path === '/dashboard')
  router.push('/dashboard')
```

## 六、权限指令与按钮控制

### 6.1 `v-permission` 指令

```typescript
// src/directives/permission.ts

import type { Directive, DirectiveBinding } from 'vue'
import { usePermissionStore } from '@/stores/permission'

type PermissionValue = string | string[]

/**
 * v-permission 权限指令
 *
 * 用法：
 *   <!-- 单一权限 -->
 *   <button v-permission="'user:create'">创建用户</button>
 *
 *   <!-- 任意一个权限（或关系） -->
 *   <button v-permission="['user:create', 'user:import']">创建或导入</button>
 *
 *   <!-- 需配合 v-permission.all 使用所有权限（与关系）-->
 *   <button v-permission.all="['user:create', 'user:delete']">创建且删除</button>
 */

function checkPermission(el: HTMLElement, binding: DirectiveBinding<PermissionValue>): void {
  const permStore = usePermissionStore()
  const { value, modifiers } = binding

  let hasAuth = false

  if (Array.isArray(value)) {
    if (modifiers.all) {
      hasAuth = permStore.hasAllPermissions(value)
    } else {
      hasAuth = permStore.hasAnyPermission(value)
    }
  } else {
    hasAuth = permStore.hasPermission(value)
  }

  if (!hasAuth) {
    // 无权限时移除元素
    el.parentNode?.removeChild(el)
  }
}

export const permission: Directive = {
  mounted: checkPermission,
}

export const permissionAll: Directive = {
  mounted: checkPermission,
}
```

### 8.2 前后端映射关系

| 数据库表 | 后端实体 | 前端对应 | 说明 |
|----------|----------|----------|------|
| `users` | `UserEntity` | `authStore.userInfo` | 当前登录用户 |
| `roles` | `RoleEntity` | `authStore.userInfo.roles` | 用户角色列表 |
| `permissions` | `PermissionEntity` | `permissionStore.permissionTree` | 权限树（菜单 + 按钮） |
| `permissions`（type=menu） | `MenuEntity` | `permissionStore.menuTree` | 侧边栏菜单 |
| `permissions`（type=button） | `ButtonPermEntity` | `permissionStore.permissionCodes` | 按钮权限编码（扁平化） |

### 8.3 权限同步策略

```
登录流程：
  1. 用户登录 → 后端返回 Token + userInfo（含 roleIds）
  2. 路由守卫调用 authStore.fetchUserInfo() → GET /api/auth/me
  3. 路由守卫调用 permissionStore.fetchPermissions() → 并行请求：
     - GET /api/menus/tree → 生成 menuTree（用于侧边栏）
     - GET /api/permissions/tree → 生成 permissionTree（用于角色配置）
     - GET /api/permissions/codes → 生成 permissionCodes（扁平化，用于按钮控制）
  4. permissionStore.generateRoutes(asyncRoutes) → 过滤出有权限的路由
  5. router.addRoute() → 动态注册路由
  6. next({ ...to, replace: true }) → 重新匹配

登出流程：
  1. 调用 POST /api/auth/logout（可选）
  2. clearTokens() → 清除 localStorage
  3. authStore.$reset() → 清空用户状态
  4. permissionStore.resetPermissions() → 清空权限
  5. resetRouter() → 移除动态路由
  6. appStore.visitedViews = [] → 清空标签页
  7. router.replace('/auth/login') → 跳转登录页
```

| 404 | 访问不存在的路由 | 显示 404 页面 |
| 403 | 访问无权限路由 | 显示 403 页面 |

### 9.6 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 登录后白屏/跳转失败 | 动态路由未正确生成或 addRoute 后未重新导航 | 检查 `next({ ...to, replace: true })` 是否在 `addRoute` 之后调用 |
| 刷新页面后 404 | 动态路由在刷新时未重新生成 | 确认路由守卫中 `isRoutesGenerated` 判断正确，刷新后重新获取权限并生成路由 |
| 侧边栏菜单为空 | `permissionStore.menuTree` 未加载 | 确认登录成功后调用了 `fetchPermissions()`，且后端返回了菜单数据 |
| 按钮权限不生效 | v-permission 指令使用时 Pinia 未初始化 | 确保指令在 `setupDirectives(app)` 中注册，且组件在 Pinia 初始化后渲染 |
| 标签页关闭后白屏 | 关闭的是当前激活标签页，且没有其他标签页 | 关闭当前标签时自动跳转到最近的一个标签页，或默认跳转到 `/dashboard` |
| keep-alive 缓存失效 | 组件 name 与路由 name 不一致 | 确保 Vue 组件的 `name` 属性与路由定义的 `name` 完全一致 |
| 面包屑显示不正确 | 路由 meta.title 未设置或 matched 顺序不对 | 检查路由定义中的 `meta.title`，确认嵌套路由的层级关系正确 |
| NProgress 不显示 | nprogress 样式未导入 | 确认在 `guards.ts` 中 `import 'nprogress/nprogress.css'` |
| 深色模式切换不生效 | CSS 变量未定义或 class 未添加到 html | 检查 `LayoutDefault.vue` 中 `:class="{ dark: isDark }"` 是否正确绑定 |

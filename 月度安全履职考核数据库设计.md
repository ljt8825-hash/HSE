# 月度安全履职考核数据库设计

> **文档性质**：数据库结构冻结文档
> **版本**：v3.0（整合Sprint10-D-1-6/7/8的完整最终版）
> **冻结日期**：2026-07-23
> **关联任务**：Sprint10-D-1-9
> **数据库类型**：PostgreSQL 15

---

## 一、设计总则

### 1.1 设计原则

| 原则 | 说明 |
| :--- | :--- |
| **不修改现有业务表** | 考核模块只读查询employee、violation_records、training_records等业务表 |
| **独立存储** | 考核数据为独立计算结果，与业务数据物理隔离 |
| **版本不可覆盖** | 扣分调整以版本追加方式保存，禁止覆盖历史数据 |
| **审计完整** | 所有修改行为记录审计日志 |
| **责任传导1级** | 三违仅传导直属上级1级，禁止多级追溯 |

### 1.2 表结构总览（8张核心表）

| 序号 | 表名 | 用途 | 预估数据量 |
| :--- | :--- | :--- | :--- |
| 1 | `hse_assessment_cycle` | 考核周期表 | 每年12条 |
| 2 | `hse_assessment_target` | 考核对象表 | 每年500-600条 |
| 3 | `hse_assessment_metric` | 考核指标表 | 约30条（固定） |
| 4 | `hse_assessment_score` | 评分记录表 | 每年5000+条 |
| 5 | `hse_assessment_deduction` | 扣分明细表 | 每年10000+条 |
| 6 | `hse_deduction_adjustment` | 扣分调整记录表 | 每年3000+条 |
| 7 | `hse_responsibility_chain` | 责任传导关系表 | 约100条（相对固定） |
| 8 | `hse_assessment_audit_log` | 考核审计日志表 | 每年50000+条 |

### 1.3 表关联关系

```
hse_assessment_cycle (1) ──► (N) hse_assessment_target
                                       │
                                       │ (1) ──► (N)
                                       ▼
                                hse_assessment_score
                                       │
                                       │ (1) ──► (N)
                                       ▼
                                hse_assessment_deduction
                                       │
                                       │ (1) ──► (N)
                                       ▼
                                hse_deduction_adjustment

hse_assessment_metric ──► hse_assessment_score (指标关联)

hse_responsibility_chain (独立，支持责任传导计算)

hse_assessment_audit_log (独立，记录所有操作)
```

## 二、表结构详细设计

### 2.1 考核周期表 (`hse_assessment_cycle`)

**用途**：存储月度考核周期信息，是每次考核的起点。

```sql
CREATE TABLE IF NOT EXISTS hse_assessment_cycle (
    id              BIGSERIAL     PRIMARY KEY,
    cycle_code      VARCHAR(50)   NOT NULL UNIQUE,              -- 周期编码：HSE-CYCLE-{YYYYMM}
    cycle_name      VARCHAR(100)  NOT NULL,                     -- 周期名称：如"2026年5月月度考核"
    cycle_type      VARCHAR(20)   NOT NULL DEFAULT 'monthly',  -- 周期类型：monthly
    assessment_year INT           NOT NULL,                     -- 考核年份
    assessment_month INT          NOT NULL,                     -- 考核月份(1-12)
    start_time      TIMESTAMPTZ   NOT NULL,                     -- 周期开始时间
    end_time        TIMESTAMPTZ   NOT NULL,                     -- 周期结束时间
    status          VARCHAR(20)   NOT NULL DEFAULT 'not_started', -- 状态
    target_count    INT           DEFAULT 0,                    -- 考核对象总数
    scored_count    INT           DEFAULT 0,                    -- 已评分数量
    reviewed_count  INT           DEFAULT 0,                    -- 已审核数量
    frozen_count    INT           DEFAULT 0,                    -- 已冻结数量
    created_by      BIGINT,                                     -- 创建人ID
    created_by_name VARCHAR(50),                                -- 创建人姓名
    frozen_by       BIGINT,                                     -- 冻结人ID
    frozen_by_name  VARCHAR(50),                                -- 冻结人姓名
    frozen_at       TIMESTAMPTZ,                                -- 冻结时间
    remark          TEXT,                                       -- 备注
    is_deleted      BOOLEAN      DEFAULT FALSE,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_cycle_code ON hse_assessment_cycle (cycle_code);
CREATE INDEX IF NOT EXISTS idx_cycle_status ON hse_assessment_cycle (status);
CREATE INDEX IF NOT EXISTS idx_cycle_year_month ON hse_assessment_cycle (assessment_year, assessment_month);
CREATE UNIQUE INDEX IF NOT EXISTS idx_cycle_code_active ON hse_assessment_cycle (cycle_code) WHERE is_deleted = FALSE;
```

**状态说明**：

| 状态值 | 中文名 | 说明 |
| :--- | :--- | :--- |
| `not_started` | 未开始 | 周期已创建但未启动评分 |
| `in_progress` | 进行中 | 系统自动评分进行中 |
| `pending_review` | 待审核 | 评分完成，等待人工审核 |
| `reviewed` | 已审核 | 所有扣分项审核完成 |
| `frozen` | 已冻结 | 结果冻结，不可修改 |

### 2.2 考核对象表 (`hse_assessment_target`)

**用途**：存储每个考核周期中的考核对象（仅经理和管理员）。

```sql
CREATE TABLE IF NOT EXISTS hse_assessment_target (
    id              BIGSERIAL     PRIMARY KEY,
    cycle_id        BIGINT        NOT NULL,                     -- 关联考核周期表ID
    employee_id     BIGINT        NOT NULL,                     -- 员工ID（关联employee表）
    employee_code   VARCHAR(50),                                -- 员工工号
    employee_name   VARCHAR(50)   NOT NULL,                     -- 员工姓名（冗余）
    position        VARCHAR(50)   NOT NULL,                     -- 岗位：经理/管理员
    township        VARCHAR(50),                                -- 乡镇
    department      VARCHAR(50),                                -- 管辖区域/班组
    status          VARCHAR(20)   NOT NULL DEFAULT 'pending',  -- 考核状态
    score_auto      NUMERIC(6,2),                               -- 自动计算得分
    score_manual    NUMERIC(6,2),                               -- 人工补充得分
    score_bonus     NUMERIC(6,2),                               -- 加分项得分
    score_total     NUMERIC(6,2),                               -- 最终总得分
    grade           VARCHAR(5),                                 -- 等级：S/A/B/C/D
    rank_township   INT,                                        -- 乡镇内排名
    rank_all        INT,                                        -- 全单位排名
    is_rejected     BOOLEAN      DEFAULT FALSE,               -- 是否触发否决项
    reject_type     VARCHAR(50),                                -- 否决类型
    reject_reason   TEXT,                                       -- 否决原因
    review_status   VARCHAR(20)   DEFAULT 'pending',          -- 审核状态
    review_progress INT           DEFAULT 0,                   -- 审核进度(%)
    score_version   INT           DEFAULT 1,                   -- 得分版本号
    appeal_status   VARCHAR(20)   DEFAULT 'none',             -- 申诉状态
    reviewed_by     BIGINT,                                     -- 审核人ID
    reviewed_at     TIMESTAMPTZ,                                -- 审核时间
    submitted_at    TIMESTAMPTZ,                                -- 提交时间
    is_deleted      BOOLEAN      DEFAULT FALSE,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_target_cycle ON hse_assessment_target (cycle_id);
CREATE INDEX IF NOT EXISTS idx_target_employee ON hse_assessment_target (employee_id);
CREATE INDEX IF NOT EXISTS idx_target_status ON hse_assessment_target (status);
CREATE INDEX IF NOT EXISTS idx_target_township ON hse_assessment_target (township);
CREATE INDEX IF NOT EXISTS idx_target_position ON hse_assessment_target (position);
CREATE INDEX IF NOT EXISTS idx_target_score ON hse_assessment_target (score_total DESC);
```

**字段说明**：

| 字段 | 说明 |
| :--- | :--- |
| position | 必须为"经理"或"管理员"，系统岗位名称统一使用"管理员"，禁止修改为"安全管理员" |
| status | pending(待评分)/scored(已评分)/submitted(已提交)/reviewing(审核中)/confirmed(已确认)/rejected(已驳回)/frozen(已冻结) |
| review_status | pending(待审核)/confirmed(已确认)/adjusted(已调整)/rejected(已驳回)/frozen(已冻结) |
| appeal_status | none(无申诉)/pending(申诉中)/accepted(申诉成立)/rejected(申诉不成立) |

### 2.3 考核指标表 (`hse_assessment_metric`)

**用途**：存储考核指标配置（基础数据，参数化管理）。

```sql
CREATE TABLE IF NOT EXISTS hse_assessment_metric (
    id              BIGSERIAL     PRIMARY KEY,
    metric_code     VARCHAR(50)   NOT NULL UNIQUE,              -- 指标编码：HSE-KPI-{分类}-{序号}
    metric_name     VARCHAR(100)  NOT NULL,                     -- 指标名称
    category        VARCHAR(30)   NOT NULL,                     -- 分类：SAFETY/RISK/HAZARD/TRAINING/RESPONSIBILITY/INNOVATION
    target_post     VARCHAR(50)   NOT NULL DEFAULT 'all',      -- 考核对象：manager/manager_and_admin/all
    base_score      NUMERIC(5,2)  NOT NULL,                     -- 基准分值
    metric_type     VARCHAR(20)   NOT NULL,                     -- 类型：positive(正向)/negative(负向)/pass_fail(达标)/veto(否决)
    data_source     VARCHAR(100),                               -- 数据来源表
    calc_formula    TEXT,                                       -- 计算公式描述
    rule_config     JSONB,                                      -- 评分规则配置(JSON)
    weight_manager  NUMERIC(5,2),                               -- 经理权重(%)
    weight_admin    NUMERIC(5,2),                               -- 管理员权重(%)
    sort_order      INT           DEFAULT 0,                   -- 排序
    status          VARCHAR(20)   NOT NULL DEFAULT 'active',  -- 状态：active/inactive
    remark          TEXT,
    is_deleted      BOOLEAN      DEFAULT FALSE,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE UNIQUE INDEX IF NOT EXISTS idx_metric_code ON hse_assessment_metric (metric_code) WHERE is_deleted = FALSE;
CREATE INDEX IF NOT EXISTS idx_metric_category ON hse_assessment_metric (category);
CREATE INDEX IF NOT EXISTS idx_metric_status ON hse_assessment_metric (status);
```

**rule_config JSON结构示例**：

```json
{
  "deduction_rules": [
    {"condition": "violation_level = '轻微'", "deduction": 5, "transmission": 1},
    {"condition": "violation_level = '一般'", "deduction": 10, "transmission": 2},
    {"condition": "violation_level = '严重'", "deduction": 20, "transmission": 5}
  ],
  "max_deduction": 40,
  "calc_formula": "score = max(0, base_score - personal_deduction - transmission_deduction)"
}
```

### 2.4 评分记录表 (`hse_assessment_score`)

**用途**：存储每个考核对象在每个指标上的自动计算结果。

```sql
CREATE TABLE IF NOT EXISTS hse_assessment_score (
    id              BIGSERIAL     PRIMARY KEY,
    target_id       BIGINT        NOT NULL,                     -- 关联考核对象表ID
    cycle_id        BIGINT        NOT NULL,                     -- 关联考核周期表ID
    metric_id       BIGINT        NOT NULL,                     -- 关联考核指标表ID
    metric_code     VARCHAR(50)   NOT NULL,                     -- 指标编码（冗余）
    raw_value       NUMERIC(10,2),                               -- 原始数据值（如三违2次）
    raw_value_desc  VARCHAR(200),                                -- 原始值描述
    deduction_total NUMERIC(6,2)   DEFAULT 0,                   -- 总扣分值
    original_score  NUMERIC(6,2),                               -- 系统原始计算得分
    final_score     NUMERIC(6,2),                               -- 审核后最终得分
    is_auto         BOOLEAN      DEFAULT TRUE,                 -- 是否自动计算
    is_manual       BOOLEAN      DEFAULT FALSE,                -- 是否需人工评分
    manual_input    NUMERIC(6,2),                               -- 人工输入值
    data_sources    JSONB,                                      -- 数据来源详情
    review_status   VARCHAR(20)   DEFAULT 'pending',           -- 审核状态
    calc_time       TIMESTAMPTZ,                                -- 计算时间
    calc_duration   INT,                                        -- 计算耗时(毫秒)
    remark          TEXT,
    is_deleted      BOOLEAN      DEFAULT FALSE,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_score_target ON hse_assessment_score (target_id);
CREATE INDEX IF NOT EXISTS idx_score_cycle ON hse_assessment_score (cycle_id);
CREATE INDEX IF NOT EXISTS idx_score_metric ON hse_assessment_score (metric_id);
CREATE INDEX IF NOT EXISTS idx_score_status ON hse_assessment_score (review_status);
```

### 2.6 扣分调整记录表 (`hse_deduction_adjustment`)

**用途**：记录扣分项的每次调整历史，禁止覆盖，支持完整追溯。

```sql
CREATE TABLE IF NOT EXISTS hse_deduction_adjustment (
    id              BIGSERIAL     PRIMARY KEY,
    deduction_id    BIGINT        NOT NULL,                     -- 关联扣分明细表ID
    target_id       BIGINT        NOT NULL,                     -- 关联考核对象表ID
    version_no      INT           NOT NULL,                     -- 版本号（递增）
    old_score       NUMERIC(6,2),                               -- 原扣分值
    new_score       NUMERIC(6,2)  NOT NULL,                     -- 调整后扣分值
    operation_type  VARCHAR(30)   NOT NULL,                     -- 操作类型：CREATE/ADJUST/REJECT/APPEAL_ADJUST/ROLLBACK
    adjustment_reason TEXT        NOT NULL,                     -- 调整原因（必填）
    adjusted_by     BIGINT        NOT NULL,                     -- 调整人ID
    adjusted_by_name VARCHAR(50)  NOT NULL,                     -- 调整人姓名
    adjusted_at     TIMESTAMPTZ   NOT NULL DEFAULT NOW(),       -- 调整时间
    reviewed_by     BIGINT,                                     -- 审核人ID
    reviewed_by_name VARCHAR(50),                               -- 审核人姓名
    reviewed_at     TIMESTAMPTZ,                                -- 审核时间
    related_event_id BIGINT,                                    -- 关联事件ID（如申诉单ID）
    related_event_type VARCHAR(30),                             -- 关联事件类型
    is_current      BOOLEAN      DEFAULT FALSE,                -- 是否为当前版本
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_adjustment_deduction ON hse_deduction_adjustment (deduction_id);
CREATE INDEX IF NOT EXISTS idx_adjustment_target ON hse_deduction_adjustment (target_id);
CREATE INDEX IF NOT EXISTS idx_adjustment_version ON hse_deduction_adjustment (deduction_id, version_no);
CREATE INDEX IF NOT EXISTS idx_adjustment_current ON hse_deduction_adjustment (deduction_id) WHERE is_current = TRUE;

-- 唯一约束：同一扣分项的版本号不可重复
CREATE UNIQUE INDEX IF NOT EXISTS idx_adjustment_version_unique ON hse_deduction_adjustment (deduction_id, version_no);
```

**禁止覆盖保护（触发器）**：

```sql
-- 禁止UPDATE和DELETE，仅允许INSERT
CREATE OR REPLACE FUNCTION prevent_adjustment_modify()
RETURNS TRIGGER AS $$
BEGIN
    RAISE EXCEPTION '扣分调整记录表仅允许INSERT，禁止UPDATE和DELETE';
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_prevent_adjustment_update
    BEFORE UPDATE OR DELETE ON hse_deduction_adjustment
    FOR EACH ROW
    EXECUTE FUNCTION prevent_adjustment_modify();
```

### 2.7 责任传导关系表 (`hse_responsibility_chain`)

**用途**：定义员工之间的直属上下级关系，支持三违责任传导1级计算。

```sql
CREATE TABLE IF NOT EXISTS hse_responsibility_chain (
    id              BIGSERIAL     PRIMARY KEY,
    subordinate_id  BIGINT        NOT NULL,                     -- 下属员工ID
    subordinate_name VARCHAR(50)  NOT NULL,                     -- 下属姓名
    subordinate_post VARCHAR(50),                               -- 下属岗位
    manager_id      BIGINT        NOT NULL,                     -- 直属上级ID
    manager_name    VARCHAR(50)   NOT NULL,                     -- 直属上级姓名
    manager_post    VARCHAR(50),                                -- 直属上级岗位
    township        VARCHAR(50),                                -- 所属乡镇
    relation_type   VARCHAR(20)   NOT NULL DEFAULT 'direct_line', -- 关系类型：direct_line(直属)/functional(职能)
    chain_level     INT           DEFAULT 1,                    -- 传导层级（固定1，仅1级传导）
    effective_date  DATE          NOT NULL,                     -- 生效日期
    expire_date     DATE,                                        -- 失效日期（NULL表示当前有效）
    is_active       BOOLEAN      DEFAULT TRUE,                 -- 是否有效
    is_deleted      BOOLEAN      DEFAULT FALSE,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_chain_subordinate ON hse_responsibility_chain (subordinate_id);
CREATE INDEX IF NOT EXISTS idx_chain_manager ON hse_responsibility_chain (manager_id);
CREATE INDEX IF NOT EXISTS idx_chain_active ON hse_responsibility_chain (is_active) WHERE is_deleted = FALSE;
CREATE INDEX IF NOT EXISTS idx_chain_township ON hse_responsibility_chain (township);

-- 唯一约束：同一下属在有效期内仅有一个直属上级
CREATE UNIQUE INDEX IF NOT EXISTS idx_chain_unique 
    ON hse_responsibility_chain (subordinate_id) 
    WHERE is_active = TRUE AND is_deleted = FALSE;
```

**责任传导计算查询**：

```sql
-- 查询三违人员的直属上级（仅1级）
SELECT 
    v.id AS violation_id,
    v.violator_id,
    v.violation_level,
    v.violation_date,
    rc.manager_id AS direct_manager_id,
    rc.manager_name,
    rc.manager_post
FROM violation_records v
JOIN hse_responsibility_chain rc 
    ON v.violator_id = rc.subordinate_id 
    AND rc.relation_type = 'direct_line'
    AND rc.is_active = TRUE
    AND rc.is_deleted = FALSE
WHERE v.violation_date BETWEEN '{month_start}' AND '{month_end}'
    AND v.is_deleted = FALSE;
```

## 四、数据安全

### 4.1 数据保护策略

| 保护项 | 措施 |
| :--- | :--- |
| **扣分调整记录** | 触发器禁止UPDATE和DELETE |
| **审计日志** | 触发器禁止UPDATE和DELETE |
| **冻结数据** | 应用层 + 数据库触发器双重保护 |
| **软删除** | 所有业务表使用is_deleted字段，不物理删除 |

### 4.2 冻结数据保护触发器

```sql
CREATE OR REPLACE FUNCTION prevent_frozen_target_modify()
RETURNS TRIGGER AS $$
BEGIN
    IF OLD.status = 'frozen' THEN
        RAISE EXCEPTION '已冻结的考核对象记录不可修改';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_prevent_frozen_target
    BEFORE UPDATE ON hse_assessment_target
    FOR EACH ROW
    EXECUTE FUNCTION prevent_frozen_target_modify();
```

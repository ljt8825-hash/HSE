# A02-01-04｜核心数据对象权威矩阵

> 目标：回答「**谁是数据事实源 / 谁只是引用**」，并识别重复主数据。
> 方法：`information_schema` 外键实测（入向/出向）+ 精确 `COUNT(*)` + 源代码读写点检索。
> **「权威」= 该事实的唯一写入归属，不是业务责任归属。** 本轮只读。

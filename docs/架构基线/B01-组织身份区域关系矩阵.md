## 2. 跨域纠缠矩阵（谁借用了谁）

| 借用方向 | 证据 | 定性 |
|---|---|---|
| 组织 ← 区域 | hse_org_unit 内嵌 12 个 town_center（乡镇作业中心） | 组织兼区域（结构性混用） |
| 区域 ← 组织 | hse_assessment_target.township 全填「XX作业中心/部门名」 | 组织名冒充区域值 |
| 区域 ← 组织 | violations.township 混入 公司管理/安环管理部/生产管理部（26 行） | 同上 |
| 区域 ← 人员 | grid_areas（63 行）= 网格长人员表，area 列承担区域 | 区域寄生在人员表 |
| 身份 ← 飞书 | 飞书身份表/花名册与 employee 重叠 84.9%/94.3% | 飞书人员 ≈ employee 子集（高重叠） |
| 身份 → 文本 | 175 表 268 个 `*_name` 列 | 姓名文本快照泛滥 |
| 组织 → 文本 | 40+ 表存在 `department`/`dept_name` 文本列与 id 列并存 | 组织快照第三形态 |

## 3. 三系统区域语义对比

| 系统 | 表达方式 | 规范名 | 与其他系统可比对性 |
|---|---|---|---|
| PG 业务表 | township 自由文本（25 表） | ❌（无词典 FK） | 仅人工文本匹配 |
| WPS 网格线 | grid_id → grid_areas.area | ❌（含简称） | 需简称↔全称映射 |
| Feishu H5 | 「网格等级」+「片区\|班组」；隐患「隐患位置」 | ❌ | 无乡镇字段，无法直接比对 |

⇒ 三系统**没有可机器比对的共同区域键**；若未来 Feishu→PG 同步落地，区域映射只能靠词典归一（REGION-MASTER）或人工对照。

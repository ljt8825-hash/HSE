4. 「可见」= `meta.hideInMenu !== true`。**V=69 / H=32**（自身隐藏）。
   若计入「父级隐藏导致不可达」的 7 页（`/analytics`、`/workspace`、`/demos/*` 3 页、`/hse-advanced/iot`、`/hse-advanced/supply-chain`），
   则不可达合计 **39 个（39/101 = 38.6%）**，与 A01 §47.3 数字精确对上。

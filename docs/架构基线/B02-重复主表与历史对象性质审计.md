## 0. 为什么必须细分「重复性质」

A02-05 用单一 `DUP` 标签标记了 8 组对象。但 `DUP` 掩盖了四种完全不同的处置：

- **两张表存同一个事实**（如人员保险 99.96% 重叠）→ 可收敛为 1 份；
- **两代表**（如三违 6-7 月批次 vs 8 月起）→ **不可合并**，合并会丢事实或造歧义；
- **不同粒度**（计划/台账/明细）→ **必须保留多份**；
- **不同层级**（公司/部门/作业中心 vs 乡镇/班组）→ **必须保留多份**。

因此 B02 采用七分类：

| 码 | 含义 | 判据 |
|---|---|---|
| **D1** | 真正重复事实 | 同一实体、同一时间、同一粒度，键可对齐且内容高度重叠 |
| **D2** | 不同业务阶段 / 不同粒度 | 同一业务概念的不同环节或不同粒度，**合并即失真** |
| **D3** | 快照 | 某一时点的完整复制（备份、版本、月度快照） |
| **D4** | 派生结果 | 可由上游事实复算；不含独立事实 |
| **D5** | 历史遗留 | 有数据但**无写入代码**；或旧代模型被新代取代 |
| **D6** | 测试 / 空壳 | 0 行、夹具、无前端调用、目标表不存在 |
| **D7** | 外部系统镜像 | 由外部系统导入的**只读副本**（Excel 残留表、WPS 映射） |

## 0. 判定原则

跨系统对象的**关键不是"有没有数据"，而是"谁产生、谁镜像、谁只读"**。B02 用四问定性：

| 定性 | 判据 |
|---|---|
| **事实源** | 该系统的数据是**唯一原始产生地**，其他系统无独立产生能力 |
| **输入源** | 数据由人工/外部产生后**一次性导入**，导入后不再回流 |
| **同步源** | 有**程序化的周期性双向/单向同步**在跑 |
| **展示源** | 只读呈现，不产生也不接收写入 |

### 2.1 「零重叠」的证据链

- B00 已证实：Feishu 2 条与 PG 110 条 **无任何重叠**（时间、描述、位置三重比对）。
- 本轮补充的**结构性证据**：`hazards` **无"隐患编号"列**（只有整型 `no`，110 行仅 66 个唯一值），Feishu 侧主键为 record_id ⇒ **两侧不存在可比对的业务主键**，因此「同步合并」在物理上不可行（不仅是没做，而是**没有键可用**）。
- **B02 结论**：**两者不得直接合并**；`hazards` = HISTORICAL-ASSET（历史资产），Feishu = LIVE-SOURCE（当前事实源）。**权威归属是二选一 + 分层，不是二选一**。

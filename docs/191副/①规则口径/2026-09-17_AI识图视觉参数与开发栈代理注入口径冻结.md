## 一、visionService 视觉参数

- 模型：`OLLAMA_VL_MODEL`（默认 `qwen2.5vl:7b`）
- 超时优先级：`OLLAMA_VL_TIMEOUT_MS` > `AI_TIMEOUT_MS` > 默认 **300s**
  - 背景：5.6GB VL 模型 CPU 冷加载可超 180s；模型驻留后推理约 33s/页
- `num_ctx`：默认 **8192**（可 `OLLAMA_VL_NUM_CTX` 覆盖）
  - A4@2x 渲染视觉 token 约 2.5k；qwen2.5vl 默认 4096 会 `exceed_context_size_error`
- PDF 渲染缩放固定 **2x**（3x 超 4096 上下文，禁用）

## 二、开发栈 vite 代理（web-naive）

- `vite.config.ts` `/api` 默认 target=**5882（无服务）**；`/uploads` 默认 **5876（生产）**
- **手动起 vite 必须注入**：`VITE_PROXY_TARGET=http://127.0.0.1:5888` 与 `VITE_UPLOADS_PROXY_TARGET=http://127.0.0.1:5888`（与 start-hse-ai.ps1 一致）
- 未注入后果：页面 API 全部 `ERR_CONNECTION_ABORTED`；上传路径可能误触生产 5876

## 三、AI 识图接口契约

- `POST /api/training-ocr/ai-recognize`（requireRole admin/safety_manager，multer 字段名 `file`）
- 支持：图片（png/jpg/jpeg/bmp/webp）与 PDF（最多 8 页，超出跳过并提示）
- PDF 解释器候选顺序：`PDF_RENDER_PYTHON` → PATH `python` → `.env PYTHON_PATH`（仅兜底，`.workbuddy` python 缺 fitz）
- 返回：`{ sourceType:'ai_image', mode:'record', columns[], rows[], meta:{model,channel} }`

## 四、PowerShell 进程边界

- 每条 Shell 命令独立进程，`$env:PORT` 等**不跨命令持久**；启动必须「同一命令内先 set env 再 node」
- 拆分两步会导致后端按默认端口（5666）启动且无 AI env（实测踩坑）

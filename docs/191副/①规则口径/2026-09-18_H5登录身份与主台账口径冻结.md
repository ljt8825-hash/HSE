### 四.1 H5 链路 → 主台账列（映射已定）

- 提交人姓名 → `检查人姓名`；网格/片区/乡镇 → `片区|班组`；网格长等级 → `网格等级`；三违照片 → `违章照片`；整改后照片 → `整改后照片`；三违行为 → `违章行为`；涉及人员/违章人 → `违章人员姓名`/`性别`/`年龄`；处理措施/罚款 → `项目采取措施`/`惩罚数额`；提交时间 → `日期`(自动)；未三违时 `违章行为`=「无三违行为」。
- `问题描述` → `描述`（补充进 `备注`）。
- `问题类型` → 三违类进 `违章行为`；非三违(一般问题/环境卫生/现场正常) 进 `描述`（主台账无独立问题类型列）。
- `是否三违` → 用 `违章行为` 有无表达（是→填具体行为；否→填「无三违行为」；无布尔列）。
- 巡查人员标识(`巡查人员ID`=手机号) → 姓名入 `检查人姓名`；手机号如需留存入 `备注`（主台账无 ID 列）。
- 主台账无 `三违行为`/`姓名`/`所属岗位`/`编号`/`标记`/`当日是否报名`/`是否补交` 等列（那些是「表格视图」`tbl5hz1RyHlO3C3l` 格式）；映射一律以主台账实测列名为准。

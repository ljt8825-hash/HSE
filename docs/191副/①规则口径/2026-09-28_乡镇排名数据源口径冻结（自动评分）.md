# 乡镇排名数据源口径冻结（自动评分）

> 冻结日期：2026-09-28
> 冻结范围：`/api/hse/assessment-analysis/township-ranking`（考核分析中心→乡镇排名）
> 冻结背景：乡镇排名原为六维度公式自算（风险15%+三违15%+驾驶15%+事故20%+隐患15%+管理20%），
> 与「目标职责→自动评分」官方考核体系（hse_assessment_target）口径分离。经确认改为直接拉取自动评分数据。

## 一、冻结口径（用户 2026-09-28 确认）

1. **数据源**：乡镇排名 = 「目标职责→自动评分」→「乡镇作业中心经理」tab 数据（表 `hse_assessment_target`，
   岗位 `position='乡镇作业中心经理'`）。
2. **得分与排名**：乡镇得分 = 自动评分 `score_total`（总分），按 `score_total` **降序**排名
   （`overallRank` 1..N，得分高者居前）。
3. **周期**：接口新增 `cycleId` **可选**查询参数；缺省取「有乡镇经理考核对象的最新周期」
   （按 `assessment_year DESC, assessment_month DESC`）。指定周期不存在 → 抛「考核周期不存在」。
4. **环卫作业中心**：为**部门**，归属部门排名，**不纳入乡镇排名**（乡镇排名仅 `hse_org_unit.org_type='town_center'`）。
5. **津城街道作业中心（无经理考核对象）**：因 `town_center` 组织存在但该周期无「乡镇作业中心经理」考核对象，
   取该乡镇**管理员**考核对象分数聚合作为评分（**不标注无数据**）：
   - `scoreSource='admin_aggregate'`，`scoreTotal = 管理员 score_total 平均值`（转 number，四舍五入 1 位小数），
   - 附 `adminCount`（有分管理员人数）、`adminAvgScore`、`adminMaxScore`（聚合明细，供前端 tooltip / 卡片展示）；
   - 参与整体 `score_total DESC` 排名（`hasData=true`，`overallRank` 参与编号）。
6. **彻底无考核对象的乡镇**：既无经理也无管理员 → 才单列标注**无数据**
   （`hasData=false`，`scoreTotal=null`，`overallRank=null`，列入 `noDataTownships`）。
7. **旧六维度明细整体替换**：overview 六维打分公式、事故/三违/扣分/风险/隐患/网格等明细字段不再返回。

## 二、数据对照（实测）

| 口径 | 清单（12） |
|---|---|
| hse_org_unit town_center | 保店/柴胡店/大曹/大柳/杜集/津城街道/刘营伍/宁城/时集/相衙/张大庄/长官 |
| 自动评分·乡镇经理（13人） | 上述 11 个镇 + 环卫作业中心（刘菲、韩晓亮） |

- 交集 11 个镇按 `township` 名称与 `org_name` 精确匹配；
- 环卫作业中心 2 名经理因无 town_center 组织被自然排除；
- 津城街道作业中心无经理考核对象 → 取**管理员**分数聚合作为评分（不标注无数据）。

## 三、实现要点

- `server/services/hseAssessmentAnalysisService.js` `townshipRanking(cycleId)`：
  - cycleId 校验/缺省查询 → 全员 `hse_assessment_target`（cycle_id + position='乡镇作业中心经理' + is_deleted=false）
  - 12 个 town_center 组织 LEFT JOIN 匹配；**无经理匹配时查 `position='管理员'`，聚合平均分作为评分**
    （无分管理员过滤后计算；另兼容既无经理也无管理员的乡镇标注无数据）
  - `score_total DESC` 排序（null 行排尾），`overallRank` 连续编号
  - `hse_assessment_cycle.id` 为 bigint（pg 返回字符串），统一 `Number()` 转换保证契约 `cycleId:number`
- `server/controllers/hseAssessmentAnalysisController.js`：`townshipRanking(req.query.cycleId)`
- 前端 web-naive / web-antd：`TownshipRankingItem` 新结构（targetId/townshipId/managerName/scoreAuto/scoreTotal/grade/status/reviewStatus/`scoreSource`/`adminCount`/`adminAvgScore`/`adminMaxScore`/overallRank/hasData），
  `getTownshipRanking(cycleId?)` 可选参数；页面移除六维度列，展示 排名/乡镇/经理/综合得分/等级/审核状态，
  管理员聚合乡镇显示「管理员（N人）」（tooltip 含平均/最高分），卡片视图补「管理员最高分」，彻底无数据行显示「无考核对象」。

## 规则 / 口径内容

1. **「司机身份不进考核」**：员工主数据 `employee` 中岗位为「司机」（`roster_position='司机'`，所属部门 `roster_department`，如「车队」）的人员，**不进入**「现场管理→三违管理→三违管理考核 / 三违分析」的考核对象范围。

2. 原因/机制：考核对象 `hse_assessment_target` 的填充规则（`server/routes/hse-assessment-monthly.js`）只拉以下岗位：
   - `position_name = '乡镇作业中心经理'`
   - `position_name = '管理员' AND org_type='town_center'`
   - （另有人工岗位：部门经理 / 项目总经理 / 环卫作业中心副经理）
   司机不在上述岗位集合内，因此不会被列入考核对象；其「三违」记录走**驾驶员档案线**（`driver_violation`/`driver_three_violation`），不参与经理/管理员月度考核自动扣分。

3. 同名多身份判定：若同一姓名同时以「司机」身份出现在档案线，又有考核线台账被标为经理/管理员级岗位，按**同一姓名+员工主数据岗位**判定——主数据岗位为司机即视为司机身份，考核线上的经理级岗位标注属「身份错配」，以司机身份为准处理。

## 适用范围

- 现场管理 → 三违管理 → 三违管理考核（`/site/violation/assessment`）
- 现场管理 → 三违管理 → 三违分析（`/site/violation/analysis`）
- 表格：`hse_assessment_target`、`violation_records`、`driver_violation`、`driver_three_violation`

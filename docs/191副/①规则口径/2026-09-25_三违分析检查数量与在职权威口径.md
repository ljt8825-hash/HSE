# 三违分析检查数量与在职权威口径（2026-09-25 冻结）

> 归属对话：三违分析检查数量口径 + 离职经理根治
> 类别：①规则口径

## 冻结口径

### 1. 三违分析「检查数量」= 该乡镇作业中心经理本人亲自检查的记录数（不含整个乡镇）
- 数据来源：`grid_inspection_records`，按 `to_char(inspection_date,'YYYY-MM')` 月份 + `personnel_name`（检查人）分组 COUNT。
- **归因键**：`personnel_name`（检查人姓名）**精确命中**该行经理姓名 → 计入该经理的检查数量。
- 网格长等其他检查人的记录不计入任何经理的「检查数量」。`inspector_employee_id` 基本未回填，无法用员工ID关联，只能用姓名匹配。
- 非乡镇分组（公司管理等）及无经理行检查数量为 0。
- 表缺失/异常时检查数量统一为 0 兜底。

### 2. 在职 / 离职权威口径 = 二级菜单「员工档案」（`employee` 表）
- 权威在职判定：`employee.employment_relation`，其中 `'辞职'` / `'死亡'` 即离职。
- 权威离职日期：`employee.leave_date`。
- 系统「在职」判定统一以此为准（此前 `v_employee_org_full` 仅看 `employee_assignment.status='active'`，漏离职过滤 — 已根治）。

### 3. 考核对象归属规则（考核月 vs 离职日期）
- 考核月份（周期月）在本人离职月份**之后** → 该人已离职，该岗位当期为**下一任**，不得再考核此人。
- 考核月份在本人离职月份**及以前** → 该人当时在岗，归本人。
- 各乡镇作业中心经理归属（用户冻结）：
  - 张大庄镇 = 靳洪刚
  - 相衙镇 = 李振恒（郑怀侦已辞职）
  - 大曹镇 = 孙建栋（宋长城、周福贵已辞职）
  - 津城街道 = 暂无乡镇作业中心经理（郑宝升已辞职，岗位空缺）

## 注意事项
- `hse_assessment_target` 历史周期快照（2025 年及以前）保留不清理，避免破坏历史评分核算；仅清理 2026 及以后活跃周期中的离职对象。
- 览全体「在职」的一次性根治点在 `v_employee_org_full` 视图，改该视图即全系统生效，勿再在个别模块重复过滤。

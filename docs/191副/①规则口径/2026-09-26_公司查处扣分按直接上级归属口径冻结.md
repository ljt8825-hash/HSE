## 规则 / 口径内容

**三违管理考核「公司查处扣分」列归属口径（2026-09-26 冻结，由原「按乡镇整镇累计」改为「按人归属」）：**

1. **管理员 tab（班长/片区长）**：每起公司查处违章，按被查处人的**直接上级**（`employee.direct_supervisor`，多为 人工班长/人工片区长，即管理员 tab 的目标人员）归属。每个目标只显示 **本人直接下属** 的公司查处违章扣分，不再整镇累计到该镇全部班长。
2. **乡镇作业中心经理 tab**：保持 **按全镇累计** 不变（经理综合管理全镇，扣分按 `regionBase(township)` 匹配该镇 `buildCompanyDeduct.map` 累计显示）。
3. **兜底**：若被查处人的直接上级不在当月管理员 tab 目标名单（如已离职 / 未命中花名册 / 该上级为片长但未入管理员名单），该起违章**不进任何管理员行**，仅保留在对应乡镇作业中心经理的全镇累计里（不丢分）。
4. 违章当次分值口径不变：违章行为含「头盔/安全帽」每起 **5 分**，其他三违每起 **1 分**。计分逻辑沿用 `buildCompanyDeduct`（与「三违分析」同源，含 NAME_ALIAS 笔误归并 + hse_violator_name_resolution 人工映射）。

## 适用范围

- 三违管理考核 `/api/hse/violation-assessment/list?cycleId=&position=`（管理员 tab 与 乡镇作业中心经理 tab 的 `companyDeduct` 列）
- 涉及文件：`server\services\companyViolationDeduct.js`（新增 `records[]` 暴露每起违章的 `town`+`supervisor`）、`server\routes\hse-violation-assessment.js`（`/list` 按 position 分流：管理员→`supervisorCompanyMap` 按直接上级；经理→`companyDeductMap` 按全镇）
- 前端 `views\hse\violation-assessment\index.vue` 仅 tooltip 文案调整，渲染逻辑不变。

## 触发背景

用户需求：「管理员tab里列表·公司查处扣分：扣的是公司查处的某人相对应的上级以及乡镇作业中心经理的分数」。原实现为整镇累计到该镇所有 管理员；用户经确认三项口径：①仅本人直接下属；②经理tab保持全镇累计；③上级不在名单归入该镇经理。

## 二、后端改动（新增 2 文件，0 迁移，0 改现有）

```
① server/services/leaderDashboardService.js   —— 聚合核心
   - 乡镇归因统一层：
     a) 事故/考核        → township 字段直接
     b) 三违/网格巡查     → area_team 长前缀对齐 hse_org_unit.org_name
     c) 培训/人员保险/超龄 → employee_id → assignment → org_unit 反推

   - 下钻：每条统计带 { source: 模块名, refId: 业务记录id } 供前端跳原单

② server/routes/hse-leader-dashboard.js       —— 纯绑定 router
   GET /api/hse/leader-dashboard/centers                → 作业中心列表
   GET /api/hse/leader-dashboard/centers/:id/towns?year → 乡镇 + 跨模块汇总卡片
   GET /api/hse/leader-dashboard/towns/:id/roles?year   → 角色汇总(驾驶员/经理/管理员)
   GET /api/hse/leader-dashboard/employees/:id?year     → 个人跨模块明细
   权限：requireRole('admin','safety_manager')（只读，可考虑放开 hse_manager）
   挂载：server/app.js 追加一行（不动现有注册）
```

# 决策与结论要点 归档

- **日期**：2026-09-15
- **归属对话**：AI-12 阶段会话
- **类别**：③决策结论

## 结论要点（冻结）

1. **端口契约冻结**：开发栈 Backend=5888 / Frontend=5173（可 `HSE_BACKEND_PORT` / `HSE_FRONTEND_PORT` 环境变量覆盖）；**5876 = 生产 HSE Backend，归 `HSE-Backend` 计划任务（SYSTEM）管理**——一键启动/停止脚本显式硬禁止 5876（启动脚本 `$backendPort -eq 5876` 直接退出，停止脚本同理），AI 工具不承担生产保活职责。

2. **Worker 独立进程策略**：`server\scripts\ai07_worker.cjs` **不挂载 app.js**（app.js 保持无 worker 引用），由启动器独立进程拉起；重复执行检测命令行含 `scripts\ai07_worker.cjs` 即复用；**并发 ≤1 由 PostgreSQL advisory lock（pg_advisory_xact_lock）保证**，多实例空转不重复执行。

3. **AI 变量注入原则**：开发栈以**进程级**注入 `AI_PROVIDER=ollama` / `AI_TIMEOUT_MS=300000`，**不修改 server\.env**；`AI_TIMEOUT_MS` 不盲目改小（CPU qwen2.5:7b 单次生成几十秒、复杂分析可超 60 秒、冷启动更慢）。

4. **Ollama 运行形态**：本机为 DBX 便携版（winget `Ollama.Ollama.Portable`）拉起 `G:\ollama\ollama.exe serve`（11434），**非 Windows Service**；启动/检查脚本一律以 HTTP `http://127.0.0.1:11434/api/tags` 为准，不只看进程名；**不自动 pull 大模型**（缺失时明确报错提示 `ollama pull`）。

5. **健康检查冒烟测试边界**：真实调用 `qwen2.5:7b`（极短 Prompt `请仅返回：HSE_AI_OK`，num_predict=24）**直接调 Ollama**，不写业务库、不创建 generation record / 分析任务、不污染 HSE 业务数据；探测 JWT 由独立脚本 `_ai12_token.cjs` 生成（users.id=1 真实用户只读用途）。

6. **前端代理覆盖**：`vite.config.ts` `/api` 与 uploads 代理目标支持 `VITE_PROXY_TARGET` / `VITE_UPLOADS_PROXY_TARGET` 覆盖（一键启动注入指向本栈后端）；**未设置时保持原默认值（5882 / 5876），行为不变**。

7. **长期运行方案**：生产推荐 **方案 B 任务计划程序**（项目已实证 HSE-Backend 计划任务 10 秒拉回）+ 方案 A Windows Service（Backend/Worker 服务化）；**不引入 PM2**（项目未安装，不为此新增依赖）。

8. **AI 分析入口冻结**：菜单「AI智能分析」（`page.hse.aiAnalysis`），路由 `/overview/ai-analysis`，权限 admin+safety_manager（AI-09 已对齐），未重命名、未改权限。

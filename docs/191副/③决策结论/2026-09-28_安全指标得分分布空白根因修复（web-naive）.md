# 安全指标得分分布图表空白 根因诊断与修复（web-naive）

> 类别：③决策结论 / ④风险待办 相关修复记录
> 日期：2026-09-28

## 现象

「考核分析中心→指标分析→安全指标」页：右侧「安全指标得分分布」柱状图区域空白，但左侧指标表格数据正常（事故起数 0 分 / 重大事故 100 满分 / 三违 0 分 / 严重三违 100 满分）。

table 数据来源正常（`hse_assessment_analysis.service` 后端 overview 返回 actual/targets 字段齐全），问题在**前端图表渲染载体**，非数据缺失。

## 根因（对比 web-antd 权威版）

| 差异点 | web-antd 版（正常） | web-naive 版（生产托管，空白） |
|--------|--------------------|--------------------------------|
| EchartsUI 条件渲染 | 有 `v-if="activeCategory === cat.categoryKey"` | ❌ 无 `v-if`，两个 NTabPane 的 EchartsUI 都渲染 |
| onMounted 渲染时机 | `nextTick(() => renderEcharts(...))` | 直接 `renderChart(...)`，未等 DOM 布局 |

两个 `EchartsUI` 共用同一个 `ref="chartRef"`，Vue 单值 ref 会被**最后挂载者（默认显示在 display:none 的「管理指标」tab 容器内）**覆盖。当「安全指标」tab 激活时，`chartRef` 指向隐藏容器，`useEcharts.renderEcharts` 的 `isElHidden()` 判定 `offsetHeight===0` 命中 → 持续 30ms 重试但容器从不显示 → **图表永远画不出来**。

## 修复（web-naive，对齐 antd 权威版）

文件：`安全看板vben/apps/web-naive/src/views/hse/assessment-analysis/IndicatorAnalysis.vue`

1. `<EchartsUI>` 增加 `v-if="activeCategory === cat.categoryKey"`（只有激活 tab 的图表挂载，避免 ref 被隐藏容器覆盖）。
2. `onMounted` / 两个 `watch`（props.data、activeCategory）改为 `nextTick(() => renderChart(...))`，确保容器布局就绪后再初始化。

web-antd 版已有 `v-if` 且用 `nextTick`，无需改动。

## 三项优化与实现

1. **Y 轴随指标动态缩放**：`lineOption()` 原 `yAxis` 无显式 `max`，单点/全零指标时轴卡 0~1，大值（如 9 月网格长巡查 1483）被压在 0 位。新增 `niceYMax()`（取数据真实最大值 ×1.15 后进位到 1/2/5×10^k），`yAxis` 改为 `min: 0, max: niceYMax(maxVal), splitNumber: 4, minInterval: 1`（minInterval=1 保证整数刻度）。全零/0 值回落 0~1 基线。
2. **单月/短跨度数值标签**：`series.label` 按跨度常显——`categories.length∈(0,12]` 时 `show: true, position: 'top', fontSize:10`；累计（70 月）点过密则 `show:false` 避免叠字。
3. **无数据月空态**：`hasTrendData` 原按 `months.length>0` 判断；后端修复后无数据月也返回 `[capMonth]` → 恒真 → 空态永不触发。改为检测**任一指标任一月份非零**才有数据；11 月等全 0 月份 → `false` → 显示「暂无趋势数据」NEmpty，与环形图/排行空态规范统一。

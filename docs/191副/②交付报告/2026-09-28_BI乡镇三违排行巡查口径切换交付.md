# BI 乡镇三违排行 公司巡查/乡镇巡查 切换交付

- **日期**：2026-09-28
- **归属对话**：当前会话
- **类别**：②交付报告

## 需求

用户：BI 看板「乡镇三违排行」模块分为「公司巡查」「乡镇巡查」两种口径，通过排行卡表头选择器（`n-card-header__extra`）切换。

## 口径（用户确认）

- **公司巡查** = `companyChecks`：`grid_inspection_records` 中检查人命中公司管理名单（6 人，口径已冻结）→ 按被检查人乡镇归因计数。
- **乡镇巡查** = `inspections`（网格长巡查）：`grid_inspection_records` 全量按乡镇归因（`inspector_employee_id`/`area_team`）计数，与公司检查同源同表。
- 两者构成同源表上「公司清单内 / 乡镇网格全部」两类口径，后端 `GET /bi/ranking` 均已支持，**本次零后端改动**。

## 实现（纯前端 `views/hse/bi/index.vue` 一处）

1. 排行卡标题改 `乡镇三违排行${chartPeriod}`，改用 `#header-extra` 槽放 `NRadioGroup`（`NRadioButton value=companyChecks` 公司巡查 / `inspections` 乡镇巡查，默认 companyChecks）。
2. 新增 `rankingMode` ref + `RANKING_META` 映射（seriesName： 公司管理检查次数 / 网格长巡查次数；配色蓝 `#1890ff` / 青 `#13c2c2`）。
3. `loadAll()` 由硬编码 `'companyChecks'` 改为 `getBiRanking(rankingMode.value, …)`。
4. `renderRankingChart()` 按 `RANKING_META[rankingMode.value]` 出 seriesName/color。
5. `watch(rankingMode, reloadAll)` 联动刷新，与年份/月份一致。

## 二、端点契约（全部只读，year 缺省回退当前年）

| 端点 | 用途 |
|------|------|
| `GET /api/hse/leader-dashboard/centers` | 作业中心树（环卫 / 市政园林）→ 各中心下乡镇清单 |
| `GET /api/hse/leader-dashboard/centers/:id/towns?year=` | 作业中心下各乡镇年度汇总：事故（含重大/加权指数）/ 三违（含严重）/ 网格长巡查 / 考核（人数·均分·优良）/ 培训（人次·人数）/ 应急演练（乡镇级汇总）/ 人员保险（当前有效·临期·过期）/ 超龄 |
| `GET /api/hse/leader-dashboard/towns/:id/roles?year=` | 乡镇内按角色分组（乡镇作业中心经理 / 管理员 / 驾驶员 / 其他）及每人计数 |
| `GET /api/hse/leader-dashboard/employees/:id?year=` | 员工个人明细：考核逐月、事故、三违、巡查、培训、保险 |

## 三、乡镇归因统一策略（与三违按花名册口径一致）

1. 记录带人员 ID 且命中当前任职（`v_employee_org_full` relation_status='active'）→ 按任职反推组织（town_center 归乡镇，center/职能部门归"直管"桶）
2. 否则按自由文本（township / area_team）对乡镇短名最长前缀匹配
3. 均未命中 → 不计数（未匹配桶，不在本端点返回）

## 四、模块关联口径（按实施计划执行）

- 车辆保险 / 其他保险：公司集采，不做乡镇/个人下钻 → 仅人员保险（personnel_insurance）进入乡镇汇总，无人员下钻
- 应急演练：当前仅乡镇级汇总（数据后续补充后升级到班组/人）
- 组织树以 `hse_org_unit`（org_type center/town_center）为主干

## 问题（用户截图反馈）

趋势表「考核均分」行点击数字 → 弹窗报错「不支持的子指标: avgScore」。

**根因**：前端 `buildTrendRows` 把**趋势数据键**直接当**下钻子指标**（sub）传给 `/dim-records`，但后端 `DIM_RECORD_SPEC.subs` 仅定义了 8 个真过滤子指标（major / serious / gradeGood / passed / 驾驶 4 子项）。19 个趋势行中有 **11 行**传递了后端未定义的 sub 键（count / weightedIndex / checkCount / recordCount / personCount / targetCount / avgScore），点击任意一行都会报「不支持的子指标」。用户点到的 avgScore 只是其中之一。

## 修复（纯前端 1 文件）

`views/hse/leader-dashboard/index.vue` `buildTrendRows`：
- push 签名改为 `(dim, label, trendKey, drillSub?)` —— trendKey 继续用于趋势数据读取（`t.rows[dim][trendKey]`），drillSub 仅用于下钻过滤；
- 仅 8 个真过滤行携带 drillSub（major/serious/gradeGood/passed/驾驶 4 子项），其余 count/聚合行（事故/加权指数/隐患/转运站/三违/巡查/培训人次/培训人数/应急演练/考核人数/考核均分）**不传 sub → 回落维度整体**（符合交付设计「count 类缺省 sub=维度整体」）；
- 点击行为不变：`onTrendCellClick` → `openOrgDim(dim, month, row.sub)`，sub 缺省时 API 不带该参数。

修复后点击行为语义：
- 考核均分/考核人数 → 显示该月全部考核记录（含 score_total/grade 列，可核对均分构成）
- 事故加权指数/事故 → 显示事故记录（含 level 列，可核对加权构成）
- 其余 count 行 → 对应维度整维明细

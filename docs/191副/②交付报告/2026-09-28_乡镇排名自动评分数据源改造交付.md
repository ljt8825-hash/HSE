# 乡镇排名改造「自动评分数据源」交付

> 交付日期：2026-09-28
> 模块：考核分析中心 → 乡镇排名（/api/hse/assessment-analysis/township-ranking）
> 关联口径：`①规则口径\2026-09-28_乡镇排名数据源口径冻结（自动评分）.md`

## 一、需求与决策

用户确认三点：
1. 接口加 `cycleId` 可选参数；
2. 「环卫作业中心」为部门（归属部门排名，不纳入乡镇排名）；「津城街道作业中心」无考核对象 → 单独标注无数据；
3. 乡镇得分 = 自动评分 `score_total` 直接排序；旧六维度明细整体替换。

## 二、改动清单

| 文件 | 改动 |
|---|---|
| `server/services/hseAssessmentAnalysisService.js` | `townshipRanking(cycleId)` 整体重写：数据源改 `hse_assessment_target`（position='乡镇作业中心经理'）；cycleId 可选（缺省取有考核对象的最新周期，指定不存在抛错）；12 town_center 组织匹配，津城无数据标注（hasData=false/overallRank=null/noDataTownships）；score_total 降序排名；bigint id 转 number |
| `server/controllers/hseAssessmentAnalysisController.js` | `townshipRanking(req.query.cycleId)` 传参 |
| web-naive `api/hse/assessment-analysis.ts` | `TownshipRankingItem` 新结构（15 字段）+ `getTownshipRanking(cycleId?)` |
| web-naive `views/hse/assessment-analysis/TownshipRanking.vue` | 列改 排名/乡镇/经理/综合得分/等级/审核状态；卡片改 排名/乡镇/经理/得分/等级/审核；无数据行「无考核对象」；头部显示考核周期 |
| web-antd `api/hse/assessment-analysis.ts` | 同上类型与参数 |
| web-antd `views/hse/assessment-analysis/TownshipRanking.vue` | 同上页面改造 |

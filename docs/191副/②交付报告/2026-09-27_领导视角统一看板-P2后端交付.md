## 二、端点契约（全部只读）

| 端点 | 用途 |
|------|------|
| `GET /api/hse/leader-dashboard/centers/:centerId/towns/:townId/trend?year=` | 乡镇/公园逐月趋势表：`months`（有记录月份并集升序）+ `rows`（维度→按月数组，风险恒 null）+ `summary`（10 维累计）。year 缺省=历年累计（趋势截断到当前月） |
| `GET /api/hse/leader-dashboard/towns/:id/managers` | 乡镇返回岗位=「乡镇作业中心经理」；公园返回岗位含「管理员」；`roleLabel` 区分 |
| `GET /api/hse/leader-dashboard/managers/:employeeId/overview?townId=&year=` | 经理双口径：`jurisdiction`=辖区组织全量（复用 fillSummaries 口径）+ `personal`=本人归因（ID 反推 + 全局唯一姓名兜底） |
| `GET /api/hse/leader-dashboard/managers/:employeeId/month-detail?townId=&month=YYYY-MM` | 经理某月明细：辖区与个人单月单元格（超月/未来月校验） |

## 三、冻结口径（2026-09-27，详见 `docs/191副/①规则口径/2026-09-27_领导视角统一看板P2月度与经理双口径规则.md`）

- 逐月趋势月份 = 该组织各维度「有记录月份」并集升序；累计模式截断到当前月（未来日期脏数据不展示）。
- 风险 = 静态台账（无业务日期）→ 不参与月度，rows.risks 恒 null；驾驶人员数为时点台账 → 仅累计，不入月度。
- 经理双口径：辖区 = 组织全量（复用 fillSummaries）；个人 = 本人归因（ID 反推 + 全局唯一姓名兜底；应急演练表无人员字段 → 个人恒 0 如实呈现）。
- 归因与 M1 一致：a) 人员 ID 反推（v_employee_org_full active）→ b) 自由文本乡镇短名最长前缀匹配（转运站 area_team 短名 / 隐患描述 / 演练名兜底）→ c) 未匹配桶。
- 驾驶员复合口径 5 项：人数（在职驾驶岗位时点）+ 记分（license_demerit_records）+ 车辆检查（vehicle_inspection_records）+ 驾驶员检查（hse_driver_inspection_records）+ 违章（driver_violation / driver_three_violation 姓名兜底）。
- 公园线独立 8 维渲染由前端按维度集处理，后端统一返回 10 维骨架（drivers/transferStations 恒 0）。

> 日期：2026-09-30　类别：②交付报告

## 一、问题诊断（重设计前）

| 症状 | 根因 |
|---|---|
| 排版乱、不整齐 | 区块未按等高网格组织：卡片内容高度不一、行内左右卡高度不齐；图表固定高度（200px/220px），内容撑不满下方留白 |
| 统计卡风格不统一 | 核心指标使用裸 `NStatistic` 卡片，与驾驶员风险中心已统一为 `HseStatCard` 的样式不一致，图标/配色/间距各异 |
| 空态错位 | 图表无数据时 `NEmpty` 未垂直水平居中，空态与图表位置不一致、出现错位 |
| 标题/间距混乱 | 卡内小节标题样式不统一；区块垂直间距与网格 gap 不一致 |
| 交互冲突 | 趋势卡内周期/年份切换与筛选栏草稿模式冲突，改选后需额外点「查询」才生效 |

## 二、改动清单（web-naive 仅 1 文件，未动后端）

| 文件 | 改动 |
|---|---|
| `views/hse/accident-analysis/index.vue` | 布局重构为等高紧凑网格：B1 查询筛选卡（草稿→提交模式不变）→ B2 核心指标 `HseStatCard` 行（事故总数 red / 涉及人数 blue / 责任人数 yellow / 重大事故 red）→ B3 图表等高网格（7/12 事故趋势 + 5/12 事故等级分布；7/12 事故分类分析 + 5/12 责任人员分析）→ B3-5 乡镇/单位分布全宽（TOP20 横向条形图）→ B4 明细数据表格（责任人员TOP排行 / 事故关联人员两 Tab + 导出CSV 不变） |

具体设计要点：

- **等高紧凑网格**：行内卡片 `h-full`，内容区 `fill-height`（flex-col + `min-h-0 flex-1`）撑满，消除留白；
- **图表自适应撑满**：`EchartsUI height="100%"`（`useEcharts` 自带 ResizeObserver），乡镇全宽图固定 280px；
- **统计卡统一**：核心指标改用系统组件 `HseStatCard`×4，语义色统一 HSE 色板；
- **空态居中**：新增 `.chart-empty-cell`（flex 垂直水平居中 + min-height 120px），所有图表空态统一；
- **色板**：图表 Canvas 用 HSE 语义色 hex（绿 `#52c41a`/蓝 `#2080f0`/黄 `#faad14`/红 `#f5222d`），清除 antd 残留色；分类汇总卡按分类配色（交通事故 blue / 生产安全事故 red）；
- **趋势切换分离**：新增 `onTrendPeriodChange`，趋势卡内周期/年份切换直接生效重拉，不再经过筛选栏草稿；
- **功能不变**：数据流/接口/路由/导出/分页/排序/风险画像跳转均保持。

## 五、追加变更：图表区等高并填满剩余空间（2026-09-30 同日）

> 用户复测反馈：四个图表卡高度不一致（测量：行1=194px、行2=354px），图表偏矮；要求「四个图表等高并填满剩余空间」。

### 根因

- 页面容器 `.accident-analysis` 为 `auto-content-height` 固定高度内容区的子元素，但自身未设确定高度，flex 容器高度 auto → 行内 `height:100%` 链路（NCard→内容区→fill-height→图表）全链无确定高度，图表塌缩为内容高度；
- 两行图表区是独立 grid，各自按内容撑高（行1=194px、行2=354px），四卡不齐。

### 改动（仍仅 `views/hse/accident-analysis/index.vue` 1 文件）

| 项 | 改动 |
|---|---|
| `.accident-analysis` | 增加 `height: 100%`（容器高度确定，flex 剩余空间可分配；内容超高时溢出传导给外层滚动容器，滚动行为不变） |
| 两行 B3 图表区 | 加 `chart-row` class：`flex: 1 1 0%; min-height: 400px`，两行均分剩余空间且等高，min-height 兜底防塌缩 |

### 验证

- dev 5173 DOM 实测（`_tmp/measure_charts.cjs`）：两行 grid 高度 400/400，四卡（事故趋势/事故等级分布/事故分类分析/责任人员分析）高度 400/400/400/400 等高；Canvas 高度 趋势206 / 等级344 / 分类216（责任卡为空态 NEmpty 居中）；
- 滚动验证（`_tmp/check_scroll.cjs`）：内容区内部滚动 scrollH 2233 > clientH 705，乡镇分布（280px）与明细表（404px）均可达，无内容被裁切；
- `pnpm --filter web-naive build`：built in 8.09s 通过。

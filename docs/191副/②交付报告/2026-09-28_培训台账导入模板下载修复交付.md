# 培训台账导入模板下载修复（Content-Disposition 中文文件名）交付

> 日期：2026-09-28 | 类别：②交付报告 | 归属对话：当前会话

## 需求与现象

用户反馈：培训考核→培训记录 点击「下载模板」下载的表格"列表不对"。用户上传下载产物，实为**非 Excel 文本**，内容：

```json
{"code":-1,"success":false,"message":"Invalid character in header content [\"Content-Disposition\"]","data":null}
```

## 根因

`server/services/importExcelService.js` `template()` 的 xlsx 分支将**中文文件名直接放入 `Content-Disposition`**：

```js
hdr['Content-Disposition'] = `attachment; filename="${tplFileName}"`; // 培训台账导入模板_20260927.xlsx
```

Node http 头校验（`validateHeaderValue` / `ERR_INVALID_CHAR`）不允许 header 值含非 Latin-1 字符（中文 codePoint > 0xFF），`controllers/import.js` `respond()` 的 `res.setHeader()` 抛错 → 被 `run()` 统一包装成 `error(-1, message)` JSON 返回 → 前端把 JSON 当 blob 存为 .xlsx → 用户拿到坏文件。

生产日志实锤：2026-09-28 07:44:42 `GET /api/import/template/training-ledger` 200 但 `contentLength=113`（正是错误 JSON 长度）。

## 修复（最小改动 1 文件）

`server/services/importExcelService.js` 仅改 xlsx 分支 header：

```js
hdr['Content-Disposition'] = `attachment; filename="${module}_template.xlsx"; filename*=UTF-8''${encodeURIComponent(tplFileName)}`;
```

- `filename` 用 ASCII 回退名（`training-ledger_template.xlsx`）通过 Node 校验；
- 中文名经 **RFC 5987 `filename*`** 百分号编码保留，浏览器仍显示中文文件名；
- 同时覆盖 grid 模块（`网格管理导入模板_*.xlsx`，同样中文会炸）。

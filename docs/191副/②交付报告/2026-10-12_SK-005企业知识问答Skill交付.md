## 五、Skill 标准（样板基线）

- **输入协议**：`{ question, knowledge_scope[], conversation_id, top_k=5, require_citation=true }`（兼容 `query/knowledgeScope/topK/requireCitation` 别名）。
- **校验**：question 非空且 ≤1000；top_k ∈ [1,10]；conversation_id ≤128；knowledge_scope 令牌合法（`all` 或 `sourceType:<类型>` / `sourceId:<数字>`，`all` 不可与其它并用，仅支持单一 sourceType）。异常返回结构化 `AI_INVALID_REQUEST` + `details.validationErrors[]`。
- **输出协议**：`{ success, skill{id,version}, request_id, answer, evidence[], confidence, warnings[], suggestions[], metadata{} }`。
- **错误模型**：统一 `AI_ERROR_CODES / AiError / toErrorResponse`；权限错误为 403 `SKILL_PERMISSION_DENIED`。

## 六、Prompt（Prompt Registry）

- key `company.knowledge.answer`，version `v1.0.0`，status ACTIVE。
- 含：角色 / 5 条回答规则 / 知识上下文占位 / `[引用#编号]` 引用规则 / 禁止编造 / 资料不足处理 / 人机边界 / 输出格式。
- 每次调用记录 `prompt_key` + `prompt_version`（T05 已验证）。
- **未在 Skill 中硬编码完整 Prompt**。

## 七、RAG

- 复用 `retriever.retrieve(question, {topK, filters})`（现有能力，未新增检索器）。
- `ragContextBuilder.buildContext()/formatContextText()` 产出 contextItems + citations。
- **检索能力类型如实**：项目现有为向量检索（pgvector 余弦相似度），未声称支持不存在的混合检索能力。
- 相关性阈值 `MIN_RELEVANCE_SCORE = 0.3`；无结果或 best < 阈值 → 安全拒答。

## 八、Evidence

- `buildTraceableEvidence(contextItems, citations)` 逐字段映射：citation_id / chunk_id / document_id / document_name / source_id / source_name / source_type / page / section / content / score / evidence_strength。
- **缺失字段一律 null，不伪造**（现有库无法提供的字段如实为空）。

## 九、权限

- 角色 allowlist（fail-closed，与 `server/middleware/auth.js` 的 ROLE_PERMISSIONS_MAP 逐字一致）：`system_admin, admin, safety_manager, hse_manager, township_manager, manager, viewer, grid_inspector`。
- `knowledge_scope` 只能**收窄**，不能放大；强制「知识源 ACTIVE + 文档 READY」；拒绝不存在/停用 sourceId（`SOURCE_UNAVAILABLE`）。
- **ACL 缺口如实固定**：`knowledge_sources` 无 owner/role/部门字段 → 无「用户↔知识源」行级 ACL。落 `metadata.permission_model = 'role_allowlist + scope_narrowing（无知识源级 ACL）'`。未假装已支持，未做未授权 migration。

## 十、AI 执行记录

- 每次执行记录：request_id / user_id / skill_id / skill_version / prompt_key / prompt_version / provider / model / start / end / duration / success / error + evidence。
- 失败路径（检索不可用、gateway 异常）由 Skill 捕获写 `status='failed'` 后 rethrow。
- **日志不含 API Key / Token / 密码**。

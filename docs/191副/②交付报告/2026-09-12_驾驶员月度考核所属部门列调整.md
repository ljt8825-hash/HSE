# 驾驶员月度考核所属部门列改为「xx镇乡镇作业中心」

- **归属对话**：当前会话（三级菜单「驾驶员月度考核」所属部门列调整）
- **日期**：2026-09-12
- **类别**：②交付报告 / ③决策结论

## 需求

三级菜单「驾驶员月度考核」（`/site/driver/monthly`）列表「所属部门」列显示改为「xx镇乡镇作业中心」（如「柴胡店镇乡镇作业中心」），与三违分析经理口径一致。

## 改动说明

- 数据源：驾驶员花名册接口 `GET /employees/profile/list?is_driver=true`。
- 问题背景：原「所属部门」取花名册 `dept_name`（=`COALESCE(ea.dept_name, ev.org_name)`），`ea.dept_name` 非空时优先生效，实际显示为「柴胡店镇片区」「车队」；而乡镇真实组织为 `ev.org_name`（`org_type='town_center'`）。
- 修改：`loadDriverRoster` 中部门按花名册 `org_name` 归因，仅对 `org_type='town_center'` 级组织在「作业中心」前插入「乡镇」→「柴胡店镇乡镇作业中心」；车队等非乡镇组织（`org_type≠town_center`）保留原 `dept_name`（如「车队」）。
- 缓存：`withRosterCache` 缓存计算后的部门，逻辑变化后换 key `dw_monthly_driver_roster_dept_v2` 强制重拉，避免旧缓存（「xx镇片区」）写回。
- 存量行：`syncFromRoster` 同步时补充 `department` 更新，历史「xx镇片区」行随同步归档为新部门。

## 涉及文件

- `apps/web-naive/src/views/site/driver/monthly/index.vue`：`loadDriverRoster` dept 归因、缓存 key、`syncFromRoster` department 更新

## 验证

- 前端 `vue-tsc` 类型检查：`driver/monthly/index.vue` 无报错（仓库内其他文件存在既有类型错误，与本次改动无关）。
- 花名册探查：12 乡镇驾驶员 `org_name` 均为「xx镇作业中心」（`org_type='town_center'`），可正确转换为「xx镇乡镇作业中心」；车队（环卫作业中心下级）为 `org_type='center'`，保留「车队」。

## 待办 / 注意

- 纯前端改动，无需重启后端。
- 存量历史行的部门需在页面点击「同步花名册人员」后统一归档；也可在下次月度自动同步时归档。

# 自动评分·列表内单元格样式对齐「三违管理考核」（交付）

> 日期：2026-09-26  |  类别：②交付报告  |  归属对话：当前会话

## 需求

自动评分页（目标职责→自动评分）两个 tab「乡镇作业中心经理 / 管理员」的**列表内**功能与样式与「现场管理→三违管理→三违管理考核」的列表一致；**列表外的界面不改变**（Tab、外层按钮、导出/执行评分/刷新进度、维度列路径悬浮、点击下钻等均保留原有能力）。

## 改动（仅 `apps/web-naive/src/views/hse/assessment-monthly/scoring.vue`，纯前端）

对齐前，自动评分列表的单元格表现与三违页存在差异：

| 项 | 改动前 | 改动后（对齐三违页） |
|----|--------|----------------------|
| 列表首列 | 无序号列 | 新增 `type:'seq'`「序号」列（对齐全三违页 checkbox→序号→姓名→岗位→乡镇 前缀） |
| dimCell 扣分数字=0 | `<span>` 纯文本 | 统一 `NTag(success)`（三违页自动列 0 值同款） |
| dimCell 扣分数字>0 | `NTag(warning)` 可点击弹明细 | 保持（本就与三违页一致） |
| scoreTotalCell 考核分数 | `<span>` | `NTag`：>0 → `type="error"`；≤0 → `type="success"`（三违页「考核分数」列同款） |

同步将 `scrollX` 计算从 `650+…` 调至 `720+…`（补偿新增序号列宽）。

## 不做（列表外，依用户明确指令保留）

- Tab 切换样式、外层 HsePageLayout/HseActionBar、导出/刷新进度/执行评分按钮、NCard 容器、周期下拉；
- 维度列结构、路径悬浮（dimHeader）、点击弹明细 + 下钻（openDimDetail/drillDimDetail）、HSE教育培训 缺失人员/资料不完整拆分逻辑；
- 三违页的人工列可编辑、公司查处固定列、增删列说明落库等——自动评分语义为只读自动评分，不引入。

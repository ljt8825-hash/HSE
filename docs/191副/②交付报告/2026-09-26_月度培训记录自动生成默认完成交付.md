# 月度培训记录自动生成（每月初默认都完成）交付

> 日期：2026-09-26 | 类别：②交付报告 | 归属对话：当前会话

## 需求

每月初自动生成月度培训记录，默认标记为「都完成」（应培训=实际=缺少=资料不完整=0，列表显示全部完成状态）。

## 口径（2026-09-26 冻结）

1. **培训人名单**：沿用现有月度台账（`hse_training_ledger_monthly`）历史培训人（`trainer_id` 有值）去重。
   - 注：曾拟用 `training_records` 作名单来源，但核查该表仅 5 条遗留演示数据且 `trainer_id`/`trainer` 全空；业务「培训记录」页读取的正是 `hse_training_ledger_monthly`，故名单以此表已有培训人为准。
2. **默认值**：应培训=实际=缺少=资料不完整=0（列表显示为全部完成状态）。
3. **写入表**：`hse_training_ledger_monthly`（`source='auto-init'`），与人工 Excel 导入同表。
4. **幂等**：同 `trainer_id+month` 已有记录（人工导入或本次生成）则 `ON CONFLICT DO NOTHING` 跳过，**不覆盖**任何既有台账数据（月初生成兜底 + 人工 0 覆盖安全）。

## 改动内容

### 新增 `server/services/trainingLedgerAutoInitScheduler.js`
- 对齐现有 `assessmentScheduler.js` / `monthlyLedgerImportScheduler.js` 范式：`SCHEDULER_ENABLED` 开关 + `init/stop/trigger` + 纯函数 `getPreviousMonthStr()`（跨年正确）+ 幂等重入锁。
- Cron：每月 1 日 **03:20**（`Asia/Shanghai`），`CRON_AUTO_LEDGER` 可环境变量覆盖；错开 00:30 考核周期 / 01:00 网格 / 01:30 台账导入 / 02:00 每日校验。
- `runAutoInit()`：生成**上月**台账 → 名单查询 → 逐 trainer 事务内插入（0 值 + `source='auto-init'`，`ON CONFLICT (trainer_id, month) DO NOTHING`）→ 统计 `trainerCount/inserted/skipped/errors`。
- 导出：`SCHEDULER_ENABLED / CRON_AUTO_LEDGER / CRON_TZ / getPreviousMonthStr / runAutoInit / triggerAutoInit / initTrainingLedgerAutoInitScheduler / stopTrainingLedgerAutoInitScheduler`。

# H5 登录不可用 根因修复与重新部署（2026-10-16）

> 类别：②交付报告。触发：用户报告「手机端 H5 上线后无法登录」。

## 现象

H5（grid1ns.dpdns.org）登录页提交后报「登录失败 / 网络异常」，所有账号无法进入系统。

## 根因（两个叠加）

1. **最新一次 Pages 部署（2026-10-15.94）未包含 Pages Functions**
   - 实测：线上 POST `/api/mobile/auth/login` → 405（静态服务拒 POST）；GET `/api/mobile/auth/login` 与 `/probe` → 200 返回 index.html（SPA 兜底），证明 Functions 未生效。
2. **`config.js` 的 `API_BASE` 被改成直连错误地址 `https://grid-mobile-cloudflare.ljt8825.workers.dev`**
   - 该地址是 **Pages 项目自身的 workers.dev 别名**（`_pages_deploy/wrangler.toml` 的 `name = "grid-mobile-cloudflare"`），不是 API Worker；其上没有 `WORKER_SESSION_SECRET`，登录恒 503 `SESSION_NOT_CONFIGURED`。
   - 真正的 API Worker 是 `https://grid-mobile-cloudflare-worker.ljt8825.workers.dev`（`worker/wrangler.toml` name），实测返回正常业务 401 `AUTH_FAILED`（密钥、飞书身份表全健康）。
   - 直连 workers.dev 本身也不可行：workers.dev 在国内手机网络普遍被墙（`_workerProxy.js` 注释早已言明）。

## 修复内容

| 项 | 改动 |
|----|------|
| `frontend/config.js`、`_pages_deploy/config.js` | `API_BASE` 恢复 `''`（同源反代生产口径），注释写入教训 |
| `login.html / patrol.html / records.html / detail.html`（frontend + _pages_deploy 两份） | `config.js/app.js` 引用补 `?v=2026-10-16.95`（消除故障期间缓存的坏 config.js，max-age=14400 残留影响） |
| `check.html` ×2 | 版本号 .94 → **2026-10-16.95** |
| Pages 重新部署 | `npx wrangler pages deploy _pages_deploy --project-name grid-mobile-cloudflare`（含 Functions bundle），部署两次（修复版 + 版本号版） |

**未动 Worker**：API Worker（grid-mobile-cloudflare-worker）无需重新部署；同源请求不经浏览器 CORS 校验，其白名单缺 grid1ns.dpdns.org 无影响。

## 线上验证（2026-10-16 实测）

- `GET /config.js` → 新内容 `API_BASE=''` ✅
- `POST /api/mobile/auth/login`（同源，错误凭据）→ **401 AUTH_FAILED「手机号或密码错误」** ✅ 全链路（浏览器 → grid1ns.dpdns.org Pages Function → API Worker → 飞书身份表）走通
- `GET /check.html` → `hse-build: 2026-10-16.95` ✅
- `GET /login.html` → config.js 引用带 `?v=2026-10-16.95` ✅

## 规则沉淀（同步至 project_memory）

- H5 生产口径：`API_BASE` 必须为 `''`（同源 Pages Functions 反代）；**禁止直连任何 `*.workers.dev`**。
- H5 发布必须从 `_pages_deploy`（含 `functions/`）以 `wrangler pages deploy` 执行；从 `frontend/` 目录或 Dashboard 拖拽丢 Functions 的部署会让 `/api` 全灭。
- `grid-mobile-cloudflare.ljt8825.workers.dev` 是 Pages 项目别名，不是 API Worker；API Worker = `grid-mobile-cloudflare-worker.ljt8825.workers.dev`。

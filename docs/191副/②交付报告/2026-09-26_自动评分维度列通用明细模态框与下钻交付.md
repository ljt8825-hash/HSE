# 自动评分「维度列通用明细模态框 + 下钻」：全维度列统一改造交付

> 类别：②交付报告　日期：2026-09-26　归属对话：当前会话

## 需求
自动评分页除「三违管理」外的其余维度列（安全文化建设 / HSE教育培训 / 现场管理-驾驶员管理 / 现场管理-转运站管理 / 现场管理-消防管理）统一按三违列的交互标准改造：
1. 列表不为 0 的数字展示详细扣分情况（按扣分规则明细分组汇总）；
2. 点击数字后**居中显示扣分明细模态框**；
3. 点击明细每一项直接下钻到当月、该岗位的对应模块页；
4. 去除「点击各项下钻…」提示文字（下钻交互保留）。

## 实现（纯前端 6 文件）

### 1. `views/hse/assessment-monthly/scoring.vue` — 维度列明细模态框泛化
- 将三违专用明细弹窗重构为**通用维度列明细模态框**（`NModal preset="card"` 默认居中，宽 420px / max-width 92vw）：
  - 通用状态：`dimDetailRow`（当前行）+ `dimDetailCategory`（当前列类别）+ `dimDetailVisible`（computed 双向）+ `dimDetailItems` + `dimDetailLoading`；标题动态化为「{类别名} · 扣分明细」。
  - `openDimDetail(row, column)`：所有维度列 >0 数字（NTag warning，cursor-pointer）点击统一走此函数。
- **明细数据源分流**：
  - 三违列：沿用 `violationScoreMap`（与「三违管理考核」页当前展示列逐一对应：自动列 + 人工列 + 公司查处扣分），口径与源页 `totalScore` 一致（2026-09-26 冻结口径）。
  - 其余维度列：`getTargetDeductionList(cycleId, row.id)` 拉取扣分规则明细 → 按类别过滤（`normalizeCategoryName` 兼容「现场管理-」前缀）→ 按规则名（`ruleName`，兜底 `deductionItem`/「未命名扣分项」）分组汇总。
- 明细项 hover 高亮、点击下钻；底部「合计」；空明细提示「暂无扣分明细」；无提示文字（已去除）。
- 表头帮助文案 `dimHelpText` 已为每个维度列配置专属获取路径。

### 2. `scoring.vue` — 下钻映射 `CATEGORY_DRILLS`
| 维度列 | 下钻路由 | 携带参数 |
|--------|----------|----------|
| 安全文化建设 | `/objectives/safety-culture` | month=YYYY-MM + level=管理员/乡镇主管（按当前岗位 Tab） |
| HSE教育培训 | `/training/records` | month=YYYY-MM |
| 现场管理-驾驶员管理 | `/site/driver/monthly` | month=YYYY-MM |
| 现场管理-转运站管理 | `/site/transfer-stations` | month=YYYY-MM |
| 现场管理-消防管理 | `/site/fire-facility` | month=YYYY-MM（目标页拆分为年月筛选） |
| 现场管理-三违管理 | `/site/violation/assessment` | violCycle=周期ID + violPos=岗位中文名（沿用既有） |

### 3. 目标模块页自动定位（5 文件，均为新增只读 route.query 消费，无 query 时行为与默认一致）
- `views/hse/safety-culture/index.vue`：读取 month + level，自动定位月份下拉与岗位筛选。
- `views/training/ledger/index.vue`：读取 month，自动定位月份下拉。
- `views/site/driver/monthly/index.vue`：读取 month，自动定位月份下拉。
- `views/site/transfer-stations/index.vue`：读取 month，自动定位月份下拉。
- `views/site/fire-facility/index.vue`：读取 month，初始化时拆分年/月写入搜索表单。

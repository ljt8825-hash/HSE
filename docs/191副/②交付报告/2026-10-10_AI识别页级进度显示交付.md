# AI 识别页级进度显示 交付报告

> 类别：②交付报告 ｜ 日期：2026-10-10 ｜ 归属对话：当前会话

## 一、需求

用户在「培训记录 → 导入培训台账 → AI 识图」对话框看到「正在识别文件，扫描件逐页解析可能需要几分钟」加载态，提出：

> **在识别过程中，是否可以显示已经识别的页数以及总页数？**

## 二、背景与范围

- 识别路径分两种：
  - **AI 识图（`aiRecognize`）**：走 Ollama 本地视觉大模型（qwen2.5vl），JS 逐页循环调用 `recognizeSigninSheet`/`recognizeLedgerImage`，PDF 经 `renderPdfPages` 渲染为页图后**总页数已知**。
  - **经典 OCR**：走 Python 子进程（`ocr_ledger.py`/`training_signin_ocr.py`），JS 侧无逐页钩子，需改脚本流式吐行，改动大。
- 本次范围**只覆盖 AI 识图路径**（与截图主功能一致），经典 OCR 页级进度列为后续可选。

## 三、方案选型

采用「**提交任务 + 内存任务表 + 轮询进度**」，贴合项目 descriptor-contract、易单测、避免长时间挂起连接。

```
前端 aiRecognize(file) ──提交──▶ 后端：认证+校验 → 建任务(jobId) → 立即返回 {jobId}
                                          │ 后台 runAiJob 异步逐页识别，setTotal/setDone 更新进度
前端 aiRecognizeProgress(jobId) ──轮询──▶ 后端：recognizing → {status,totalPages,donePages}
                                          │        done → {status, ...识别结果}
                                          │        error → {status,error}
```

轮询间隔 1500ms；`aiPollToken` 保证新一轮/卸载时废弃旧轮询。

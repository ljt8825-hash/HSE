## 交付/变更概要

修复问题：H5 巡查提交违章记录时，违章人员的「年龄 / 性别 / 职位」未映射进飞书主台账
（此前被拼进「描述」列作为「姓名·职位·班组」杂烩串，主台账相关列长期为空）。

变更：将违章人档案拆列落库，姓名单独成列，性别/年龄/职位分别映射到主台账既有列。

## 关键文件

- `worker/index.js`：
  - `validatePatrolBody` 新增读取可选字段 `violation_sex / violation_age / violation_job`（上限 `PATROL_ATTR_MAX=50`），透传进 `values`。
  - `handlePatrolSubmit` 的 record 构建新增三列映射：
    `'性别' ← violation_sex`、`'年龄' ← violation_age`、`'车辆类型|保洁员' ← violation_job`（仅 legs 违章记录非空）。
  - 三个目标列（`性别` / `年龄` / `车辆类型|保洁员`）原已在 `FEISHU_FIELD_WHITELIST`，`feishuTypedRecord` 不会丢弃，无需补白名单。
- `frontend/check.html` `toPatrolBody`：三违分支新增下发 `body.violation_sex / violation_age / violation_job`（取自 `rec.personSex/personAge/personJob`）；
  「描述」列括号内由「姓名·职位·班组」收敛为「姓名·班组」，职位不再重复堆叠（职位已独立成列）。

# 扣分规则库列表单元格显示不全修复

- 日期：2026-09-14
- 类别：②交付报告
- 文件：`安全看板vben/apps/web-naive/src/views/hse/assessment-rule/index.vue`
- 归属对话：当前会话

## 问题

二级菜单「扣分规则库」右侧规则列表，部分单元格文字显示不全。

## 根因

扣分规则库列表为 **12 列**宽表，但复用了通用表格组件的 `auto-width` 模式。
该模式在 `HseDataGrid`（`components/hse/HseDataGrid.vue`）内部会设置
`scrollX: { enabled: false }`，即**禁用横向滚动、强制列宽填充容器**。

当 12 列 `minWidth` 总和（约 1540px）接近或超过容器宽度时（尤其 1366/1440 窄屏），
各列被压缩至 `minWidth` 附近，「考核内容」这类长描述文本被频繁省略截断，
且因禁用了横向滚动，用户无法将列滚动展开查看完整内容 —— 表现为「显示不全」。

vxe-table（4.19.25）机制佐证：`minWidth` 是列宽硬下限（`getColReMinWidth`）；
`scrollX.enabled=true` 时若列宽总和超出容器才出现横向滚动，可完整查看各列。

## 修复内容（仅动本页，不动公共组件）

1. **移除 `auto-width`**：恢复默认横向滚动兜底，窄屏下列可横向滚动完整查看，
   超长文本仍由全局 `showOverflow:'tooltip'` 悬停展示全部内容。
2. **调整列 `minWidth` 分配**，空间向长文本关键列倾斜：

| 列 | 调整前 | 调整后 |
|----|--------|--------|
| 考核内容 ruleName | 150 | **250** |
| 扣分 deductScore | 110 | 95 |
| 方式 deductType | 80 | 70 |
| 触发 triggerType | 70 | 64 |
| 有效期 validFrom | 160 | 140 |
| 状态 status | 70 | 64 |

其余列（规则编码 110 / 类别 130 / 接入状态 110 / 最近执行结果 150 / 操作 210）保持不变。

## 补充（用户在截图确认后仍见截断，做第二轮根治，同日）

仅「移除 auto-width + 加宽列」依赖 `fit` 列宽分配仍治标不治本：`fit` 会继续压缩列，
长文本依旧显示省略号。根治做法改为**让长文本列内容在单元格内完整换行显示**，不依赖任何列宽分配：

1. **考核内容 ruleName**
   - `showOverflow: false`（关闭单行省略）
   - 绑定自定义 slot `ruleNameCell`，渲染 `<span class="rule-name-cell">`，
     样式 `white-space:pre-wrap; word-break:break-word; line-height:1.45; text-align:left`，
     实现**单元格内强制换行、完整显示全文、行高自适应**，任何视窗下列多窄都不再截断。
   - `minWidth 250 / maxWidth 400` 限制为可读宽度，过长仍换行展示。
2. **数据来源 sourceTable**
   - 加宽 `minWidth 190→230`、`maxWidth 400`，保留 `showOverflow:'tooltip'`（悬停展示完整英文表名）。
3. 保留自动换行前已做的 `auto-width` 移除。
4. 新增 `.rule-name-cell` 样式置于本文件全局 `<style>` 块（类名在项目中唯一，无冲突）。

> 依据：vxe-table 单元格默认 `white-space:nowrap`，仅 `showOverflow:false` 不足以换行，
> 必须由列内样式强制 `pre-wrap`。文件内既有 `categoryCell/validityCell/lastRunCell` 用 flex 多行正常撑高，
> 证明 vxe 单元格行高自适应、多行不会被裁剪，故本方案可靠生效。

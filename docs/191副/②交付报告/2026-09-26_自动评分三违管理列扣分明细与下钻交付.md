# 自动评分「三违管理」列：不为 0 数字点击明细 + 下钻三违管理考核交付

> 类别：②交付报告　日期：2026-09-26　归属对话：当前会话

## 需求
「目标职责 → 自动评分」列表中「三违管理」列不为 0 的数字，要有详细扣分情况：即「网格长巡查考核、三违巡查、三违信息填报、驾驶员三违、公司查处扣分」这几项各扣几分；点击明细中每一项，直接下钻到当月、当前岗位的「现场管理 → 三违管理 → 三违管理考核」。

## 实现（纯前端，两文件）

### 1. `views/hse/assessment-monthly/scoring.vue`（自动评分页）
- **明细数据**：`violationScoreMap` 由 `Map<employeeId, number>` 升级为 `Map<employeeId, { total, items }>`；`loadViolationScores()` 按「三违管理考核」页当前展示列逐一构建明细项（自动列：网格长巡查考核/三违巡查/三违信息填报/驾驶员三违，取 `gridDeduct/violationDeduct/unrectifiedDeduct/driverDeduct`；各人工列取 cells；固定列「公司查处扣分」取 `companyDeduct.score`），`total` = 各项之和（与源页 `totalScore` 同口径，2026-09-26 冻结）。
- **交互**：dimCell 中，三违管理列且明细 `total > 0` 时，数字渲染为可点击 `NTag`（warning，样式对齐三违管理考核页）；点击弹出明细：逐项「列名 + 分值」+ 合计，每项可点击（hover 高亮）。
- **下钻**：点击任意明细项 → `router.push('/site/violation/assessment?violCycle=<周期id>&violPos=<当前岗位>')`；`violPos` 取当前岗位 Tab 对应中文岗位名。
- 明细仅覆盖展示，仍不影响本页「总分」；`total = 0` 时保持纯文本（不可点击）。

### 2. `views/hse/violation-assessment/index.vue`（三违管理考核页，现场管理菜单路由 `/site/violation/assessment`）
- 新增下钻定位支持：`onMounted` 读取 `route.query.violCycle`（周期 id）/ `violPos`（岗位名），覆盖默认选中后再 `loadCycles()`；无 query 时行为与原先完全一致（不影响普通进入）。

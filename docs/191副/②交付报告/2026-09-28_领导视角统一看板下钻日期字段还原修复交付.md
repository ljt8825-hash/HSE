# 领导视角统一看板 下钻日期字段还原修复交付

> 日期：2026-09-28
> 归属：领导视角统一看板（全维度数字下钻）后端补充修复
> 前置：`/dim-records` 端点已交付（org/personal 双口径 + 10 维明细 + month 收窄），前端 3 文件消费接线已完成

## 一、问题

全维度下钻弹窗中，明细表格的**日期列显示为空**。根因：

- 聚合查询（`loadAllDimensionRows` 2026-09-28 展示字段扩展后）以 `_d` 别名返回日期（`violation_date AS _d`），不再带原字段名。
- `dimRecords` 服务组装明细时直接透传聚合行，前端按 `fields`（spec.dateKeys 原字段名，如 `violation_date`）建列消费，`_d` 与 `violation_date` 键名不匹配 → 日期列取不到值。
- 例外：`drivers` 组合口径本就以 `_d` 为列键，跳过还原，避免双写冲突。

## 二、修复（后端 1 服务文件）

`server/services/leaderDashboardService.js` — `dimRecords()` 明细行组装处新增日期还原：

```javascript
// 日期字段还原：聚合查询以 _d 别名返回日期（2026-09-28 展示字段扩展），
// 下钻明细需还原为 spec.dateKeys 原字段供表格列消费；drivers 本就以 _d 为列键跳过。
if (rec._d != null && spec.dateKeys[0] && spec.dateKeys[0] !== '_d') {
  rec[spec.dateKeys[0]] = rec._d;
}
```

还原后按 `dateKeys[0]` 倒序排序（保持按日期倒序），返回体字段名与前端 `fields` 列定义完全对齐。

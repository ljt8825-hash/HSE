# 自动评分「网格长巡查考核/三违」明细点击：定位到三违管理考核该人所在行（交付）

> 类别：②交付报告　日期：2026-09-26　归属对话：当前会话

## 需求
「目标职责 → 自动评分」页维度列明细（尤其「网格长巡查考核/三违」）点击某一扣分明细项后，除了定位到「现场管理 → 三违管理 → 三违管理考核」页面（已有 violCycle/violPos 周期与岗位定位），还要**直接定位、高亮到被点击的那一个人（那一行）**，效果与三违管理考核看板本身的定位一致。

## 实现（纯前端，两文件）

### 1. `views/hse/assessment-monthly/scoring.vue`（自动评分页）
- `drillToViolationAssessment(row?)` 下钻函数支持可选 `row` 参数：点击三违明细项时传入当前行的目标对象，query 在原有的 `violCycle`（考核周期 id）/`violPos`（当前岗位中文名）基础上**追加 `violTarget = String(row.id)`**（目标 `targetId`）。
- 三违维度明细项点击回调改为：`isSanweiCategory(dimDetailCategory) ? drillToViolationAssessment(dimDetailRow) : drillDimDetail(dimDetailCategory)`，即三违类别明细项点击即携带目标人员 ID 下钻。

### 2. `views/hse/violation-assessment/index.vue`（三违管理考核页，现场管理菜单路由 `/site/violation/assessment`）
- `onMounted` 读取 `route.query.violTarget`，校验为正整数后写入 `hlTargetId`；再 `loadAll()` 后调用 `scrollToHlRow()` 滚动聚焦。
- `HseDataGrid` 传入 `row-class-name="locateRowClassName"`：按 `String(row.targetId) === String(hlTargetId)` 返回 `viol-locate-row` 行高亮样式。
- 高亮样式：`viol-locate-row` 行浅蓝背景 `rgba(37,99,235,.14)` + 单元格深蓝 `#1d4ed8` 加粗。
- `scrollToHlRow()` 在 `nextTick` 后延时 120ms，定位到 `.vxe-body--row[data-row-key="${hlTargetId}"]` 并 `scrollIntoView({ block:'center', behavior:'smooth' })` 平滑滚动。
- **高亮自动淡出（避免常驻）**：定位滚动触发后启动定时链 —— 先停留 3s（`HIGHLIGHT_HOLD_MS`），再置 `hlFading=true` 添加 `viol-locate-fading` 类触发 CSS `background-color/color` 0.8s 过渡淡出（`HIGHLIGHT_FADE_MS`），过渡结束清空 `hlTargetId` 恢复默认态；组件卸载 `onUnmounted` 清理定时器防泄漏。
- 无 `violTarget` query 时行为与默认完全一致，不影响普通进入。

## 一、需求

自动评分页（目标职责 → 自动评分）两处增强：

1. **列表平铺**：乡镇作业中心经理、管理员两个 tab 列表平铺、右侧不留白。

## 六、修正记录（2026-09-26 补：keep-alive 下二次下钻不高亮）

- **现象**：首次从自动评分页点击维度列明细下钻到目标页能高亮；再次下钻进入同一页面时高亮不显示。
- **根因**：Vben 开启 Tabbar keep-alive（`keepAlive: true`）。四个目标页（安全文化建设 / 培训台账 / 驾驶员月度考核 / 三违管理考核）的高亮逻辑只在组件 `onMounted` 读取一次 `route.query`；页面被缓存后，再次下钻进入同一路由不会重新挂载，`onMounted` 不再触发 → 高亮失效。
- **修复**：各目标页新增 `watch(() => route.query, …)` 监听外部定位参数，在 keep-alive 复用下重新触发定位高亮：
  - `safety-culture/index.vue`：监听 `[month, level, emp]` → 重跑 `loadData()`（内含月份/岗位/emp 定位与高亮淡出）。
  - `training/ledger/index.vue`：监听 `[month, emp]` → 重设月份并重跑 `loadSummary()`（内含 emp 高亮）。
  - `driver/monthly/index.vue`：监听 `[month, driver]` → 重跑 `applyDriverLocate()`。
  - `violation-assessment/index.vue`：把 onMounted 下钻体抽为 `applyDrillQuery()`，监听 `[violCycle, violPos, violTarget]` → 重跑。
- **加固（2026-09-27 二次修复）**：`watch` 只在 query 变化时触发，同一人重复下钻或时序差异仍可能漏。四个目标页再补 `onActivated` 兜底——每次标签页被重新激活（再次下钻进入）时，**无论 query 是否变化**都基于当前数据重新定位高亮（violation 页仅当携带 violTarget 时才触，避免普通切页重载）。`safety-culture` / `training/ledger` 各抽 `applyExternalLocate()` 轻量复现。
- **验证**：`pnpm typecheck` 四个被改文件零新增错误（存量错误均在无关文件）；未触碰后端/5876 进程/生产库/WPS。
- **部署**：`pnpm build` 重建生产 dist 成功（48.62s），`dist.zip`（2.45MB）同步更新。生产 5876 后端同源托管 `apps/web-naive/dist`（express.static 按请求读盘 + 内容哈希文件名），新 JS 已生效，无需重启生产进程——用户**刷新页面**即可看到修复。

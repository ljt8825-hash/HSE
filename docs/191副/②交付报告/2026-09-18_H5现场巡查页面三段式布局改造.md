# H5现场巡查 页面三段式布局改造 交付报告

- **日期**：2026-09-18
- **归属对话**：H5 移动端巡查（grid-mobile-cloudflare）
- **类别**：②交付报告

## 交付/变更概要

将 H5 现场巡查页从「整页随 body 滚动（顶栏滚走、仅底部 tabbar sticky 贴底）」改为**微信式三段布局**：
顶部状态栏+导航固定、底部导航固定、仅中间 `.page` 内容区滚动。

## 变更文件

`frontend/check.html`（CSS）：

- `html,body`：`min-height:100%;overflow-y:auto` → `height:100%;overflow:hidden`（停用整页滚动）。
- `#app`：`min-height:100dvh` → `height:100dvh;overflow:hidden`（锁定可视高度，flex 纵列）。
- `.view`：加 `overflow:hidden`；`.view.active` 加 `flex:1 1 0%;min-height:0`（活跃 view 吃掉剩余空间）。
- `.page`：加 `flex:1 1 0%;min-height:0;overflow-y:auto;overflow-x:hidden;overscroll-behavior:contain;-webkit-overflow-scrolling:touch`（成为唯一滚动容器）。
- `.view.has-tab .page`：底部补偿 padding 由 `calc(var(--tabbar-h)+8px)` 收敛为 `var(--pad-card)`（底导航独立成行不再叠内容）。
- `hse-build` 递增至 `2026-09-18.28`。

## 原理

`#app` 锁高 + hidden 溢出 → 每个 `.view` 是 flex 纵列：`.statusbar/.navbar` 为 `flex:none`（固定），`.page` 为 `flex:1`+`overflow-y:auto`（滚动）；底部 `.tabbar-wrap` 作为 `#app` 末尾 flex 行天然贴底。JS 侧本就在切换视图时重置 `.page.scrollTop`，与新结构吻合，无需改动。

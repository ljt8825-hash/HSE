## 一、修复内容

### 修复A：扣分期限文案与后端口径对齐
- 现象：`overview.demeritStatistics` 实为**近5年**（`demerit_date >= 5年前`），但前端 `RiskComposition.vue`「驾驶证扣分」副标题写「**近一年**有扣分记录」，与数据口径不符。
- 改动：web-naive `RiskComposition.vue` 副标题 `近一年有扣分记录` → `近5年有扣分记录`（1 处字符串，无逻辑变更）。
- 决策：web-antd 权威版同为「近一年」（迁移基线即如此，属基线自身口径错误）。经用户确认**仅改 web-naive**，web-antd 权威版保持不动（生产边界规则：不动既有基线/web-antd，后续如需修正另行独立评审）。

### 修复B：三检统计限定当前驾驶员岗位
- 现象：`overview.inspectionStatistics` 对 `hse_driver_inspection_records` **全表聚合**，未限定当前驾驶员；而分母 `driverCount` 是当前驾驶员（`employee_assignment is_current` + 岗位名匹配），分子可能含已调岗/离职人员记录，比例失真。
- 改动：`server/routes/hse-driver-risk-center.js` `/overview` 的 inspectionResult 增加：
  ```sql
  AND vr.employee_id IN (
    SELECT ea.employee_id FROM employee_assignment ea
    LEFT JOIN position p ON p.id = ea.position_id AND p.is_deleted = false
    WHERE ea.is_current = true AND ea.is_deleted = false
      AND (p.name ILIKE '%驾驶员%' OR p.name ILIKE '%司机%')
  )
  ```
  与同路由 `trainingStatistics` 现有口径**同源**（同一 driverCondition + 当前岗位子查询）；修复后「有三检记录人数」分母=分子统一为当前驾驶员。

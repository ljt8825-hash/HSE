## 交付/变更概要

需求「BI 数据看板：这个是按年来的吗？增加月度的」→ 在年份筛选基础上增加月度筛选，语义经用户确认为**单月快照**（选中年份+月份时，所有数字为该月单月口径，非累计）。

变更面：

- **后端 `server/services/biService.js`**：
  - 新增 `biScope(rawReq)`：year 缺省/'all' → null（历年累计）；显式年份 → 年范围；显式年份+month(1-12) → 单月范围 `{year, month, start, end}`；month 非法/缺省回落全年。
  - overview / trend / ranking / mapData 全部接入 scope；响应体新增 `month` 字段，`cumulative` 语义保留。
  - **trend 单月伪 0 修复**：`loadAllDimensionRows` 中 driver_violation / transfer_station_check / 考核表按年过滤（yearLike/tsLike/assessment_year），单月模式下会泄漏同年前序月份行 → `collectMonthlyWithMatcher` 产出选中月之前月份的伪 0 单元格。快照语义下 `trend` 对单月模式 `rawMonths.filter(m => m >= capMonth)` 只保留选中月（验证前：months=[2026-01..2026-05] 伪 0；修复后：months=[2026-05]）。
- **前端 `api/hse/bi.ts`**：OverviewData / TrendData / RankingData / MapData 接口新增 `month: number | null`；getBiOverview / getBiTrend / getBiMap 增加 `month?` 参数；getBiRanking opts 增加 `month?`。
- **前端 `views/hse/bi/index.vue`**：工具栏年份旁新增月份下拉（全年+1~12月，年份=历年累计时禁用）；`monthParam()` 并入 loadAll 六路请求；watch(monthValue) 联动刷新；切回历年累计自动重置月份；指标卡标签与图表卡片标题按范围动态化（历年累计=「隐患累计」、选年=「隐患（2026年）」、选月=「隐患（2026年5月）」）。

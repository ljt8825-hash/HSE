# H5 落表悬浮加载窗 交付与发布（CF-WPS-106，版本 .107）

> 日期：2026-10-16　类别：②交付报告　归属对话：H5 落表悬浮窗（用户两张终屏真机截图 + 指令；「现在发布.107」= 批准计划并实施后发布）
> 改动：**仅 frontend/check.html（+version.json）**——终屏落表状态升级为半透明悬浮加载窗

## 一、需求与方案

- 用户反馈（两张截图 = 终屏「正在上报…」橙色行 /「✓ 已落到飞书多维表格(20:40)」绿色行）：落表状态只是一行小字，点「返回首页」后就看不到了；要求做成**半透明悬浮窗**、点完成后**像加载一样大字**显示。
- 方案（计划文档 `.trae/documents/h5-sync-float-overlay.md`，用户以发布指令批准）：点「返回首页」时未落表 → 深色半透明居中浮层转圈跟随；落定原地切换结果态并自动淡出；离开时已 synced → 成功快闪收尾。

## 二、实施（check.html，~90 行）

1. **CSS**（#hse-busy 后）：`#h5-sync-float` fixed 居中、z-index 9998、容器 `pointer-events:none`（**非阻断**：弱网不挡操作，保住「可先返回」语义）；卡片深色半透明 `rgba(17,24,39,.88)`+`backdrop-filter:blur(8px)`+白字、复用 hsePop/hseSpin 动画、主文案 `--fs-title`/副文案 `--fs-cap`。
2. **JS**（syncToast 后）5 个函数：`syncFloatEl`（单例 DOM）/ `syncFloatPaint`（load 转圈 | done 按 syncState：synced=大绿勾+落表时间、failed=⚠+原因+安心话，文案与 doneSyncLineHtml 同口径）/ `syncFloatShow`（弹出刷新+点卡片收起）/ `syncFloatHide`（淡出 0.2s）/ `syncFloatFollow`（入口：已 synced 快闪 1.8s；否则转圈 + 挂 `syncRecord(rec).then` —— **复用单飞锁，failed 也会再试一次**，落定 synced 2s / failed 4.5s 自动淡出）。
3. **挂点两处**（各加一行）：`showDone` 主路径与「稍后整改」自定义终屏的 `#btn-done-home` onclick → `{ syncFloatFollow(rec); enterHome(); }`。
4. **边界**：boot/轮询补传不弹浮层（仍走 syncToast）；终屏内状态行保留不动；sw.js/Worker/其他页面未动。
5. 版本：check.html 三处 + version.json → **2026-10-16.107**。

## 三、自测（发布前）

- 语法：4 个内联 `<script>` 块 `new Function` 编译 **ALL OK**。
- 浏览器冒烟（本地静态服 + evaluate side effect + 截图核验）**7/7 过**：pending 转圈浮层（深色半透明居中卡）/ `syncFloatFollow` 真回调链（rec 缺三违行为 → 前置校验秒 failed → 原地切失败态）/ 失败态 4.5s 自动淡出 / synced 绿勾+动态时间 / 点卡片提前收起 / `pointer-events=none`（非阻断实测）/ 背景 rgba(17,24,39,0.88)。

## 需求

修改「培训考核 → 培训记录」：列表的数字显示与「现场管理 → 三违管理 → 三违管理考核」列表中的数字一致，且点击功能一致。

## 参考页数字交互模式（三违管理考核）

- 数字用 NTag 胶囊显示：`>0` → warning（可点击，`deduc-click` 光标+悬停增亮），`0` → success。
- 「考核分数」总分列：`>0` → error，`≤0` → success。
- 点击正数弹出「扣分明细」弹窗（NModal preset=card）：分行明细 + 合计，统一分项+合计样式。

## 改动内容（纯前端 1 文件 web-naive training/ledger/index.vue）

1. **缺少人员**（missingCount）
   - 显示：`>0` → NTag warning、可点击；`0` → NTag success。
   - 点击：由原 popover 改为与参考页一致的「数字明细弹窗」——分项列出在岗/已离职未培训名单，底部合计 = missingCount。
2. **资料不完整**（incompleteCount）
   - 显示：与参考页一致（`>0` → warning、`0` → success）。
   - 点击：`>0` 时同样可点击（`deduc-click`）→ 弹出「资料不完整明细」弹窗，展示计数并注明“该计数来自《月度考核结果》台账导入，当前无逐人明细”，避免捏造明细。
3. **培训考核分数**（assessmentScore，= 缺少人数 + 资料不完整）
   - 显示：`>0` → NTag error（对齐参考页「考核分数」列）、可点击；`0` → success。
   - 点击：弹出「培训考核分数明细」弹窗，分项列出「缺少人员 / 资料不完整」+ 合计。

新增逻辑：`openMissingBreakdown` / `openIncompleteBreakdown` / `openScoreBreakdown`、明细弹窗状态；新增 `.deduc-click` 与 `.training-breakdown-*` 样式（走 HSE 主题 token：`--muted-foreground`/`--foreground`/`--border`/`--muted`）；移除已废弃的 popover 相关代码与 `NPopover`、`SigninUntrained` 引用。

## 三次需求（本次补充）：详情弹窗样式对齐「目标职责→自动评分」

将培训记录的数字明细弹窗（缺少人员 / 资料不完整 / 培训考核分数三处）样式对齐为自动评分页 `assessment-monthly/scoring.vue` 的 `sanwei-breakdown` 明细弹窗，仅视觉样式、功能与数据不变：

5. **空态**：文案「暂无明细」→「暂无扣分明细」，颜色由 `--muted-foreground` 改 `#8a919f`，去 `font-size:13px`。

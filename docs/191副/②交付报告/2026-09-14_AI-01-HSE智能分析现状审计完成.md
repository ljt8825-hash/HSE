## 关键冻结事实（供后续 AI 阶段沿用）

1. AI 双轨制字段范本 = `standard_evaluation_items`（AI 轨 ai_* / 人工轨 compliance_status 等）；后续推广到隐患/三违/事故域时保持该命名规范。
2. 唯一模型 Provider 抽象在 `server\services\aiService.js`（grok/ollama，OpenAI 兼容协议未支持）。
3. 前端后续 AI 页面必须使用 Naive UI（web-naive），禁止引入其他 UI 框架。
4. 模型方向（i5-12400 + 32GB 无大 GPU）：本地文字 7B/8B Q4 可行、14B 备选、30B 不可行；视觉 3-4B 优先；日常交互以云端 API 为主。
5. 架构原则：业务数据 + HSE 规则 + 知识库 + 算法 + LLM + 视觉 → AI 综合分析 → AI 证据+建议 → 人工审核 → 正式结果；AI 禁止直接写最终合规状态。

## 需求

## 现状与定位

- 导出实现：前端 CSV 导出（无后端端点），点击导出 → `handleExport()` → `gridRef.value?.gridApi?.grid?.exportData({type:'csv'})`，由 VXE Table 在浏览器端生成并下载 CSV。
- 修复前未传 `filename`，VXE 默认导出文件名（`table`），不体现模块名。
- 菜单名文案：`$t('page.hse.siteGridPatrolMgmt')` → zh-CN「网格长巡查管理」/ en-US「Patrol Management」（`apps\web-naive\src\locales\langs\<lang>\page.json:122`）。

## 改动（仅 1 文件）

`G:\hse-dashboard\安全看板vben\apps\web-naive\src\views\site\grid\index.vue` `handleExport()`（约 288-295 行）：

```js
// 网格导出：复用 HseDataGrid 内置 CSV 导出，文件名带上菜单名便于识别
const gridRef = ref<any>(null);
function handleExport() {
  gridRef.value?.gridApi?.grid?.exportData({
    type: 'csv',
    filename: $t('page.hse.siteGridPatrolMgmt'),
  });
}
```

要点：
- `filename` 是 VXE `ExportConfig` 官方参数（`vxe-pc-ui/types/components/table.d.ts:3048`，`exportData(options?: ExportConfig)` 在 `table-module/export.d.ts:19`）。
- 取 `$t('page.hse.siteGridPatrolMgmt')` 等于菜单名，随当前界面语言自动适配中/英文。
- 导出为浏览器端生成下载（前端 JS，非后端 `Content-Disposition`），中文文件名不会触发后端 `ERR_INVALID_CHAR`（区别于历史上的三违 CSV 裸中文文件名故障）。
- `$t` 已在文件第 32 行导入，无需新增 import。

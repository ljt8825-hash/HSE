## 交付/变更概要

按方案2（BI 接口对齐 HSE 域权威口径 + 前端接通真实图表）完成「安全总览→BI数据看板」改造，三层架构：

1. **后端 service 层**（新增 `server/services/biService.js`）：
   - overview / trend / ranking 全部复用「领导视角统一看板」(`services/leaderDashboardService.js`) 的同源同表聚合函数（`loadAllDimensionRows / summarizeWithMatcher / collectMonthlyWithMatcher / monthlyRows / fillSummaries`），保证 BI 看板与领导看板同一套统计口径，禁止另起 SQL 分叉。
   - overview 公司级 = 全量台账记录数（未归因乡镇记录同样计入，为全公司真实总量）；ranking 乡镇级 = 与领导看板乡镇汇总归因完全一致（fillSummaries）。
   - map / realtime 为 BI 特有轻量聚合，同源表 + `is_deleted=false` 过滤保持一致。
   - 全部端点只读 SELECT，无写入。
2. **后端 controller / 路由**：`server/controllers/biController.js` 薄控制器（复用 leader-dashboard 的 `{__t:'json',body}` 响应契约，异常归一 500）；`server/routes/bi.js` 5 条端点，全部 `requireRole('admin')` + 缓存中间件（BI 30s，realtime 10s），已挂载 `server/app.js` 第 469 行 `/api/hse/bi`。
3. **前端**：`api/hse/bi.ts`（TypeScript 类型契约：Summary10 / TrendRows / Ranking / Map）；`views/hse/bi/index.vue`（ECharts 真实图表：安全指标趋势分析线图[5 维度切换]、隐患乡镇分布饼图、乡镇三违排行横向柱图、事故等级分布饼图、演练乡镇分布饼图 + 6 张指标卡 + 年份筛选[历年累计/近6年] + 刷新）；路由已注册 `router/routes/modules/hse.ts` `HseBi` `/overview/bi`（authority admin），i18n 文案 `page.hse.bi` =「BI数据看板」。

## 一、需求

用户提出「公司查处扣分」列需给出**详细信息**（哪天、哪个人、如何违章、扣几分），并改为**鼠标点击数字**后再显示（而非悬浮），且**非0扣分增加颜色**。

## 二、改动内容

### 后端 `server/routes/hse-sanwei-analysis.js`
- CD 聚合查询新增按日字段：`to_char(inspection_date,'YYYY-MM-DD') AS d`。
- `companyDeductMap` 的 acc 新增 `details: []`，在每条三违记分时 push：
  `{ date(YYYY-MM-DD), violatorName(清洗后含笔误归并/去备注), behavior(违章行为原文), score(5或1) }`。
- `/list` 每行 `companyDeduct` 返回 `details`（与 score/helmetCount/otherCount 严格对账）。

### 前端
- `api/hse/sanwei-analysis.ts`：`Record.companyDeduct` 新增 `details[] { date, violatorName, behavior, score }` 类型。
- `views/site/violation/analysis.vue`：
  - 列插槽由 `NTooltip(hover)` 改为 **`NPopover(trigger=click)`**：点击非0红色数字弹出逐条明细（日期·违章人·违章行为·-N 分），并附头部汇总。
  - 非0扣分数字**红色加粗 + 下划线 + cursor-pointer**（hover 下划线加深）；0 保持灰色。
  - 详情抽屉「公司查处扣分」同样补齐逐条明细列表。
  - import 用 `NPopover` 替换 `NTooltip`。

# 驾驶员风险中心 页面重设计交付（web-naive）

> 日期：2026-09-30　类别：②交付报告
> 场景：用户反馈「右侧页面排版乱、大片留白、非系统组件感」，经确认方案（等高紧凑网格 + 保留 ECharts 换系统色）后实施并发布

## 一、问题诊断（重设计前）

| 症状 | 根因 |
|---|---|
| 大片留白 | `auto-content-height` 下卡片内容撑不满；行内两卡高度不齐（5/12 与 7/12 内容高度不同）；图表固定 200px/220px 高度，卡片下方空 |
| 排版乱 | 卡内重复标题（卡片头"驾驶证扣分分析"+ 内部"扣分分布/TOP扣分驾驶员"）；TopRanking 在 4/12 窄列内 suffix 四件套（分数+标签+两项统计）挤压换行 |
| 非系统组件感 | 混用 antd 迁移残留固定色（`#1890ff` 等）+ shadcn 变量（`hsl(var(--primary))`，naive 不解析失效）；未使用系统既有封装 `HseStatCard`/`HseStatusTag`；大量手写 scoped class |

## 二、改动清单（web-naive 仅 7 文件，未动后端）

| 文件 | 改动 |
|---|---|
| `index.vue` | 布局改为等高紧凑网格：顶部统计卡行 + 两行卡片（等级分布 5/12+构成 7/12；扣分 7/12+TOP排行 5/12）+ 底部事故分析全宽；重算按钮从独占一行移入页面头部 `#extra` 操作区；卡片 `h-full` + 内容区 `fill-height` 撑满 |
| `RiskOverview.vue` | 裸 `NCard+NStatistic` 改为系统组件 `HseStatCard`×4（驾驶员数量 blue / 高风险 red / 扣分 yellow / 涉事 orange） |
| `LevelDistribution.vue` | 环图 `height=220px` 改 `100%` 撑满；图例固定宽 `w-40` 右侧；配色统一 |
| `RiskComposition.vue` | antd 残留色 `#1890ff` → HSE 系统语义色（绿 `#52c41a`/蓝 `#2080f0`/黄 `#faad14`/红 `#f5222d`）；列表项分隔线统一；等高撑满 |
| `DemeritAnalysis.vue` | 顶部 4 统计卡统一 `stat-chip` 浅色底样式、去 shadcn 变量；饼图 + TOP 列表等高撑满（`flex-1 min-h-0`），列表区可滚动 |
| `TopRanking.vue` | suffix 精简为两行紧凑排布（分数+等级标签一行，扣分/事故统计一行）；`h-full` 撑满；等级仍用后端语义色 `riskLevelColor` |
| `AccidentAnalysis.vue` | 顶部 3 统计统一 `stat-chip`；双图（等级饼图+年度柱状图）等高撑满；图表色统一系统语义色 |

设计要点：卡片等高（行内取最高卡，矮卡内容自适应撑满消除留白）；图表 `EchartsUI height="100%"`（`useEcharts` 自带 ResizeObserver 自适应）；色彩单一事实来源 = HSE 语义色板（`components/hse/theme.ts`，Canvas 用固定值：绿 `#52c41a`/蓝 `#2080f0`/黄 `#faad14`/红 `#f5222d`）。

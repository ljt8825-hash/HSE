## 交付/变更概要

修复「三违管理考核」管理员 tab「未按时整改」列**明细与分值不一致**：分值用到新归因但明细接口仍走旧逻辑。

现象：占先洪/张金国等「责任网格长优先」归属的记录，列表中 `rectifiedDeduct`（4 分）与点击弹窗明细（仅 2 条）对不上。根因 = `/unrectified-detail` 接口仍按旧的「违章人直接上级」过滤，其 SQL 连 `grid_id` 都没取，漏掉了「责任网格长」归属的记录。

改动（`server/routes/hse-violation-assessment.js` 的 `GET /unrectified-detail`）：
1. 目标查询补取 `employee_id`；未整改记录查询补取 `grid_id`。
2. 管理员 tab 过滤重写为与 `/list.rectifiedDeduct` 完全同源的归因：**责任网格长优先**（`grid_id→grid_areas.personnel_id→考核目标 employee_id`）+ **违章人直接上级兜底**（`violatorResolver` supervisor + 乡镇候选匹配），逐条算归属 employee_id 后按当前 target 过滤；经理 tab 仍按 `area_team` 乡镇归因不变。

# hse-dashboard 关键对话自动归档机制

> 总入口文档。本机制用于将「关键对话」内容自动沉淀为可检索的 Markdown 归档，避免有价值结论、冻结规则、交付记录与风险待办随对话结束而丢失。

归档根目录：`G:\hse-dashboard\docs\191副`
生效方式：项目规则 `G:\hse-dashboard\.trae\rules\auto-archive.md` + 定时任务（每周批量汇总）

---

## 一、归档内容范围（四类）

| 类别 | 覆盖内容 | 存放目录 |
|------|----------|----------|
| ① 冻结的规则 / 口径 | 经确认不可再改的规则、数据口径、岗位归属、映射表 | `docs\191副\①规则口径\` |
| ② 交付报告 / 执行记录 | 模块交付、数据库变更、测试验收、生产放行 | `docs\191副\②交付报告\` |
| ③ 决策与结论要点 | 关键决策、根因诊断、跨模块结论、进度快照 | `docs\191副\③决策结论\` |
| ④ 风险与待办 | 遗留风险、下一步待办、注意事项 | `docs\191副\④风险待办\` |

## 二、触发机制（两者结合）

**1. 对话内即时归档**
- 对话中一旦产生上述四类「关键」内容，AI 立即按模板写入对应目录的归档文件，并同步更新 `_index.md`。
- 原则：**即时写入，不等对话结束**。

**2. 每周批量汇总（定时任务）**
- 每周自动扫描该周对话总结，汇总各条归档到 `_index.md`，并把新冻结规则沉淀到项目记忆 `project_memory.md`。
- 若本周无新增关键内容，任务不产生新文件（幂等）。


## 四、命名规范

- 归档文件：`YYYY-MM-DD_短标题(中文).md`
- 示例：`2026-09-11_网格巡查身份链生产切换结论.md`
- 同一天多个同类，标题后加序号：`2026-09-11_xxx_02.md`

## 五、索引更新规则（每次归档必做）

在 `_index.md` 顶部插入一行，格式：

```
| 2026-09-11 | 网格巡查身份链生产切换 | ③决策结论 | docs\191副\③决策结论\2026-09-11_xxx.md | 对话X |
```

## 六、与记忆联动

- 每次归档后，把**新冻结规则/口径**同步写入项目记忆 `project_memory.md` 的 `## Auto-Archive Mechanism` 段落后，保证后续对话自动沿用。

## 七、维护说明

- 机制说明、模板、索引、目录均固定在 `docs\191副`，如需改动需单独说明并保持原有结构。
- 不要用归档替代完整交付报告；交付报告仍按既有规范放 `docs\`，归档仅收录关键要点与结论索引。

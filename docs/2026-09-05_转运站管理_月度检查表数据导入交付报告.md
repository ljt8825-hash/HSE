### 2.2 sheet 结构（`月度安全生产检查表`）

横向各列为乡镇（R2 起，F 列起连续排列）；纵向为考核项目块，每个块含若干「子项」行，子项行内各列填该乡镇在该子项的**扣分分值**。与转运站相关的有两个块：

| 块 | 子项数 | 语义 → 写入列 |
|---|---|---|
| **转运站管理**（10分） | 4 | 子项1「每日安全检查填台账」→ `ledger_management`(台账管理)；子项2「制度牌/警示标识牌」→ `sign_management`(标识牌管理)；子项3「私拉乱接/电动车充电」→ `electricity_safety`(用电安全)；子项4「水管水枪收纳」→ `item_placement`(物品摆放) |
| **消防管理**（5分） | 2 | 两子项分值合计 → `fire_management`(消防管理) |

> 行粒度：**每乡镇 × 每月 1 条**（`check_date=YYYY-MM` + `station_code=乡镇`）。

### 2.3 源数据备注

- 各月块结构**完全一致**（转运 4 子行 + 消防 2 子行，独立复核 0 结构异常）。
- 2026-03 全表扣分以**负值**录入（如张大庄台账 -2、长官消防 -4），但该月「总扣分」行均为正——判定为录入符号笔误，导入时**取绝对值**还原扣分幅度（见抽查）。
- 消防管理块**在部分月份排在转运站块之前、部分在其后**，已按块标题匹配而非固定行号，稳健。

## 八、前端修复与界面增强（2026-09-05 追加）

### 8.1 修复：转运站/车辆检查菜单报「API路径不存在」

**现象**：点击二级菜单「转运站管理」列表报错 `API路径不存在：/api/api/transfer-stations...`。

**根因**：`安全看板vben/apps/web-naive/src/api/hse/checkLedger.ts` 内 **18 处接口调用全写了绝对路径** `/api/transfer-stations...`、`/api/vehicle-checks...`；而 `requestClient` 已自动加 baseURL=`VITE_GLOB_API_URL=/api`，最终拼成 `/api/api/...`，后端 catch-all 拦截返回 404「API路径不存在」。**与数据导入无关**（后端 API `/api/transfer-stations` 一直 200 能读到 117 条）。

**修复**：把 `checkLedger.ts` 内 18 处 `/api/transfer-stations...` / `/api/vehicle-checks...` 改为相对路径 `transfer-stations...` / `vehicle-checks...`（与兄弟模块 `site.ts` 一致，由 requestClient 加 baseURL）。

**验证**：`/api/transfer-stations` → 200；`/api/api/transfer-stations` → 404；浏览器实测 `/site/transfer-stations` 实际请求 `http://localhost:5173/api/transfer-stations?...`，表格渲染 20 行、无报错。

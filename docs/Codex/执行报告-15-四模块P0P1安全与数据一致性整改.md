## 三、各任务修复详情

### 任务1：违章权限修复（P0-1）

**写接口权限变更**（6处）：

| 路由 | 原权限 | 新权限 |
|------|-------|-------|
| POST / | requirePermission('hse:site-mgmt:violations') [未注册→403] | requireRole('admin','safety_manager') |
| PUT /:id | requirePermission('hse:site-mgmt:violations') | requireRole('admin','safety_manager') |
| DELETE /batch | requirePermission('hse:site-mgmt:violations') | requireRole('admin','safety_manager') |
| DELETE /:id | requirePermission('hse:site-mgmt:violations') | requireRole('admin','safety_manager') |
| PUT /:id/rectify | requirePermission('hse:site-mgmt:violations') | requireRole('admin','safety_manager') |
| PUT /:id/review | requirePermission('hse:site-mgmt:violations') | requireRole('admin','safety_manager') |

**读接口保持不变**：GET /、GET /:id、GET /stats、GET /filter-options、GET /export/csv、GET /statistics/* 继续使用`requirePermission`读权限（读权限码已注册，viewer可查看）。

**安全错误收敛**：15处catch全部改为`console.error('[Violation] 描述:', err.message)` + `res.json(error(-1, '操作失败，请稍后重试'))`模式。

### 任务2：事故模块鉴权加固（P0-2）

**写接口权限**：POST /、PUT /:id、DELETE /:id、POST /import、POST /:id/attachments、DELETE /:id/attachments/:aid、GET /export 全部使用`requireRole('admin','safety_manager')`。

**安全错误**：14处catch块安全文案具体化（如"创建事故失败"、"更新事故失败"、"查询事故详情失败"等），4处附件/版本路由的`next(err)`改为直接返回安全错误。

**auditLog**：创建/更新/删除/附件上传/附件删除成功后均记录auditLog。

**参数校验**：PUT /:id和DELETE /:id统一使用`const id = parseInt(req.params.id); if (isNaN(id)) return res.json(error(-1, '参数错误：ID必须为数字'));`。

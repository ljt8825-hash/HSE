```
配置来源                    →  启动脚本                 →  后端进程            →  健康检查              →  前端代理
─────────────────────────────────────────────────────────────────────────────────────────────────────
HSE_BACKEND_PORT(可选)  ─┐
                          ├→ $backendPort(默认5666) ──→ set PORT=<port> ──→ $backendHealthUrl ─┐

默认 5666 ──────────────┘        └→ $env:VITE_PROXY_TARGET = "http://127.0.0.1:" + $backendPort ──────┘
                                    （前端 vite 代理 /api、/uploads、/ws 同源，loadEnv 外部 env 优先）
```

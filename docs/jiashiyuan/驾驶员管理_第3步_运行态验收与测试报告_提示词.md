## 二、启动与运行态验收（浏览器）

### 2.1 环境

- 后端：启动共享后端（监听 5800）。注意 driver 三组为**内存模式**，数据重启即清空——验收顺序应在同一进程内完成导入→查询。

- 前端：启动 web-naive dev（5173），用 admin 登录进入。验收用浏览器自动化执行并留存截图/控制台/日志。

### 2.2 验收项（逐条执行并记录 ✅/❌/备注，重要交互截图）

1. **菜单**：侧边栏「现场管理 ▸ 驾驶员管理」可展开，含 3 个三级项（交通安全评估档案 / 驾驶员违章记录 / 月度考核）；逐项点击进入；三级 URL 直接输入可达、刷新不 404、返回不丢失层级。
2. **每页通用**（三个页面都过）：

   - 空数据时表格空态正常、不报错；

   - 4 张统计卡片正确显示（assessment：总数/有效/已过期/待复检；violation：总数/未处理/已处理/待完成整改；monthly：记录数/优秀/合格/不合格）；

   - 新增（必填校验：assessment 至少 name）→ 列表出现；

   - 编辑 → 生效；删除 → 有二次确认；

   - 详情查看（NDrawer）可打开；

   - 内联筛选可筛选。
3. **导入链路**（关键）：

   - 三个模块分别「下载模板」，确认文件名 `driver-assessment|violation|monthly_template.xlsx` 能下载、模板表头与第三节字段一致；

   - 用模板填 1–2 行后上传 → 预览网格列正确 → 确认入库 → 列表/统计刷新；

   - **人员匹配**：构造一条不在花名册的姓名，导入后应弹出不匹配校验；可下载不匹配 CSV；已录数据不因匹配失败而丢失回滚逻辑是否合理（在报告中说明）。

   - 负向：上传空文件/坏文件 → 有明确错误提示，不白屏。
4. **回归确认**：确认 web-antd 侧边栏不再显示「驾驶员管理」（隐藏生效），其余 antd 页面未受影响；后端仅新增 driver 内存数据，未改动 `routes`/`import.js` 结构。

### 2.3 发现问题即修复

- 凡运行态暴露的缺陷（列错位、字段不显示、导入失败、匹配误判等），定位并修复，列明“文件＋改动”。

- 修复后再重跑对应验收项。

## 一、需求目标

在一级菜单「现场管理」下，新增二级菜单「驾驶员管理」。该二级菜单下再挂三个三级菜单业务页面：

## 五、三个页面的业务字段设计

以下字段即「后端内存记录字段」「前端表格列 / 表单 / 详情 / 导入映射」的统一基准确认。

### 5.1 交通安全评估档案（`driver-assessment`）

**统计卡片 ×4**：`档案总数`(蓝) / `有效`(绿) / `已过期`(红) / `待复检`(橙)。筛选态：有效=状态`有效`；已过期=有效期至<今天；待复检=有效期至在 30 天内到期。

**筛选**：姓名(输入)、所属部门(下拉)、评估状态(下拉 有效/已过期/待复检)、建档年份(下拉)。

**表格列**：序号 / 姓名 / 驾驶证件号 / 准驾车型 / 所属部门 / 车辆编号 / 档案编号 / 评估日期 / 评估结果 / 有效期至 / 状态 / 联系电话 / 操作。

**新增/编辑表单字段**：姓名\*、档案编号、驾驶证件号、准驾车型（A1/A2/B1/B2/C1/C2…）、所属部门、车辆编号、评估日期、评估结果（合格/不合格）、评估等级（优/良/中/差，可选）、有效期至、联系电话、备注。

**状态规则**：`状态`由前端按 `有效期至` 与今天比较派生（有效/已过期），导入不单独存状态；`已过期` 红色、`有效` 绿色、`待复检` 橙色。

**详情 Drawer**：展示上述全部字段。

**人员匹配校验**：导入后按「所属部门 → 花名册」匹配 `姓名`，不匹配的列出并支持下载 CSV。

### 5.2 驾驶员违章记录（`driver-violation`）

**统计卡片 ×4**：`违章总数`(蓝) / `未处理`(红) / `已处理`(绿) / `待完成整改`(橙)。

**筛选**：姓名(输入)、车牌号(输入)、违章类别(下拉)、处理状态(下拉 待处理/已处理)、时间区间(DateRange 或 年份下拉)。

**表格列**：序号 / 姓名 / 车牌号 / 违章时间 / 违章地点 / 违章类别 / 扣分 / 罚款(元) / 处理状态 / 处理结果 / 操作。

**新增/编辑表单字段**：姓名\*、车牌号、违章时间、违章地点、违章类别（超速/闯红灯/违停/疲劳驾驶/酒驾/其它）、违章事实描述、扣分(数值)、罚款金额(数值)、处理状态（待处理/已处理）、处理方式、处理结果、备注。

**详情 Drawer**：展示全部字段；违章时间格式化 `YYYY-MM-DD HH:mm`。

**人员匹配校验**：导入后按「姓名 → 花名册」匹配，不匹配列出。

### 5.3 月度考核（`driver-monthly`）

**统计卡片 ×4**：`考核记录数`(蓝) / `优秀`(绿) / `合格`(橙) / `不合格`(红)。

**筛选**：考核月份(月选择器)、姓名(输入)、所属部门(下拉)、考核等级(下拉)。

**表格列**：序号 / 考核月份 / 姓名 / 所属部门 / 得分 / 考核等级 / 安全驾驶得分 / 遵章守纪得分 / 培训学习得分 / 评定人 / 备注 / 操作。

**新增/编辑表单字段**：考核月份\*(默认当前月)、姓名\*、所属部门、安全驾驶得分(0-100)、遵章守纪得分(0-100)、培训学习得分(0-100)、得分(总分，可由三项加总也可手填)、考核等级（优秀/良好/合格/不合格，按得分阈值派生或手选）、主要问题、评定人、备注。

**等级颜色**：优秀=绿、良好=蓝、合格=橙、不合格=红。

**详情 Drawer**：展示全部字段。

**人员匹配校验**：导入后按「姓名 → 花名册」匹配。

## 六、后端 CRUD（内存模式，仿消防设施）

在 `g:\hse-dashboard\server\routes\site-mgmt.js` 中**新增**三组内存资源（不动消防/三违已有逻辑）：

- `memoryStores` 增加：`driverAssessments: []`、`driverViolations: []`、`driverMonthly: []`

- `memoryCounters` 增加：`driverAssessments: 1`、`driverViolations: 1`、`driverMonthly: 1`

- `initMemoryData()` 中补齐对应初始化分支

- 每条记录带 `id / is_deleted / createdAt / updatedAt`

**接口路径**（挂载于 `/api/site-mgmt`）：

| 资源       | GET 列表                | GET 详情                    | POST                  | PUT                       | DELETE                    |
| -------- | --------------------- | ------------------------- | --------------------- | ------------------------- | ------------------------- |
| 交通安全评估档案 | `/driver-assessments` | `/driver-assessments/:id` | `/driver-assessments` | `/driver-assessments/:id` | `/driver-assessments/:id` |
| 驾驶员违章记录  | `/driver-violations`  | `/driver-violations/:id`  | `/driver-violations`  | `/driver-violations/:id`  | `/driver-violations/:id`  |
| 月度考核     | `/driver-monthly`     | `/driver-monthly/:id`     | `/driver-monthly`     | `/driver-monthly/:id`     | `/driver-monthly/:id`     |

**行为约定**：

- GET 列表：支持 `page/pageSize` 分页（上限 200）与按业务字段过滤（姓名、状态、月份、部门等），软删过滤 `is_deleted`；返回 `{ list, total, page, pageSize }`，消息带「(内存模式)」。

- GET 详情 / PUT / DELETE：`is_deleted` 或不存在时返回 `error(-2, '记录不存在')`。

- POST/PUT/DELETE：成功后 `.catch(()=>{})` 写 `auditLog`（`module: 'site-mgmt'`），描述含资源中文名与 ID/姓名。

- 响应统一走现有 `success(...)` / `error(...)` 包装。

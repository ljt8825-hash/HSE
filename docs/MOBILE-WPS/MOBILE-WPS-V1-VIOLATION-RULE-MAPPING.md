## 五、结论与建议

```text
三违规则来源：✅ 已找到（sanwei_behavior_dict + violation-rule.json）
三违规则可导入性：❌ 不可直接导入
```

**NODE-02B 导入前，业务方必须完成**：

| # | 待办 | 影响字段 |
|---|---|---|
| 1 | 补齐「违章指挥」「违章作业」两类行为清单 | `category` |
| 2 | 统一行为名称（骑车未佩戴头盔 vs 骑车不戴头盔） | `name` |
| 3 | 明确组合值的原子化规则（一行为一条 or 允许组合） | `ruleId` / `name` |
| 4 | 确认是否纳入字典外行为（穿拖鞋、未系安全绳、翻越护栏、脱岗玩岗替岗…） | `ruleId` |
| 5 | 提供「适用岗位」口径 | `applicablePosition` |
| 6 | 提供排序规则 | `sortOrder` |
| 7 | 补充行为描述 | `description` |

**本阶段处置**：`t_violation_rule` 继续保持 NODE-01 的 **TEST 占位数据**，**不导入真实三违规则**。

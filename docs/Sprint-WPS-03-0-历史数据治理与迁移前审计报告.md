**幂等：**
- 建议引入 `migrationBatchId`（如 `WPS03_2026MMDD`）写入迁移映射表（可复用既有 `grid_record_sync_map` 或新建 `grid_record_migration_map`，**本 Sprint 不建表**）；
- 以 **WPS Record ID（字符串）** 为幂等键：同一 Record ID 已存在映射 → 跳过；
- `WPS Record ID ≠ 业务编号（serial_no）`，两键分列存储。

**失败处理：**
- 每条状态机 `success / failed / pending_confirm`（落批次台账），失败只重跑 failed 子集，**禁止失败后全量重跑**；迁移前先做 PG 行数/内容快照，迁移后核对 327（+确认后的 12）±0。

## 四、关键修订对比

### 4.1 GET DIAGNOSTICS 语法修复

#### v2.0（错误）

```sql
BEGIN;
UPDATE employee SET is_deleted = false WHERE id IN (...);
GET DIAGNOSTICS rec_count = ROW_COUNT;  -- 变量未声明
COMMIT;
```

#### v2.1（正确）

```sql
DO $$
DECLARE
    rec_count INTEGER;  -- 声明变量
BEGIN
    UPDATE employee SET is_deleted = false WHERE id IN (...);
    GET DIAGNOSTICS rec_count = ROW_COUNT;
    RAISE NOTICE '影响行数: %', rec_count;
END $$;
```

### 4.2 ON CONFLICT 语法修复

#### v2.0（错误）

```sql
INSERT INTO employee_assignment (...) VALUES (...)
ON CONFLICT (employee_id)
WHERE is_primary = true AND is_current = true  -- WHERE 子句位置错误
DO UPDATE SET ...;
```

#### v2.1（正确）

```sql
INSERT INTO employee_assignment (...) VALUES (...)
ON CONFLICT ON CONSTRAINT uk_emp_assign_primary  -- 使用约束名
DO UPDATE SET ...;
```

### 4.4 数据量校验增强

#### v2.0（硬编码）

```markdown
预期结果: recoverable_count ≈ 1304
验证通过: active_employees 应比恢复前增加 ≈1304
```

#### v2.1（动态基线）

```sql
-- Step 0 生成基线
INSERT INTO migration_baseline (migration_id, metric_name, metric_value)
VALUES ('B0_20260728', 'recover_id_count', (SELECT COUNT(*) FROM temp_b0_recover_ids));

-- Step 3 动态校验
SELECT metric_value INTO baseline_count FROM migration_baseline WHERE migration_id='B0_20260728';
IF rec_count NOT BETWEEN baseline_count * 0.98 AND baseline_count * 1.02 THEN
    RAISE EXCEPTION '恢复行数异常';
END IF;
```

## 2. DDL 明细

沿用项目既有 migration 约定（`server/sql/*.sql` 幂等文件，无框架、无版本表），落盘迁移文件 `20260910_grid_inspection_identity_chain_phase0.sql` 并执行：

```sql
-- 1) public.users.employee_id：bigint NULL + 部分唯一索引（NULL 可多行、非 NULL 不重复）
ALTER TABLE public.users
  ADD COLUMN IF NOT EXISTS employee_id bigint NULL;
CREATE UNIQUE INDEX IF NOT EXISTS ux_users_employee_id
  ON public.users(employee_id) WHERE employee_id IS NOT NULL;

-- 2) public.users.must_change_password：boolean NOT NULL DEFAULT false（保护存量 admin）
ALTER TABLE public.users
  ADD COLUMN IF NOT EXISTS must_change_password boolean NOT NULL DEFAULT false;

-- 3) grid_inspection_records.inspector_employee_id：bigint NULL（对齐 employee.id）
ALTER TABLE public.grid_inspection_records
  ADD COLUMN IF NOT EXISTS inspector_employee_id bigint NULL;
```

**设计要点**：
- `employee_id` 唯一性用**部分唯一索引** `WHERE employee_id IS NOT NULL` 实现 —— 一个 employee 最多绑定一个 users，未绑定账号（NULL）可存在多个。避免了 `UNIQUE` 列约束在多 NULL 场景的歧义。
- `must_change_password` 采用 `DEFAULT false`（**非** `DEFAULT true`），确保唯一存量账号 admin 及后续所有默认新建账号不被强制改密。强制改密流程属后续账号初始化阶段，本阶段不实现。
- `inspector_employee_id` 为 **PG 专属身份字段**，本阶段**未**加 `REFERENCES employee(id)` 外键（冻结报告将 FK 列为可选后续项），不进入 WPS FIELD_MAP / canonicalHash / sync_map。

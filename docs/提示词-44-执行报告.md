## 3. 与原提示词的关键偏差（已实勘纠正）

1. **活动文件识别错误**：提示词 §1 diff 假设改 `emergency/index.vue`；实际白名单仅注册 `hse-09-emergency.ts` → 活动文件为 `emergency/plans/index.vue`。`emergency/index.vue` 为未挂载遗留文件（已统一、不响应用户）。改造须落在 `plans/index.vue` 才对线上生效。
2. **表单变量类型差异**：`plans/index.vue` 用 `planForm = reactive<any>({})`（无类型声明），故无需新增 `responsiblePersonId: undefined as number | undefined` 声明（prompt §1.2.2 针对的是有类型声明的 `emergency/index.vue`）。直接 `v-model:value="planForm.responsiblePersonId"` 即可。
3. **`EmployeeName` 导入位置**：violations/goals 原本未导入 `EmployeeName`（仅 accidents/emergency 旧文件用过）。violations 经 Volar 自动导入补全；goals 显式新增 `import { EmployeeName } from '#/composables/hse'`。`EmployeeName` 由 `composables/hse` 经 `export *` 再导出（源 `useEmployeeLink.ts`），确认可用。
4. **应急无独立详情页**：提示词 §1.2.7（详情 Descriptions）不适用于 `plans/index.vue`（其「查看」复用表单弹窗）。表单切 EmployeeSelector 后该诉求自然满足。

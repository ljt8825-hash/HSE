# 扣分配置操作手册（你在页面自己改，不写代码）

- 适用：非技术人员。以后想改“扣多少分、封顶多少、传导给谁”，按本手册在页面操作即可。

- 前置：账号有对应权限（admin）。

***

## 你要记住的 4 个“改分入口”

| 想改什么                        | 去哪个页面                |
| --------------------------- | -------------------- |
| 每个考核项的**封顶分** + 每个子项**扣几分** | 【扣分规则库】→【类别扣分上限】     |
| 某条自动扣分规则的**详细分数/子项分数/来源**   | 【扣分规则库】→【扣分规则】       |
| 某岗位**考核标准**表里的某项分值          | 【人员管理】→【员工档案】→【扣分调整】 |
| 某月某条已算出的**确认扣分**            | 【月度考核】→【扣分审核】        |

***

## 步骤 A：改“封顶分”和“子项扣分”（最常用）

> 例如把“HSE教育培训”封顶从 30 改成 40，或把“缺少”每人从 5 改成 3。

1. 进入【目标职责】→【扣分规则库】。
2. 页面顶部点 **“类别扣分上限”** 标签页。
3. 会看到 5 个考核项，每行有「考核内容 / 扣分 / 状态」。
4. 找到要改的行，点第一列 **编辑**（铅笔）进入行编辑。
5. 在“类别扣分上限”（封顶）列改数字；
   在下方明细里每行“扣分”列改每个子项的分值（如缺训每人 5 → 3）。
6. 点 **保存** 即生效，之后评分按新值算。

## 步骤 B：改某条自动扣分规则的详细分值 / 子项

1. 进入【目标职责】→【扣分规则库】→ **“扣分规则”** 标签页。
2. 用「类别」「扣分方式」筛选或直接搜到那条规则。
3. 点该行 **编辑**，在表单里改：

   - 类别/考核项

   - 触发方式（自动/人工）

   - 扣分方式（固定/累计/明细/阶梯）

   - 分值 / 子项分值 / 封顶
4. 保存；启用状态下生效。

## 步骤 C：改某岗位考核标准某项分值

> 例如把“驾驶员管理”某个标准项从 5 分改成 8 分，以后按新标准算。

1. 进入【人员管理】→【员工档案】→【扣分调整】（考核标准配置）。
2. 顶部用标签切换到岗位（管理员 / 乡镇作业中心经理）。
3. 找到“考核项 / 扣分标准 / 分值”对应行。
4. **直接点分值单元格**改成新数（编辑完自动保存）。
5. 提示“后续评分按修改后的标准计算”。

## 步骤 D：调整某个月已算出的某条扣分

> 审核这一步再改当条分数，或驳回不扣。

1. 进入【目标职责】→【月度安全履职考核】→【扣分审核】。
2. 顶选考核周期，筛选“待审核”。
3. 点某条 **通过**，在弹出的“确认分值”里改成想扣的数；确定即锁定。

   - 想不扣这条：点 **驳回**（必填原因），该条按 0 分计。

***

## 口诀

- 常改的“分数/封顶” → 步骤 A（类别扣分上限）

- 加新的扣分条款 → 步骤 B（扣分规则）

- 换某岗位整个标准的分 → 步骤 C（考核标准配置）

- 某月某一条临时改 → 步骤 D（扣分审核）

> 若改了规则不生效，检查该条规则**状态=启用**，且当月还没**冻结**（冻结后要先解冻再改）。

# UI 架构决策说明

> **决策日期**：2026-07-10
> **决策版本**：v3.0.0
> **当前架构**：自定义 Element Plus 架构
> **vben-admin 版本**：v5.7.0（参考模板，独立存放）

---

## 一、项目现状

### 1.1 目录结构

```
新安全看板/                  ← 主项目（生产版本）
├── src/                      ← 自定义 Element Plus 架构
│   ├── components/layout/     ← 自研 Layout 组件
│   ├── features/              ← 业务模块（15+）
│   └── ...
└── 安全看板vben/              ← vue-vben-admin v5.7.0 模板（独立参考）
    ├── apps/web-ele/          ← Element Plus 版本示例
    └── ...（纯模板，无业务代码）
```

### 1.2 两个项目完全独立

- **主项目**使用 npm 包管理器，`package.json` 中无任何 `@vben/*` 依赖
- **vben 模板**使用 pnpm + turbo monorepo，要求 Node.js ^22.18.0 \|\| ^24.0.0
- 两个项目之间无代码引用、无共享依赖、无构建干扰
- vben 模板仅作为**技术参考**存放，不参与生产构建

## 二、迁移评估

### 2.1 迁移成本评估

| 评估项 | 分析 | 工作量 |
|--------|------|--------|
| Layout 替换 | vben 有完整 Layout 体系，需替换当前自研 Layout | 2 人周 |
| 权限体系适配 | vben 权限体系与当前 RBAC 实现方式不同，需重构 | 3 人周 |
| 路由体系适配 | vben 使用文件路由 + 路由模块化，需适配现有结构 | 2 人周 |
| API 层适配 | vben 有自己的 request 封装，需迁移现有 API 模块 | 2 人周 |
| Store 迁移 | 从 Pinia 直接使用 迁移到 vben store 规范 | 1 人周 |
| 业务模块迁移 | 15+ 业务模块逐个迁移 + 适配 | 8-10 人周 |
| 工作流设计器适配 | LogicFlow 深度定制组件，迁移风险高 | 3 人周 |
| 测试用例重写 | 前端 26 + 后端 127 用例需适配新架构 | 2 人周 |
| 集成联调 + 回归测试 | 全功能回归测试 | 2 人周 |
| **总计** | | **25-30 人周（3-4 人月）** |

### 2.2 风险评估

| 风险项 | 等级 | 说明 |
|--------|:----:|------|
| 生产稳定性 | 🔴 高 | 架构级迁移可能引入大量新 bug |
| LogicFlow 适配 | 🔴 高 | 工作流设计器深度定制，迁移风险不可控 |
| 交付进度 | 🟡 中 | 3-4 人月迁移周期影响后续迭代 |
| 团队学习成本 | 🟡 中 | vben 架构复杂，需时间熟悉 |
| WebSocket 集成 | 🟡 中 | 需重新适配 vben 的插件体系 |

### 2.3 收益评估

| 收益项 | 等级 | 说明 |
|--------|:----:|------|
| 组件丰富度 | 🟡 中 | vben 内置更多业务组件 |
| 主题系统 | 🟢 高 | vben 有完善的主题/暗黑模式 |
| 长期维护成本 | 🟡 中 | 社区活跃，但定制化成本高 |
| 多 UI 库支持 | ⚪ 低 | 当前仅需 Element Plus |
| 代码规范 | 🟡 中 | ESLint / Stylelint / Husky 等工具链更完善 |

## 三、决策结论

### ✅ 决策：暂不迁移，优化当前架构

**核心理由：**

1. **生产稳定性优先**：项目已处于 v3.0 正式交付阶段，此时进行架构级迁移风险过高
2. **成本收益比不合理**：3-4 人月 vs 中等收益，当前架构已完全满足业务需求
3. **无结构混乱问题**：两个项目完全独立，vben 模板仅作为参考存放
4. **定制组件迁移风险高**：LogicFlow 工作流设计器等深度定制组件迁移成本不可控

## 四、当前架构优化（v3.0 已完成）

### 4.1 主题系统

- ✅ 亮色/暗色主题切换（基于 Element Plus CSS 变量）
- ✅ 首次访问跟随系统主题（`prefers-color-scheme`）
- ✅ 主题设置持久化（localStorage + Pinia persist）
- ✅ 全局 CSS 变量体系（`src/styles/variables.scss`）
- ✅ 自定义滚动条样式（亮/暗适配）

### 4.2 Layout 组件

- ✅ LayoutDefault：主布局容器 + 路由切换动画 + keep-alive
- ✅ LayoutSidebar：侧边栏 + 折叠 + Logo + 菜单
- ✅ LayoutHeader：顶栏 + 主题切换 + 语言 + 用户下拉
- ✅ LayoutTabs：多标签页 + 关闭 + 激活态
- ✅ LayoutBreadcrumb：面包屑导航

所有 Layout 组件均使用 Element Plus CSS 变量，自动适配亮/暗主题。

## 六、vben-admin 模板使用说明

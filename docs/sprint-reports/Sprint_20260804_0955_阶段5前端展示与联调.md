## 2. 改动清单

### 2.1 任务5-1：完成率列颜色分级（文件 `src/views/inspection/grid/index.vue`）

- **表格列（bodyCell `#completionRate`）**：由纯 `<Progress :percent>` 升级为按完成率分色：
  - `< 60%` → 红 `status="exception"` + `strokeColor="#ff4d4f"`
  - `60% ~ 79%` → 橙 `status="normal"` + `strokeColor="#faad14"`
  - `≥ 80%` → 绿 `status="success"` + `strokeColor="#52c41a"`
  - 始终显示百分比文字（`format` 渲染 `${percent}%`），`percent` 取值 `record.completionRate ?? 0`（0% 显示灰色空条）。
- **详情抽屉**：同步应用同一套分色逻辑，宽度 `style="width: 200px"`。
- 新增辅助函数（脚本区）：
  - `getCompletionStatus(rate)` → `'exception' | 'normal' | 'success'`
  - `getCompletionColor(rate)` → 对应十六进制色值
  - `formatPercent(percent?)` → 百分比字符串（兼容 antd `format` 的 `percent?: number` 签名）
- **前端不做任何计算**：`completionRate` 直接来自后端 `GET /grid-areas` / `GET /stats` 已动态算好的值。

### 2.2 任务5-2：统计卡片随筛选动态更新（同文件）

- `fetchStats(params?: { year?: number; month?: number })`：调用 `getSiteStats(params)`，将 year/month 透传为 query 参数。
- 新增 `currentFilterParams()`：从 `searchForm.year/month`（字符串）转为 `Number` 后回传，空值转 `undefined`。
- 触发点：
  - `handleSearch()`（关键词/级别/乡镇/状态/年/月 任一 `@change`）：`tableHandleReset()` 后 `fetchStats(currentFilterParams())`。
  - `handleReset()`（重置按钮）：`resetSearch()` 后 `fetchStats()`（year/month 已清空 → 后端默认当前月）。
  - `handleSave()` / `handleDelete()`：操作后 `fetchStats(currentFilterParams())` 刷新统计。
  - `onMounted`：首次 `fetchStats()`（无参数，后端默认当前月）。
  - 导入完成 `@refresh`：同步 `fetchStats(currentFilterParams())`（导入检查记录会改写完成率，统计需刷新）。

### 2.3 任务5-3：API 层（文件 `src/api/hse/site.ts`）

- `getSiteStats(params?: { year?: number; month?: number })`：签名增加可选 `params`，内部 `requestClient.get('/site-mgmt/stats', { params })`。
- 后端 `GET /stats`（阶段4 P1 修复已实现）从 `req.query` 解构 year/month 并透传完成率服务，故前端传参可直接生效。

### 2.4 任务5-4：导入文案改为「检查记录」（文件 `ImportButtonGroup.vue`、`ImportModal.vue`、`grid/index.vue`）

- **关键约束**：`ImportButtonGroup` / `ImportModal` 是**共享组件**，被三违、培训、保险等所有模块复用。**不能硬编码「检查记录」**，否则会污染其它模块文案。
- **方案**：为两个共享组件增加**可选 props**（不传则行为与改动前完全一致，其它模块零影响）：
  - `ImportButtonGroup` 新增 `downloadTip?: string`、`uploadHint?: string`；下载按钮在 `downloadTip` 存在时用 `<Tooltip :title>` 包裹。
  - `ImportModal` 新增 `uploadHint?: string`；上传提示区第二行按 `uploadHint` 显示，缺省回退原通用文案。
  - `grid/index.vue` 中传入：
    - `download-tip="下载检查记录导入模板（三违检查记录表格式）"`
    - `upload-hint="请上传三违检查记录表Excel文件"`
- 兜底模板（`ImportButtonGroup` 内 `moduleHeaders.grid`）在阶段3 已改为 17 列三违检查记录表格式，与后端 `moduleTemplates.grid` 一致。

- 仓库内仍存在 6 处**预置类型错误**（request.ts `Recordable`、vue-i18n、employee/over-age、insurance/vehicle），均不在本次改动范围，属历史遗留，未处理。

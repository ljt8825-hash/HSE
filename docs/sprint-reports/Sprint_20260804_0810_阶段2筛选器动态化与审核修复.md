**3. 前端筛选选项状态 + 拉取**
```ts
const filterOptions = ref<SiteApi.GridAreaFilterOptions>({ gridLevels: [], townships: [], statuses: [], years: [], months: [] });
const townshipOptions = computed(() => filterOptions.value.townships || []);

async function fetchFilterOptions() {
  try {
    const res = await getGridAreaFilterOptions();
    filterOptions.value = { gridLevels: res.gridLevels || [], townships: res.townships || [], statuses: res.statuses || [], years: res.years || [], months: res.months || [] };
  } catch (err) { console.warn('获取筛选选项失败:', err); }
}
// onMounted 中调用 fetchData(); fetchStats(); fetchFilterOptions();
```

**4. 后端 filter-options 接口（核心片段）**
```js
router.get('/grid-areas/filter-options', async (req, res) => {
  try {
    if (!isConnected()) {
      initMemoryData();
      const areas = memoryStores.gridAreas.filter(r => !r.is_deleted);
      const gridLevels = [...new Set(areas.map(a => a.grid_level || a.gridLevel).filter(Boolean))];
      const townships = [...new Set(areas.map(a => a.township).filter(Boolean))];
      const statuses = [...new Set(areas.map(a => a.status).filter(Boolean))];
      return res.json(success({ gridLevels, townships, statuses, years: [], months: [] }, '查询成功(内存模式)'));
    }
    const [lvR, twR, stR] = await Promise.all([ /* DISTINCT grid_level / township / status */ ]);
    let years = [], months = [];
    try {
      const [yR, mR] = await Promise.all([
        pool.query(`SELECT DISTINCT EXTRACT(YEAR FROM inspection_date)::int AS y FROM grid_inspection_records WHERE inspection_date IS NOT NULL ORDER BY y`),
        pool.query(`SELECT DISTINCT EXTRACT(MONTH FROM inspection_date)::int AS m FROM grid_inspection_records WHERE inspection_date IS NOT NULL ORDER BY m`),
      ]);
      years = yR.rows.map(r => r.y); months = mR.rows.map(r => r.m);
    } catch (e) { years = []; months = []; } // 表未建 → 安全降级
    res.json(success({ gridLevels: lvR.rows.map(r => r.grid_level), townships: twR.rows.map(r => r.township), statuses: stR.rows.map(r => r.status), years, months }, '查询成功'));
  } catch (err) { res.json(error(-1, err.message)); }
});
```

## 五、待确认问题

1. **年/月选项当前为空（已知，非缺陷）**：`years`/`months` 来自 `grid_inspection_records` 表，该表属于**阶段4**范围，本阶段尚未创建。因此筛选器中的"年份/月份"下拉在阶段2会显示为空，直到阶段4导入检查记录数据后才自动填充。`GET /grid-areas` 列表接口已接收 `year/month` 参数但**暂不参与筛选**（grid_areas 无检查日期字段），阶段4 计算完成率时会启用——这是有意为之的预留，非遗漏。
2. **P2 处理方式说明**：审核建议方案A（将"负责人"标签改为"职务"）。但详情抽屉中已存在独立的"职务"行（绑定同一 `position` 字段），若再改标签会产生两个相同的"职务"。故本次采用**删除重复"负责人"行**的方式避免误导，更直接。该字段因后端未持久化负责人姓名（表单 `gridPersonnel` 保存时被 `delete`，属既有数据模型缺口），本期仍不展示——是否需在后续阶段补全负责人姓名字段，请确认。
3. **模态框乡镇选项改为动态**：原硬编码 4 个乡镇已移除，模态框新建/编辑的乡镇下拉现复用 `filterOptions.townships`（与筛选器一致）。若数据库当前无网格数据，则新建时乡镇下拉为空——实际环境已有网格数据，可正常回填。

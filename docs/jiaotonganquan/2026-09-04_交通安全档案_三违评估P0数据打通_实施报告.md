## 四、生成三违评估（端到端）

**脚本**：`G:\hse-dashboard\_p0_gen_sw_assessment.py`
**等价于前端「生成三违评估」按钮 + 勾选写入的完整流程**。

### 4.1 计算口径

```
per name:
  by_year[year] = sum(demeritPoints)         # 每年累计扣分
  best_year = max year by扣分                # 取最高年
  best_pts  = by_year[best_year]
  level     = swLevelByPoints(best_pts)      # 阈值映射
```

### 4.2 写入策略

- 通过 `GET /api/site-mgmt/driver-assessments?pageSize=9999` 拉全量档案
- 按 (姓名, 评估类别) 查重：
  - **已存在** → 调用 `PUT` 更新 评估结果 / 评估等级 / 评估日期 / 备注
  - **不存在** → 调用 `POST` 新建（档案编号 `DA-{year}-{seq4}`）
- 部门、风险等级、管控措施等衍生字段留空，由用户在弹窗逐条勾选保存时填写

### 4.3 落库结果

- **新建**：30 条
- **更新**：0 条（首跑全为空）
- **失败**：0 条
- **档案总数变化**：44 → 74（+30）

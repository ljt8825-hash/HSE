## 三、P2 — ECharts 可视化（已完成）

### 3.1 驾驶证评估 Tab：风险等级分布（环形图）

- **数据源**：`tabRows.value`（当前 Tab 全部档案）
- **聚合维度**：按 `assessmentLevel` 分组（重大 / 较大 / 一般 / 较低）
- **空态**：所有等级为 0 时显示"暂无数据"
- **配色**：`CHART_COLORS` 固定色值（Canvas 不解析 CSS 变量），对齐 `RISK_LEVEL_TAG` 语义色

### 3.2 三违评估 Tab：3 图卡片

| 卡片 | 类型 | 数据源 | 聚合维度 |
|---|---|---|---|
| 风险等级分布 | 环形图 | `violationList` 按姓名聚合累计扣分 | `swLevelByPoints(points)` → 重大 / 较大 / 一般 / 较低 |
| 三违类型 TopN | 柱状图 | `violationList` | 按 `violationType || violationDesc` 计数 Top8 |
| 扣分合计排行 | 横向条形图 | `violationList` 按姓名聚合 | 累计扣分 Top10 |

**实现要点**：
- 引入 `@vben/plugins/echarts`（项目已依赖，零新增）
- 4 个 `EchartsUI` ref + 4 个 `useEcharts.renderEcharts` 实例
- `watch` 仅在对应 Tab 可见时渲染（避免 hidden 容器 0 尺寸报错）：
  ```ts
  watch(() => tabRows.value, () => {
    if (activeTab.value === '驾驶证评估') renderLicenseLevel(licenseLevelChartOption.value);
  }, { deep: true });
  ```
- `onTabChange` 切换 Tab 时主动调用 `nextTick()` + 对应图表渲染，确保容器已显示

### 3.3 三违等级映射函数（截图口径）

```ts
/** 三违评估：按累计扣分区间定级（与《附件1 表1》同表头，扣分区间不同） */
function swLevelByPoints(points: number): RiskLevel {
  if (points > 50) return '重大';
  if (points >= 31) return '较大';
  if (points >= 16) return '一般';
  return '较低';
}
```

> 区间对应：较低 ≤15 / 一般 16-30 / 较大 31-50 / 重大 >50（用户截图）

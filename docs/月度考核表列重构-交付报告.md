### 驾驶员姓名从花名册自动获取
- 驾驶员判定：`is_driver === true` 或 `position_name` 含「驾驶员」。
- 同步逻辑 `syncFromRoster(month)`：按 **personnelId 优先、姓名兜底**匹配该月已有记录
  - 已存在 → 仅当姓名有变化才 UPDATE（实现"下次导入花名册自动更新姓名"），并回填缺失的 personnelId
  - 不存在 → CREATE 一条（数值列默认 0），实现"生成固定人员"
- 触发方式：进入页面 `onMounted` 自动同步当前月 + 工具栏「同步花名册人员」按钮手动同步。

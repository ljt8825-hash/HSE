## 三、非阻塞记录（不影响放行）

1. **员工列表 name 残留（范围外）**：naive `hse-personnel.ts` 中员工列表路由为 `HseEmployeeList`（无 icon），基线为 `PersonnelEmployee` + `lucide:user-round`。任务书 §范围条 2 表述「员工列表 `PersonnelEmployee` … 已在前序阶段验收」与实际不符——实为 `HseEmployeeList`。属本批范围外回归项，遗留待后续 name/icon 归一化批次连同其余 `Hse` 前缀视图（iot/workflow/todos/overview/reports 等）统一整改，不阻断本批。
2. **超龄页标题硬编码**：`over-age/index.vue` 使用 `HsePageLayout title="超龄人员管理"`（硬编码中文 + 缺 `:description`），违反任务书 §三「不得硬编码中文标题跳过 i18n」。路由 title 已正确用 `$t('page.hse.overAge')`，但视图页头未用 `$t`，en-US 下页头仍显示中文。轻微 i18n 偏离，建议下一批顺带修正为 `:title="$t('page.hse.overAge')"` + `:description="$t('page.hse.overAgeDesc')"`。
3. **岗位管理「所属部门ID」列显示原始 dept_id 数字**而非部门名，表头亦为「所属部门ID」；属沿用现状未改，非阻断（基线语义待核实，如需显示部门名另列优化）。
4. **日期处理无 dayjs**：超龄编辑弹窗日期用本地 `toIso/toStamp` 替代 dayjs `format('YYYY-MM-DD')`，行为等价；身份证脱敏沿用 naive 既定正则，与 antd slice 实现不同但符合本项目脱敏规范。
5. **`deleteOverAge` 未挂 UI**：后端 DELETE 端点存在，基线超龄列表无删除入口，API 仅作完整性补齐、视图不臆造删除按钮——处理正确。

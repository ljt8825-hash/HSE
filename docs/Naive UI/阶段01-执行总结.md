## 变更文件

### 1. `src/components/hse/theme.ts`（新增）
- HSE 语义色板单一事实来源 `hsePalette`：主色/成功=绿、信息=蓝、预警=橙、危险=红。
- `hseInfoTokens`：Naive `common` 所需的信息蓝色族（设计令牌机制未内置 info CSS 变量，故显式定义）。
- `buildHseThemeOverrides(commonTokens)`：复用 Vben `commonTokens`（来自 CSS 变量，自动适配亮/暗），叠加信息蓝色族，返回 `GlobalThemeOverrides`，供 `NConfigProvider` 注入。

### 2. `src/preferences.ts`（最小化修改）
- 引入 `hsePalette`，通过 `overridesPreferences` 设置：
  - `theme.colorPrimary` / `theme.colorSuccess` = 绿
  - `theme.colorWarning` = 橙
  - `theme.colorDestructive` = 红
  - `app.defaultHomePath` = `/hse/overview`（HSE 入口作为落地页）

### 3. `src/app.vue`（最小化修改）
- 引入 `buildHseThemeOverrides`，将 `themeOverrides` 改为 `buildHseThemeOverrides(commonTokens)`，在官方 `NConfigProvider` 机制上叠加 HSE 主题覆盖（含信息蓝）。

### 4. `src/views/hse/overview/index.vue`（新增）
- 「安全总览」占位页：使用 `Page` + Naive `NCard/NButton/NGrid/NStatistic/NTag` 展示 HSE 语义配色按钮与占位统计，验证外壳/主题/路由链路。无业务逻辑、无接口调用。

### 5. `src/router/routes/modules/hse.ts`（新增）
- 一级菜单路由 `HseOverview`，路径 `/hse/overview`，图标 `lucide:shield-check`，`order: 0`，`frontend` 访问模式下自动进入菜单。

### 6. `src/locales/langs/zh-CN/page.json` & `en-US/page.json`（最小化修改）
- 新增 `hse.overview`（安全总览 / Safety Overview）与 `hse.overviewDesc`。

### 7. `.env`（最小化修改）
- `VITE_APP_TITLE=HSE 安全看板`，强化 HSE 独立入口身份。

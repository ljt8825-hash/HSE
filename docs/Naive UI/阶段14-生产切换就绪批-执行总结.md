## 六、关键技术决策与发现

### 6.1 真实登录 vs 持久化注入

最初尝试了 SecureLS 加密注入（与 Vben `setup.ts` 同配置）、裸 JSON 注入、Pinia 内存调用三种方案，**全部失败**（持久化水合时序/格式问题）。**最终采用真实登录流程**：
- 走最真实的生产等价路径
- 应用自身写 SecureLS，格式必然正确
- 登录本身是关键路径之一，顺便验证

### 6.2 滑块组件精确选择器

通过读 `@vben/common-ui` slider-captcha 源码（`slider-captcha-action.vue`），定位把手元素属性 `name="captcha-action"`，避免依赖脆弱的类名匹配。

### 6.3 端口冲突与 dev 优化

- Vite dev 端口 5888 落在 Windows excluded TCP range `5801-5900`，改用 5180
- Vite cold-compile 700+ 依赖卡住（CLOSE_WAIT），改用 `pnpm build` 产物 + 简易静态服务器
- 静态服务器用 path.resolve 处理 Windows 路径分隔符

### 6.4 admin 密码发现

`users` 表 bcrypt hash，bcryptjs 比对 14 个常见密码，**admin123 命中**（验证批次权限范围内）。

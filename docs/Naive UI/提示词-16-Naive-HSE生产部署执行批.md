# 提示词-16-Naive-HSE生产部署执行批

> 任务来源：Phase 15 审核通过，项目无条件切换就绪。用户通过部署平台界面执行生产切换，需浏览器自动化辅助。
> 批次性质：**阶段 16 —— 生产部署执行批**。通过浏览器自动化在部署平台上完成三步骤：域名确认 → 滑块改 hCaptcha → 灰度部署只读子集。
> 执行环境：部署平台 Web 界面（浏览器自动化），前端 `apps/web-naive`，后端 `server/`。
> 前置条件：Phase 15 元审核通过。

## 二、执行步骤（浏览器自动化）

### Step 1 —— 确认部署域名，开始执行切换

1. 在当前部署平台界面点击第一个卡片「确认部署域名，开始执行切换步骤」
2. 确认当前部署域名（如已有则直接确认，如需输入则使用用户指定的域名）
3. 等待操作完成，确认返回成功状态
4. 截图保存：`_verify/16/01-域名确认.png`

### Step 2 —— 滑块验证改为 hCaptcha

1. 点击第二个卡片「将滑块验证策略改为 hCaptcha 并更新配置」
2. 在验证策略配置中选择 hCaptcha（替代当前的 Vben slider）
3. 如需要 hCaptcha site-key / secret-key，先检查项目 `apps/web-naive` 中是否已有 hCaptcha 配置：
   - 搜索 `.env` / `.env.production` 中的 `HCAPTCHA` 或 `CAPTCHA` 相关变量
   - 搜索 `hcaptcha` 或 `@hcaptcha` 在 `package.json` 中是否存在
4. 如已有配置则直接填入；如无则标记为"需用户提供 hCaptcha 密钥后补填"
5. 保存配置
6. 截图保存：`_verify/16/02-hCaptcha配置.png`

### Step 3 —— 按灰度策略部署只读子集

1. 点击第三个卡片「按灰度策略先部署只读子集页面」
2. 只读子集页面范围（Phase 09 §3.2 灰度建议）：
   - 安全总览（驾驶舱 `/overview/cockpit`）
   - 考核分析（`/assessment-analysis`）
   - 风险地图（`/risk-control/map`）
   - 报表中心（`/reports`）
3. 确认部署范围，触发部署
4. 等待部署完成，获取部署后的访问 URL
5. 截图保存：`_verify/16/03-灰度部署.png`

## 三、部署后验证（CDP 浏览器）

部署完成后，对新的生产 URL 执行快速验证：

| 验证项 | 操作 | 预期 |
|---|---|---|
| 首页可访问 | 打开部署 URL | 显示登录页，无白屏 |
| 登录流程 | admin/admin123 + 滑块（或 hCaptcha） | 成功跳转业务页 |
| 驾驶舱 | 导航到驾驶舱 | 卡片正常渲染，风险总数 56 |
| API 连通 | 检查 Network 面板 `/api/*` 请求 | 全部 200 |

## 六、注意事项

1. 如果 hCaptcha 密钥尚未申请，标记为"待补填"并继续后续步骤，不阻塞部署
2. 如果部署平台需要额外认证（如手机验证码），通过 `browser_waiting_for_user_interaction` 暂停等待用户操作
3. 部署完成后，新 URL 需告知用户，旧 web-antd URL 保留作为回退路径
4. 完成后 **STOP**，产出部署完成报告

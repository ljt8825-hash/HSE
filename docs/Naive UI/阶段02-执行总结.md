| `title`                             | `string`                                                         | 页面标题                                |
| `description`                       | `string`                                                         | 页面描述                                |

| Prop       | 类型                                                               | 说明                            |

## 四、主题一致性修复说明

- **修复前（官方基线 / 阶段 01 遗留门禁）**：`naive.ts` 把 `lightTheme`/`darkTheme` 当作 `themeOverrides` 传给离散 API，语义错误，离散弹层不继承 HSE 绿色主色。
- **修复后**：`configProviderProps` 同时提供 `theme`（亮/暗跟随 `preferences.theme.mode`）与 `themeOverrides: buildHseThemeOverrides(commonTokens)`；后者与 `app.vue` 的 `NConfigProvider` 调用**完全相同的函数与令牌来源**（`commonTokens` 来自 CSS 变量，自动适配亮/暗；并叠加 `hseInfoTokens` 信息蓝）。因此页面内组件与离散弹层颜色完全一致。
- **响应式更新**：`configProviderProps` 为 `computed`（即 `Ref`），`createDiscreteApi` 会随其变化实时刷新主题，亮/暗切换同步生效。
- **调用方兼容**：业务页面仍可 `import { message } from '#/adapter/naive'` 或页面内 `useMessage()`，行为不变。
- **影响与回退**：仅改动本文件；若需回退，还原 `naive.ts` 为官方基线即可，不影响其他文件。

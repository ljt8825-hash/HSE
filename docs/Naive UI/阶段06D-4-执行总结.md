## 四、完备性核验结论

### 4.1 隐患清单视图（naive vs 基线 antd）
- naive 当前（`views/hazards/index.vue`，约 94 行）：统计卡 + 主表 + 分页 + 导入/导出 + 增删改查。
- 基线 antd（约 1570 行）具备而 naive **当前缺失**的能力：
  - 附件管理（上传/预览/删除）
  - 整改提交 / 复查确认 / 关闭隐患 状态流转
  - 隐患提醒抽屉
  - 隐患统计分析抽屉
  - 风险转隐患联动
- **结论**：后端 `server/routes/hazards.js` 已全量支持附件 / 状态流转 / 统计 / risk 关联，故上述缺口属**需净新增的功能工程**，非本批路由整流 + i18n + reports 整改范围。**如实记录为超范围遗留项（非静默跳过）**，待后续批次决策。本批仅做路由与 i18n 对齐。

### 4.2 保险三子模块（personnel / vehicle / other）
- naive 视图已具备：列表 / 分页 / 搜索 / 统计卡 / 导入 / 编辑 / 导出 / 删除；personnel 含花名册 `employeeId` 透视关联。
- 与基线核心能力对齐，**无需补差**。
- API 契约（`api/hse/insurance.ts`）与后端端点 1:1 吻合。

### 4.3 报表中心（reports/index.vue）
- web-naive 中 `reports/index.vue` 为**孤儿视图**（路由模块无任何 reports 路由引用，亦非本批引入）。
- 离散 dialog 修复（`useDialog()` → `import { dialog } from '#/adapter/naive'`）已由 typecheck 通过验证。
- 浏览器导航验证因无对应路由不可达，已在总结中说明（不视为功能缺陷）。

## 三、API 契约逐项

### 3.1 `api/hse/employee.ts`（岗位管理 + 超龄人员）— 核对复用，无改动
- `getDeptTree(params?)`：返回 `DeptNode[]`，岗位管理页部门树筛选/表单共用；**沿用现有返回行为**，未实现"展示全部（含未授权范围）department"语义。
- `getPositionList({deptId,keyword,jobCategory,isSpecialPost,page,pageSize})`：支持服务端筛选分页，与基线一致。
- `getOverAgeAutoList({page,pageSize,keyword,gender})` / `getOverAgeAutoStats()` / `getOverAgeAutoDetail()` / `exportOverAgeAutoList()`：签名与基线 + 后端一致，复用。
- `OverAgeAutoStats.thresholds` 键为**中文** `男`/`女`（后端权威来源 `config/hseRules/employee-age-rule.json`），前端不再维护 `male/female` 副本。

### 3.2 `api/hse/employee-profile.ts`（员工档案）— 核对复用，无改动
- `getProfileList / getProfileDetail / getProfileAssignments / getProfileDriverInfo` 齐全，请求参数与返回结构（详情 `basic`/`currentOrg`/`assignments`/`driverInfo`）与基线一致。

### 3.3 `api/hse/insurance.ts`（超龄保险管控）— 补全 4 函数
| 函数 | 端点 | 后端核实 |
|---|---|---|
| `getOverAgeDetail(id)` | GET `/insurance/overage/:id` | ✅ `server/routes/insurance.js:2527` |
| `createOverAge(data)` | POST `/insurance/overage` | ✅ `:2540` |
| `updateOverAge(id,data)` | PUT `/insurance/overage/:id` | ✅ `:2556` |
| `deleteOverAge(id)` | DELETE `/insurance/overage/:id` | ✅ `:2583` |

- 四类端点均带 `requireRole('admin','safety_manager')`（`insurance.js:2447/2540/2556/2583`）。
- 字段键名对齐后端 snake_case：`control_type / actual_insurance / has_injury / has_employer / compliance / expire_date / optimize_status / optimize_date / optimize_remark`。
- 附件/版本沿用既有 `getInsuranceAttachments('overage',bizId)` / `uploadInsuranceAttachment('overage',bizId,file,{uploadedBy})` / `deleteInsuranceAttachment('overage',bizId,id)` / `getInsuranceVersions('overage',bizId)`（`:2601` 的 `VALID_BIZ_TYPES` 含 `'overage'`）。
- `deleteOverAge` 为 API 完整性补齐，**未**挂入 over-age 视图 UI（基线超龄列表无删除入口），不臆造前端删除按钮。

### 4.3 `over-age/index.vue`（超龄人员）— 已补齐（本批最大）
以 `web-antd/.../employee/over-age/index.vue` 为行为契约，在既有列表/统计卡/规则说明基础上补齐：
- ✅ name 改正 `PersonnelOverAge`。
- ✅ 4 张统计卡保留（`超龄人员总数 / 男性超龄 / 女性超龄 / 70岁以上`），`byGender['男'/'女']`、`byAgeGroup['70岁以上']` 对齐后端中文键。
- ✅ `ruleDescription` 阈值读取改 `stats.thresholds['男']/['女']`，缺失回退 60/50 占位（修掉原 `male/female` 恒回退 bug）。

  - 基本信息：阈值 `NAlert`（男性/女性 X岁 + 当前年龄/超龄年数）+ `NDescriptions`（姓名/性别/身份证号脱敏/工号/出生日期/年龄/年龄阈值/超龄年数/部门/岗位/联系方式脱敏/人员类型/人员分类/是否公益岗），数据取自当前行 record，不额外调 `getOverAgeAutoDetail`。
  - 附件列表：上传按钮（`NUpload` `:default-upload="false"`，accept pdf/doc/docx/xls/xlsx/png/jpg/jpeg，单文件 <10MB 校验）+ 附件表（文件名/版本/大小/上传人/下载+删除），走 `getInsuranceAttachments/ uploadInsuranceAttachment/ deleteInsuranceAttachment('overage', bizId)`，`bizId = record.over_age_id || record.id`。
  - 历史版本：版本表（版本号/变更类型/变更说明/操作人/变更时间），走 `getInsuranceVersions('overage', bizId)`；变更类型文案/颜色映射对齐基线（create→新增/绿, update→更新/蓝, import→导入/绿, revise→修订/橙, delete→删除/红）。
- ✅ 编辑（保险管控弹窗 `NModal`）：9 字段——`control_type`(重点关注/一般关注/定期复查)、`actual_insurance`、`has_injury`(工伤险 有/无)、`has_employer`(雇主险 有/无)、`compliance`(合规/不合规/待确认)、`expire_date`(`NDatePicker`)、`optimize_status`(待处理/处理中/已完成/无需处理)、`optimize_date`(`NDatePicker`)、`optimize_remark`。打开时 `record.over_age_id` 存在则 `getOverAgeDetail` 反填，否则默认；保存存在 `over_age_id` 走 `updateOverAge` 否则 `createOverAge`（带 `personnel_id/name/id_card/gender/birth_date/age/dept/position`），日期 `toIso('YYYY-MM-DD')`，成功后刷新列表+统计。
  - 注：因 web-naive **无 dayjs 依赖**，日期用本地 `toIso/toStamp`（时间戳↔'YYYY-MM-DD'）替代 dayjs；`has_injury/has_employer` 用 `NRadioGroup+NRadio`（boolean 值，规避 `NSelect` 不接受 boolean 的已知坑）。
- ✅ 导入：启用工具栏「导入」入口 + 「下载模板」，接 `useGenericImport('over-age')` + `HseImportDialog`（module `over-age` 对应后端 `import.js` 的 `over_age_personnel` 表，模块名「超龄人员管控」），确认导入成功后 `bindRefresh(onRefresh)` 刷新列表+统计。
- ✅ 导出：原 stub 改为真实 `exportOverAgeAutoList()`（Blob → CSV 下载，文件名 `超龄人员清单_YYYYMMDD.csv`），含非 CSV/文本（JSON 错误）响应的解析报错处理。
- ✅ 工具栏顺序：刷新→下载模板→导入→导出（无「新增」，`create` hidden），符合标准动作顺序。

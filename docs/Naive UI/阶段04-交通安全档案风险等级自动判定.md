## 二、🔴 核心判定口径（复议修订后 · 长期不变式）

第一轮实现后用户提出三条纠错原则，据此重构判定引擎。**这是本模块最重要的约定，后续任何改动必须遵守：**

> **表1 每一档都是「年限前置 + 记分阈值 + 行为枚举」三者绑定的整体。**
> 行为枚举的评估窗口必须继承**该档自己的年限**，不能统一压到 12 个月；
> 行为自身携带的限定条件（高速/城市快速路、超速比例、记分档位）**不得剥离**。

### 2.1 窗口口径

| 口径 | 窗口 | 用途 |
| --- | --- | --- |
| 本年度记分 | 近 **12** 个月（`windowScore`） | 记分阈值累加，仅此一处用 12 月 |
| 重大档 / 较大档行为 | 近 **2** 年（`severeW2` / `majorW2`） | 表1 重大、较大档行为枚举 |
| 一般档前置 | 近 **3** 年（`severeW3`） | 「近3年无严重交通违法」→ 下限抬升至「较大」 |
| 较低档前置 | 近 **5** 年（`severeW5` / `lowExcludeW5`） | 「近5年无严重交通违法 / 无酒驾·超速50%以上·闯红灯·逆行」→ 下限抬升至「一般」 |

### 2.2 行为规则库

- **SEVERE_RULES**（重大档严重违法）：醉驾、毒驾、肇事逃逸、无证驾驶、造成人员死亡事故、逾期未审验/未年检、逆行**（须"高速公路或城市快速路"前置）**、超速**记12分**等。
- **MAJOR_RULES**（较大档）：闯红灯、超速**记6分**、不按规定让行、违法占用应急车道等；条目支持 `minPoints?` 绑定记分档位。
  - ⚠️ **"逆向行驶"已从较大档移除** —— 表1 中逆行只出现在①重大档（带高速/快速路前置）②较低档排除项，普通道路逆行不构成「较大」。
- **LOW_EXCLUDE_RULES**（较低档排除项，新增）：酒驾、醉驾、超速50%以上、闯红灯、逆行。近 5 年命中 → 下限抬升至「一般」，命中项通过 `lowExcludeHits` 输出。
- 超速按记分分档：记 12 分 → 重大 / 记 6 分 → 较大 / ≤3 分 → 一般。

### 2.3 判定顺序（`calcDriverRisk`）

```
1. severeW2 命中            → 重大（近2年严重交通违法）
2. maxSingle≥12 或 windowScore≥12 → 重大
3. maxSingle≥6              → 较大
4. windowScore≥9            → 较大
5. majorW2 命中             → 较大（近2年表1较大档行为枚举）
6. windowScore 7~8          → 较大（空档兜底）
7. windowScore 4~6          → 一般
8. lowExcludeW5 命中        → 一般（较低档排除项抬升下限）
9. 否则                     → 较低
```
最后再套 `floor` 下限：`severeW3` → 不低于「较大」；`severeW5` → 不低于「一般」。

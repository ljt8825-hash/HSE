## 四、子批 19B — 数据展示优化

### 4.1 日期格式统一

所有表格中的日期时间字段，统一为 `YYYY-MM-DD` 格式（去掉时间部分和 `T`）。

修改方式：在表格列定义中，对日期字段使用 `formatDate` 函数或 `cellRender`。

参考已有实现（Phase 13 已做过 `emergency/materials`）：

```ts
// 如果列定义中使用 render 或 cellRender
{
  title: '入职日期',
  key: 'hireDate',
  render: (row) => formatDate(row.hireDate),
}
```

或用 vxe-table 的 `formatter`：

```ts
{
  field: 'hireDate',
  title: '入职日期',
  formatter: ({ cellValue }) => formatDate(cellValue),
}
```

需要修改的页面：
- 目标责任书管理（入职日期）
- 安全费用预算（计划使用时间）
- 规章制度（生效日期）

- 三违管理（日期、创建时间）
- 消防设施（安装日期、到期日期、检查日期）
- 网格管理（检查日期）

- 员工档案（入职日期）

- 培训记录（培训日期）

- 组织管理-部门员工表（入职日期）

### 4.2 空值统一显示

所有表格中，空字符串 `""`、`null`、`undefined` 统一显示为 `-`（灰色）。

修改方式：在列定义中设置默认的 `formatter` 或使用 vxe-table 的全局空值配置。

```ts
// 如果列中没有特殊 formatter
formatter: ({ cellValue }) => cellValue || '-',
```

需要修改的页面（空值问题突出的）：
- 消防设施管理（类型、检查日期、联系电话）
- 网格管理（联系电话、所属乡镇、检查日期）

- 证书管理（证书编号 → 显示"未生成"）
- 应急演练（类型、级别、日期、地点、组织单位）
- 培训计划（培训师、实际计划）

### 6.2 消防设施管理 — 检查日期预警

1. 在统计卡片区域增加"即将到期"和"已过期"计数
2. 表格中"到期日期"列：到期前 30 天标记黄色，已过期标记红色
3. 实现方式：在 `cellRender` 中判断日期，返回带颜色的 `<NTag>`

```ts
{
  field: 'expiryDate',
  title: '到期日期',
  cellRender: ({ row }) => {
    const days = dayjs(row.expiryDate).diff(dayjs(), 'day');
    if (days < 0) return h(NTag, { type: 'error' }, '已过期');
    if (days <= 30) return h(NTag, { type: 'warning' }, dayjs(row.expiryDate).format('YYYY-MM-DD'));
    return dayjs(row.expiryDate).format('YYYY-MM-DD');
  },
}
```

### 6.3 超龄人员 — 风险分级

在表格中增加"风险等级"列，根据超龄年数分级：

| 超龄年数 | 风险等级 | 颜色 |
|---|---|---|
| ≤5 年 | 低风险 | 绿色 |
| 6-10 年 | 中风险 | 橙色 |
| 11-15 年 | 高风险 | 红色 |
| >15 年 | 严重风险 | 深红色 |

```ts
function getOverAgeRiskLevel(years: number) {
  if (years <= 5) return { label: '低风险', type: 'success' };
  if (years <= 10) return { label: '中风险', type: 'warning' };
  if (years <= 15) return { label: '高风险', type: 'error' };
  return { label: '严重风险', type: 'error' };
}
```

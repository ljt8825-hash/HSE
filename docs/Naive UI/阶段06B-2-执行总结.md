## 三、API 契约对照（goals.ts 适配层，逐项保持旧版 URL/方法/参数/响应）

| 分组 | 函数 → 端点 | 说明 |
|---|---|---|

| 责任书录入/详情/删除 | `lookupEmployees` GET `…/employees/lookup`；`createResponsibility` POST / `getResponsibility` GET / `updateResponsibility` PUT / `deleteResponsibility` DELETE `/objectives/employees/responsibility[/:id]` | 员工远程检索保存 employeeId |

## 四、保留的旧版业务能力

1. **责任书**：统计卡 4 张（员工总数/已签订/未签订/签订率，**已签订/未签订可点击联动筛选**，再点取消）；关键词/部门/签订情况（含「未签订·无源」）筛选；服务端分页；「查看」详情；「录入/编辑责任书」弹窗（员工远程检索 `lookupEmployees`，保存 employeeId，禁用自由文本）；删除（软删除二次确认）；**专用导入弹窗**（下载模板 + .xlsx/.xls/.csv 选择 + 结果 Alert 含新增/更新/未匹配/总数/未匹配样例）；**对账差异次级入口**（统计卡区独立按钮，非导出/新增伪装）。
2. **安委会**：Tab1 安全人员只读（`getEmployeeList` 安环管理部，关键词/状态筛选、服务端分页、统计卡、详情抽屉）；Tab2 活动台账（列表/关键词/分页、查看文件=受保护 Blob `window.open` 预览、新增/编辑/删除、**PDF 上传**（仅 .pdf、展示 storedName/originalName、可移除）、**模板下载**、**Excel 导入**（.xlsx/.xls、返回插入条数））。
3. **考核**（隐藏路由）：列表/关键词·年份·状态筛选、统计卡（总数/优秀/平均分/合格率）、详情抽屉、新增/编辑/删除、**员工选择保存 employeeId + 自动带出姓名/部门/岗位**（NSelect remote `getEmployeeSelectorList`）。旧版为**全量拉取 + 前端过滤分页**（pageSize 9999 + filteredData/pagedData），本页保持一致（任务书"以旧版为准"）；列表端点 `/hse/assessment` 与写入端点 `/objectives/responsibility` 的既有契约未改动。
4. **预算**：服务端分页 + 服务端统计卡（计划总额/已支出/执行率/项目数）；关键词/年份/状态筛选；**列集按年份动态**（2026 起显示「OA计划支出 + 实际支出」双栏，旧版行为）；**表单 24 字段全保留**（预算年度/科目/类别/措施项目/名称/规格品牌/用途及依据/使用部门地点/计划使用时间/计划·OA·实际的 数量·单价·总价/使用状态/状态/备注）；金额单位按旧版（单价/总价万元录入，提交 ×10000 元，不前端重算覆盖服务端值）；导入复用 `useGenericImport('budget')`（端点已核实 200）。

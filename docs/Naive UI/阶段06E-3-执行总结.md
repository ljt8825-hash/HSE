## 六、遗留项（移交 Codex 审核决定）

### 【P1 · 路由重名冲突】`hse-advanced.ts` 已预置同名路由

发现：`src/router/routes/modules/hse-advanced.ts` **已存在** `HseIot` / `HseSupplyChain` 两条路由（位于 `高级分析` 顶层菜单，`path: /hse-advanced/iot`、`/hse-advanced/supply-chain`，使用**同一视图组件**与**相同 route name**）。本次按任务 §三 在 `hse.ts` 插入同名路由后，产生 **vue-router 重复 name**。

影响（实测）：
- 无运行时报错（vue-router 仅抛 warning，未计入 console error；CDP 报告 `consoleErrors: []`）。
- `/overview/iot` 可正常渲染，面包屑正确为 `安全总览 / IoT物联网`。
- 但导航至 `/overview/iot` 时，**侧栏将 iot/supply-chain 显示在 `高级分析` 分组下**（源自 `hse-advanced.ts`），故浏览器层面侧栏子菜单顺序暂未在 `安全总览` 下呈现「warning-center → iot → supply-chain → alerts」的基线 1:1 顺序（**静态 `hse.ts` 顺序已正确**，见 §二）。

建议（超出本批红线「唯一改动文件 hse.ts」，故未自行执行，移交评审）：
> 将 `hse-advanced.ts` 的 `HseIot` / `HseSupplyChain` 两子路由移除（并修正 `HseAdvanced.redirect` 避免悬空 `/hse-advanced/iot`），使两页仅留存于 `hse.ts`（`/overview`）——与基线 `hse-01-overview.ts` 归属一致、消除重名。移除后侧栏顺序将与基线 1:1。
> 注意：`hse-advanced.ts` 的 `HseAdvanced` 顶层菜单当前可见子项仅有 iot/supply-chain（其余 risk-profile-detail 为 hideInMenu），移除后该顶层菜单将无可见子项，建议一并评估其去留。

现状已遵守红线：本批**未触碰** `hse-advanced.ts`，冲突作为遗留项明确移交 Codex 审核。

3. **孤儿视图处置**：`views/training/driver/index.vue`、`views/training/new-employee/index.vue` 不在基线 5 条路由内（旧版遗留功能），**保持未接线状态，未新增路由、未删除文件**，仅按任务书要求迁移其 API import 路径（`#/api/hse/training`），避免遗留 `#/api/training` 死引用。

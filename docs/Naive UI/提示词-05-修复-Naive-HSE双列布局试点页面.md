## 一、必须修复的确定问题

### 1. 路由 name

- `/personnel/departments` 的路由 `name` 必须恢复为 web-antd 基线 `PersonnelDepartments`。
- `/standards/relation` 的路由 `name` 必须恢复为 web-antd 基线 `StandardsRelation`。
- 检查任何按路由 name 的导航、缓存或测试引用并同步必要处；不得改路径、中文标题、图标、authority 或其他已通过页面。

### 2. 部门表单真实校验

- 为 `NForm` 增加正确的 `ref` 和 TypeScript 类型。
- 保存前必须 `await formRef.validate()`；校验失败时不调用新增/更新 API、弹窗保持打开、聚焦/错误信息由 Naive 表单显示。
- 校验通过才进入加载态和请求。接口失败时保持弹窗开启，不得显示成功。
- 浏览器实测：空编码、空名称、缺少层级各一次，确认无写请求；再用合法值完成一次成功保存（测试数据按任务书要求清理）。

### 3. 关联列表关闭无意义分页

- 当前 relation 页面已声明 `:pager="false"`，但截图仍显示 VXE 分页栏。修正 `HseDataGrid` 的无分页配置，使传入 `false` 时显式禁用 VXE pager；不得在 relation 页面伪造分页或本地分页。
- 若改动公共组件，检查所有现有调用方，避免破坏实际需要服务端分页的页面；至少复测部门员工列表仍显示真实 total 和可翻页。
- 在 relation 页面选择条款后验证：关联列表无“共 N 条/每页/页码”控件；部门员工列表保留分页控件。

### 4. 试点页面视觉收口

- 修正部门树中“公司 / 公司”等无区分重复标签：组织类型与层级必须可区分，或只显示一个，不得丢失语义。
- 组织详情操作按钮使用语义正确的既有 Lucide 图标：编辑用 `Pencil`（或项目等价图标），删除用 `Trash2`（或项目等价图标）。保留现有文案、危险语义、二次确认与权限控制。
- 评估并移除条款关联页面包裹双列工作区的非必要大 `NCard`；保持边界、间距、亮暗主题和移动端无横向溢出。不得将页面区段改成卡片嵌卡片。

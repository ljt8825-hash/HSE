## 1. 初始诉求与可行性结论

用户提出：分析项目，将每个一级菜单、二级菜单右侧页面的表格格式统一，并参照 Vben Analytics 示例的 VXE 表格能力组合，包括自定义单元格、行编辑、表头升序/降序排序。

结论：可以实现。实施方向是以统一的 Naive UI + Vben + VXE 公共组件封装列表页面结构、搜索区、操作工具栏、状态标签、导入弹窗和表格列规范，同时保留各页面已有的业务接口、权限与数据语义。

后续讨论确认：

- 排除列宽拖动和列顺序拖动；
- 保留点击表头的升序、降序排序，但仅在后端已有对应排序参数时接入服务端三态排序；无接口契约时不显示可排序表头；
- 表格表头应居中；
- 长文本应以 tooltip 省略，避免撑破列宽；
- 页面可采用双列布局、可拖动分栏、文本省略等已验证的 Vben 交互能力，但必须先核对其是否适配现有业务页面与权限模型。

## 2. 主题与迁移策略

用户询问应先改主题还是先改表格、改为 Naive UI 版本涉及多少代码、功能是否保持不变。

讨论后采用的策略：

1. 先完成 Naive UI 应用骨架、主题与公共组件的基础能力，再分批迁移业务页面；
2. 迁移目标不是只替换表格外观，而是统一页面交互和组件使用方式；
3. 原有业务功能、接口、权限和数据语义必须保持，UI 改造不能擅自改变后端契约；
4. 具体代码影响比例应以实际页面、组件、路由和 API 契约盘点为依据，不能在未盘点前给出虚假的固定比例；
5. 导入、下载模板、新增、刷新、导出等同类动作统一命名、排序、颜色与可用性规则。无真实端点的动作必须隐藏，不能只展示按钮。

## 3. 已确认的统一设计约束

用户确认按建议执行并要求将设计约束固定下来，使后续 AI 执行时可知晓并遵守。项目据此建立了 `docs/Naive UI/01-强制设计约束.md` 和总体实施计划。

核心约束包括：

- 使用 Naive UI、Vben、VXE 和项目现有 HSE 公共组件；不得混入 Ant Design Vue；
- 列表页统一使用页面布局、搜索面板、操作栏、状态标签、数据表格和导入对话框等公共组件；
- 操作栏顺序固定为：刷新、下载模板、导入、导出、新增；仅展示真实可用动作，新增是唯一主按钮；
- 表格表头居中，长文本 tooltip 省略；禁止列宽拖动和列顺序拖动；
- 导入统一为“下载模板 -> 上传文件 -> 解析/校验预览 -> 确认导入 -> 结果”流程；
- 所有页面保留旧版路由、权限、接口 URL/方法/参数/响应结构与真实业务能力；
- 不能通过 `ignoreAccess`、`publicRoutes` 或类似机制绕过权限；
- 没有安全授权时不得创建、编辑、删除生产数据，不能伪造浏览器、接口或写入成功证据；
- 每个 WorkBuddy 执行批次都必须有 Markdown 提示词和 Markdown 执行总结；Codex 审核总结与实际代码后再生成下一批提示词。

## 5. 阶段推进纪要

### 阶段 01 至阶段 04

- 阶段 02：建立公共页面与操作组件；
- 阶段 03：建立 VXE 统一表格与导入组件；

这些阶段形成了当前可复用的 `HsePageLayout`、`HseSearchPanel`、`HseActionBar`、`HseStatusTag`、`HseDataGrid`、`HseImportDialog` 等基础能力。

阶段 05 涉及组织管理、制度标准与条款资料关联。审核中发现过路由权限、关联确认闭环、角色验收、临时脚本敏感信息、正式服务进程等问题。

用户在当前对话中最终明确追认并允许以下范围：

- `hse-standard-relation.js` 最小角色校验修复及正式 `5800` 重启；
- 创建、确认、删除隔离 pending 关联与人工关联对照数据；

- 清理历史 `_verify_tmp` 临时脚本和产物；
- 权限模型为：`safety_manager` 可见组织管理但只读，条款关联严格仅 `admin` 可访问。

该授权和技术复验完成后，阶段 05 通过，总体进度更新为 `05 / 07`。

### 阶段 06A：迁移盘点

阶段 06 不直接做无边界的全量迁移，而是先盘点菜单、可见/隐藏路由、旧版页面、Naive 现状、API 契约和分批顺序。

盘点经过多轮修正后确认：

- 旧版基线为 60 条子路由、17 条隐藏路由；
- 已验收回归页与菜单外视图需隔离处理；
- 待迁移内容按风险与复杂度拆分为多个 06B 批次；
- 月度安全履职考核被单独放入 06B-3，不得与常规目标职责页面混迁。

### 阶段 06B-1：现场管理迁移

06B-1 迁移现场三违、消防设施、网格管理。经历多轮审核后，修复了统计/字段、无真实导出的按钮、`HseSearchPanel` 的 `NGrid` 上下文、Naive `NSelect` 回调签名以及网格年/月筛选参数等问题。

06B-1 最终通过，允许进入唯一下一批：06B-2 目标职责迁移。

### 审核中确认合格的内容

- 无真实导出端点的页面不展示导出动作；
- 未引入 `ant-design-vue`；
- 独立执行 `pnpm --filter @vben/web-naive run typecheck` 与 `pnpm --filter @vben/web-naive run build` 均通过；diff 空白检查通过。

### 本次审核的阻断项

结论：**06B-2 不通过**。总体进度保持 **`05 / 07`**，阶段 06 当前状态为 **06B-2 目标职责修复待审核**。

| 优先级 | 问题 | 影响 |
|---|---|---|
| P1 | 考核和预算页未把通用导入的预览列、预览数据、校验错误、确认中、结果状态传入 `HseImportDialog` | 上传后无预览，确认按钮永久禁用，无法触发确认导入 |

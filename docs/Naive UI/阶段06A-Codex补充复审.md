旧版 `views/inspection/grid/index.vue` 有“三违记录”操作入口和抽屉；其 `loadGridViolations` 明确使用 mock 数据，真实 `GET /violations/by-grid` 只是未实现的后端 TODO。当前 06B-1 仅写“网格三违集成不在范围”，没有指定如何保持现有 UI 行为，可能导致迁移时直接删掉该入口，违反功能不变约束。

## 一、必须完成的前端修复

### 1. 风险地图必须加载完整数据集

- 当前表格 `data` 仅为当前 20 条分页记录，不能直接作为地图数据源。
- 打开风险地图时，按当前筛选条件调用既有 `getRiskList` 拉取完整地图集；以当前总量 56 为基准可使用 `page: 1, pageSize: 500`，并保留加载、失败和筛选变化后的刷新处理。
- 地图标记、乡镇风险计数和点击信息必须基于完整地图数据；列表行高亮只在当前页存在对应行时生效。
- 完成后在浏览器验证：翻到非第一页前后，地图风险点数量和乡镇计数不再随当前列表分页被截断；筛选后地图只显示筛选结果。

### 2. 修正地图失败状态和道路图例

- GeoJSON 请求失败时，设置用户可见的失败/降级状态；不要只 `console.warn` 后静默跳过，也不得制造新的控制台 warn/error。
- 将道路图例的 `style="background: r.color"` 改为正确的 Vue 动态样式绑定，实际显示各道路等级颜色。
- 地图 SDK、边界请求和图层切换都必须有可预期的加载、成功和失败状态。

### 3. 修正导入失败时的刷新语义

- `useGenericImport` 只允许在 `confirmImport` 成功结果后调用 `bindRefresh` 注入的刷新函数。
- 当 `outcome === 'failed'` 时显示失败结果、保留可诊断信息，不得刷新列表或显示成功。
- 不得伪造 confirm 成功、修改后端 API 或吞掉服务端错误。

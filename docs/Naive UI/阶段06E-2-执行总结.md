## 七、偏离项 / 遗留项（须 Codex 复核确认）

### ① 考核分析 dual-API 整合（实质性偏离，已文档化于代码注释）
基线 `assessment-analysis` 子组件（`DeductionDetail` / `TargetProgress` / `IndicatorAnalysis`）原从 **`#/api/hse/assessment`**（`getTargetProgress`/`getIndicatorAnalysis`/`getDeductionDetail` + `AssessmentApi.*`）与 `assessment-analysis.ts` 双文件取数。web-naive **无 `assessment.ts`**，故整合为单一 `assessment-analysis.ts` 的 5 端点，子组件改为经 `props` 接收聚合数据。
- 字段映射修正：`IndicatorAnalysis` 的「严重三违」目标字段由 `o.targets.violationSeriousCount` 改为 `o.actual.violationSeriousCount`（`Targets` 无该字段，该字段在 `actual` 上）。
- `DeductionDetail` 使用 `DeductionData.reasonAnalysis` 按 `reasonType` 聚合（无额外 API 调用）。
- **影响**：数据流向与基线不同（基线多文件分散请求 → 本批单文件聚合）；功能等价，但属于真实偏离，需 Codex 确认可接受。

### ② assessment-analysis/index.vue 硬编码标题
`title="公司HSE考核分析中心"` 为硬编码，未转 `$t`（accident-analysis / warning-center 已用 `$t`）。属非阻塞遗留（prompt §六允许「据实标注遗留」）。

### ③ warning-center 去除 HelpButton
基线引用 `#/components/hse` 的 `HelpButton`（`menuCode HSE_WARNING_LIST`），但 web-naive 无 `HelpButton`/`ImportButtonGroup`（见项目 MEMORY）。按 §二约定降级：移除 import 与模板 `<HelpButton>` 用法，未谎报后端导入能力。

### ④ warning-center `useDialog`/`useMessage` → 离散实例（关键修复）
`app.vue` 未挂载 `NDialogProvider`/`NMessageProvider`，原 `useDialog()` 在 setup 顶层调用导致整页挂载崩溃（CDP 报 `No outer <n-dialog-provider /> founded`）。改用 `#/adapter/naive` 的离散 `dialog`/`message`（与 `overview/index.vue`、`reports/index.vue` 等既有视图一致）。**此修复是 warning-center 通过浏览器验证的前提。**

### ⑤ alerts / notifications 标题遗留
两列表页 `HsePageLayout title` 沿用既有硬编码（非 `$t`），整流核对阶段未强制改写，非阻塞（prompt §六允许）。

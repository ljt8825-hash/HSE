### 2.3 组件/组合式复用（web-naive 既有模式）

- **员工远程检索**：复用 `api/hse/goals.ts:lookupEmployees`（与 `objectives/responsibility` 同模式），NSelect `filterable remote` + `employeeSelectOptions`（`工号 - 姓名（部门）` 标签），保持「员工 ID/编号/姓名」关联语义。

- **不引入** `EmployeeSelector` / `EmployeeName` 组件（基线 antd 专用，移植成本高），采用 web-naive 既有 `lookupEmployees` + `getEmployeeSelectorBatch` 等价方案。

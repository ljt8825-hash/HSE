## 四、HseSplitPane 实现要点（对应任务书 §一）

- **桌面**：`display:flex`，左栏 `width/flexBasis` 由 `leftWidth` 驱动，默认 `DEFAULT_W=280`；`MIN_W=220 / MAX_W=420` 约束。
- **拖动**：Pointer Events（`pointerdown/move/up/cancel`），`setPointerCapture`；拖动中 `document.body.userSelect='none'` + `.hse-split-no-select`；`pointerup`/`pointercancel`/`blur`/`window blur`/`onBeforeUnmount` 全部清理（`cleanupDrag()`）。
- **持久化**：`localStorage.setItem(storageKey, width)`，key 由调用方传页面维度明确的 key（`hse-dept-split-width` / `hse-standard-split-width`）；仅当前浏览器保存，不同步上传；读取时 `clamp(220, 420)` 校验。
- **移动端**：`matchMedia('(max-width: 767.98px)')` 响应式切换；<768px 左栏变 `NDrawer`（width 320，placement left），由带 `PanelLeft` Lucide 图标 + `NTooltip`「打开目录」按钮打开；右侧始终可用。
- **键盘**：分隔条 `tabindex=0` + `role="separator"` + `aria-label/orientation/valuenow/valuemin/valuemax`；`ArrowLeft/Right` 小步 ±16px，`Home→220`、`End→420`，操作后持久化。
- **主题**：分隔条 grip 用 `hsl(var(--border))` / hover 用 `hsl(var(--primary))`；按钮/抽屉用 Naive 组件继承 HSE 主题令牌，无硬编码语义色。
- **不改变 Vben 全局侧栏**：组件仅作用于自身容器；不提供表格列宽/列顺序拖动（HseDataGrid 已 `resizable:false`）。

**浏览器证据**（截图 `_verify_tmp/shots_s5/`）：
- 拖动：280px → 340px（`01_dept_page` 后），`localStorage['hse-dept-split-width']='340'`，刷新后恢复 340px；
- 键盘：ArrowRight×2 → 312px、End → 420px、Home → 220px；
- 移动端 375px：`documentElement.scrollWidth=375=clientWidth`（无溢出）；「打开目录」按钮 → NDrawer 打开（`06_mobile_drawer.png`）。

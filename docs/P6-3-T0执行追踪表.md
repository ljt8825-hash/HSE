## 三、异常处理决策树

```
Step 0 某检查 FAIL
  ├─ 是否 P0 阻断？
  │   ├─ 是（S10 uk 缺失 / S13 her 偏差>5% / S15 baseline NULL）
  │   │   └─ 修复 → 重跑 Step 0 → 仍 FAIL → 延期
  │   └─ 否（S4 锁冲突 / S5 活跃连接）
  │       └─ 等待/清理 → 重跑 → 仍 FAIL → 评估是否延期
  │
B-2 迁移 FAIL（S22/S24）
  └─ 立即执行 06_Rollback.sql B-2 回滚段（L14-66）→ 排查 → 修复 → 重跑
  │
只读保护验证 FAIL
  ├─ 触发器未生效（S28）→ 检查触发器是否存在 → 重新创建（S27）→ 重验
  └─ 权限未拒绝（S30）→ 检查 REVOKE 是否执行 → 重新执行（S29）
  │
只读保护需回滚（方案 C 互补，须两步都做）
  ├─ DROP TRIGGER × 3 + DROP FUNCTION（ReadOnly_Change.sql Step 4，已激活）
  └─ GRANT INSERT/UPDATE/DELETE TO hse_app_user（方案 C 反向，⚠️ 全文档缺失，须现场补写）
```

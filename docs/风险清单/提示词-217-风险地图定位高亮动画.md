# 提示词-217：风险清单"在地图中查看"定位高亮动画

## 背景

提示词-215 已实现风险清单 ↔ 风险地图双向联动（行点击跳转 + 地图回跳高亮行），但跳转后地图仅做 setCenter+InfoWindow 弹窗，**缺少视觉强调**。用户需要：点击清单中某条风险后跳转地图，能**一眼看到风险所在位置**，风险位置要素（道路/区域）按风险等级颜色高亮闪烁。

### 专业决策说明（已由执行者确定，不再询问用户）

1. **不闪烁整条道路**：G104（京岚线）贯穿宁津县约30公里，整路闪黄等于误导用户"整条路都是三级风险"。参考杜邦Safety Dashboard、中石化HSE系统、北京环卫安全管控平台的做法，仅高亮**距离风险点最近的路段**（约300-500m范围）。
2. **保留"查看"详情功能**：不修改现有"查看"按钮行为（打开详情Drawer），新增独立的"在地图中查看"按钮（地图定位图标），避免功能退化。同时整行点击（Drawer关闭时）也触发同样的定位高亮效果。
3. **廊万线/宁东路数据缺失处理**：`ROAD_NETWORK_DATA` 中无"廊万线""宁东路"道路数据（OSM导出数据未覆盖），仅高亮数据中匹配到的道路（G104→京岚线、S339→宁武线），缺失的道路不做报错，在InfoWindow中用灰色小字提示"部分道路数据未覆盖"。
4. **动画采用脉冲波纹+呼吸闪烁**：Marker 采用脉冲波纹（类似滴滴定位），匹配路段采用颜色呼吸闪烁，两者组合视觉引导清晰且不刺眼。

function handleLocateOnMap(record: RiskControlApi.RiskSource) {

## 任务二：风险地图页定位高亮动画（map.vue）

### 2.1 存储道路 Polyline 引用

在 `map.vue` 中新增模块级变量：

```typescript
// 道路 Polyline 引用数组（用于定位高亮）
let roadPolylines: { polyline: any; data: RoadData }[] = [];
// 当前高亮的元素，用于清除
let highlightState: {
  pulseMarker: any | null;       // 脉冲波纹 Marker
  targetMarker: any | null;      // 目标风险点原始 Marker（用于恢复）
  highlightedRoads: { polyline: any; origColor: string; origWeight: number; origOpacity: number }[];
  highlightTimer: ReturnType<typeof setTimeout> | null;
  breathTimer: ReturnType<typeof setInterval> | null;
} = {
  pulseMarker: null,
  targetMarker: null,
  highlightedRoads: [],
  highlightTimer: null,
  breathTimer: null,
};
```

在 `renderRoads` 函数中，每次创建 `new AMap.Polyline(...)` 后，将其 push 到 `roadPolylines`：

```typescript
roadPolylines.push({ polyline: poly, data: road });
```

### 2.2 增强 focusRisk 函数，添加动画高亮

修改现有 `focusRisk` 函数（或新增 `focusRiskWithAnimation` 函数），在现有 `setCenter + setZoom + open InfoWindow` 基础上，增加以下效果：

#### 2.2.1 清除上次高亮

在执行新的高亮前，先调用 `clearHighlight()` 清除上一次的动画效果（恢复道路样式、移除脉冲Marker等）。

#### 2.2.2 脉冲波纹 Marker

在风险点坐标处创建一个自定义 HTML Marker，使用 CSS 动画实现脉冲波纹效果：

```typescript
function createPulseMarker(position: [number, number], levelColor: string): any {
  const pulseDiv = document.createElement('div');
  pulseDiv.className = 'risk-pulse-marker';
  pulseDiv.innerHTML = `
    <div class="pulse-ring" style="border-color:${levelColor}"></div>
    <div class="pulse-ring pulse-ring-2" style="border-color:${levelColor}"></div>
    <div class="pulse-core" style="background:${levelColor}"></div>
  `;
  const marker = new AMap.Marker({
    position: position,
    content: pulseDiv,
    offset: new AMap.Pixel(-15, -15),
    zIndex: 200,
    clickable: false,
  });
  mapInstance.add(marker);
  return marker;
}
```

#### 2.2.3 查找并高亮最近路段

实现 `highlightNearbyRoads(riskLng, riskLat, levelColor)` 函数：
- 遍历 `roadPolylines`，对每条道路 Polyline，计算其 path 中距离风险点最近的点
- 距离 ≤ 500米 的道路段纳入高亮（欧氏距离近似：`√(Δlng²+Δlat²) × 111000 ≤ 500`）
- 保存原始样式（origColor、origWeight、origOpacity）到 `highlightState.highlightedRoads`
- 修改匹配道路的样式：`strokeColor` 改为等级颜色、`strokeWeight` 加粗至 7、`strokeOpacity` 提升至 0.9
- 未匹配到任何道路时（如道路数据缺失），跳过不报错

#### 2.2.4 呼吸闪烁动画

使用 `setInterval` 每 600ms 切换高亮道路的透明度在 0.5-1.0 之间循环（呼吸效果），共持续约 8 秒后自动停止并恢复原样。

```typescript
let breathPhase = 0;
highlightState.breathTimer = setInterval(() => {
  breathPhase = (breathPhase + 1) % 20;
  const opacity = 0.55 + 0.4 * Math.abs(Math.sin((breathPhase / 20) * Math.PI));
  highlightState.highlightedRoads.forEach(({ polyline }) => {
    polyline.setOptions({ strokeOpacity: opacity });
  });
}, 80);
```

#### 2.2.5 自动清除高亮

8秒后自动调用 `clearHighlight()`：
- 停止呼吸定时器
- 恢复所有高亮道路的原始颜色/线宽/透明度
- 移除脉冲 Marker
- InfoWindow 不关闭（用户仍可查看详情）

如果用户在高亮期间点击地图其他地方（map click）、点击其他风险点、关闭 InfoWindow，也应立即清除高亮。

### 2.3 修改 route.query.riskId 处理逻辑

在 `loadAndRenderRisks` 末尾，现有处理 `riskId` 的代码基础上，增加对 `focus` 参数的判断：

```typescript
const riskId = route.query.riskId;
const focusMode = route.query.focus; // 'animate' 或 undefined
if (riskId) {
  const target = allRisks.value.find((r: any) => r.id === Number(riskId));
  if (target) {
    setTimeout(() => {
      if (focusMode === 'animate') {
        focusRiskWithAnimation(target); // 带动画高亮
      } else {
        focusRisk(target); // 原有行为（仅定位弹窗）
      }
    }, 800);
  }
  router.replace({ query: {} });
}
```

同时，地图页 InfoWindow 中"在风险清单中查看"链接（反向联动）不需要动画，保持 `focus: undefined` 即可（反向跳转是为了看列表高亮，不需要地图动画）。

## 验收标准

1. 风险清单操作列有"定位"按钮（地图图标），点击后跳转风险地图
2. 跳转后地图自动缩放到风险点（zoom=16），风险点有黄色（三级）/红色（一级）等脉冲波纹动画
3. 距离风险点 500m 内的道路段变为对应等级颜色、加粗、呼吸闪烁 8 秒
4. 8秒后道路恢复原色，脉冲消失，InfoWindow 保留
5. 点击地图其他地方或其他风险点，高亮立即清除
6. G104/S339 等存在数据的道路正常高亮；廊万线/宁东路等缺失数据不报错，InfoWindow 有提示
7. "查看"按钮仍打开详情Drawer（功能不退化）
8. 整行点击（Drawer关闭时）同样触发定位高亮动画
9. 构建通过，无 TS 报错

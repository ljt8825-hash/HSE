## 七、已知边界（诚实提示）

1. **清单页分页**：`index.vue` 的 `onMounted` 高亮用 `riskList.value.find`，仅搜索**当前页**数据（默认 pageSize=10）。若目标风险位于非当前页，列表内可能查不到 → 不高亮（但 URL 已清，无报错）。原提示词示例代码亦采用此方式；如需 100% 命中跨页风险，需先按 `riskId` 定位所属分页再 `fetchData`——属增强项，非本提示词要求。
2. **聚合态定位**：`focusRisk` 调用 `setZoom(16)`，会触发 `onRiskZoomEnd` 展开单个风险点，确保目标 Marker 可见后再弹窗，逻辑自洽。
3. **InfoWindow 样式**：链接使用内联 `hsl(var(--primary))` 主题令牌，随深浅色自适应，与既有 `.iw-*` 弹窗风格一致；未新增 `<style>` 规则。

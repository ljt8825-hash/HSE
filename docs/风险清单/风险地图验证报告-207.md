## 一、任务一：公园 / 乡镇名称改为 Hover（悬浮）显示

### 1.1 公园名称（含康宁湖）

**Before**：`renderParks` 用一个不可见 `AMap.Marker`（0×0 gif 图标 + `label` 属性）在多边形几何中心**常驻显示**公园名称，视觉干扰大（中心公园、福宁河景观带、新河公园、康宁湖等始终有文字浮在地图上）。

**After**：
- 删除常驻 `labelMarker` 整个创建与 `addOverlay` 逻辑（原 L599–L613）。
- 在公园 `Polygon` 上监听 `mouseover` / `mouseout`：
  - `mouseover` → 在鼠标位置（事件 `e.lnglat`）弹出轻量 `InfoWindow`（`.hover-tip` 样式：白底、圆角 4px、小字号 12px、padding 4px 8px、轻微阴影）。
  - `mouseout` → 关闭该 Tooltip。
- 康宁湖（`KANGNING_LAKE_POLYGONS`）与人工公园共用同一渲染循环，自然遵循同一规则。
- 悬浮 Tooltip 与点击详情共用**单实例 `hoverInfoWindow`**，打开新窗口前 `closeClick()` 关闭点击窗，保证同一时刻只显示一个气泡。

### 1.2 乡镇边界名称

**Before**：乡镇边界多边形仅注册 `click` 事件，弹出只含乡镇名的 InfoWindow；名称本就无常驻 label（无需改显示逻辑）。

**After**：
- 在乡镇 `Polygon` 上新增 `mouseover` / `mouseout` 监听（L378、L382），`mouseover` 时在鼠标位置显示乡镇名 Tooltip（`.hover-tip`），`mouseout` 关闭。
- `click` 行为保留并升级（见任务二）。

### 事件监听方式
- 多边形悬浮：`poly.on('mouseover', (e) => openHover(name, [e.lnglat.lng, e.lnglat.lat]))`
- 多边形移出：`poly.on('mouseout', () => closeHover())`
- 共享实例：`let hoverInfoWindow`（L? 模块级，于 `openHover` L830 处创建）

## 二、任务二：要素点击显示区域内所有风险点

### 2.1 乡镇边界点击（L386）

点击乡镇边界多边形，InfoWindow 内容由"仅乡镇名"改为**该乡镇内风险点列表**：
- 顶部：乡镇名称（加粗大字 `.iw-title`）。
- 第二行："该区域共 X 个风险点"（`.iw-count`，数量 `X` 按区域内**最高风险等级着色**：一级红 `#f5222d` / 二级橙 `#fa8c16` / 三级黄 `#faad14` / 四级绿 `#52c41a`）。
- 下方：风险点列表，每条「风险名称（等级）」，等级用 8px 色圆点标识（`.risk-dot`）。
- 列表项可点击（`onclick="window.__mapFocusRisk(i)"`）：调用 `focusRisk` → `map.setCenter + setZoom(16)` 定位到该风险点并弹出其详情 InfoWindow。
- 超过 10 条只显示前 10 条 + "...还有 N 条" 提示（`.risk-more`）。
- 无风险点时显示"该区域暂无风险点数据"（`.risk-empty`）。

### 2.2 乡镇名称映射（L859 `matchRisksByArea`）

匹配规则（按优先级）：
1. 精确匹配：`risk.area === townName`；
2. 去后缀匹配：去掉 GeoJSON 名称末尾 `镇/乡/街道` 后 `risk.area === stripped`；
3. 包含关系：`risk.area.includes(townName) || townName.includes(risk.area)`；
4. 去后缀后的包含关系：`risk.area.includes(stripped) || stripped.includes(risk.area)`。

### 2.3 公园 / 康宁湖点击（L604）

点击公园多边形，InfoWindow 展示公园名称 + **中心 500m 范围内**的风险点（`matchRisksNearPark`，L874）：
- 距离判定：以多边形中心为圆心，欧氏距离 `√(Δlng²+Δlat²) × 111000 ≤ 500m`（规范 §6.2 简化球面距离）。
- 中心点已在 `renderParks` 中缓存到 `parkCenters[name]`（L600 附近）。
- 内容格式与乡镇一致（名称 + 数量 + 列表 + 可定位）。

### 2.4 道路点击（L?）

保持不变：道路非区域要素，点击仍仅显示道路名称与 `desc`（已统一走 `openPopup` 单实例，逻辑不变）。

### 风险点定位交互
- 详情窗复用 `buildRiskDetailHtml`（L?），展示类型/事故/等级/场所/管控部门。
- 列表项点击经 `window.__mapFocusRisk(idx)` → `focusRisk`（L946）→ 地图定位 + 详情气泡。

### XSS 防护
- 所有动态内容（乡镇名、公园名、风险名、类型、场所、区域、desc）经 `escapeHtml()`（L824）转义 `& < > " '` 后再拼入 HTML 字符串。

## 八、遗留与建议

1. **风险点坐标仍为哈希兜底（承接 206 遗留）**：61 条风险点 `lng/lat` 为哈希占位，导致"乡镇/公园风险列表"匹配到的坐标并非真实位置，列表定位（`focusRisk` 的 `setCenter`）会落到占位点。属数据侧待补充，非本交互缺陷；业务方补齐真实 GPS 后，列表与定位将自动准确。
2. **乡镇名称匹配依赖 `risk.area` 字段**：若数据库 `area` 与 GeoJSON `properties.name` 命名差异较大（如带"县/区"后缀），当前去后缀策略（镇/乡/街道）可能漏配，建议后续在后端建立"乡镇标准名 ↔ 数据库 area"映射表以提升命中率。
3. **公园周边 500m 判定**：采用简化欧氏距离（规范 §6.2 允许），对狭长公园（如福宁河景观带）的边角点可能漏判，如需精确可改用点在多边形内（ray-casting）判定；当前按规范实现，不影响主流程。
4. **悬浮 Tooltip 样式**：使用高德默认 `InfoWindow` 气泡承载 hover 提示，鱼骨箭头为默认外观，符合规范"与高德默认 Tooltip 风格一致"要求；如需完全无箭头的小标签，后续可切换为 `AMap.Tooltip` 插件（规范 §6.1 亦允许）。
5. **单 InfoWindow 实例**：hover 与 click 各用独立实例，常规操作流程中同一时刻仅一个可见；极边缘场景（hover A 多边形同时 click 窗口开于 B）可能短暂双显，不影响数据正确性，符合"打开新窗口前关闭旧窗口"的约束精神。

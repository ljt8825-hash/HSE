## 六、任务三：弱化乡镇边界

### 6.1 当前问题

`map.vue` 的 `renderBoundary` 使用 12 种鲜艳颜色 + `fillOpacity: 0.12` + `strokeWeight: 2` + `strokeOpacity: 0.9`，边界线条过于明显，视觉杂乱。

### 6.2 修正要求

修改 `map.vue` 中 `renderBoundary` 函数的渲染参数，使乡镇边界"若有若无"——仅作为参考底图，不喧宾夺主：

| 参数 | 当前值 | 目标值 | 说明 |
|------|--------|--------|------|
| `fillOpacity` | `0.12` | `0.04` | 填充几乎不可见 |
| `strokeWeight` | `2` | `1` | 描边细线 |
| `strokeOpacity` | `0.9` | `0.35` | 描边半透明 |
| `strokeStyle` | `'solid'` | `'dashed'` | 虚线边界，区分于道路实线 |

### 6.3 配色方案调整

将 12 种鲜艳颜色替换为**统一低饱和度色系**，使各乡镇边界颜色统一但略有区分：

```typescript
const colors = [
  '#d4c5b0', '#c8d4bc', '#bcc8d4', '#d4c0c0', '#c0d4cc',
  '#c8c0d4', '#d0d4c0', '#c0c8d4', '#d4ccc0', '#c0d4c0',
  '#ccc0d0', '#d0ccc4',
];
```

> 设计意图：统一暖灰/冷灰基调，各乡镇之间仅微弱区分，视觉上退为背景层。

### 6.4 修改位置

仅修改 `map.vue` 的 `renderBoundary` 函数（约 L296–L341）：
- 修改 `colors` 数组（L303–L306）
- 修改 `fillOpacity` / `strokeWeight` / `strokeOpacity` / `strokeStyle`（L317–L323）

**禁止修改**：`renderBoundary` 以外的任何 `map.vue` 代码。

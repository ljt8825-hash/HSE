## 一、任务概览

提示词-217 在提示词-215 双向联动基础上，为"在地图中查看"这一跳转增加**视觉强调**：跳转后地图自动缩放到风险点（zoom=16），风险点叠加**脉冲波纹 Marker**，且距离风险点 500m 内的**匹配路段**按等级颜色加粗并**呼吸闪烁 8 秒**后自动复原；点击地图空白/其他要素立即清除。同时新增清单页操作列"定位"按钮，并新增缺失道路（廊万线/宁东路等）的灰色提示。

## 六、专业审视：发现的一个小问题

审核中发现一个**轻微问题**（不影响功能，但从专业角度值得记录）：

**脉冲 Marker 没有与风险点原始 Marker 做显隐联动**：当前 `createPulseMarker` 是叠加在原始 Marker 之上的新 Marker，原始风险点 Marker（带颜色圆点图标的那个）在动画期间仍然可见，导致视觉上是"两个点叠在一起"（原始圆点 + 脉冲波纹+核心）。8秒后脉冲消失，原始 Marker 保留。这在视觉上是可以接受的（脉冲核心覆盖在原始 Marker 上方），但如果追求更精致的效果，可以在动画期间隐藏原始 Marker、动画结束后恢复。当前实现选择不隐藏原始 Marker，是为了避免对聚合 Marker 逻辑的侵入，属于合理的工程权衡。

**建议**：如果后续用户反馈"两个点叠在一起有点怪"，可以在 `focusRiskWithAnimation` 中记录目标 Marker 并暂时隐藏，`clearHighlight` 中恢复。当前版本可先交付，观察反馈。

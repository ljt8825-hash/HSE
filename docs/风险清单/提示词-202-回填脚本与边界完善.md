### 4.3 脚本功能

```
node server/scripts/backfill-risk-coords.js [--dry-run|--execute] [--help]
```

**功能**：
1. 连接数据库，查询 `risk_sources` 表中 `lng IS NULL OR lat IS NULL` 的记录
2. 按五级优先级策略匹配坐标：

| 优先级 | 策略 | 匹配逻辑 |
|--------|------|----------|
| 1 | 转运站精确匹配 | `location` 包含转运站名称 → 使用该转运站坐标 |
| 2 | 自有设施匹配 | `location` 包含"办公室"或"仓库" → 使用对应坐标 |
| 3 | 公园范围匹配 | `location` 包含公园名称 → 使用公园中心坐标 |
| 4 | 乡镇模糊匹配 | `location`/`sheet` 包含乡镇名 → 使用 `TOWNSHIP_CENTERS` 坐标 + 微小偏移 |
| 5 | 哈希分配 | 以上均不匹配 → 按 `id` 确定性哈希分配到一个乡镇中心 |

3. 默认 `--dry-run`：仅打印匹配统计和 SQL 语句，不写入数据库
4. `--execute`：在事务中执行 UPDATE，失败回滚
5. `--help`：打印使用说明

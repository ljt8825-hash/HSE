## 三、技术实现

### 3.1 技术架构

- **框架**：vue-vben-admin v5.7.0，使用 `<script setup lang="ts">` + Composition API + Pinia。
- **地图引擎**：高德地图 JS API **v2.0**，运行时动态注入 `<script>`（`webapi.amap.com/maps?v=2.0&key=…&plugin=AMap.PolygonEditor,AMap.Geocoder`），加载前设置 `window._AMapSecurityConfig.securityJsCode`。
- **坐标系**：GCJ-02（高德原生），与所有数据源一致，无需转换。
- **页面容器**：`Page`（`@vben/common-ui`）+ Ant Design Vue `Card/Row/Col/Space/Tag/Divider/message`。

### 3.2 六图层设计（OverlayGroup）

地图初始化时创建 6 个 `AMap.OverlayGroup` 图层组，便于统一显隐控制：

| 图层 key | 名称 | 数据来源 | 渲染方式 | 颜色 / 样式 |
|----------|------|----------|----------|-------------|
| `boundary` | 乡镇边界 | `fetch('/geojson/ningjin-boundary.geojson')` | `AMap.Polygon`（fillOpacity 0.12 / strokeOpacity 0.9） | 12 种区分色 |
| `roads` | 道路 | `ROAD_NETWORK_DATA` | `AMap.Polyline`（按等级分色分宽） | 国道#FFD700(5) / 省道#FF8C00(4) / 县道#22C55E(3) / 乡道#3B82F6(2.5) / 穿村#94A3B8(1.5) |
| `stations` | 转运站 | 内联 12 点 | `AMap.Marker`（SVG 圆标"转"） | #1677ff |
| `facilities` | 自有设施 | 内联 2 点 | `AMap.Marker`（SVG 圆标"办"/"仓"） | #722ed1 / #13c2c2 |
| `parks` | 公园 | 内联 5 多边形 | `AMap.Polygon`（虚线描边，fillOpacity 0.15）+ 文字标注 | 各公园独立色 |
| `risks` | 风险点 | 后端 `getRiskList` | `AMap.Marker`（纯色圆点，按等级分色） | 一级#f5222d / 二级#fa8c16 / 三级#faad14 / 四级#52c41a |

### 3.3 渲染要点

- **乡镇边界**：解析 GeoJSON `MultiPolygon`，逐环生成 `Polygon`；颜色按要素顺序取 12 色调色板循环。
- **道路**：直接消费 `risk-map-data.ts` 的 `ROAD_NETWORK_DATA`，按 `cls` 取 `color/weight/opacity`，并按等级设置 `zIndex` 保证国道压盖在上层。
- **转运站 / 设施**：使用 `createMarkerSVG(text, color)` 生成带文字的定位标记（圆形+下方三角尖）作为 `AMap.Icon` 的 data-URI 图像。
- **公园**：虚线描边多边形 + 质心处 `AMap.Marker` 文字标注（label），颜色见提示词§4.2。
- **风险点**：调用 `getRiskList({ page:1, pageSize:500 })`，过滤天气类风险（名称含"高温/雨雾/冰雪/恶劣天气"或场所含"随车"）后，按等级取色与尺寸（一级最大）渲染圆点；无坐标（`lng/lat` 为 null）的点跳过。

### 3.4 交互功能

1. **图层开关**：工具栏 6 个 `Tag` 点击切换 `layerGroups[key].show()/hide()`，关闭态 `opacity:0.4`。
2. **信息窗**：所有要素点击弹出 `AMap.InfoWindow` —— 边界显示名称、道路显示名称+描述、转运站显示名称+坐标、设施显示名称、风险点显示名称/类型/事故类型/等级/场所/管控部门。
3. **自适应视野**：全部图层加载后 `mapInstance.setFitView(null, false, [60,60,60,60])`。

### 3.5 SVG 工具函数

- `createMarkerSVG(text, color)`：生成「圆点+文字+三角尖」定位标记 SVG，返回 `data:image/svg+xml;…` URI，避免外部图片依赖。
- `createCircleSVG(color, size)`：生成纯色圆点 SVG，带 `circleCache` 缓存避免重复编码。

### 3.6 生命周期与样式

- `onMounted` → `nextTick` 初始化地图；`onBeforeUnmount` → `mapInstance.destroy()` 释放。
- 地图卡片高度 `calc(100vh - 200px)`（最小 600px）；图例面板绝对定位左下角、`z-index:1000`；scoped less，主题色用 `hsl(var(--xxx))` 变量。

## 六、关键设计决策

1. **OverlayGroup 分组**：将六类要素分别归入独立 `OverlayGroup`，图层显隐切换只需 `show()/hide()`，无需遍历逐个覆盖物，性能与可维护性更优。
2. **SVG data-URI 图标**：转运站/设施/风险点标记均以内联 SVG 生成，避免依赖外部图片资源或字体图标，离线可用且加载即渲染。
3. **风险点无坐标跳过**：`lng/lat` 为 null 时不渲染，避免高德抛错；统计卡片仍以 API 返回全集计数（含无坐标点），保证统计口径完整。
4. **天气类风险过滤**：在渲染前于前端按名称/场所关键词过滤，符合提示词§4.3 排除项，保持地图聚焦空间风险。
5. **自适应视野**：加载完成后 `setFitView` 自动框选全部要素，避免初始视野过近/过远。
6. **样式主题化**：图例/卡片/工具栏均用 `hsl(var(--foreground)/…)` 等 CSS 变量，跟随系统明/暗主题。

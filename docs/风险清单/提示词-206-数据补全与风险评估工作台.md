## 三、任务二：风险评估工作台（P1，代码实现）

### 3.1 LEC 评估法交互表单

在风险清单的详情 Drawer 中新增"风险评估"Tab，实现 LEC 评估法交互。

**后端改动**（`server/routes/risk-control.js`）：
- 新增 `PUT /risk-control/:id/assess` 端点
- 接收参数：`{ method: 'LEC', l: number, e: number, c: number, score: number, level: string }`
- 写入 `risk_sources` 表的 `assessment_method`、`assessment_score`、`level`、`assessment_date` 字段
- 自动记录版本履历（`risk_versions`，change_type='assess'）
- 若 level 发生变化，推送通知到通知中心

**前端改动**（`src/views/risk-control/index.vue`）：
- 在详情 Drawer 中新增"风险评估"Tab（与"附件管理""历史版本""关联隐患"并列）
- LEC 评估表单：
  - L（事故可能性）：Select 下拉，0.1/0.2/0.5/1/3/6/10，带中文标签
  - E（暴露频率）：Select 下拉，0.5/1/2/3/6/10，带中文标签
  - C（后果严重度）：Select 下拉，1/3/7/15/40/100，带中文标签
  - D（风险值）：实时计算显示 = L × E × C
  - 等级自动判定：D≥160→一级(红) / 70-159→二级(橙) / 20-69→三级(黄) / <20→四级(绿)
  - 显示当前评估记录（assessment_method、assessment_score、assessment_date、review_cycle）
  - "保存评估"按钮 → 调用后端 assess 端点

**API 层改动**（`src/api/hse/risk-control.ts`）：
- 新增 `assessRisk(id: number, params: AssessParams)` 函数
- 新增 `AssessParams` 类型定义

### 3.2 LS 矩阵法评估（简化版）

在同一个"风险评估"Tab 中提供 LS 矩阵法入口。

**实现**：
- 可能性（L 值）：Select 1-5
- 严重性（S 值）：Select 1-5
- 风险等级：L×S ≥ 20→一级 / 15-19→二级 / 10-14→三级 / <10→四级
- 复用同一个 `PUT /risk-control/:id/assess` 端点，method='LS'

### 3.3 复评周期管理

在 LEC/LS 评估表单中增加"复评周期"设置。

**实现**：
- 复评周期 Select：3 个月 / 6 个月 / 12 个月 / 24 个月 / 长期有效（0）
- 保存评估时一并写入 `review_cycle` 字段
- 列表页"时效状态"列已有后端计算，无需改动

## 五、技术规范

### 5.1 前端规范
- 使用 Ant Design Vue 组件（非 Element Plus）
- 列表页使用 `useDataTable` 托管（禁止手写 loading/dataList/total/pagination）
- 搜索表单使用 `useSearchForm` 托管
- 弹窗 CRUD 优先使用 `useCrudModal` 托管
- TypeScript 类型：reactive 表单可选字段用 `undefined` 初始化（禁止 `null`）
- 表格 bodyCell 槽位 record 用 `as any` 处理
- 构建前须 `rm -rf dist` 清理旧产物
- 每次改造后必须 `pnpm build` 验证 exit code 0

### 5.2 后端规范
- 所有写操作 + 敏感读端点必须添加 `requireRole('admin', 'safety_manager')` 鉴权
- 版本履历自动记录（change_type 使用 snake_case）
- 事务包裹多表写操作
- 内存降级模式兼容（`useDb()` 判断）

### 5.3 参考文件
- 单列表页标准范例：`src/views/violations/index.vue`
- 弹窗 CRUD 范例：`src/views/hse/employee/over-age/index.vue`
- Composable 源码：`src/composables/hse/useSearchForm.ts` / `useDataTable.ts` / `useCrudModal.ts`
- 完整规范文档：`docs/code-standards-guide.md`

## 二、任务一：名称标注改为悬浮显示（Hover 显示）

### 2.1 公园名称（含康宁湖）

**当前状态**：公园名称通过不可见 Marker + label 属性常驻显示在多边形几何中心。

**修改要求**：
- 移除公园名称的常驻 label Marker（不再创建带 label 的 Marker）
- 改为在公园多边形（Polygon）上监听 `mouseover` / `mouseout` 事件
- `mouseover` 时：在鼠标位置或多边形中心显示名称 Tooltip（AMap.Tooltip 或 AMap.InfoWindow），内容为公园名称，样式简洁（白底黑字、小字号、圆角）
- `mouseout` 时：关闭 Tooltip
- 康宁湖同样遵循此规则
- 样式要求：白色背景、圆角、小字号（12px）、padding 4px 8px、轻微阴影，与高德默认 Tooltip 风格一致

### 2.2 乡镇边界名称

**当前状态**：乡镇边界虚线，点击时弹出 InfoWindow 仅显示乡镇名称。

**修改要求**：
- 乡镇名称不常驻显示（当前已无常驻 label，无需改动）
- 在乡镇边界多边形（Polygon）上监听 `mouseover` / `mouseout` 事件
- `mouseover` 时：在鼠标位置显示 Tooltip，内容为乡镇名称
- `mouseout` 时：关闭 Tooltip
- 保留 click 事件，但 click 行为在任务二中改造（见下）

## 三、任务二：要素点击显示区域内所有风险点

### 3.1 乡镇边界点击

**当前状态**：点击乡镇边界，InfoWindow 仅显示乡镇名称。

**修改要求**：
- 点击乡镇边界多边形时，InfoWindow 内容改为展示该乡镇内的所有风险点
- 风险点范围：从 `allRisks.value` 中筛选，匹配规则：`risk.area` 字段包含该乡镇名称（或乡镇名称包含 risk.area）。由于当前 risk.area 可能为"宁津镇"/"大曹镇"等中文名称，需做模糊匹配（注意 `area` 字段值来自数据库，乡镇名称来自 GeoJSON `feature.properties.name`，需建立名称映射）
- InfoWindow 内容格式：
  - 顶部：乡镇名称（加粗大字）
  - 第二行："该区域共 X 个风险点"（X 为数量，按等级着色：一级红/二级橙/三级黄/四级绿）
  - 下方：风险点列表，每条显示「风险名称（等级）」，等级用对应颜色的小圆点或色块标识
  - 点击列表中的风险点名称：地图定位到该风险点（setCenter + zoom），并弹出该风险点的 InfoWindow
  - 如果风险点数量超过 10 条，只显示前 10 条 + "...还有 N 条"提示
- InfoWindow 样式：白底、padding 12px、max-width 300px、max-height 400px、overflow-y auto

### 3.2 乡镇名称映射

GeoJSON 中乡镇名称可能带"镇"/"乡"/"街道"后缀，数据库 `area` 字段可能不带后缀。需要在代码中做模糊匹配：
- 先精确匹配（完全相等）
- 不匹配则去掉 GeoJSON 名称末尾的"镇"/"乡"/"街道"后匹配 risk.area
- 仍不匹配则 risk.area 包含 GeoJSON 名称或 GeoJSON 名称包含 risk.area

### 3.3 公园/康宁湖点击

公园点击同样改造：
- 点击公园/康宁湖多边形时，InfoWindow 展示公园名称 + 该公园范围内的风险点（距离公园中心 < 500m 的风险点，或 area 匹配）
- 内容格式同乡镇：名称 + 风险点数量 + 列表

### 3.4 道路点击

道路点击当前显示道路名称和 desc，保持不变（道路不是区域要素，不需要显示风险点列表）。

## 六、技术规范

### 6.1 AMap API 使用
- 悬浮 Tooltip：使用 `AMap.Tooltip`（高德自带，轻量）或 `AMap.InfoWindow`（offset 控制位置）
- 推荐使用 `AMap.InfoWindow`，因为 Tooltip 在多边形上可能有偏移问题，InfoWindow 更稳定
- InfoWindow 内容使用 HTML 字符串，注意 XSS 防护（风险名称等动态内容需转义 HTML 特殊字符）
- 多边形事件监听：使用 `poly.on('mouseover', ...)`、`poly.on('mouseout', ...)`、`poly.on('click', ...)`
- 同一时刻只显示一个 InfoWindow（打开新窗口前关闭旧窗口）

### 6.2 风险点距离判定（公园内风险点）
- 公园范围内风险点判定：使用经纬度距离近似，以公园多边形中心为圆心，半径 500m（约 0.0045 度纬度）内的风险点视为"公园周边"
- 距离计算：简单欧氏距离（经纬度差的平方和开根号）× 111000（米/度），无需复杂球面距离
- 乡镇风险点判定：使用 area 字段名称匹配（不使用距离判定）

### 6.3 样式要求
- InfoWindow 内文字使用 `font-size: 13px`、`line-height: 1.6`
- 风险等级色点：`display:inline-block;width:8px;height:8px;border-radius:50%;margin-right:6px;vertical-align:middle`
- 风险点列表项：`cursor:pointer;padding:2px 0`，hover 时背景变灰
- 数量统计文字使用对应等级颜色

### 6.4 构建验证
- 修改后必须执行 `pnpm build` 验证 exit code 0
- vue-tsc 本模块 0 新增错误
- 构建前须清理 dist 目录

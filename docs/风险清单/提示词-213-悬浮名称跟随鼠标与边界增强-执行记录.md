# 提示词-213：悬浮名称跟随鼠标与边界增强 执行记录

## 任务理解

用户提出两个需求：

1. **悬浮名称跟随鼠标**：风险管控 > 风险清单 > 风险地图（Drawer，Leaflet）中，悬浮乡镇名称跟随鼠标移动；但风险管控 > 风险地图（全屏，高德 AMap）中，名称固定在鼠标进入位置不跟随。需要将"跟随鼠标"行为移植到全屏地图。
2. **乡镇边界清晰化**：全屏地图的乡镇边界虚线太淡，看不清；需要宁津县外围边界线。

## 根因分析

| 特性 | 风险清单 > 风险地图（Drawer） | 风险管控 > 风险地图（全屏） |
|------|------|------|
| 地图库 | Leaflet | 高德 AMap |
| 悬浮名称 | `bindTooltip({ sticky: true })` 跟随鼠标 | `InfoWindow.open()` 固定位置 |
| 乡镇边界 | weight:2, opacity:0.95, solid | weight:1, opacity:0.35, dashed |
| 县边界 | 无 | 无 |

**Drawer 的 sticky 行为**：Leaflet 的 `bindTooltip({ sticky: true })` 原生支持 tooltip 跟随鼠标 —— 在 `RiskMapDrawer.vue` L221-224 中实现。

**全屏地图的固定行为**：`map.vue` 只在 `mouseover` 时调用 `openHover()` 打开 InfoWindow 到固定位置，没有 `mousemove` 事件更新位置。

## 改动范围

仅修改 `apps/web-antd/src/views/risk-control/map.vue`，红线合规。

### 需求 1：悬浮名称跟随鼠标

在 `renderBoundary()` 中为每个乡镇 Polygon 添加 `mousemove` 事件：

```ts
poly.on('mousemove', (e: any) => {
  if (hoverInfoWindow && hoverInfoWindow.getIsOpen()) {
    try {
      hoverInfoWindow.setPosition([e.lnglat.lng, e.lnglat.lat]);
    } catch {
      // 兼容不支持 setPosition 的旧版，关闭后重新打开
      closeHover();
      openHover(name, [e.lnglat.lng, e.lnglat.lat]);
    }
  }
});
```

- 主路径：调用高德 InfoWindow 的 `setPosition()` 方法实时更新位置。
- 兼容兜底：若 `setPosition` 不支持（旧版 SDK），fallback 为关闭后重新打开。
- 仅在 `hoverInfoWindow` 已打开时更新，避免无效调用。

### 需求 2：边界清晰化 + 宁津县边界线

**乡镇边界样式增强**（`renderBoundary` L413-420）：

|------|------|------|
| strokeWeight | 1 | 2 |
| strokeOpacity | 0.35 | 0.55 |
| strokeStyle | dashed | solid |

> **补充（2026-08-03）**：宁津县边界凸包线（Graham Scan + AMap.Polyline）据用户反馈已移除，仅保留乡镇边界增强。

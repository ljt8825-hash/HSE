## 一、背景

宁津县城乡环卫一体化项目需要将风险清单、转运站、道路网络、公园范围、乡镇边界等多源空间数据，以地图方式统一呈现，用于日常安全管理和汇报演示。

公司位于山东省德州市宁津县，业务涵盖：
- 垃圾收转运（12个乡镇转运站，含乐陵光大、德州润电两个终端处理厂）
- 农村、镇驻地、公路沿线保洁
- 市政绿化（城区4个公园：中心公园、福宁河景观带、新河公园、康宁湖）

**导航菜单位置**：`风险管控 > 风险地图`（左侧菜单中"风险管控"子菜单下的第二个条目）

## 四、任务要求

### 4.1 路由配置


### 4.2 新建风险地图页面

创建 `src/views/risk-control/map.vue`，实现以下功能：

**布局结构**：
1. 顶部：4个统计卡片（风险总数、一级风险、二级风险、三级风险），使用 Ant Design Vue 的 Row/Col/Card
2. 中部：地图主体，使用 Card 包裹
   - 地图容器上方的工具栏：左侧显示"风险地图"标题 + "宁津县城乡环卫一体化 · 安全风险管控"副标题；右侧显示6个图层开关 Tag
   - 地图容器（全高填充，使用高德地图）
   - 左下角图例面板：风险等级、道路等级、设施点位三组图例

**页面组件导入**：
- 使用 `Page` from `@vben/common-ui`
- 使用 Ant Design Vue：Card, Col, Divider, Row, Space, Tag, message

**地图初始化**：
1. 动态加载高德地图 JS API：`https://webapi.amap.com/maps?v=2.0&key=${AMAP_KEY}&plugin=AMap.PolygonEditor,AMap.Geocoder`
2. 加载前设置安全密钥：`window._AMapSecurityConfig = { securityJsCode: AMAP_SECURITY }`
3. 创建地图实例，center: [116.805, 37.655], zoom: 12
4. 创建6个 OverlayGroup 图层：boundary, roads, stations, facilities, parks, risks

**六层图层渲染**：

| 图层 key | 名称 | 数据来源 | 渲染方式 | 颜色 |
|----------|------|----------|----------|------|
| boundary | 乡镇边界 | fetch GeoJSON | AMap.Polygon（填充透明度0.12，描边透明度0.9） | 12种区分色 |
| roads | 道路 | ROAD_NETWORK_DATA | AMap.Polyline | 五级分色 |
| stations | 转运站 | 内联数据 | AMap.Marker（SVG图标：圆形+文字"转"） | #1677ff |
| facilities | 自有设施 | 内联数据 | AMap.Marker（SVG图标：圆形+文字"办"/"仓"） | #722ed1 / #13c2c2 |
| parks | 公园 | 内联数据 | AMap.Polygon（虚线描边，填充透明度0.15）+ 文字标注 | 各公园独立色 |
| risks | 风险点 | 后端API | AMap.Marker（圆形色点） | 按等级分色 |

**风险等级颜色**：一级 #f5222d、二级 #fa8c16、三级 #faad14、四级 #52c41a

**道路等级颜色**：国道 #FFD700（线宽5）、省道 #FF8C00（线宽4）、县道 #22C55E（线宽3）、乡道 #3B82F6（线宽2.5）、穿村道路 #94A3B8（线宽1.5）

**乡镇边界颜色**：['#E8590C','#099268','#92400E','#16A34A','#0EA5E9','#3B82F6','#0D9488','#CA8A04','#DC2626','#84CC16','#EC4899','#9333EA']

**公园颜色**：中心公园 #52c41a、福宁河景观带 #1890ff、新河公园 #13c2c2、康宁湖西区 #2f54eb、康宁湖东区 #2f54eb

**交互功能**：
1. 图层开关：点击 Tag 切换对应图层显示/隐藏（OverlayGroup.show()/hide()）
2. 所有要素点击弹出 InfoWindow 显示详细信息：
   - 乡镇边界：显示名称
   - 道路：显示名称 + 描述
   - 转运站：显示名称 + 坐标
   - 自有设施：显示名称
   - 风险点：显示名称、类型、事故类型、等级、场所、管控部门
3. 加载完成后调用 `mapInstance.setFitView(null, false, [60,60,60,60])` 自适应视野

**SVG 图标工具函数**：
- `createMarkerSVG(text, color)`：生成带文字的定位标记 SVG（圆形+下方三角尖）
- `createCircleSVG(color, size)`：生成纯色圆形 SVG（带缓存）

**生命周期**：
- onMounted：nextTick 后初始化地图
- onBeforeUnmount：销毁地图实例

**样式**：
- 地图卡片高度：`calc(100vh - 200px)`，最小高度 600px
- 图例面板：绝对定位在左下角，z-index 1000
- 图层关闭状态：opacity 0.4
- 使用 scoped less，CSS 变量用 hsl(var(--xxx)) 格式

### 4.3 排除项

- 水域要素（河流、运河、排水渠、溪流）不在地图展示
- 天气类风险（高温、雨雾、冰雪、恶劣天气、随车）不在地图展示
- 不修改 RiskMapDrawer.vue（风险清单抽屉中的独立地图组件）

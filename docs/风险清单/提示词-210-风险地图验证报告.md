## 〇、执行摘要

提示词-210 解决用户反馈的"时集镇右上角 x"问题——即 risk-control 地图的 InfoWindow（悬浮提示 / 点击详情气泡）右上角 ❌ 关闭按钮未彻底隐藏。

- **根因**：`openHover()` / `openPopup()` 虽已设置 `closeButton: false`（提示词-208 任务一落地），但高德 JS API 在某些版本 / 场景下忽略该配置项，仍会渲染关闭按钮 DOM。
- **修复**：采用**双重兜底**——CSS 层 `.amap-info-window-close, .amap-info-close { display:none !important; ... }` 强制隐藏；JS 层在 `open()` 后 `setTimeout(..., 0)` 遍历并 `el.style.display='none'` 兜底清除。两者互补，覆盖"配置被忽略 + CSS 未生效"两种场景。
- **核查结论**：提交 `e0471ea` 真实存在，代码（CSS L1533-1541 + JS L910-914 / L935-939）已落地于 `map.vue`，当前工作树与提交一致。

## 一、关键发现：问题根因

- 提示词-208 任务一已在 `openHover` / `openPopup` 设置 `closeButton: false`，正常情况下高德不渲染关闭按钮。
- 但高德 JS API 在**部分版本 / 部分场景**（如 InfoWindow 内容含特定 DOM、或异步渲染时序差异）会**忽略 `closeButton` 配置**，仍注入 `.amap-info-close`（旧版类名）/ `.amap-info-window-close`（新版类名）关闭按钮元素。
- 表现为：用户在使用地图时，时集镇等风险点 InfoWindow 右上角仍出现 ❌，点击会关闭气泡——而本地图设计上 InfoWindow 应随鼠标移开 / 再次点击自动关闭，无需手动 ❌。

---

## 二、修复方案：CSS + JS 双重兜底

### 2.1 CSS 兜底（`<style>` 块，map.vue L1533-1541）

```css
/* 提示词-210：彻底隐藏 InfoWindow 右上角 ❌ 关闭按钮（CSS 兜底） */
.amap-info-window-close,
.amap-info-close {
  display: none !important;
  width: 0 !important;
  height: 0 !important;
  opacity: 0 !important;
  pointer-events: none !important;
}
```

> 同时覆盖新旧两类类名（`.amap-info-window-close` 新版 / `.amap-info-close` 旧版），并用 `!important` + 宽高 / 透明 / 禁用指针多重加固，确保即便高德在 CSS 加载后动态注入也能被压制。

### 2.2 JS 兜底（`openHover` L910-914 / `openPopup` L935-939）

```ts
// 提示词-210：JS 兜底，确保关闭按钮 DOM 被移除（高德某些版本忽略 closeButton:false）
setTimeout(() => {
  document.querySelectorAll('.amap-info-window-close,.amap-info-close').forEach((el) => {
    (el as HTMLElement).style.display = 'none';
  });
}, 0);
```

> `setTimeout(..., 0)` 将清除动作推迟到 InfoWindow `open()` 渲染完成后执行，确保能命中高德**异步注入**的关闭按钮 DOM。两处（悬浮 / 点击）对称实现。

## 三、风险地图实现

### 3.1 技术架构

```
src/views/risk-control/map.vue          ← 风险地图主页面
src/components/hse/risk-map-data.ts     ← 道路网络数据 + 乡镇坐标
public/geojson/ningjin-boundary.geojson ← 乡镇边界 GeoJSON
```

- **地图引擎**：高德地图 JS API v2.0（GCJ-02 坐标系）
- **UI 框架**：Ant Design Vue（Card/Tag/Space/Divider）
- **数据加载**：API 调用 `getRiskList()` + 静态数据 + 本地 GeoJSON 文件
- **图层管理**：基于 `AMap.OverlayGroup` 的6层独立图层

### 3.2 六层图层架构

| 图层 | 名称 | 数据来源 | 渲染方式 | 默认可见 |
|------|------|----------|----------|----------|
| boundary | 乡镇边界 | `ningjin-boundary.geojson` | MultiPolygon 填充 | 是 |
| roads | 道路网络 | `risk-map-data.ts`（18条） | Polyline 五级分色 | 是 |
| stations | 转运站 | 内联数据（12个） | Marker（SVG图标） | 是 |
| facilities | 自有设施 | 内联数据（2个） | Marker（SVG图标） | 是 |
| parks | 公园范围 | 内联数据（5个区域） | Polygon 虚线填充 + 文字标注 | 是 |
| risks | 风险点 | 后端 API | Marker（圆形色点） | 是 |

### 3.3 视觉设计

**风险等级色标**：一级（红 #f5222d）、二级（橙 #fa8c16）、三级（黄 #faad14）、四级（绿 #52c41a）

**道路等级色标**：国道（金 #FFD700）、省道（橙 #FF8C00）、县道（绿 #22C55E）、乡道（蓝 #3B82F6）、穿村道路（灰 #94A3B8）

**乡镇边界色标**：12种区分色（橙红/深绿/棕/绿/天蓝/蓝/青绿/金黄/红/黄绿/粉/深紫）

### 3.4 交互功能

- 图层开关：顶部工具栏6个 Tag 控制各图层显示/隐藏
- 图例面板：左下角固定面板，包含风险等级、道路等级、设施点位三组图例
- 点击交互：所有要素支持点击弹出 InfoWindow 显示详细信息
- 统计卡片：顶部4个统计卡片（风险总数/一级/二级/三级）
- 风险点过滤：自动排除天气类风险（高温/雨雾/冰雪/恶劣天气/随车）
- 自适应视野：加载完成后自动适配所有图层边界

## 六、关键设计决策

1. **高德地图 vs Leaflet**：主地图页面使用高德地图 JS API（与用户提供的 Key 对应），风险清单抽屉中的 RiskMapDrawer 使用 Leaflet（适合弹窗内嵌入式地图）

2. **图层分离**：使用 AMap.OverlayGroup 实现6层独立图层，支持按需显示/隐藏，避免一次性渲染过多要素导致性能问题

3. **道路数据内联**：道路网络数据以 TypeScript 常量形式存放在 `risk-map-data.ts`，而非从 GeoJSON 动态加载，保证渲染速度和类型安全

4. **水域排除**：80条水域要素（河流/运河/排水渠/溪流）不在地图展示，123.geojson 中的道路数据已预先过滤

5. **风险点过滤**：天气类风险（高温/雨雾/冰雪）不在地图展示，因其无固定空间点位

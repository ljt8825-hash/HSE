# 提示词-212：悬浮名称标签样式切换（-1 → -2）执行记录

## 任务理解

用户通过三张截图表达需求：
- 图 2（`-1`）：鼠标悬浮在乡镇/公园区域时，名称标签显示为**白底圆角卡片 + 阴影**（`.hover-tip` 当前样式）。
- 图 3（`-2`）：期望改为**无背景框、无阴影、仅显示文字**的轻量样式。

> 注：`map.vue` 中不存在名为 `-1`/`-2` 的物理图片文件；用户用 `-1`/`-2` 指代两种视觉状态。

## 改动范围

仅修改 `apps/web-antd/src/views/risk-control/map.vue`，红线合规。

### 1. `.hover-tip` 样式切换为 -2（L~1530）

```css
.hover-tip {
  /* 提示词-212：悬浮名称标签切换为 -2 样式（无背景框、无阴影，仅显示文字） */
  background: transparent !important;
  color: #1f1f1f;
  padding: 0;
  border-radius: 0;
  font-size: 13px;
  font-weight: 600;
  line-height: 1.4;
  white-space: nowrap;
  box-shadow: none;
  text-shadow:
    0 0 4px rgba(255, 255, 255, 0.9),
    0 0 2px rgba(255, 255, 255, 0.9);
}
```

- 移除 `-1` 的 `background: #fff`、`border-radius: 4px`、`box-shadow: 0 2px 8px rgba(...)`、`padding: 6px 10px`。
- 增加白色 `text-shadow` 保证文字在复杂地图背景上仍可读。

### 2. 高德 InfoWindow 容器兜底覆盖（样式末尾）

```css
.amap-info-window:has(.hover-tip),
.amap-info-content:has(.hover-tip),
.amap-info-contentContainer:has(.hover-tip) {
  background: transparent !important;
  border: none !important;
  box-shadow: none !important;
  padding: 0 !important;
}

.amap-info-window:has(.hover-tip) .amap-info-sharp,
.amap-info-window:has(.hover-tip) .amap-info-outer,
.amap-info-window:has(.hover-tip) .amap-info-inner {
  display: none !important;
}
```

- 仅对包含 `.hover-tip` 的 InfoWindow 生效，不影响 `clickInfoWindow` 的 `.iw-wrap` 弹窗。
- 清除高德默认气泡背景、边框、阴影、padding 和尖角。

### 3. JS 兜底（`openHover` L~927）

在原有 210 关闭按钮隐藏的 `setTimeout` 中扩展：

```ts
// 向上遍历 hover-tip 祖先，清除高德容器默认背景/边框/阴影/padding
// 并隐藏尖角元素，作为 CSS :has() 的兼容性兜底
```

- 与 210 逻辑共用同一轮 `setTimeout`，不新增定时器。
- 覆盖高德某些版本通过 inline style 注入的默认样式。

## 一致性保证

`openHover` 在两处被调用：
1. 乡镇边界 `mouseover`（L~429）
2. 公园 `mouseover`（L~658）

两处共用同一个 `.hover-tip` 和 `openHover`，因此**一次修改即可保证所有悬浮名称标签统一切换为 -2 样式**，无需逐层修改。

## 构建验证

尝试生产构建：

```bash
vite build --mode production --outDir dist_verify_212
```

连续两次因环境原因失败：

- 第 2 次：`Could not start thread DartWorker: 22`（设备不识别此命令）

失败与本次代码改动无关（仅 20 余行纯 CSS/JS，未引入新依赖或大资源），属当前环境资源/线程限制。

JS 兜底逻辑已用 `node -e` 验证语法正确。

## 结论

- 悬浮名称标签已从 `-1`（白底圆角阴影卡片）切换为 `-2`（无背景框纯文字）。
- 所有相关调用点（乡镇边界、公园）保持一致。
- 已移除对 `-1` 背景色/圆角/阴影的引用。
- 建议在资源充足时重跑完整生产构建。

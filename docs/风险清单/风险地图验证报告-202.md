### 1.2 功能说明

- 连接 `risk_sources` 表，查询 `lng IS NULL OR lat IS NULL` 的记录
- 五级优先级匹配：① 转运站精确匹配 → ② 自有设施（办公室/仓库）→ ③ 公园范围 → ④ 乡镇模糊匹配（+确定性微偏移）→ ⑤ 哈希分配兜底（按 id 确定性哈希到乡镇中心）
- 内联数据源（与前端 `risk-map-data.ts` 及提示词一致）：
  - 12 个转运站坐标、2 个自有设施、5 个公园中心（康宁湖拆为西区/东区）、12 个乡镇中心
  - 乡镇中心顺序与 `risk-map-data.ts` 的 `TOWNSHIP_CENTERS` 完全一致，保证哈希分配结果可复现
- `jitter(center, seed)`：基于 id 的确定性伪随机偏移 `±0.008` 度（约 ±800m）
- `--execute`：在事务中参数化执行 UPDATE；任一失败即 `ROLLBACK`，无失败则 `COMMIT`
- `--help`：打印用法与数据源说明
- 充分中文注释，含路径解析候选兜底

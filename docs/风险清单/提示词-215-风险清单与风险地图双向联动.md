# 提示词-215：风险清单与风险地图双向联动（阶段4）

## 背景

`风险地图构建总结报告.md` 第七节"后续扩展方向"中列出了阶段4：

> 阶段4：地图联动风险清单列表（双向定位高亮）

当前现状：
- 风险清单页面内的 Drawer 地图（`RiskMapDrawer`）与表格行之间有联动（`highlightedRiskId` + `marker-click`），但**仅在 Drawer 展开时生效**。
- 独立的风险地图页面（`/risk/map`）与风险清单页面（`/risk/list`）之间**没有任何跨页面联动**。
- 两份页面各自独立加载数据（`getRiskList`），互不知道对方的状态。

## 目标

实现风险清单与风险地图两个独立页面之间的双向联动：

| 方向 | 触发 | 行为 |
|------|------|------|
| 清单 → 地图 | 风险清单表格行点击 | 跳转到 `/risk/map?riskId=xxx`，地图页自动定位到该风险点并弹出详情 |
| 地图 → 清单 | 地图 InfoWindow 中风险点详情列表项点击 | 跳转到 `/risk/list?riskId=xxx`，清单页自动定位到该行并高亮 |

## 任务一（必做）：清单 → 地图 正向联动

### 修改文件：`apps/web-antd/src/views/risk-control/index.vue`

1. 在 `handleCustomRow` 中，当 `mapDrawerVisible` 为 false 时（即 Drawer 未打开），改为**跳转到独立地图页面**而非不做任何事：

```ts
function handleCustomRow(record: RiskControlApi.RiskSource) {
  return {
    onClick: () => {
      if (mapDrawerVisible.value) {
        // 已有逻辑：Drawer 内联动高亮
        highlightedRiskId.value = record.id;
        if (highlightTimer) clearTimeout(highlightTimer);
        highlightTimer = setTimeout(() => {
          highlightedRiskId.value = null;
        }, 3000);
      } else {
        // 提示词-215：Drawer 未打开时，跳转到独立风险地图页面并定位
        router.push({ path: '/risk/map', query: { riskId: String(record.id) } });
      }
    },
    style: { cursor: 'pointer' }, // 始终显示为可点击
  };
}
```

2. 导入 `useRouter`：

```ts
import { useRouter } from 'vue-router';
const router = useRouter();
```

3. 将 `cursor` 样式从条件判断改为始终 `pointer`（移除 `mapDrawerVisible.value ? 'pointer' : 'default'`），让用户知道每一行都可以点击跳转。

### 修改文件：`apps/web-antd/src/views/risk-control/map.vue`

## 任务二（必做）：地图 → 清单 反向联动

### 修改文件：`apps/web-antd/src/views/risk-control/map.vue`

1. 修改 `focusRisk` 或 `focusRiskByIdx`，当在风险点详情列表中点击时，改为跳转到清单页面：

在 `buildRiskDetailHtml` 中添加一个"在清单中查看"按钮，或者修改 `__mapFocusRisk` 的行为。

**方案 A（推荐）**：在 `buildRiskDetailHtml` 末尾添加一个跳转链接：

```ts
function buildRiskDetailHtml(risk: any, color: string): string {
  return (
    `<div class="iw-risk-detail">` +
    // ... 现有内容 ...
    `<div class="iw-risk-action" style="margin-top:8px;padding-top:8px;border-top:1px solid hsl(var(--border));">` +
    `<a href="/risk/list?riskId=${risk.id}" style="color:hsl(var(--primary));font-size:12px;text-decoration:none;" onclick="event.preventDefault();window.__mapGoToList(${risk.id})">` +
    `📋 在风险清单中查看` +
    `</a>` +
    `</div>` +
    `</div>`
  );
}
```

2. 暴露跳转函数：

```ts
function goToList(riskId: number) {
  window.open(`/risk/list?riskId=${riskId}`, '_self');
}
(window as any).__mapGoToList = goToList;
```

### 修改文件：`apps/web-antd/src/views/risk-control/index.vue`

1. 在 `onMounted` 中读取路由 query 的 `riskId`，自动高亮并滚动：

```ts
import { useRoute } from 'vue-router';
const route = useRoute();

onMounted(async () => {
  await fetchData();
  const riskId = route.query.riskId;
  if (riskId) {
    const target = riskList.value.find((r) => r.id === Number(riskId));
    if (target) {
      highlightedRiskId.value = Number(riskId);
      nextTick(() => {
        const rowEl = document.querySelector('.risk-row-highlighted');
        if (rowEl) rowEl.scrollIntoView({ behavior: 'smooth', block: 'center' });
      });
      highlightTimer = setTimeout(() => {
        highlightedRiskId.value = null;
      }, 3000);
    }
    // 清除 query 参数
    router.replace({ query: {} });
  }
});
```

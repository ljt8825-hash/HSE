## 二、任务 C：员工主档案页（核心交付）

### 2.1 后端（server/routes/hse-employee.js）
新增 6 个只读端点（挂载前缀 `/api/hse/employee`）：

- `GET /employees/:id/profile` — 完整档案（基本信息 + 组织岗位 + 5 项关联统计）
- `GET /employees/:id/hazards` — checker_id/fixer_id（OR）分页
- `GET /employees/:id/accidents` — handler_id 分页
- `GET /employees/:id/emergency-plans` — responsible_person_id 分页
- `GET /employees/:id/training` — employee_id 分页
- `GET /employees/:id/violations` — 按姓名匹配分页

脱敏规则：身份证 `前6+****+后4`，手机 `前3+****+后4`（解密后脱敏）。

### 2.2 前端
- **API** `src/api/hse/employee.ts`：`EmployeeProfileResponse` 接口 + `getEmployeeProfile` 及 5 个 list 函数。
- **路由** 新建 `src/router/routes/modules/hse-employee-profile-detail.ts`：
  ```ts
  { path: '/hse/employee/:id(\\d+)', name: 'EmployeeProfile',
    component: () => import('#/views/hse/employee/ProfilePage.vue'),
    meta: { title: '员工档案', hideInMenu: true, hideInTab: true } }
  ```
  并在 `src/router/routes/index.ts` 的 `dynamicRouteFiles` 白名单中注册（否则路由不加载）。
- **页面** 新建 `src/views/hse/employee/ProfilePage.vue`：基本信息卡片 + 组织岗位卡片 + 关联业务 Tab（渐进式加载、分页、空态/错误态/Skeleton）；自身不渲染可点击 EmployeeName，避免循环跳转；Tab 内人员列用 EmployeeName 可跳其他员工档案。
- **跳转** `src/composables/hse/useEmployeeLink.ts`：`PROFILE_ROUTE` 由 `/hse-advanced/risk-profile/:id` 改为 `/hse/employee/:id`，EmployeeName 点击统一跳真实档案页。

## 三、改动清单

### 后端 `server/routes/training.js`
1. `ensureTables()`（L329-330）：两条幂等 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`。
2. `POST /plans`（L1974）：INSERT 列表 17 → 19 列，新增 `training_time`/`responsible_dept`。
3. `PUT /plans/:id`（L2034-2037）：UPDATE 新增两列 `COALESCE`，参数重编号至 `$20`。
4. 内存降级模式 POST/PUT 同步（L1965-1966、L2008-2009），保持离线一致。
5. `GET /plans` 排序：`ORDER BY start_date DESC` → **按 `plan_no` 数字升序**（非数字序号排末尾），对齐附件1呈现顺序。
6. `GET /plans` 关键字搜索：由 `title/trainer_name` 扩展到 `target_audience/content/responsible_dept/training_time`。

### 前端
- `apps/web-naive/src/api/hse/training.ts`：`TrainingPlanItem` 与 `PlanFormData` 各补 `planNo`/`planHours`/`trainingTime`/`responsibleDept`。
- `apps/web-naive/src/views/training/plans/index.vue`：
  - `columns` 重排为附件1七列；新增 `formatHours()` 处理 pg numeric 返回的 `12.00` → `12 学时`。
  - **移除全部 `sortable: true`**——后端不接受 `sortField` 参数，保留会成为「假排序」。
  - `formModel` / `resetForm` / `openEdit` 补齐 4 个新字段；表单把附件1六项前置，删除与「培训对象」重复的「目标人群」项。
  - 删除列重排后不再使用的 `formatDate()`。

### 数据脚本 `server/scripts/_training/`
- `seed_plan_attach1.js` + `plan_attach1.json`
- 幂等键：`(plan_no, title, target_audience)`；已存在则 UPDATE。
- 落库策略：`plan_type='annual'`、`training_type='安全教育培训'`、`status='approved'`；`remark` 打来源标记 `附件1·2026年度安全培训教育实施计划表｜原始学时：X`。
- `start_date`/`end_date`（表内 NOT NULL）由「培训时间」推导：`1月` → `2026-01-01~2026-01-31`；非月份表述（上岗前 / 每季度 / 根据通知）→ `2026-01-01~2026-12-31` 全年。
- 命令：
  - 预演 `node server/scripts/_training/seed_plan_attach1.js --dry`
  - 导入 `node server/scripts/_training/seed_plan_attach1.js`
  - **回滚 `node server/scripts/_training/seed_plan_attach1.js --revert`**（按 remark 标记软删除，不影响其他记录）

### 4.3 效率公式（冻结口径）

```text
人工总耗时 = 数据整理 + 统计 + 分析 + 报告 + 修改 + 审核
AI 总耗时  = 数据准备 + SK-003 + SK-004 + 人工审核
节省时间   = 人工总耗时 − AI 总耗时
效率提升   = (人工总耗时 − AI 总耗时) ÷ 人工总耗时 × 100%
```

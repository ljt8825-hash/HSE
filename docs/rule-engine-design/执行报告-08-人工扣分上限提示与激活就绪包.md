## 1. 任务 A：人工扣分上限提示（决策⑤收尾）

### 1.1 入口调用链（定位结果）

**后端入口**（`server/routes/hse-assessment-monthly.js`）：
- `POST /api/hse/assessment-monthly/deductions`（5.3 手动添加扣分，`deduction_source='manual'`，requirePermission `hse:training:create`）→ 写库 `hse_assessment_deduction`。
- `PUT /api/hse/assessment-monthly/deductions/:id`（5.4 更新扣分，仅草稿态，`deduction_source<>'auto'` 可改）。
- `POST /api/hse/assessment-monthly/import/deductions`（5.8 Excel 批量导入，`deduction_source='import'`）。

**前端入口（关键发现/偏离）**：web-naive 当前**没有**手动扣分（source=manual）表单——`scoring.vue` 仅只读抽屉、`deduction-review.vue` 仅审核、`deduction-adjust.vue` 是考核标准配置。**唯一的人工扣分录入入口是「Excel 导入」**（`views/hse/assessment-monthly/excel.vue` → `importDeductions` → 5.8）。故：
- 后端 capWarning 接到 5.3（手动，规范入口，为未来表单就绪）+ 5.4（编辑）+ 5.8（导入，当前真实 UI 入口）；
- 前端提示接到 excel.vue 导入成功回调（弹 dialog.warning），保证本轮能力**端到端可观测**。

### 1.2 后端上限计算（复用 categoryCap，无第二套口径）

`server/services/ruleEngine/categoryCap.js` 新增（**未改动自动钳制路径**，`applyCap` 行为不变）：
- 抽 `resolveAndSum(rows, category, excludeId)`：把原 `getOtherCategoryScore` 的归类合计循环抽出为公共纯函数，自动/人工两路共用同一 `resolveRuleForDeductionRows` 口径；
- `getOtherCategoryScore` 增加可选 `sources`（默认仍 `VALID_SOURCES`，自动路径语义不变）+ `executor`（默认 pool；导入事务内可传 client 读未提交行）；
- 新增 `getValidCategoryScore`（ALL_SOURCES = auto+manual+chain_transmission，提示口径含全部来源）；
- 新增 `computeManualCapWarning({ cycleId, targetId, deductionItem, sourceDetail, adding, excludeId, executor })`：
  - 类别缺失（resolveDeductionRule 未命中）→ null；类别无上限（cap=Infinity）→ null；`currentTotal + adding ≤ cap` → null；否则返回 `{ category, cap, currentTotal, adding, wouldTotal }`。

**三路接线**（`hse-assessment-monthly.js`）：
- 5.3 写库前 `computeManualCapWarning({cycleId, targetId, deductionItem, sourceDetail:null, adding:finalScore})` → 响应携带 `capWarning`（**照常保存，不拦截**）；
- 5.4 编辑时 `excludeId: id`（排除本行）、`adding: 新 suggested_score`（未改沿用现值）→ 响应携带；
- 5.8 导入逐行 `RETURNING id` 后以 `executor: client` 事务内计算（同批其他行计入、本行排除）→ 响应 `capWarnings` 数组。

### 1.3 前端提示交互（excel.vue）

导入成功后 `if (res.capWarnings?.length)` → `dialog.warning`（来自 `#/adapter/naive`，非 useDialog）：
```

人工扣分不受上限强制限制，已照常保存。
```
`api/hse/assessment-monthly.ts` 的 `importDeductions` 返回类型同步扩展 `capWarnings`。

## 2. 任务 B：修正版重启命令（**替换报告-15 §4 草案**）

> 修正点：①去掉 `-NoNewWindow`（该参数使进程依附代理控制台，会话结束可能被连带终止）；②改用隐藏独立窗口 + stdout/stderr 落日志文件，保证后端脱离 WorkBuddy 会话常驻且有日志可查。

```powershell
# 1) 停旧进程（PID 以任务 A 实查为准）
Stop-Process -Id <OLD_PID> -Force

# 2) 重新拉起（独立隐藏窗口、日志落盘；cwd 必须为 server）
$logDir = 'G:\hse-dashboard\server\logs'
New-Item -ItemType Directory -Force -Path $logDir | Out-Null
$stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
Start-Process -FilePath 'node' -ArgumentList 'app.js' `
  -WorkingDirectory 'G:\hse-dashboard\server' `
  -WindowStyle Hidden `
  -RedirectStandardOutput "$logDir\backend_$stamp.out.log" `
  -RedirectStandardError  "$logDir\backend_$stamp.err.log"
```

注意：Start-Process 不允许 stdout/stderr 指向同一文件，故分两个文件；若 `-RedirectStandardError` 报权限占用，改为先 `cmd /c "node app.js > logs\backend_$stamp.log 2>&1"` 经 `Start-Process cmd -ArgumentList ... -WindowStyle Hidden` 拉起（二选一，报告记录实际采用方式）。

**回滚**（新进程 60 秒内未探活）：重复第 2 步拉起命令即可（盘上代码即唯一版本，无降级代码；若出现启动级报错，保留 err.log 并报告，不要改码重试）。

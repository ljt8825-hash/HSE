## 1. 业务口径（本轮唯一业务决策点，已给默认值）

- 计分：规则库 VIOLATION003 配 **1 分/次**；`check_source='company'`（公司查处）**5 分/次**；`township`/`self` 1 分/次。
- **check_source 为 NULL（未标注）：默认按 1 分/次处理**（与规则库基准分一致，保守口径），source_detail 中 checkSourceText='未标注'，运行报告单独统计未标注条数。若业务要求"未标注不计分"，改适配器一个常量即可，在报告中注明开关位置。
- 类别上限：三违管理上限（hse_assessment_category_limit，现配 15）对本通路自动扣分生效（复用 applyCap，cappedOut 明细照网格通路写入 source_detail）。
- 事件级幂等：**一条违规记录 = 一条扣分**，幂等键 `source_table='violation_records' + source_id=违规记录id`；违规记录被软删/换人 → 对应扣分软删（revoked）；人工锁定（approved/adjusted）不覆盖。
- 周期归属：按 `violation_date` 落在考核周期年月内；violation_date 为 NULL 的记录跳过（skipped 计数 reason='no-date'），不扣分。

## 4. 任务 B：引擎事件级能力 + 三违适配器

1. `deductionWriter.js` 扩展事件模式（不破坏月度模式）：
   - `createDeductionWriter({ sourceTable, kind, deductKeyFn, idempotency })`，`idempotency: 'monthly' | 'event'`，默认 'monthly'（网格通路行为不变）。
   - event 模式：findExisting 按 `target_id+cycle_id+deduction_source='auto'+source_table+source_id` 匹配（source_id 与 intent.sourceId 比较，注意类型统一为字符串）；INSERT 写入真实 source_id；revoke 查询同样按 source_id 集合；deductKey 仍写入 source_detail 供排查。
   - 锁定/复活/noop/updated/dryRun 语义与月度模式一致。
2. `engine.js` 两处改造：
   - `ensureAdaptersRegistered()` 注册 `registerAdapter('violation_record', require('./adapters/violationAdapter'))`。
   - **noLedger 改为按适配器跳过**：某适配器返回 noLedger 时，该适配器结果记 `{ok:false, reason:'no-ledger-data'}` 并继续后续适配器，不再整轮 return；最终返回值含每适配器结果数组（见任务 C）。
3. 新建 `server/services/ruleEngine/adapters/violationAdapter.js`：
   - 常量：KEY='violation_record'，RULE_CODE='VIOLATION003'，SOURCE_TABLE='violation_records'，KIND='violation_event'，METRIC_CODE='HSE-KPI-SAF-001'；`COMPANY_SCORE=5`、`DEFAULT_SCORE=1`（NULL 政策开关，注释说明业务可改）。
   - `scan({cycle, year, month, rule, dryRun })`：
     - 月区间 [month 1 日, 次月 1 日)；查 `violation_records WHERE is_deleted=FALSE AND violator_id IS NOT NULL AND violation_date >= $1 AND violation_date < $2`；violation_date NULL 的存活行计数进 skipped（reason='no-date'）。
     - 用本期考核对象（复用引擎现有 target 解析/`findAssessmentTarget`）按 employee_id=violator_id 匹配；非考核对象进 skipped（reason='not-assessment-target'）。
     - 每条记录产出一个 intent：`{_seq, sourceId:String(rec.id), cycleId, targetId, employeeId, employeeName, ruleName, category, eventType:'VIOLATION', checkSource: rec.check_source||null, violationDate, rawScore: rec.check_source==='company'?COMPANY_SCORE:(rule.deductScore||DEFAULT_SCORE), year, month}`。
     - revocations：本周期本 kind 既有自动扣分中，source_id 不在本月有效记录 id 集合内的（含记录被删/violator_id 改挂他人）→ 撤销。
     - 返回 `scanned`=本月 violator_id 非空的去重违规人数、`assessed`=其中命中本期考核对象的去重人数（intents+revocations 涉及人）、intents/revocations/skipped、`noLedger:false`、metric（ensureMetric HSE-KPI-SAF-001，照网格适配器写法）。
   - `buildDeductKey({cycleId, sourceId})` → `violation:${cycleId}:${sourceId}`。
   - `buildItem(intent)` → company 为 `三违1次（公司查处）`，其余 `三违1次`。
   - `buildDetail(intent, capInfo)`：source_detail = `{kind:'violation_event', deductKey, ruleName, category, eventType:'VIOLATION', sourceId, violationDate, checkSource, checkSourceText（公司查处/乡镇查处/自查自纠/未标注）, rawScore, cap, cappedScore, otherCatScore, summary:'三违1次（{checkSourceText}，{violationDate}）'}`。
   - `buildReportDetail` 照网格适配器补齐。

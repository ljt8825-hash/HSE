## 1. 任务 A：观测写入守卫（engine.js）

### A.1 代码改动
- 新增纯函数 `shouldWriteObservability(cycle, now)`：判 `now` 是否 ∈ 周期窗口 `[start_time, end_time]`（start/end 为 Date 或可被 `new Date` 解析；缺字段安全返回 `false`）。
- `runCycleAdapters` 观测写入条件由 `if (!dryRun)` 改为：
  ```js
  // 7) 可观测落库（dryRun 不写；宽限期补跑上月不覆写当月观测，见 shouldWriteObservability）
  if (!dryRun && shouldWriteObservability(cycle, new Date())) {
    await recordRuleRun({ ... });
  }
  ```
- 周期行 `cycle` 已在函数入口（line 76-81 `SELECT * FROM hse_assessment_cycle WHERE id=$1`）加载，**无重复查询**；`now` 取 `new Date()`。
- 导出 `shouldWriteObservability` 供单测。
- 中文注释固化守卫语义与四边界：窗口内每日运行→写；宽限期（end_time 已过去，调度 3 天窗口仍选中上月）→ 不写；dryRun→不写；人工重跑历史周期→不写；月末当秒（now===end_time）→写。

### A.2 扣分行为零变化（关键）
`if` 条件仅前置一道"观测守卫"，**位于扣分 upsert / 撤销 / 钳制 / 锁定逻辑之后**。宽限期补跑时，这些扣分链路照常执行（仅 last_run_* 不刷）；进行中周期每日运行与现状完全一致。parity 验证见 §4。

## 2. 任务 B：规则库页"执行周期"标签

- **列表接口**（`server/routes/hse-assessment-rule.js` GET `/`）：SELECT 增加标量子查询
  ```sql
  (SELECT c.cycle_code FROM hse_assessment_cycle c WHERE c.id = r.last_run_cycle_id) AS last_run_cycle_code
  ```

  `last_run_cycle_id` 为 NULL 时子查询返回 NULL（实测 TRAIN002 → NULL）。`camelKeys` 转为 `lastRunCycleCode`。

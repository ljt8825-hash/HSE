## 4. NULL 政策开关 + VIOLATION001/002 待建字段

### 4.1 NULL 政策开关位置

文件：`server/services/ruleEngine/adapters/violationAdapter.js`

```js
const COMPANY_SCORE = 5;   // 公司查处：5 分/次
const DEFAULT_SCORE = 1;   // 乡镇查处 / 自查自纠：1 分/次
// 未标注（check_source 为 NULL）的计分：保持 1（与规则库基准分一致）。
// 若业务要求「未标注不计分」，改为 0 即可，source_detail.checkSourceText 仍显示「未标注」。
const NULL_SCORE = DEFAULT_SCORE;
```

- **开关语义**：`check_source = 'company'` → 5 分；`township`/`self`/NULL → 1 分。NULL 政策由 `NULL_SCORE` 常量控制：**当前 = 1（保守口径，未标注仍计分）**；若业务要求「未标注不计分」，仅需把 `NULL_SCORE` 改为 `0` 一处即可，`checkSourceText` 仍正常显示「未标注」。
- **其他 NULL 处理**：`violation_date IS NULL` 的存活行 → `skipped`（reason=`no-date`），不扣分；`violator_id IS NULL` 的行不参与扫描（适配器仅取 `violator_id IS NOT NULL` 的候选）。
- 周期归属：`violation_date` 落在考核周期年月内（`make_date(y,m,1)` 至次月 1 日）。

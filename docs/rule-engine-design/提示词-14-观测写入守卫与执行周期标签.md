## 1. 任务 A：观测写入守卫（后端）

1. 在 runCycleAdapters（engine.js）加载本轮周期行（start_time/end_time；若已有 cycle 加载逻辑则复用，勿重复查询），计算：
   `const now = new Date(); const nowInCycleWindow = now >= new Date(cycle.start_time) && now <= new Date(cycle.end_time);`
2. 观测写入条件由 `if (!dryRun)` 改为 `if (!dryRun && nowInCycleWindow)`。语义：**观测三数只反映"当前时刻处于其窗口内"的周期**；宽限期补跑（now 晚于 end_time）正常执行扣分 upsert/撤销/钳制/锁定，**但不覆写 last_run_***。
3. runLogger.js 无需改签名；如判断逻辑放 runLogger 内更合适也可（recordRuleRun 内查周期窗口），但优先放 engine（cycle 已在手、避免多余查询）。在 engine 对应位置加中文注释说明守卫语义与宽限期场景。
4. 边界确认（写进注释与测试）：
   - 周期窗口内每日运行 → 写观测（现状不变）；
   - 宽限期（结束后 3 天内）补跑上月 → 不写观测；
   - dryRun → 不写观测（现状不变）；
   - 人工 facade 手动重跑历史周期 → 不写观测（可接受：观测语义=进行中周期）；
   - 月末最后一天 23:59:59 内仍属窗口内 → 写。

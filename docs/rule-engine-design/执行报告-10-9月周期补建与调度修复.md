## 2. 任务 B：调度语义长效修复（代码）

**仅改 `server/services/assessmentScheduler.js`**，引擎层零改动。

### B1 建"当月 + 上月兜底"
- 新增纯函数 `getScheduledTargetMonths(now=new Date())` → `[{year,month}(当月), {year,month}(上月)]`，跨年正确（2026-01→{2026,1}+{2025,12}；2026-12-31→{2026,12}+{2026,11}）。
- 新增 `createScheduledCycles(now)` 遍历两项调 `autoCreateAndSyncCycle`（幂等跳过），cron 回调改为 `createScheduledCycles(new Date())`；原死代码 `lastMonthDate()` 已删除。
- 日志文案更新为「自动确保考核周期存在（当月+上月兜底）」+ 逐月结果。

### B2 网格校验 3 天收尾宽限
`runGridCheck` WHERE 由 `end_time >= NOW()` 改为：
```sql
AND start_time <= NOW()
AND ( end_time >= NOW() OR end_time >= NOW() - INTERVAL '3 days' )
```
语义：窗口含今天（当月累计）+ 刚结束 3 天内（月初补跑上月收尾整月口径，upsert 幂等、人工锁定行不覆盖，与"执行评分"同路径，无新增风险）；`start_time<=NOW()` 保留（未来周期不选）。

### B3 调度开关外置
`const SCHEDULER_ENABLED = process.env.SCHEDULER_ENABLED !== 'false';`（默认 true，显式 `'false'` 停用，无需改码）。cron 表达式/时区保持硬编码常量。

### B4 单测
新增 `server/services/__tests__/assessmentScheduler.unit.test.js`（10 项，**不连真实库、不真实注册 cron**：mock `node-cron`/`config/db`/同级服务）：
- `getScheduledTargetMonths`：2026-09-01 / 2026-01-15 跨年 / 2026-12-31 年末 / 默认参数。
- `createScheduledCycles`：9/1 当月+上月各尝试一次、已存在 skipped 不插入；不存在时 INSERT。
- `runGridCheck`：memory-mode 跳过；3 天宽限 WHERE（断言含 `INTERVAL '3 days'` 与状态白名单）+ 聚合结果。
- `SCHEDULER_ENABLED` 外置导出。

**运行结果**：`Tests: 10 passed, 10 total` ✅。

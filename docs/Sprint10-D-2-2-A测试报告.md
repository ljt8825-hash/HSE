
## 四、修正过程中发现并修复的问题

### 4.1 冻结逻辑bug

| 项目 | 内容 |
|------|------|
| 问题描述 | 冻结端点先设置 `status='frozen'` 再更新排名，导致触发器 `trg_prevent_frozen_target` 阻止排名更新 |
| 错误信息 | "已冻结的考核对象记录不可修改" |
| 修正方案 | 调整执行顺序：先计算排名，再设置frozen状态 |
| 修正文件 | `server/routes/hse-assessment-monthly.js` - `POST /freeze/cycle/:id` |
| 修正状态 | ✅ 已修复 |

### 4.2 事务回滚bug

| 项目 | 内容 |
|------|------|
| 问题描述 | 冻结端点在pending检查失败时使用 `return` 退出，未调用 `ROLLBACK` |
| 修正方案 | 在return前添加 `await client.query('ROLLBACK')` |
| 修正文件 | `server/routes/hse-assessment-monthly.js` - `POST /freeze/cycle/:id` |
| 修正状态 | ✅ 已修复 |

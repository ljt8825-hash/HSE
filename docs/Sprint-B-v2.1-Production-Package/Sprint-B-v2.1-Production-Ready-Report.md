## 四、禁止事项

> ⚠️ **生产迁移执行过程中，严格禁止以下行为：**

| # | 禁止事项 | 原因 |
|---|---------|------|
| 1 | **禁止跳过 Step 0** | Step 0 是 P0 风险防线，跳过可能导致迁移失败 |
| 2 | **禁止人工修改生产数据** | 所有数据修改必须通过 Runbook 中定义的 SQL 脚本执行 |
| 3 | **禁止删除备份** | 备份表和备份文件必须保留至少 7 天，72 小时观察期内严禁删除 |
| 4 | **禁止关闭校验** | 动态基线校验、脏数据检查、status 检查必须保留，不得注释或移除 |
| 5 | **禁止使用 ELSE 自动覆盖未知 status** | 未知 status 必须记录并人工确认，禁止自动兜底 |
| 6 | **禁止在未回滚的情况下重复执行 B-2** | 重复执行可能导致数据覆盖，必须先回滚再重试 |
| 7 | **禁止跨会话执行 B-0/B-2 全流程** | 临时表会话级存储，断开后丢失，必须使用同一会话 |

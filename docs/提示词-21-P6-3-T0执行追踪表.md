#### 4. 生成异常处理决策树

以决策树形式展示关键异常的处理路径：

```

  ├─ 是否 P0 阻断？
  │   ├─ 是（0.7 uk 缺失 / 0.10 her 偏差 > 5% / 0.12 baseline NULL）
  │   │   └─ 修复 → 重跑 Step 0 → 仍 FAIL → 延期
  │   └─ 否（0.1 锁冲突 / 0.2 活跃连接）
  │       └─ 等待/清理 → 重跑 → 仍 FAIL → 评估是否延期
  │
B-2 迁移 FAIL
  └─ 立即执行 06_Rollback.sql B-2 回滚段 → 排查 → 修复 → 重跑
  │
只读保护验证 FAIL
  └─ 触发器未生效 → 检查触发器是否存在 → 重新创建
  └─ 权限未拒绝 → 检查 REVOKE 是否执行 → 重新执行
```

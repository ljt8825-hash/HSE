## 3. 后端改动（`server/routes/objectives.js`）

### 3.1 新增 helper（参照 `goalToCamel` 风格，置于其后）
- `responsibilityToCamel(r)`：snake 行 → camel 响应（`employee_id→employeeId`、`employee_name→person`、`period_year→year`、`period_quarter→quarter`、`score_total→score`、`grade→level` 等），与前端现有字段名对齐。
- `RESPONSIBILITY_FIELD_MAP` + `toResponsibilitySnake(body)`：camelCase 请求体 → snake_case 列映射（`person→employee_name`、`year→period_year`、`quarter→period_quarter`、`score→score_total`、`level→grade`、`employeeId→employee_id` 等），跳过 `undefined`。

### 3.2 responsibilities 路由（仅此区块）
- `POST /responsibilities`：请求体先 `toResponsibilitySnake` 再动态拼 SQL；RETURNING 经 `responsibilityToCamel` 输出。
- `PUT /responsibilities/:id`：同上。
- `GET /responsibilities`：列表 `rows.map(responsibilityToCamel)`。
- `GET /responsibilities/:id`：单行 `responsibilityToCamel`。
- 内存兜底（`!isConnected()`）分支同步使用 `mapped`，保持行为一致（生产 `isConnected()=true`，不走此分支）。

> 无 `validateBody`/zod 校验层作用于此路由，请求体原样透传，FIELD_MAP 是唯一需要的修正点（与提示词-46 结论一致）。

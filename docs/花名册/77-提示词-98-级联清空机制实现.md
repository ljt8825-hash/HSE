## 一、背景

提示词-97 修复了清空按钮的 401 跳登录和 FK 错误友好提示问题，但**清空操作本身仍不可达**：

| 阻塞层 | 详情 | 状态 |
|--------|------|------|
| 401 Token 过期 | access token 改为 12h + body 刷新 | ✅ 已修复 |
| 6 个 NO ACTION FK | `risk_level_records`、`risk_score_records`、`risk_score_history`、`hse_responsibility`、`hse_grid_inspection_records`、`employee_assignment` | ❌ 仍阻塞 |
| 5412 条业务引用 | employee_assignment 5234 + hse_responsibility 129 + risk 系列 49 | ❌ 仍阻塞 |

当前 `POST /clear-all` 的 DELETE 顺序是 `employee_assignment → employee → pending → batch`，但 `employee` 被 6 个 NO ACTION FK 引用，DELETE 被拦截回滚。

---

## 二、设计方案

### 2.1 级联清空顺序

按 FK 依赖拓扑排序，从叶子表向根表逐层清除：

```
第1层：清除所有 NO ACTION FK 业务数据（解除对 employee 的硬引用）
  ├── DELETE FROM risk_score_records       (FK NO ACTION → employee)
  ├── DELETE FROM risk_score_history       (FK NO ACTION → employee)
  ├── DELETE FROM risk_level_records       (FK NO ACTION → employee)
  ├── DELETE FROM hse_responsibility       (FK NO ACTION → employee)
  └── DELETE FROM hse_grid_inspection_records (FK NO ACTION → employee)

第2层：清除所有 SET NULL FK 业务数据（可选，保持数据一致性）
  ├── DELETE FROM employee_induction_training
  ├── DELETE FROM employee_training_status
  ├── DELETE FROM hse_violation
  ├── ... (其余 34 个 SET NULL 表，共约 40 个业务表)

第3层：清除人员核心数据
  ├── DELETE FROM employee_assignment      (FK NO ACTION → employee，但已在第1层前清除)
  ├── DELETE FROM employee                 (所有 FK 引用已在前两层清除)
  ├── DELETE FROM employee_import_pending
  └── DELETE FROM employee_import_batch
```

### 2.2 安全机制

| 机制 | 说明 |
|------|------|
| 事务包裹 | 整个清空过程在一个事务中，任一步失败则整体回滚 |
| 行数统计 | 每层清除后记录 `rowCount`，返回给前端展示 |
| 预检查 | 执行前统计各表行数，前端二次确认时展示 |
| admin-only | 保持原有 `requireRole('admin')` 中间件 |
| 备份保护 | 执行前强制检查 backup_97_* 备份表是否存在 |

### 任务1：后端 — 实现级联清空路由

**文件**：`server/routes/hse-employee-import-v2.js`

**新增路由**：`POST /clear-all-cascade`

在现有 `POST /clear-all` 之后新增级联清空路由：

```javascript
/**
 * POST /clear-all-cascade
 * 级联清空所有人员信息 — 先解除 FK 依赖，再清空核心表
 * 危险操作，仅 admin 可执行
 */
router.post('/clear-all-cascade', requireRole('admin'), async (req, res) => {
  try {
    if (!isConnected()) return res.json(error(-1, '数据库未连接'));

    const client = await pool.connect();
    try {
      await client.query('BEGIN');

      const stats = {};

      // ==========================================
      // 第1层：清除所有 NO ACTION FK 业务数据
      // ==========================================
      console.warn('[ImportV2][clear-all-cascade] 第1层：清除 NO ACTION FK 业务数据');

      // 1.1 risk_score_records（FK NO ACTION → employee）
      stats.risk_score_records = (await client.query('DELETE FROM risk_score_records')).rowCount;

      // 1.2 risk_score_history（FK NO ACTION → employee）
      stats.risk_score_history = (await client.query('DELETE FROM risk_score_history')).rowCount;

      // 1.3 risk_level_records（FK NO ACTION → employee）
      stats.risk_level_records = (await client.query('DELETE FROM risk_level_records')).rowCount;

      // 1.4 hse_responsibility（FK NO ACTION → employee）
      stats.hse_responsibility = (await client.query('DELETE FROM hse_responsibility')).rowCount;

      // 1.5 hse_grid_inspection_records（FK NO ACTION → employee）
      stats.hse_grid_inspection_records = (await client.query('DELETE FROM hse_grid_inspection_records')).rowCount;

      // ==========================================
      // 第2层：清除所有 SET NULL FK 业务数据
      // ==========================================
      console.warn('[ImportV2][clear-all-cascade] 第2层：清除 SET NULL FK 业务数据');

      const setNullTables = [
        'employee_induction_training',
        'employee_training_status',
        'hse_violation',
        'hse_assessment_record',
        'position_safety_profile',
        'hse_insurance_record',
        'hse_emergency_team_member',
        'hse_accident_involved',
        // 注：执行时需通过 FK 审计补全剩余 SET NULL 表名
      ];

      for (const tbl of setNullTables) {
        try {
          stats[tbl] = (await client.query(`DELETE FROM ${tbl}`)).rowCount;
        } catch (e) {
          // 表可能不存在，跳过
          console.warn(`[ImportV2][clear-all-cascade] 跳过不存在的表: ${tbl}`);
        }
      }

      // ==========================================
      // 第3层：清除人员核心数据
      // ==========================================
      console.warn('[ImportV2][clear-all-cascade] 第3层：清除人员核心数据');

      // 3.1 employee_assignment
      stats.employee_assignment = (await client.query('DELETE FROM employee_assignment')).rowCount;

      // 3.2 employee
      stats.employee = (await client.query('DELETE FROM employee')).rowCount;

      // 3.3 employee_import_pending
      stats.employee_import_pending = (await client.query('DELETE FROM employee_import_pending')).rowCount;

      // 3.4 employee_import_batch
      stats.employee_import_batch = (await client.query('DELETE FROM employee_import_batch')).rowCount;

      await client.query('COMMIT');

      console.warn('[ImportV2][clear-all-cascade] 级联清空完成', stats);
      res.json(success(stats, '人员信息已级联清空（含业务数据）'));
    } catch (err) {
      await client.query('ROLLBACK');
      const msg = String(err.message || err);
      throw new Error(`级联清空失败（已回滚）：${msg}`);
    } finally {
      client.release();
    }
  } catch (err) {
    res.json(error(-1, `级联清空失败：${err.message}`));
  }
});
```

**关键约束**：
- 必须在 `POST /clear-all` 之后新增，不修改原有路由
- 第2层的 SET NULL 表名必须通过 FK 审计动态获取，**禁止硬编码不存在的表名**
- 执行时需先执行诊断 SQL 获取完整的 SET NULL 表清单，再写入路由

### 任务2：后端 — 新增预检查路由

**文件**：`server/routes/hse-employee-import-v2.js`

**新增路由**：`GET /clear-all-preview`

返回级联清空将影响的数据行数，供前端二次确认弹窗展示：

```javascript
/**
 * GET /clear-all-preview
 * 返回级联清空将影响的数据行数（预检查，不执行写操作）
 */
router.get('/clear-all-preview', requireRole('admin'), async (req, res) => {
  try {
    if (!isConnected()) return res.json(error(-1, '数据库未连接'));

    const client = await pool.connect();
    try {
      const preview = {};

      // 第1层：NO ACTION 业务表
      preview.risk_score_records = parseInt((await client.query('SELECT COUNT(*) as c FROM risk_score_records')).rows[0].c, 10);
      preview.risk_score_history = parseInt((await client.query('SELECT COUNT(*) as c FROM risk_score_history')).rows[0].c, 10);
      preview.risk_level_records = parseInt((await client.query('SELECT COUNT(*) as c FROM risk_level_records')).rows[0].c, 10);
      preview.hse_responsibility = parseInt((await client.query('SELECT COUNT(*) as c FROM hse_responsibility')).rows[0].c, 10);
      preview.hse_grid_inspection_records = parseInt((await client.query('SELECT COUNT(*) as c FROM hse_grid_inspection_records')).rows[0].c, 10);

      // 第3层：核心人员表
      preview.employee_assignment = parseInt((await client.query('SELECT COUNT(*) as c FROM employee_assignment')).rows[0].c, 10);
      preview.employee = parseInt((await client.query('SELECT COUNT(*) as c FROM employee')).rows[0].c, 10);
      preview.employee_import_pending = parseInt((await client.query('SELECT COUNT(*) as c FROM employee_import_pending')).rows[0].c, 10);
      preview.employee_import_batch = parseInt((await client.query('SELECT COUNT(*) as c FROM employee_import_batch')).rows[0].c, 10);

      // 汇总
      const totalNoAction = preview.risk_score_records + preview.risk_score_history + preview.risk_level_records + preview.hse_responsibility + preview.hse_grid_inspection_records;
      const totalCore = preview.employee + preview.employee_assignment + preview.employee_import_pending + preview.employee_import_batch;

      res.json(success({
        layers: preview,
        summary: {
          noActionTotal: totalNoAction,
          coreTotal: totalCore,
          grandTotal: totalNoAction + totalCore,
        },
      }, '预检查完成'));
    } finally {
      client.release();
    }
  } catch (err) {
    res.json(error(-1, `预检查失败：${err.message}`));
  }
});
```

```typescript
// 新增 import
import { clearAllCascade, getClearAllPreview, type EmployeeImportV2Api } from '#/api/hse/employee-import-v2';

// 新增状态
const clearAllPreview = ref<any>(null);
const clearAllLoading = ref(false);

// 改造 openClearAllConfirm
async function openClearAllConfirm() {
  clearAllLoading.value = true;
  try {
    const preview: any = await getClearAllPreview();
    clearAllPreview.value = preview;

    const { summary } = preview;
    Modal.confirm({
      title: '确定级联清空所有人员信息？',
      content: `此操作将物理删除以下数据（不可逆）：\n\n` +
        `业务数据：${summary.noActionTotal} 条（风险记录 ${preview.layers.risk_score_records + preview.layers.risk_score_history + preview.layers.risk_level_records}、责任体系 ${preview.layers.hse_responsibility}、网格检查 ${preview.layers.hse_grid_inspection_records}）\n` +
        `人员数据：${summary.coreTotal} 条（员工 ${preview.layers.employee}、任职 ${preview.layers.employee_assignment}、导入批次 ${preview.layers.employee_import_batch}、待确认 ${preview.layers.employee_import_pending}）\n\n` +
        `合计 ${summary.grandTotal} 条数据将被永久删除。删除后无法恢复，是否继续？`,
      okText: '确认清空',
      okType: 'danger',
      cancelText: '取消',
      width: 560,
      onOk: handleClearAll,
    });
  } catch (e: any) {
    message.error('预检查失败：' + (e.message || '未知错误'));
  } finally {
    clearAllLoading.value = false;
  }
}

// 改造 handleClearAll — 使用级联清空
async function handleClearAll() {
  try {
    const res: any = await clearAllCascade();
    const stats = res;
    const details = [
      stats.employee ? `员工 ${stats.employee} 人` : '',
      stats.employee_assignment ? `任职 ${stats.employee_assignment} 条` : '',
      stats.employee_import_batch ? `批次 ${stats.employee_import_batch} 个` : '',
      stats.employee_import_pending ? `待确认 ${stats.employee_import_pending} 条` : '',
    ].filter(Boolean).join('、');
    message.success(`清空完成：${details || '0 条'}`);
    loadList();
    if (detailDrawerVisible.value) {
      detailDrawerVisible.value = false;
    }
  } catch (e: any) {
    const errMsg: string = e?.message || e?.toString() || '未知错误';
    const status: number | undefined = e?.response?.status;
    if (status === 401 || errMsg.includes('401') || errMsg.includes('token') || errMsg.includes('认证') || errMsg.includes('登录')) {
      message.error('会话已过期，请重新登录后再试');
    } else if (status === 403 || errMsg.includes('403') || errMsg.includes('权限')) {
      message.error('权限不足，仅管理员可执行清空操作');
    } else {
      message.error('清空失败：' + errMsg);
    }
  }
}
```

## 四、后端阻塞（超出本提示词范围，需单独后端修复）

本提示词明确 **禁止修改后端路由**。联调发现 `hse-org-center.js` 存在两处后端缺陷，导致"写操作"与"类型枚举"不可用：

### 阻塞1：`requireRole` 调用形式错误（导致所有写接口 403）
- 全仓其他路由均用**展开写法** `requireRole('admin', 'safety_manager')`（rest 参数 `...allowedRoles` 收成 `['admin','safety_manager']` → `.includes('admin')` 为真）。
- `hse-org-center.js` 三处写路由误用**数组写法** `requireRole(['admin', 'safety_manager'])` → `allowedRoles` 变成 `[['admin','safety_manager']]` → `.includes('admin')` 恒假 → **永久 403**。
- 影响：`POST/PUT/DELETE /org` 与 `POST/PUT/DELETE /operation-unit` 全部不可达。
- **建议修复（后端，1 行 ×3 处）**：将 `requireRole(['admin', 'safety_manager'])` 改为 `requireRole('admin', 'safety_manager')`；或把 `requireRole` 签名改为 `function requireRole(allowedRoles)` 支持数组。

### 阻塞2：`/org/types` 与 `/operation-unit/types` 被 `/:id` 路由顺序遮蔽
- `GET /org/types` 被 `GET /org/:id` 先匹配，`"types"` 被当 id 解析 → "无效的类型 bigint 输入语法"。
- 影响：类型枚举接口失效。
- **前端兜底**：本页组织类型下拉**未依赖该接口**，改用静态 `orgTypeOptions`（company/department/center/town_center，与 `orgTypeLabel` 映射一致），功能不受影响。`getOrgTypes`/`getOperationUnitTypes` 函数仍按规范导出，待后端修复路由顺序后可启用。

> 上述两项均属后端路由缺陷，不在本提示词改动范围内；前端已做兼容，待后端修复后写操作与枚举即自动生效，**无需改前端**。

## 五、前端功能实现说明

### 已实现（读取类，依赖的 GET 接口均联调正常）
- **组织树**：`a-tree`（`field-names` 为 `{title:'org_name', key:'id', children:'children'}`），节点标题 `org_name [类型中文] (org_code)`，停用节点 `node-inactive` 样式；搜索框大小写不敏感、递归保留父路径；默认展开第一层。
- **组织详情**：`a-descriptions` 2 列 bordered，含 组织名称/编码/类型(tag)/层级路径/编制人数(0→`-`，与 114 一致)/状态(启用绿/停用灰)/描述。
- **关联班组（映射管理）**：选中组织后展示其下已映射 department（v110 `org_unit_id` 关联）。数据取自 `getDeptList`（`#/api/hse/employee`，camelCase），表格列 序号/班组名称/班组编码/层级(levelText)/状态。
- **弹窗**：新增/编辑组织（上级组织 disabled 显示、组织编码必填且编辑时 disabled、组织名称必填、组织类型 select、排序、描述）。本次**不含组织负责人选择器**（manager_id），与提示词约定一致。
- **权限**：`canEdit = hasAccessByRoles(['admin','safety_manager'])`，与 departments.vue 一致。

### 关联班组映射的兼容处理（重要）
- **主路径**：按规范过滤 `department.org_unit_id === 当前组织 id`（精确 v110 映射）。
- **临时兜底**：实测当前后端 `GET /departments` 与 `/departments/tree` **未返回 `org_unit_id` 字段**（属后端读接口未暴露该列，超出本提示词范围），故主路径暂不命中。改用 **v110 前缀逻辑反向匹配**：`当前组织.org_name.startsWith(department.name)`（即 `hse_org_unit.org_name LIKE department.name || '%'` 的反向），使 12 个乡镇作业中心可正确展示其映射班组，功能可见。
- 后端在 department 读接口补齐 `org_unit_id` 后，主路径自动生效，兜底逻辑可移除（已在代码注释标注）。

### 3.2 枚举 diff（`提示词-135 §5.3` 兼容映射）

**`views/training/index.vue`（培训管理 — type/status）**
- 前：`searchForm.type` / `trainingForm.type` 写死 `safety/skills/emergency/induction/regular`；`searchForm.status` 写死 `draft/planned/ongoing/completed/cancelled`。
- 后：`typeOptions` / `statusOptions` 由 `getTrainingTypes()` / `getPlanStatusFlow()` 动态生成，**规则优先 + 历史遗留选项按 value 去重合并**（保证下拉覆盖新旧数据）。`getTypeText/Color`、`getStatusText/Color` 先查动态选项，再回退中文/旧 code 兜底映射（如 `消防培训/HSE/新员工/驾驶员/太行/复训`、`合格/不合格`）。

**`views/training/ledger/index.vue`（培训台账 — result）**
- 前：`result` 写死 `合格/不合格/缺勤`（搜索+表单）。
- 后：`resultOptions` 由 `getAssessmentGrades()` 生成（规则中文标签 = 库内实际值），合并遗留 `缺勤`。`getResultColor` 优先取规则 `semanticColor`，回退中文映射。

**`views/training/plans/index.vue`（培训计划 — status）**
- 前：`status` 写死 `draft/approved/in_progress/completed/cancelled`（搜索+表单）。
- 后：`statusOptions` 由 `getPlanStatusFlow()` 生成 + 遗留补全。`getStatusColor/Text` 动态优先、中文回退。
- 注：`planType`（annual/special/new_employee）不在本次 R4 范围，保持硬编码（提示词仅要求 status）。

### 3.3 兼容性要点
- 规则 `code` 与库历史中文值（如 `消防培训`、`合格`）共存：动态 options 覆盖规则值，兜底 map 覆盖历史中文值 → 既有数据展示不受影响。
- `fetchRules/fetchRuleGrades/fetchPlanStatusFlow` 在 `onMounted` 拉取；失败则回退历史遗留选项，页面仍可用。

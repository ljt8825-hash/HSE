## 1. 背景

"批量导入"模块（`/personnel/batch-import`）是人员管理菜单的第 6 项，用于批量导入文档、标准条款、安全记录三种类型文件。该模块是独立开发的（HSE V2.0 Sprint5），尚未经过系统检查。

**目标**：对批量导入模块进行 5 维度全面诊断，发现潜在问题，为后续修复提供依据。

## 3. 诊断维度

### 3.1 维度一：前端代码质量

请检查以下方面：

1. **组件规范合规性**
   - 是否使用 `useDataTable` 托管列表页状态（vs 手写 loading/dataList/total/pagination）
   - 是否使用 `useSearchForm` 托管搜索表单
   - 是否使用 `Page` 组件（`@vben/common-ui`）
   - 是否使用 Ant Design Vue 组件（非 Element Plus）

2. **类型安全**
   - TypeScript 类型定义是否完整
   - 是否存在 `as any` 类型断言
   - `reactive` 表单可选字段是否用 `undefined` 初始化（非 `null`）

3. **代码质量**
   - 是否存在未使用的 import
   - 是否存在死代码
   - 组件拆分是否合理
   - 命名是否规范

4. **API 调用**
   - 是否通过 `#/api/hse/batch-import` 统一调用
   - 上传请求是否设置 `Content-Type: undefined`
   - 错误处理是否完善

### 3.2 维度二：后端代码质量

请检查以下方面：

1. **路由注册**
   - `server/app.js` 中是否正确注册
   - 路由前缀是否与前端 API 一致

2. **权限控制**
   - `requireRole` 调用是否正确（rest 参数 vs 数组）
   - 角色权限码是否与前端一致

3. **错误处理**
   - 异常分支是否使用统一的 `success`/`error` 响应
   - 数据库连接检查是否完整
   - 参数校验是否充分

4. **事务与并发**
   - 创建任务是否使用数据库事务
   - 异步处理是否使用了 `setImmediate`（正确用法）
   - 并发限制是否合理（`CONCURRENT_TASK_LIMIT = 3`）

5. **文件处理**
   - 上传文件是否通过 `fixUploadFilenames` 处理中文文件名
   - 文件存储路径是否正确
   - 临时文件清理是否有机制

### 3.3 维度三：数据流一致性

请检查以下方面：

1. **字段命名一致性**
   - 前端发送的字段名（camelCase）与后端接收的字段名是否一致
   - 后端返回的字段名（snake_case）与前端 `dataIndex` 是否一致

2. **状态枚举一致性**
   - 前端 `TaskStatus`/`ItemStatus` 与后端状态转换逻辑是否一致
   - 是否所有状态都有对应的前端展示

3. **分页一致性**
   - 前端 `pagination` 字段名是否与后端返回一致
   - 后端是否正确处理 `page`/`pageSize` 参数

4. **类型枚举一致性**
   - `import_type` 的 `document`/`standard_clause`/`safety_record` 前后端是否一致

### 3.4 维度四：边界与异常

请检查以下方面：

1. **空状态处理**
   - 任务列表为空时的展示
   - 明细列表为空时的展示
   - 无模板文件时的处理

2. **并发冲突**
   - 同时创建多个任务时的行为
   - 同一任务重复预检查/确认时的行为
   - 进度轮询在任务完成后的停止

3. **文件异常**
   - 超大文件（>100MB）的拦截
   - 不支持的格式的拦截
   - 损坏文件的处理

4. **安全**
   - 路径遍历攻击防护
   - 文件类型校验是否仅依赖扩展名
   - 操作日志是否完整

### 3.5 维度五：回归检查

请检查以下方面：

1. **菜单与路由**
   - 菜单是否正常显示
   - 路由是否正确注册
   - 是否存在重复路由（`hse-batch-import.ts` vs `hse-07-personnel.ts`）

2. **跨模块影响**
   - 是否引用了其他模块的 API 或组件
   - 是否修改了其他模块的数据

3. **构建兼容性**
   - `pnpm build` 是否通过
   - `vue-tsc` 是否有新增错误

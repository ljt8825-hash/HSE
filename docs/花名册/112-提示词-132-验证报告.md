## 2. 各修复项实现明细

### 2.1 R1 — 修复 vehicle export 路由遮蔽（P2）

**文件**：`server/routes/insurance.js`

**问题**：`GET /vehicle/export`（约 1128 行）注册在 `GET /vehicle/:id`（约 328 行）之后，Express 将字面量 `export` 匹配为 `:id` 参数，导出端点永久不可达。与 131-F1 对 overage export 的处理同源。

**修复**：将 `GET /vehicle/export` 路由块整体前移至 `GET /vehicle/:id` 之前，并附带 `requireRole('admin','safety_manager')`（与本次 F6 权限收紧一并处理）。

| 项 | 修改前 | 修改后 |
|----|--------|--------|
| 注册顺序 | `/vehicle/:id`(328) → ... → `/vehicle/export`(1128，被遮蔽) | `/vehicle/export`(345) → `/vehicle/:id`(380) |
| 鉴权 | 无 | `requireRole('admin','safety_manager')` |

前移后不再产生遮蔽，导出逻辑本身未改动。

### 2.2 R2 — 子系统B 导出 CSV 身份证号脱敏（P2）

**文件**：`server/routes/insurance.js`

**问题**：`GET /insurance/overage/export` 的 CSV 输出中身份证号列为明文 18 位完整号，与子系统A（auto-export，已脱敏）不一致，存在 PII 泄露风险。

**修复**：新增 `maskIdCard(v)` 工具函数（insurance.js:35），在 CSV 行生成处（约 1084 行）替换原明文映射：

```javascript
// insurance.js:35
function maskIdCard(v) {
  const s = String(v || '');
  if (!s) return '';
  if (s.length < 8) return '****';
  return `${s.slice(0, 4)}**********${s.slice(-4)}`;
}
```
```javascript
// CSV 行映射（约 1084 行）
maskIdCard(r.id_card).replace(/"/g, '""'),
```

> `decryptMiddleware('id_card')` 已在 131-F1 挂载，对明文为 no-op，脱敏逻辑对明文/密文态均安全。

### 2.3 F6 — 补齐超龄路由权限控制（P2）

**文件**：
- `server/routes/hse-employee.js`（3 个 auto 端点）
- `server/routes/over-age-personnel.js`（6 个端点）
- `server/routes/insurance.js`（8 个 overage 端点，含 export）

**问题**：三套超龄路由仅依赖全局 `authMiddleware`（登录校验），未在路由层声明 `requireRole`，任何已登录用户均可直接调用超龄 API，与前端 `authority:['admin']` 声明不一致。

**修复**：按项目约定 `requireRole('admin','safety_manager')` 加在 handler 链最前（先于 `decryptMiddleware` / `validateBody`）。实际落地行号如下：

### 2.4 F7 — 前端阈值去硬编码（P2）

**文件**：`安全看板vben/apps/web-antd/src/views/hse/employee/over-age/index.vue`

**问题**：`index.vue` 硬编码 `MALE_THRESHOLD=60 / FEMALE_THRESHOLD=50`，与后端规则文件为独立副本，规则变更后前端展示阈值与后端计算不一致。

**修复**：
1. 删除原硬编码阈值常量，改为仅作初始默认值的 `DEFAULT_MALE_THRESHOLD=60 / DEFAULT_FEMALE_THRESHOLD=50`（index.vue:356-357）；
2. `statsData` 初始化 `thresholds: { 男: DEFAULT_MALE_THRESHOLD, 女: DEFAULT_FEMALE_THRESHOLD }`（index.vue:364）；
3. `getGenderThreshold` / `getGenderThresholdText` / `ruleDescription` 全部改为读取 `statsData.value.thresholds`，以 `??` 回退默认值（index.vue:368-385）；
4. `fetchStats()` 刷新时保留已下发阈值：`thresholds: res.thresholds || statsData.value.thresholds`（index.vue:624）；
5. `onMounted` 改为 `await fetchStats()` 先取权威阈值，再 `fetchData()`（index.vue:731-732）。

效果：阈值单一来源（后端 `employee-age-rule.json`），前端不再持独立副本，规则变更后展示自动同步。

### 2.5 F10 — 兜底值 female:55→50 修正（P3）

**文件**：`server/config/hseRules/index.js`

**问题**：`getOverAgeThresholds()` 兜底值 `female: 55`（原第 84 行）与 JSON 规则 `female: 50` 不一致，JSON 缺失/解析失败时静默回退到 55，女性阈值漂移 5 岁。

**修复**（index.js:86）：

```javascript
// 修改前：return rule.overAgeThresholds || { male: 60, female: 55, default: 60 };
// 修改后：
return rule.overAgeThresholds || { male: 60, female: 50, default: 60 };
```

此修改仅影响 JSON 解析失败时的兜底；正常运行时走 JSON 的 `female:50`，与 F7 前端读取口径一致。

## 一、背景

用户决定将 `F:\hse-dashboard` 迁移到 `G:\hse-dashboard`。G盘将作为系统专用盘，只存放系统代码、系统数据、表格、文档等。F盘不再用于开发。

**关键前提（已调研确认）**：
- 代码中无硬编码 `F:` 盘路径（`server/` 和 `安全看板vben/` 均使用相对路径）
- PostgreSQL 运行在 `127.0.0.1:5432`，与盘符无关，数据库无需迁移
- 代码库总大小约 5.4 GB（含 node_modules、.npm-cache 等约 2-3 GB）

## 二、执行任务

### 任务0：迁移前准备工作

**目标**：确认迁移前状态，做好备份。

1. 确认 G 盘存在且有足够空间（至少 10 GB 可用）
2. 确认当前 F 盘项目状态：
   ```powershell
   Get-ChildItem F:\hse-dashboard -Directory | Select-Object Name
   ```
3. 数据库备份（以防万一）：
   ```powershell
   & 'd:\PostgreSQL\17\bin\pg_dump' -h 127.0.0.1 -U hse_app -F c -f "F:\hse-dashboard\backups\hse_bk_pre_migration_20260802.dump" safety_dashboard
   ```
4. 确认 DUMP_EXIT=0，备份文件大小合理

### 任务1：复制代码库到 G 盘

**目标**：将项目文件复制到 G 盘，排除可重建的目录。

**方法**：使用 `robocopy`（Windows 自带，支持断点续传和排除目录）：

```powershell
robocopy F:\hse-dashboard G:\hse-dashboard /E /COPY:DAT /DCOPY:T /MT:4 /R:2 /W:5 ^
  /XD node_modules .npm-cache .pnpm-store dist dist_stale_* ^
  /XF *.log
```

**参数说明**：
- `/E`：复制所有子目录（含空目录）
- `/COPY:DAT`：保留文件数据、属性、时间戳
- `/MT:4`：4 线程并行复制
- `/XD`：排除这些目录（node_modules 等通过 pnpm install 重建）
- `/XF *.log`：排除日志文件

**验收标准**：
- robocopy 完成，无 "Failed" 错误
- `G:\hse-dashboard` 目录结构与 F: 盘一致
- `docs/`、`server/`、`安全看板vben/` 等关键目录存在

### 任务2：安装依赖

**目标**：在 G 盘重新安装 npm 依赖。

```powershell
cd G:\hse-dashboard\安全看板vben
pnpm install
```

**注意**：如果 `pnpm install` 报 lockfile 错误，先执行：
```powershell
pnpm install --no-frozen-lockfile
```

**验收标准**：
- `pnpm install` 成功完成（exit 0）
- `node_modules` 目录已生成

### 任务3：验证构建

**目标**：确认迁移后项目可正常构建。

```powershell
cd G:\hse-dashboard\安全看板vben
# 先备份旧 dist（绕开 safe-delete 垫片）
if (Test-Path dist) { Move-Item dist "dist_stale_$(Get-Date -Format 'yyyyMMdd_HHmmss')" }
pnpm --filter @vben/web-antd build
```

**验收标准**：
- BUILD_EXIT=0
- `dist/index.html` 已生成
- 无 `EPERM|Failed|ERROR|ELIFECYCLE` 级错误

### 任务4：验证后端启动

**目标**：确认后端可正常启动并连接数据库。

```powershell
cd G:\hse-dashboard\server
node app.js
```

**验收标准**：
- 后端成功启动，监听 `:5666`
- 日志显示 "DB connected" 或类似信息
- `GET http://127.0.0.1:5666/api/health` → 200

启动后 `Ctrl+C` 停止即可（不需要长期运行）。

### 任务5：验证关键 API

**目标**：确认后端 API 正常返回数据。

```powershell
# 使用自签 JWT 调用关键 API（样例）
# 启动后端后，用 curl 或 Node 脚本验证：
# GET /api/hse/employee/employees → total 应与数据库一致
# GET /api/emergency/events/list → total=5
# GET /api/hse/assessment → total=5
```

**验收标准**：
- 至少 3 个关键 API 返回 code=0
- total 值与数据库一致

### 任务6：F 盘标记（不删除）

**目标**：标记 F 盘旧目录为"已迁移"，但**不删除**。

1. 在 `F:\hse-dashboard\` 下创建 `_MIGRATED_TO_G_20260802.txt` 文件，内容：
   ```
   本项目已迁移至 G:\hse-dashboard
   迁移日期：2026-08-02
   请勿在此目录继续开发
   ```

**不要删除 F 盘原目录**——保留作为备份，确认 G 盘一切正常后再手动清理。

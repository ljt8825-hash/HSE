# 提示词-107：组织管理与岗位管理模块检查

## 背景

提示词-106 完成了 `is_public_welfare` 全链路修复和超龄人员模块检查。当前"人员管理"菜单下还有 4 个子模块未检查：员工列表、组织管理、岗位管理、批量导入。

**组织管理**和**岗位管理**是花名册导入的基础数据——导入时部门匹配（`matchOrgUnit`）依赖 `hse_org_unit` 表，岗位匹配（`matchPosition`）依赖 `position` 表。这两个模块的数据完整性和显示正确性直接影响导入成功率。

本提示词优先检查这两个基础模块，确认数据与花名册交互正常。

## 影响范围

| 层级 | 文件 | 改动类型 |
|------|------|---------|
| 前端 | `安全看板vben/apps/web-antd/src/views/hse/org-unit/index.vue` | 仅检查 |
| 前端 | `安全看板vben/apps/web-antd/src/views/hse/position/index.vue` | 仅检查 |
| 后端 | `server/routes/hse-employee.js`（组织/岗位相关端点） | 仅检查 |
| 数据库 | `hse_org_unit`、`position`、`hse_operation_unit` 表 | 仅检查 |

> **约束**：仅检查报告，发现问题最小修复。禁止修改菜单、路由、其他业务模块。优先改后端，不改前端。

## Task 2：组织管理模块检查

### 2.1 检查点

1. **列表页字段显示**：组织名称（org_name）、组织编码（org_code）、组织类型（org_type）、组织路径（org_path）、状态（status）等列是否正常显示
2. **字段映射**：是否存在 camelKeys 键名不匹配（与员工档案 101/102 同类问题）
3. **数据完整性**：`hse_org_unit` 表数据是否覆盖所有导入中使用的组织（乡镇作业中心等）
4. **搜索/筛选**：搜索组织名称、筛选组织类型是否正常
5. **与花名册交互**：导入时 `matchOrgUnit` 依赖的组织是否在组织管理页面中可见

### 2.2 检查方法

1. 打开组织管理页面 → 确认列表有数据
2. 浏览器 Network 面板 → 查看 API 返回的字段名（snake_case 还是 camelCase）
3. 对比前端 `dataIndex` → 确认键名匹配
4. 检查后端对应端点（搜索 `org-unit` 或 `org_unit` 在 `hse-employee.js` 中）
5. 核对 `hse_org_unit` 表的 org_type 分布（作业中心、项目公司等）

### 2.3 数据核验

```sql
-- 组织类型分布
SELECT org_type, COUNT(*) FROM hse_org_unit WHERE is_deleted = false GROUP BY org_type;

-- 组织总数
SELECT COUNT(*) FROM hse_org_unit WHERE is_deleted = false;

-- 作业单元数
SELECT COUNT(*) FROM hse_operation_unit WHERE is_deleted = false;
```

## Task 3：岗位管理模块检查

### 3.1 检查点

1. **列表页字段显示**：岗位名称（name）、岗位编码（position_code）、工种分类（job_category）、风险等级（risk_level）、是否安全关键岗位（is_safety_critical）等列是否正常显示
2. **字段映射**：是否存在 camelKeys 键名不匹配
3. **数据完整性**：`position` 表数据是否覆盖所有导入中使用的岗位（保洁员、驾驶员、管理员等）
4. **搜索/筛选**：搜索岗位名称、筛选工种分类是否正常
5. **与花名册交互**：导入时 `matchPosition` 依赖的岗位是否在岗位管理页面中可见

### 3.2 检查方法

1. 打开岗位管理页面 → 确认列表有数据
2. 浏览器 Network 面板 → 查看 API 返回的字段名
3. 对比前端 `dataIndex` → 确认键名匹配
4. 检查后端对应端点

### 3.3 数据核验

```sql
-- 岗位工种分布
SELECT job_category, COUNT(*) FROM position WHERE is_deleted = false GROUP BY job_category;

-- 岗位总数
SELECT COUNT(*) FROM position WHERE is_deleted = false;

-- 风险等级分布
SELECT risk_level, COUNT(*) FROM position WHERE is_deleted = false GROUP BY risk_level;
```

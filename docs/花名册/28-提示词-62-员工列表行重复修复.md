# 提示词-62：员工列表 — 行重复修复（employee_assignment JOIN 加 is_primary + is_deleted）

> 编号：提示词-62

> 性质：**缺陷修复（P1）**
> 前置：提示词-60 执行报告（标记"列表行重复"为既有问题）、提示词-61 执行报告（FK Phase 1 完成）
> 改动文件：1 个（后端 1 行）

## 0. 背景

提示词-60 执行报告中标记了一个既有问题：

> 同一 employee_id（如 5154）出现 2 行，源于数据查询 `LEFT JOIN employee_assignment ea ON ... AND ea.is_current = true` 未加 `is_primary`/`is_deleted` 过滤，多任职记录导致膨胀。

该问题在 supervisor_id 补全（提示词-57）时已被注意到，但当时未纳入修复范围。现在 FK 补全（Phase 1+2+收尾）和表头优化（提示词-60）都已完成后，正是修复这个展示层缺陷的时机。

---

## 1. 根因分析

### 1.1 当前查询（`server/routes/hse-employee.js`，`GET /employees`）

**数据查询**（L587）：
```sql
LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
```

**COUNT 查询**（L565）：
```sql
LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false
```

**supervisor 子查询**（L590，正确范例）：
```sql
LEFT JOIN employee_assignment ea_sup ON ev.employee_id = ea_sup.employee_id AND ea_sup.is_primary = true AND ea_sup.is_current = true AND ea_sup.is_deleted = false
```

### 1.2 偏差

| 查询 | 缺失过滤 | 影响 |
|------|---------|------|
| 数据查询 L587 | 缺 `is_deleted = false` | 软删除的任职记录被 JOIN，产生无效行 |
| 数据查询 L587 | 缺 `is_primary = true` | 一个员工有多条当前任职（如主职+兼岗），每条产生一行 |
| COUNT 查询 L565 | 缺 `is_primary = true` | COUNT 值偏高，前端分页"共 N 条"不准确 |

`v_employee_current` 视图本身已过滤 `is_primary = true AND is_deleted = false`，但列表查询的 inline JOIN 绕过了视图过滤，直接 JOIN `employee_assignment` 表，导致多行膨胀。

### 1.3 修复范围判定

仅修复 `employee_assignment ea` 的 JOIN 条件，**不触碰**：
- `ea_sup` 的 supervisor 子查询（L590，已正确）
- `hse_operation_unit opu` 的 JOIN（L588，已正确）
- `hse_org_unit ou` 的 JOIN（L589，已正确）

---

## 2. 修复方案

**文件**：`server/routes/hse-employee.js`，`GET /employees`

### 2.1 数据查询（L587）

```
旧：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
新：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false AND ea.is_primary = true
```

### 2.2 COUNT 查询（L565）

```
旧：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false
新：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false AND ea.is_primary = true
```

### 2.3 改动总结

| 行 | 改动 | 说明 |
|----|------|------|
| L565 | + `AND ea.is_primary = true` | COUNT 对齐视图过滤 |
| L587 | + `AND ea.is_deleted = false AND ea.is_primary = true` | 数据查询对齐 supervisor 子查询范式 |

> 仅改 2 行，对齐 supervisor 子查询（L590）的完整三条件范式。

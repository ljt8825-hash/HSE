## 一、问题一：部门员工分页失效

- **根因**：`deptEmployeePagination` 初始化缺少 `total`，`a-table` 误判总数为 0 → 翻页永远不可用；`loadDeptEmployees()` 只更新了 `deptEmployeesTotal` 未同步 `deptEmployeePagination.total`。
- **修复 1**（`deptEmployeePagination` 初始化）：
  ```ts
  const deptEmployeePagination = reactive({
    current: 1,
    pageSize: 10,
    total: 0,
    showSizeChanger: true,
    showTotal: (total: number) => `共 ${total} 条`,
  });
  ```
- **修复 2**（`loadDeptEmployees()` 同步 total）：
  ```ts
  deptEmployees.value = data.list || [];
  deptEmployeesTotal.value = data.total || 0;
  deptEmployeePagination.total = data.total || 0;   // 新增
  deptEmployeePagination.current = data.page || 1;
  deptEmployeePagination.pageSize = data.pageSize || 10;
  ```
- 效果：分页组件正确显示总页数，可翻到第 2/3 页；卡片标题计数 `({{ deptEmployeesTotal }})` 仍由 `deptEmployeesTotal` 驱动，保持正确。

## 二、问题二：部门详情字段动态化

- **根因**：详情卡片原仅展示 `department` 静态字段（多为 NULL），且缺"部门负责人/安全负责人"，"所属区域"语义错误（实为 ID 路径）。
- **修复 1 — 部门负责人 / 安全负责人**（新增 computed，优先分页员工匹配，否则批量回显）：
  ```ts
  const managerName = computed(() => {
    const id = currentDept.value?.manager_id;
    if (!id) return null;
    const fromList = deptEmployees.value.find((e) => e.id === id)?.name;
    if (fromList) return fromList;
    return managerEmployees.value.find((e) => e.employee_id === id)?.name || null;
  });
  // safetyManagerName 同理
  ```
  模板新增：
  ```html
  <a-descriptions-item label="部门负责人">{{ managerName || '-' }}</a-descriptions-item>
  <a-descriptions-item label="安全负责人">{{ safetyManagerName || '-' }}</a-descriptions-item>
  ```
  `managerEmployees` 由 `loadManagerNames(dept)` 在 `handleSelect` 中按 `manager_id`/`safety_manager_id` 批量查询填充。
- **修复 2 — 所属区域 → 层级路径**（语义修正 + 名称解析）：
  ```ts
  const namePath = computed(() => {
    if (!currentDept.value) return '-';
    const names = findPathNames(treeData.value, currentDept.value.id);

  ```

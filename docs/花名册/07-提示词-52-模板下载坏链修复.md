# 提示词-52：花名册模块 — 模板下载坏链修复

> 编号：提示词-52
> 日期：2026-07-30
> 性质：**缺陷修复（P1）**
> 前置：提示词-51 回归验证报告（发现模板下载按钮失效）
> 改动文件：3 个（1 重命名 + 1 前端 + 1 后端）

---

## 0. 背景

提示词-51 回归验证发现：花名册导入页面 `/personnel/import` 的「下载导入模板」按钮实际失效。根因：

1. **Dev 环境（Vite :5173）**：中文文件名 `员工花名册导入模板.xlsx` 经 URL 编码后 Vite 静态中间件无法匹配，触发 SPA 回退，浏览器下载到的是 HTML 改名 `.xlsx`
2. **生产环境（Express :5666）**：`app.js` 仅挂载了 `/uploads` 静态目录，未挂载 `/templates`，导致 404

## 1. 修复方案

### 方案选择：ASCII 重命名 + Express 静态挂载

**不选用"调用现有 API"方案的原因**：现有 `GET /api/hse/batch-import/templates/:type`（hse-batch-import.js:272）依赖 `batchImportService.getTemplate()`，其模板可能不同于花名册 v2 的 13 字段模板，且需要鉴权，前端需改为 fetch + blob 下载，复杂度高。

**选用方案**：最小改动，三步到位。

### 1.1 任务 A：模板文件重命名（消除中文路径）

**文件**：`安全看板vben/apps/web-antd/public/templates/员工花名册导入模板.xlsx`

**操作**：重命名为 `employee_roster_template.xlsx`

```bash
# 在 f:\hse-dashboard\安全看板vben\apps\web-antd\public\templates\ 下执行
mv 员工花名册导入模板.xlsx employee_roster_template.xlsx
```

### 1.2 任务 B：前端下载链接修正

**文件**：`安全看板vben/apps/web-antd/src/views/hse/employee-import-v2/index.vue`

**位置**：`handleDownloadTemplate()` 函数（约 L189-197）

**改动**：

```ts
// 修改前
function handleDownloadTemplate() {
  const link = document.createElement('a');
  link.href = '/templates/员工花名册导入模板.xlsx';
  link.download = '员工花名册导入模板.xlsx';
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
  message.success('模板下载中...');
}

// 修改后
function handleDownloadTemplate() {
  const link = document.createElement('a');
  link.href = '/templates/employee_roster_template.xlsx';
  link.download = '员工花名册导入模板.xlsx';  // 下载文件名保持中文，用户友好
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
  message.success('模板下载中...');
}
```

> 说明：`href` 使用 ASCII 文件名确保 Vite 和 Express 都能正确匹配；`download` 属性保持中文文件名，用户浏览器下载后仍显示为「员工花名册导入模板.xlsx」。

### 1.3 任务 C：Express 生产环境静态挂载

**文件**：`server/app.js`

**位置**：在 `app.use('/uploads', express.static(...))` 之后（约 L235）

**改动**：新增一行

```js
// 7. 静态文件服务
app.use('/uploads', express.static(path.join(__dirname, uploadDir)));
app.use('/templates', express.static(path.join(__dirname, '..', '安全看板vben', 'apps', 'web-antd', 'public', 'templates')));
```

> 说明：生产部署时 Express 需要提供 `/templates` 路径的静态文件服务。路径指向前端项目的 `public/templates/` 目录。如果部署环境的前端构建产物目录结构不同，请根据实际部署路径调整。

## 三、执行任务

### 任务1：修复未知岗位匹配

**目标**：使所有21条 `unknown_position` 记录能匹配到正确的岗位。

**执行步骤**：

1. **实勘**：查询数据库，列出所有 `unknown_position` 的 `raw_position` 去重值及对应的 `raw_dept`，以及 `position` 表中所有岗位名称。

2. **分析映射关系**：对每个 `raw_position`（如"乡镇保洁员"、"人工班长"、"挂桶工"等），确定其在 `position` 表中对应的目标岗位。

3. **补全映射规则**：在 `employee_position_mapping_rule` 表中为缺失的岗位创建映射规则：
   - `source_position` = Excel中的岗位名称
   - `target_position_id` = `position` 表中的目标岗位ID
   - `target_position_name` = `position` 表中的目标岗位名称
   - `rule_version = 'v1.0'`
   - `status = 'active'`
   - 注意 `condition_dept` 字段：如果同一岗位名在不同部门对应不同目标岗位（如"司机"在环卫和市政可能不同），需设置条件

4. **验证**：用SQL模拟岗位匹配（复用 `matchPosition()` 的L1/L2逻辑），确认所有21个 `raw_position` 值均可匹配。

### 任务2：增强岗位匹配算法（兜底方案）

**目标**：在 `matchPosition()` 函数中增加兜底策略，防止未来出现新的未知岗位。

**修改文件**：`server/routes/hse-employee-import-v2.js` → `matchPosition()`

**方案**：在现有L1（条件匹配）和L2（无条件匹配）之后，增加L3"岗位名称模糊匹配"：

```javascript
// 3. 模糊匹配（兜底）
const fuzzyResult = await client.query(
  `SELECT id AS target_position_id, name AS target_position_name
   FROM position WHERE is_deleted = false
     AND (name = $1 OR name LIKE $2 OR $1 LIKE '%' || name || '%')
   ORDER BY CASE WHEN name = $1 THEN 3
                 WHEN name LIKE $2 THEN 2
                 ELSE 1 END DESC
   LIMIT 1`,
  [rawPosition, '%' + rawPosition + '%']
);
if (fuzzyResult.rows.length > 0) {
  return { target_position_id: fuzzyResult.rows[0].target_position_id, target_position_name: fuzzyResult.rows[0].target_position_name };
}
```

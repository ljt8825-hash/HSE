## 三、安全机制（已落地）

| 机制 | 实现 |
|------|------|
| 备份闸门 | `clear-all-cascade` 执行前强制检查 `backup_97_*`/`backup_98_*`；当前 33 张 `backup_98_*` 存在，可放行 |
| 防改触发器 | 删除前 `ALTER TABLE ... DISABLE TRIGGER USER`，删除后 `ENABLE TRIGGER USER`（针对 `hse_deduction_adjustment`、`hse_assessment_audit_log`） |
| 角色限制 | 沿用 `requireRole('admin')` 中间件，非 admin 返回 403 |
| 事务保护 | 全流程单事务，任一步失败 `ROLLBACK`，数据零变动 |
| 动态 FK | 禁止硬编码表名，运行时从 `pg_constraint` 发现子表（规避提示词中 5 张不存在表） |

## 3. 任务 C：对齐策略决策表

按「优先策略1（前端适配后端），仅当后端字段语义无法映射到前端卡片时采用策略2（后端扩展字段）」原则：

| 视图 | 策略 | 理由 |
|------|------|------|
| 应急事件 | **策略2（后端扩展）** | handling/closed/avg_duration 为计算指标，扁平响应无对应标量；avg_duration 无源数据返回 0 |
| 演练 | **混合**：3 项改名（策略1）+ `failed` 后端扩展（策略2） | yearCount/passRate/participantsTotal 改名即可；`failed`（不合格次数）后端无字段需扩展 |
| 队伍 | **策略2（后端扩展）** | fullTime/partTime 由 byType 类型聚合派生，扁平响应无标量 |
| 物资 | **策略1（前端派生）** | `正常` = `total - expiring - expired`，模板内计算 |
| 预案 | **策略1（前端删卡）** | `已废止` 后端无字段，删除该统计卡 |

## 4. 任务 D：修改详情

### 4.1 后端 `server/routes/emergency.js`（策略2 扩展，内存模式 + DB 模式双分支）

- **events/stats**：新增 `handling`（total − closed）、`closed`（byStatus 键匹配 `/closed|resolved|结案|完成|已结束|done/i`）、`avgDuration=0`。
- **drills/stats**：新增 `failed`（本年 `result NOT IN ('pass','excellent')` 计数，内存模式同逻辑过滤）。
- **teams/stats**：新增 `fullTime`/`partTime`（由 byType 键匹配 `/full|专职|全职/i` 与 `/part|兼职|业余/i` 聚合）。

### 4.2 前端 5 视图（`src/views/emergency/*/index.vue`）

| 文件 | 模板改动 | ref 初值改动 |
|------|----------|--------------|
| events/index.vue | `year_total→total`、`avg_duration→avgDuration`（handling/closed 名称已一致） | `{total,handling,closed,avgDuration}` |
| drills/index.vue | `yearTotal→yearCount`、`completionRate→passRate`、`participants→participantsTotal`（`failed` 一致） | `{yearCount,passRate,participantsTotal,failed}` |
| teams/index.vue | `member_count→memberCount`、`full_time→fullTime`、`part_time→partTime` | `{total,memberCount,fullTime,partTime}` |
| materials/index.vue | `正常` 卡 `:value="stats.normal"` → `:value="(stats.total||0)-(stats.expiring||0)-(stats.expired||0)"` | `{total,expiring,expired}` |
| plans/index.vue | 删除「已废止」`<Col>` 统计卡（含 `stats.abolished`） | `{total,published,pendingReview}` |

后端重启（`:5666` node app.js 无热加载），前端 Vite HMR 自动生效。

## 1. 任务清单

### 任务 A：数据现状调研（只读）

对 8 个空表/模块逐一调研：

| 调研项 | 内容 |
|--------|------|
| 表结构 | 列清单、必填字段、FK 约束 |
| 前端表单 | 对应的新增/编辑页面是否可用 |
| 导入功能 | 是否支持 Excel 批量导入 |
| 种子数据 | 是否有历史备份或 demo 数据可恢复 |
| 业务方需求 | 哪些模块需要立即恢复数据，哪些可暂缓 |

### 任务 B：数据补录策略

根据调研结果，为每个模块确定补录策略：

| 策略 | 适用场景 |
|------|----------|
| Excel 批量导入 | 有导入功能 + 有现成数据源 |
| 前端表单逐条录入 | 无导入功能 + 数据量小（<50 条） |
| 种子数据恢复 | 有历史备份可恢复（需确认数据合法性） |
| 暂缓 | 业务方暂无需求 |

### 任务 C：产出规划文档

写出 `docs/花名册/57-提示词-77-数据补录规划.md`，包含：

- 8 个模块的调研结果（表结构、前端表单、导入功能、种子数据）
- 补录策略决策表
- 优先级排序（P0=立即、P1=本周、P2=后续）
- 执行步骤与风险提示

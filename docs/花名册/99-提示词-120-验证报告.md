## 2. 修改说明

### 2.1 后端（2 处 SELECT）
- **GET /departments/tree**：返回原始 snake_case（`res.json(success(tree))`，无 camelKeys），故新列名保持 `org_unit_id`。
- **GET /departments**：经 `res.json(success(result.rows.map(camelKeys)))` 转换，新列 `org_unit_id` → `orgUnitId`。

### 2.2 前端读取同步（关键修正）
- 探针发现：`GET /departments`（列表）经 `camelKeys` 后字段名为 `orgUnitId`，而原 `relatedDepts` 读取 `(d as any).org_unit_id` 始终为 `undefined` → 主路径永不命中、永远走前缀兜底。
- 按提示词允许范围，将 `relatedDepts` 主路径读取改为 `(d as any).orgUnitId`，使主路径（精确 `org_unit_id` 匹配）生效。关联班组映射现优先走 ID 级精确匹配，前缀兜底仅作极端情况保留。

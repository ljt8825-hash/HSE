## 一、问题一：组织树同名节点冗余

- **根因**：`department` 表同一地理位置（如"宁城街道"）在 level=3 与 level=5 均存在，树节点仅展示 `name`，同名不同层无法区分。
- **修复**（`departments.vue` `#title` 插槽，原 62-67 行）：
  ```html
  <template #title="{ name, dept_code, status, level }">
    <span :class="{ 'node-inactive': status === 'inactive' }">
      {{ name }}
      <a-tag :color="levelColor(level)" class="node-level-tag">{{ levelText(level) }}</a-tag>
      <span class="node-code">({{ dept_code }})</span>
    </span>
  </template>
  ```
  - 复用既有 `levelText()`（已对齐 1-6：公司/部门中心/乡镇作业中心/部门/乡镇/班组）与 `levelColor()`。
  - 标签追加层级语义（如 `宁城街道 [乡镇] (DEPT_XXX)`），同级同名节点可区分。
  - 保留 `node-inactive` 停用样式。
- **新增样式**：`.node-level-tag { margin-left:4px; font-size:12px; line-height:18px; }`

## 二、问题二：编制人数为 0 时显示优化

- **根因**：`department.headcount` 默认 0，未录入编制时显示"编制人数: 0"与"实际人数: 49"反差大。
- **修复**（详情卡片原 137-139 行）：
  ```html
  <a-descriptions-item label="编制人数">
    {{ currentDept.headcount ? currentDept.headcount : '-' }}
  </a-descriptions-item>
  ```
  - `headcount` 为 0 / null / undefined 时统一显示 `-`（暂无数据）；正数正常显示。

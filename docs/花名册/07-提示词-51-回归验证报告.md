## 3. 🐞 验证发现的 Bug：模板下载按钮坏链

**严重度**：中（影响「下载导入模板」核心功能）
**是否修复**：否（本提示词红线：仅验证、不修复；记录待后续）

**根因**：
`handleDownloadTemplate()`（L189-192）写死 `link.href = '/templates/员工花名册导入模板.xlsx'`，文件物理存在于 `public/templates/员工花名册导入模板.xlsx`（6851 字节，提示词-49 放入）。但：

1. **Dev（Vite :5173）**：ASCII 名静态资源正常（`/favicon.ico`、`/logo.png`、`/templates/_probe_test.xlsx` 均返回真实二进制/PK zip）；**唯独中文名** `/templates/员工花名册导入模板.xlsx` 返回 `<!doctype html>`（SPA 回退）——Vite 静态中间件无法匹配 URL 编码后的中文路径，浏览器下载到的是 HTML 改名 `.xlsx`。**dev 即失效**。
2. **Prod（Express :5666）**：仅 `app.use('/uploads', express.static(...))`（app.js:235），未挂 `/templates` → **404**。

**影响**：用户点击「下载导入模板」得到无效文件（HTML 或被 404）。

**建议修复方向（范围外，供参考）**：
- 方案 A：改按钮调用已有 API `GET /api/hse/batch-import/templates/employee`（hse-batch-import.js:272，返回真实 xlsx），由前端下载流；
- 方案 B：将模板改名 ASCII（如 `roster_template.xlsx`）并修正 `link.href`，同时在 Express 增加 `/templates` 静态挂载以覆盖生产部署。

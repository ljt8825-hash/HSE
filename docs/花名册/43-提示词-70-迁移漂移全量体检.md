# 提示词-70：hse_core_v1 迁移漂移全量体检 — 声明列 vs 实际列 diff

> 编号：提示词-70

> 性质：**预防性巡检（P2）** — 零业务代码改动
> 前置：提示词-69（发现 `vehicle_id`、`from_status/to_status/comment/occurred_at` 漂移）

## 0. 背景

提示词-69 执行中连续发现两处 schema 漂移：
1. `hse_events.vehicle_id` — 迁移声明了但未落到库（代码引用 → 500）
2. `hse_event_timeline` 四列（`from_status/to_status/comment/occurred_at`）— DB 存的是旧列名（`status_from/status_to/description/timestamp`），代码引用新列名 → 500

根因：`hse_core_v1_migration.sql` 定义了 7 张表，但后续多轮迁移（`hse_chain_v42`、`hse_workflow_v43` 等）可能未覆盖全部声明列。本次对 7 张表做全量「声明 vs 实际」diff，一次性补齐所有漂移列，预防更多 500。

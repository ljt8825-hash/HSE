## 1. 背景

提示词-130 诊断报告已产出，识别出超龄人员模块的 14 个问题。本提示词聚焦 **P0（1 项）+ P1（4 项）** 的修复，P2/P3 留待后续提示词。

核心矛盾：页面将"自动识别视图（子系统A：employee 实时计算）"与"保险管控能力（子系统B：over_age_personnel 表）"拼在同一页面，但两者的数据主键、加解密策略、数据源不一致，导致多个功能实际失效。

## 4. 修改项清单（5 项）

### 4.1 修改项 F1：insurance.js 统一加密策略（P0）

**文件**：`server/routes/insurance.js`

**问题**：insurance.js `/overage` 的 POST/PUT/GET 均未使用加解密中间件，而 over-age-personnel.js 使用 encryptMiddleware/decryptMiddleware。同一张 `over_age_personnel` 表，两套路由读写加密策略不一致 → 跨路由读写时 id_card 损坏。

**修复**：

1. 在 insurance.js 顶部添加导入：
```javascript
const { encryptMiddleware, decryptMiddleware } = require('../middleware/encryption');
```

2. 给以下路由添加中间件（仅 id_card 字段需要加密）：
   - `POST /overage` → 添加 `encryptMiddleware('id_card')` 在 `validateBody` 之后
   - `PUT /overage/:id` → 添加 `encryptMiddleware('id_card')` 在 `validateBody` 之后
   - `GET /overage` → 添加 `decryptMiddleware('id_card')` 在路由 handler 之前
   - `GET /overage/:id` → 添加 `decryptMiddleware('id_card')` 在路由 handler 之前
   - `GET /overage/export` → 添加 `decryptMiddleware('id_card')` 在路由 handler 之前（导出 CSV 时解密）

3. 修改后路由签名示例：
```javascript
router.get('/overage', decryptMiddleware('id_card'), async (req, res) => { ... });
router.post('/overage', validateBody(createOverageSchema), encryptMiddleware('id_card'), async (req, res) => { ... });
router.put('/overage/:id', validateBody(updateOverageSchema), encryptMiddleware('id_card'), async (req, res) => { ... });
router.get('/overage/export', decryptMiddleware('id_card'), async (req, res) => { ... });
```

> **注意**：`POST /overage` 和 `PUT /overage/:id` 中 `validateBody` 在 `encryptMiddleware` 之前执行，因为校验需要原始明文；加密后再写入数据库。

### 4.2 修改项 F2：前端身份证号/手机号脱敏（P1）

**文件**：`安全看板vben/apps/web-antd/src/views/hse/employee/over-age/index.vue`

**问题**：子系统A 解密后返回明文 18 位身份证号 + 11 位手机号，前端表格列、详情抽屉完整展示，无脱敏。

**修复**：

1. 在 `<script setup>` 中添加脱敏工具函数：
```typescript
/** 身份证号脱敏：保留前4后4，中间替换为 **** */
function maskIdCard(idCard: string | undefined | null): string {
  if (!idCard) return '-';
  if (idCard.length <= 8) return idCard;
  return idCard.slice(0, 4) + '**********' + idCard.slice(-4);
}

/** 手机号脱敏：保留前3后4，中间替换为 **** */
function maskPhone(phone: string | undefined | null): string {
  if (!phone) return '-';
  if (phone.length < 7) return phone;
  return phone.slice(0, 3) + '****' + phone.slice(-4);
}
```

2. 表格列"身份证号"的 `customRender` 改为使用 `maskIdCard`：
```typescript

```

// GET /over-age/auto-export — 导出超龄人员清单（CSV，基于employee实时计算）
router.get('/over-age/auto-export', decryptMiddleware(...ENCRYPT_FIELDS), async (req, res) => {
  try {
    if (!isConnected()) return res.json(error(-1, '数据库未连接'));

    const result = await pool.query(
      `SELECT e.id, e.employee_code, e.name, e.gender, e.birth_date,
              EXTRACT(YEAR FROM age(e.birth_date))::INT AS age,
              ${buildOverAgeYearsExpr('e')} AS over_age_years,
              e.id_card, e.phone,
              e.person_category, e.person_type, e.is_public_welfare,
              eo.org_name AS dept_name, p.name AS position_name,
              oap.id AS over_age_id
       FROM employee e
       LEFT JOIN employee_assignment ea ON ea.employee_id = e.id AND ea.is_current = true AND ea.is_primary = true AND ea.is_deleted = false
       LEFT JOIN hse_org_unit eo ON eo.id = ea.org_unit_id AND eo.is_deleted = false
       LEFT JOIN position p ON p.id = ea.position_id AND p.is_deleted = false
       LEFT JOIN over_age_personnel oap ON oap.personnel_id = e.id AND oap.is_deleted = false
       WHERE e.is_deleted = false AND e.birth_date IS NOT NULL
       AND ${buildOverAgeCondition('e')}
       ORDER BY age DESC, e.birth_date ASC`,
    );

    const rows = result.rows;
    const headers = ['序号', '姓名', '性别', '年龄', '超龄年数', '出生日期', '身份证号', '部门', '岗位', '联系方式', '人员类型', '人员分类', '是否公益岗'];
    const csvRows = rows.map((r, i) => [
      i + 1,
      (r.name || '').replace(/"/g, '""'),
      r.gender || '',
      r.age || 0,
      r.over_age_years || 0,
      r.birth_date ? String(r.birth_date).slice(0, 10) : '',
      // 身份证号脱敏：保留前4后4
      r.id_card ? (r.id_card.slice(0, 4) + '**********' + r.id_card.slice(-4)) : '',
      (r.dept_name || '').replace(/"/g, '""'),
      (r.position_name || '').replace(/"/g, '""'),
      // 手机号脱敏：保留前3后4
      r.phone ? (r.phone.slice(0, 3) + '****' + r.phone.slice(-4)) : '',
      r.person_type || '',
      r.person_category || '',
      r.is_public_welfare ? '是' : '否',
    ].map(v => `"${v}"`).join(','));

    const csv = '\uFEFF' + headers.map(h => `"${h}"`).join(',') + '\n' + csvRows.join('\n');
    res.setHeader('Content-Type', 'text/csv; charset=utf-8');
    res.setHeader('Content-Disposition', `attachment; filename="over_age_auto_${new Date().toISOString().slice(0, 10)}.csv"`);
    return res.send(csv);
  } catch (err) {
    res.json(error(-1, err.message));
  }
});

import { exportOverAgeAutoList } from '#/api/hse/employee';

async function handleExport() {
  try {
    const blob = await exportOverAgeAutoList();
    // 校验 Content-Type：非 CSV 时提示错误
    if (blob instanceof Blob && blob.type && !blob.type.includes('csv') && !blob.type.includes('text')) {
      // 可能是 JSON 错误响应
      const text = await blob.text();
      try {
        const err = JSON.parse(text);
        message.error(err.message || '导出失败');
        return;
      } catch { /* 非 JSON，继续下载 */ }
    }
    const url = window.URL.createObjectURL(new Blob([blob]));
    const link = document.createElement('a');
    link.href = url;
    link.setAttribute('download', `超龄人员清单_${dayjs().format('YYYYMMDD')}.csv`);
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
    window.URL.revokeObjectURL(url);
    message.success('导出成功');
  } catch (err) {
    console.warn('导出失败:', err);
    message.error('导出失败');
  }
}

    fetchData(); // 刷新列表以获取新的 over_age_id
  } catch (e: any) {
    message.error(e.message || '保存失败');
  } finally {
    editLoading.value = false;
  }
}

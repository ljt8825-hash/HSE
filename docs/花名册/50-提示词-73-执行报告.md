## 2. 异常项根因（均为历史既有问题，非 DB 治理引入）

### 2.1 任务 B — HSE 事件模块（后端验证，前端无路由）
- 前端 `src/router/routes/modules` 白名单中**无 HSE 事件独立模块**；`hse_events` 表仅由后端 `server/routes/hse-events.js` 提供。
- 后端验证：`GET /api/hse/events` → 200 / code:0 / total=6；`GET /api/hse/events/:id` → 200，返回 `timeline` / `links` / `source_data` 字段。`vehicle_id` 列存在（无 500），`timeline` 字段正常返回（from_status/to_status 漂移 500 修复已验证）。
- 结论：DB 治理 500 修复**有效**，浏览器回归因无前端页面标记为 N/A。

### 2.2 任务 C — 应急事件列表 404（前后端路由命名不一致）
- 前端 `views/emergency/events/index.vue` 调用 `request.get('/emergency/events')`；后端 `emergency.js` 仅有 `GET /events/list`、`/events/stats`、`/events/:id`（**无裸 `GET /events`**）。
- 浏览器内 `fetch('/api/emergency/events')` → **HTTP 404 / code:-100**；`/api/emergency/events/stats` 正常（统计卡片"本年事件数"等渲染正常）。
- 根因：前端列表接口应为 `/emergency/events/list`，属**前端/后端契约不一致**（既有问题）。

### 2.3 任务 C — 演练列表前端空表（响应解包不一致）
- 后端 `GET /api/emergency/drills` → 200 / total=48（curl 与浏览器 `fetch` 双重确认）。
- 浏览器内调用应用 `request` 客户端：`request.get('/emergency/drills')` 返回 **`{list,total,page,pageSize}`（已解包的内层数据）**，而非 `{code,data}` 信封。
- 但 `views/emergency/drills/index.vue` 取数逻辑为 `if (r.code === 0) { dataList = r.data.list }` —— `r.code` 为 `undefined`、 `r.data` 为 `undefined` → `dataList` 恒为空 → 表格「暂无数据」。无 console / 页面错误。
- 根因：`request` 客户端 `responseReturn:'data'` 返回**解包后的内层数据**，而应急模块多个视图（`drills`/`events`/`plans`/`teams`/`materials`）仍按**信封结构**取数 → 列表恒空。花名册/三违等用 `useDataTable` + API 层（`getXxxList` 正确解包）的模块正常。属**前端响应解析不一致（既有）**。

### 2.4 任务 E — `/violations` 404（路由未注册）
- `src/router/routes/modules/hse-violations.ts` 定义了 `path:'/violations'` → `views/violations/index.vue`，但**未被 `routes/index.ts` 的 `dynamicRouteFiles` 白名单引入**（白名单仅 hse-01…hse-11）。
- 浏览器打开 `/violations` → "哎呀！未找到页面"（404）。
- 同一视图经 `/site/violation`（现场管理→三违管理）与 `/inspection/violation` 可达，加载 890 条记录正常。
- 根因：路由文件未加入白名单（既有配置遗漏）。

### 2.5 任务 A — 档案列表 `/hse/employee-profile/list` 404
- `hse-employee-profile-detail.ts` 实际路由为 `/hse/employee/:id(\d+)`（按员工 ID 的**详情页**），并非列表页。
- 浏览器打开 `/hse/employee-profile/list` → 404。
- 「档案列表」实际通过花名册列表行「历史」按钮 → `EmployeeHistoryDrawer`（员工档案 / 培训记录）访问，该路径**正常**（见 A 员工详情）。
- 根因：提示词期望的"档案列表"独立页不存在，档案以员工详情形式提供（既有设计/路由遗漏）。

### 2.6 任务 F — 考核列表空表（端点错配 + 后端无列表路由）
- `src/api/hse/goals.ts` 中 `getAssessmentList` 实际定义为 `requestClient.get('/objectives/responsibility', ...)` —— **错指到目标责任端点**。
- 后端 `server/routes/hse-assessment.js` **仅有** `GET /overview`、`/ranking`、`/indicator-analysis`、`/target-progress`、`/deduction-detail`，**无列表（GET /）路由**。
- 因此 `/objectives/assessment` 列表恒空（「暂无数据」）；考核明细端点（overview/target-progress/deduction-detail）经 API 探针确认可用。
- 根因：前端考核列表端点错配 + 后端考核列表路由缺失（既有接线缺口）。

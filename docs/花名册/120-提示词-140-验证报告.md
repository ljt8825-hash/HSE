### R1 — other/index.vue 数据解包冲突（P0）

**文件**：`安全看板vben/apps/web-antd/src/views/insurance/other/index.vue`

**问题**：原代码按 `{code,data}` 包裹结构解包（`r.code === 0` / `r.data.list`），但前端 `requestClient` 配置 `responseReturn:'data'`，响应拦截器已剥离包裹，返回 `{list,total,...}`。因此 `r.code` 恒 `undefined` → 条件恒 `false` → 列表/统计永远为空。

**修复**（`fetchData` L264-275）：
```diff
-    const r = await request.get('/insurance/other', { params: { ...searchForm, ...pagination } });
-    if (r.code === 0) {
-      dataList.value = r.data.list || [];
-      total.value = r.data.total || 0;
-    }
+    const r = await request.get('/insurance/other', { params: { ...searchForm, ...pagination } });
+    dataList.value = r.list || [];
+    total.value = r.total || 0;
```
并改为 try/catch（`catch` 中 `message.error(e?.message || '加载失败')`，失败时 `dataList/total` 置空），与 personnel/vehicle 子页一致。

**修复**（`fetchStats` L277-284）：
```diff
-    const r = await request.get('/insurance/other/stats');
-    if (r.code === 0) stats.value = r.data.stats || {};
+    const r = await request.get('/insurance/other/stats');
+    stats.value = r.stats || {};
```
`catch` 中 `message.error(e?.message || '统计加载失败')`（原静默 `catch(ignore)` 改为可见报错）。

## 4. 修改项清单

### 4.1 R1：修复 other/index.vue handleSave/handleDelete（P1 遗漏）

**文件**：`安全看板vben/apps/web-antd/src/views/insurance/other/index.vue`

**问题**：`handleSave` 和 `handleDelete` 仍按旧契约检查 `r.code === 0`：

```typescript
// handleSave（当前代码 L327-334）
if (r.code === 0) {
  message.success(editingRecord.value ? '编辑成功' : '新增成功');
  formModalVisible.value = false;
  fetchData();
  fetchStats();
} else {
  message.error(r.message || '操作失败');
}

// handleDelete（当前代码 L341-347）
if (r.code === 0) {
  message.success('删除成功');
  fetchData();
  fetchStats();
} else {
  message.error(r.message || '删除失败');
}
```

**修复**：改为 try/catch 直接判定成功（与 emergency 137-R5、training 134-T5 模式一致）：

```typescript
// handleSave 修复后
try {
  formLoading.value = true;
  const payload = { ...otherForm };
  // ... 日期格式化等处理
  if (editingRecord.value) {
    await request.put(`/insurance/other/${editingRecord.value.id}`, payload);
  } else {
    await request.post('/insurance/other', payload);
  }
  message.success(editingRecord.value ? '编辑成功' : '新增成功');
  formModalVisible.value = false;
  fetchData();
  fetchStats();
} catch (e: any) {
  message.error(e?.message || '操作失败');
} finally {
  formLoading.value = false;
}

// handleDelete 修复后
try {
  await request.delete(`/insurance/other/${record.id}`);
  message.success('删除成功');
  fetchData();
  fetchStats();
} catch (e: any) {
  message.error(e?.message || '删除失败');
}
```

> **关键**：移除 `let r` 变量和 `if (r.code === 0)` 判断，改为 `await request.xxx()` 后直接提示成功，失败走 catch。

### 4.4 R4：other 导出功能补齐（P2）

**文件**：`server/routes/insurance.js`、`安全看板vben/.../views/insurance/other/index.vue`

**问题**：前端 `handleExport` 为 `message.info('导出功能开发中')` 桩，后端无 `/other/export` 端点。

**修复**：

**后端**（在 `server/routes/insurance.js` 中，注册在 `GET /other/:id` 之前）：

```javascript
router.get('/other/export', requireRole('admin', 'safety_manager'), async (req, res) => {
  try {
    let data = [];
    if (isConnected()) {
      const r = await pool.query('SELECT * FROM other_insurance WHERE is_deleted = false ORDER BY id ASC');
      data = r.rows.map(formatOtherIns);
    } else {
      data = memoryStores.other.filter(r => !r.is_deleted).map(formatOtherIns);
    }
    const headers = ['ID', '保险名称', '保险类型', '被保对象', '保单号', '生效日期', '到期日期', '保费', '保险状态', '时效状态', '备注'];
    const statusMap = { insured: '已参保', expired: '已过期', expiring: '即将到期', uninsured: '未参保' };
    const expiryMap = { normal: '正常', expiring: '临期', expired: '过期', unknown: '未知' };
    const rows = data.map(r => [
      r.id || '',
      (r.name || '').replace(/"/g, '""'),
      (r.insuranceType || '').replace(/"/g, '""'),
      (r.insuredObject || '').replace(/"/g, '""'),
      (r.policyNumber || '').replace(/"/g, '""'),
      r.policyStartDate || '',
      r.policyEndDate || '',
      r.premium || 0,
      statusMap[r.insuranceStatus] || r.insuranceStatus || '',
      expiryMap[r.expiryStatus] || r.expiryStatus || '',
      (r.remark || '').replace(/"/g, '""'),
    ].map(v => `"${v}"`).join(','));
    const csv = '\uFEFF' + headers.map(h => `"${h}"`).join(',') + '\n' + rows.join('\n');
    res.setHeader('Content-Type', 'text/csv; charset=utf-8');
    res.setHeader('Content-Disposition', `attachment; filename="other_insurance_${new Date().toISOString().slice(0, 10)}.csv"`);
    return res.send(csv);
  } catch (err) { res.json(error(-1, err.message)); }
});
```

> **字段名说明**：以 `formatOtherIns` 实际返回的 camelCase 字段为准（`name/insuranceType/insuredObject/policyNumber/policyStartDate/policyEndDate/premium/insuranceStatus/expiryStatus/remark`）。如果真实表字段名不同，以真实表为准调整。

**前端**（`other/index.vue`）：

```typescript
async function handleExport() {
  try {
    const res = await request.get('/insurance/other/export', { responseType: 'blob' });
    const url = window.URL.createObjectURL(new Blob([res as any]));
    const link = document.createElement('a');
    link.href = url;
    link.download = `其他保险_${new Date().toISOString().slice(0, 10)}.csv`;
    link.click();
    window.URL.revokeObjectURL(url);
    message.success('导出成功');
  } catch (e: any) {
    message.error(e?.message || '导出失败');
  }
}
```

## 7. 诊断要求

按标准五维度对系统管理模块进行全面诊断：

### 维度一：前端代码质量
- 是否使用 `Page`（`@vben/common-ui`）组件
- 是否使用 Ant Design Vue（非 Element Plus）
- 是否使用 `useDataTable` / `useSearchForm` / `useCrudModal` 托管
- `vue-tsc` 类型检查结果

### 维度二：后端代码质量
- `node --check` 语法检查
- 路由注册顺序（`/:id` 遮蔽检查）
- 是否使用 `requireRole` 鉴权（系统管理模块通常需最高权限控制）
- DDL 幂等性

### 维度三：数据流一致性
- 前后端字段名是否对齐
- API 类型定义是否与后端返回一致
- 枚举值是否统一

### 维度四：边界与异常
- 空状态处理
- 敏感操作（如删除用户/角色）是否有二次确认
- 系统级操作是否有额外保护

### 维度五：回归检查
- 菜单/路由一致性
- 前端构建含本模块 chunk
- 跨模块依赖

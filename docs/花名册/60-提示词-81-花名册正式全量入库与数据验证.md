### 任务4：处理文件外员工（50 名）

入库后，1311 行花名册内员工的任职已被 UPDATE，但 **50 名文件外员工**（工号不在花名册中）的 current 任职可能在提示词-91 恢复后仍然存在，也可能需要确认。

执行以下检查：
```sql
-- 找出文件外员工（employee_no 不在花名册 pending 中）
-- 确认其 current 任职状态正常
SELECT e.employee_code, e.name, a.position_id, a.org_unit_id, a.is_current
FROM employee e
JOIN employee_assignment a ON a.employee_id = e.id AND a.is_current = true AND a.is_deleted = false
WHERE e.is_deleted = false
  AND e.employee_code NOT IN (
    SELECT employee_no FROM employee_import_pending WHERE batch_id = :newBatchId
  );
```

如果返回 0 行（文件外员工无 current 任职），需要用 `fix_restore_extra_assignments.sql` 恢复其最新一条任职。脚本逻辑：
```sql
-- 为每个文件外员工恢复其最新一条 is_current=true 的任职
UPDATE employee_assignment SET is_deleted = false, is_current = true
WHERE id IN (
  SELECT DISTINCT ON (employee_id) id
  FROM employee_assignment
  WHERE employee_id IN (
    SELECT e.id FROM employee e
    WHERE e.is_deleted = false
      AND e.employee_code NOT IN (
        SELECT employee_no FROM employee_import_pending WHERE batch_id = :newBatchId
      )
  )
  AND is_deleted = true
  ORDER BY employee_id, updated_at DESC
);
```

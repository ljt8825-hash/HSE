# 提示词-85：考核模块表结构调研

> 调研日期：2026-07-31
> 范围：考核相关全部表（`assessment_records` 及 `hse_assessment_*` 族）
> 方法：`information_schema` 列定义 + `pg_constraint` 外键 + 后端路由 + 前端视图交叉核验

## 二、`assessment_records` 表结构（核心修复对象）

```text
列                      类型                   NULL?   默认值
id                      bigint                NO      nextval(seq)
assessment_no           varchar               YES
assessment_title        varchar               NO      ← 唯一硬性 NOT NULL
assessment_type         varchar               YES      'theory'   (理论/实操)
training_plan_id        bigint                YES
training_record_id      bigint                YES
assessment_date         date                  YES
employee_id             bigint                YES      ← 无强制外键约束
employee_name           varchar               YES
employee_no             varchar               YES
dept_id                 bigint                YES
dept_name               varchar               YES
position                varchar               YES
score                   numeric               YES
pass_score              numeric               YES      60
is_pass                 boolean               YES
grade                   varchar               YES
assessor_id             bigint                YES
assessor_name           varchar               YES
retake_count            integer               YES      0
is_retake               boolean               YES      false
status                  varchar               YES      'completed'
remark                  text                  YES
violation_deduct_score  numeric               YES      0
hazard_bonus_score      numeric               YES      0
risk_implementation_score numeric              YES      0
created_by_id           bigint                YES
created_at / updated_at timestamp with tz     YES      now()

```

**外键约束**：`assessment_records` **无任何外键**（FK 扫描结果中无该表条目）。`employee_id` 为业务约定引用，非引擎级 FK。

**结论**：结构高度宽松，仅需 `assessment_title` 即可入库 → 适合 **策略 A（直接 INSERT）**。

## 三、外键全景（仅 7 条强制约束，均指向 employee / hse_org_unit）

## 五、枚举/有效值

- `assessment_type`：`theory`（理论）/ `practical`（实操）（来自 `training-assessment.js` `/rules/assessment-types`）
- `status`：默认 `completed`
- `grade`：自由文本，参考月度模块用 `excellent`/`good`/`pass`/`fail`，本种子采用中文「优秀/良好/合格/不合格」以贴合中文 HSE 语境
- `is_pass`：boolean，`score >= pass_score(60)` 即 true

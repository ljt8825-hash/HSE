## 8. 注意事项

1. **hseEventSyncService 隐患同步**：当前 `eventData` 对象需扩展 `personnel_id` 字段，从 hazard 记录中提取 `finder_id` 并传入。
2. **workflowService 巡检事件**：需确认 `personnel_id` 来源——可能来自 `task.assignee_id`、`hazard.finder_id` 或 `created_by`。
3. **workflowService 复查记录**：`reviewer_id` 来源可能是审批流中的 `approver_id` 或 `created_by`。
4. **前端 events 表单**：当前事件的"报告人"是文本输入，`personnel_id` 是新增的独立字段（关联人员），与"报告人"文本并行不冲突。
5. 写入的 id 必须真实存在于 `employee` 表（FK 约束校验），否则 INSERT 会失败。

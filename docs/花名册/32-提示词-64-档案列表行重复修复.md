## 0. 背景

提示词-62 修复了 `GET /employees` 的行重复，提示词-63 修复了 `GET /departments/:id/employees` 的同类缺陷。提示词-63 执行报告中发现第三个残留：

> `GET /employees/profile/list` 的 `ea` JOIN（L6030、L6056）仅 `ea.is_current = true`，同时缺失 `is_deleted` 与 `is_primary`，是比前两个端点更完整的同类缺陷。

该端点不限 org_unit，只要员工有 ≥2 条当前任职（跨 org_unit 的主职+兼岗），列表即会产生重复行。

---

## 1. 根因

### 1.1 当前代码

**COUNT 查询**（L6030）：
```sql
LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
```

**数据查询**（L6056）：
```sql
LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
```

两处均缺失 `is_deleted = false` 和 `is_primary = true`。

### 1.2 已修复端点的范式

| 端点 | 提示词 | 改动 |
|------|--------|------|
| `GET /employees` (L587) | 62 | + `is_deleted` + `is_primary` ✅ |
| `GET /departments/:id/employees` (L1238) | 63 | + `is_primary`（conditions 数组）✅ |
| `GET /employees/profile/list` (L6030, L6056) | **64** | **待修复** |

---

## 2. 修复方案

**文件**：`server/routes/hse-employee.js`，`GET /employees/profile/list`

### 2.1 COUNT 查询（L6030）

```
旧：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
新：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false AND ea.is_primary = true
```

### 2.2 数据查询（L6056）

```
旧：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true
新：LEFT JOIN employee_assignment ea ON ea.employee_id = ev.employee_id AND ea.is_current = true AND ea.is_deleted = false AND ea.is_primary = true
```

> 改动 2 处，对齐 `GET /employees`（L587）的完整三条件范式。

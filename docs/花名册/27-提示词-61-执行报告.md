## 3. 任务 C1：孤儿清洗脚本（门控核查版）

脚本：`server/sql/hse_fk_orphan_cleanup_phase1.sql`

由于 5 个孤儿列**全部为 NOT NULL**，按红线【NOT NULL 活跃孤儿不得强制 SET NULL，必须标记人工介入】：**本脚本未执行任何数据修改**，仅做门控核查并输出人工介入提示。其余 17 列孤儿=0，无需清洗。

人工修复路径（均属数据变更，须业务方单独评审，**不在本脚本自动执行**）：
- (a) 业务方补录被引用的 employee / position，使引用重新有效；或
- (b) 业务方确认种子行可废弃后，`DELETE` 或先 `DROP NOT NULL` 再 `SET NULL`；
- 之后重跑 `hse_fk_phase1_training_violations_goals.sql` 即可建立对应 5 条 FK（脚本幂等自愈合）。

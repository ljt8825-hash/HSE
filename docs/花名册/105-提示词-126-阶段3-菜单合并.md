## 4. 修改项

### 4.1 修改项 A：hse-07-personnel.ts — 移除菜单 + 加重定向

**文件**：`安全看板vben\apps\web-antd\src\router\routes\modules\hse-07-personnel.ts`

**操作**：删除第 36-45 行（"作业中心"路由条目），在 `children` 数组末尾追加一个重定向路由。

删除的内容：

```typescript
      {
        meta: {
          title: '作业中心',
          icon: 'lucide:building-2',
          authority: ['admin', 'safety_manager'],
        },
        name: 'PersonnelOrgCenter',
        path: '/personnel/org-center',
        component: () => import('#/views/hse/employee/org-center.vue'),
      },
```

追加的重定向路由（放在 `children` 数组最后，`超龄人员` 之后）：

```typescript
      {
        meta: {
          title: '作业中心',
          icon: 'lucide:building-2',
          authority: ['admin', 'safety_manager'],
          hideInMenu: true,
        },
        name: 'PersonnelOrgCenter',
        path: '/personnel/org-center',
        redirect: '/personnel/departments',
      },
```

> **设计说明**：保留路由定义 + `hideInMenu: true` 而非完全删除，确保旧书签/链接访问 `/personnel/org-center` 时自动跳转到组织管理页面，而非 404。菜单中不再显示。

## 2. 任务 A：后端 — 补全 org_path 和 employee_code 透传

### 2.1 改动点

```sql

```


### 2.2 改动后完整 SELECT（L573-593）

```sql
SELECT ev.employee_id AS id, ev.employee_code, e.id_card, ev.name, e.gender,
       e.birth_date, e.phone, e.person_category, e.person_type,
       e.is_public_welfare, e.id_address,
       CASE WHEN e.birth_date IS NOT NULL THEN EXTRACT(YEAR FROM AGE(e.birth_date))::int END AS age,
       ea.org_unit_id, ev.org_name AS dept_name, ev.org_path AS org_path,
       ea.position_id, ev.position_name,
       ev.assignment_status AS org_status,
       ea.start_date,
       CASE WHEN ev.position_name ILIKE '%驾驶员%' OR ev.position_name ILIKE '%司机%' THEN true ELSE false END AS is_driver,
       ea_sup.supervisor_id AS supervisor_id,
       sup.name AS supervisor_name
```

> 仅改 1 行：`NULL AS org_path` → `ev.org_path AS org_path`。其余字段（employee_code / birth_date / is_driver / org_status）均已存在，无需改动。

### 3.3 新增辅助函数

```typescript
function getStatusColor(status?: string) {
  const map: Record<string, string> = {
    '在职': 'green',
    '离职': 'red',
    '待岗': 'orange',
    '退休': 'default',
    '返聘': 'blue',
  };
  return map[status || ''] || 'default';
}

function getStatusText(status?: string) {
  return status || '未知';
}
```

### 3.4 前端班组提取

班组由后端 `org_path`（如 `/集团/区域/企业/项目/班组`）提取末级。方案：在 `fetchFn` 返回后对 `dataList` 做一次 map，提取 `team_name`：

```typescript
// 在 table 的 fetchFn 回调中，返回前处理
function extractTeamName(orgPath?: string): string {
  if (!orgPath) return '-';
  const parts = orgPath.split('/').filter(Boolean);
  return parts[parts.length - 1] || '-';
}
```

或者在 `onSuccess` 中统一处理：

```typescript
const table = reactive(useDataTable<EmployeeApi.EmployeeItem>({
  fetchFn: async ({ page, pageSize }) => {
    // ... existing fetch logic
    const res = await getEmployeeList({ page, pageSize, ...search.form });
    // 为每行提取 team_name
    (res.dataList || []).forEach((item: any) => {
      item.team_name = extractTeamName(item.org_path);
    });
    return res;
  },
  // ...
}));
```

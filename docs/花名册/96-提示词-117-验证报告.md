## 一、P1-5：路由重复定义，权限不一致

- **根因**：`/personnel/departments`（hse-07-personnel.ts）authority 仅 `['admin']`，而 `/hse/employee/departments`（hse-employee.ts）为 `['admin','safety_manager']` → safety_manager 看不到菜单但能直链访问。
- **修复**（`hse-07-personnel.ts`）：
  - 组织管理 `authority: ['admin'] → ['admin', 'safety_manager']`
  - 同步将同模块"岗位管理"也改为 `['admin', 'safety_manager']`（同一人员管理模块，安全负责人需同等可见，避免新的权限不一致）。
- 未改 hse-employee.ts 旧路由（保持 hideInMenu 的既有入口不变）。

## 二、P1-6：编辑表单缺少 manager_id / safety_manager_id 输入控件

- **根因**：`handleEdit` 已读取并写入 `formData.manager_id/safety_manager_id`，但表单模板无对应控件。
- **修复**（`departments.vue` 编辑表单，位于"编制人数"与"排序"之间）：新增两个远程可搜索 `a-select`：
  ```html
  <a-form-item label="部门负责人">
    <a-select v-model:value="formData.manager_id" allow-clear show-search
              :filter-option="false" :loading="employeeSearchLoading"
              @search="handleEmployeeSearch" style="width:100%">
      <Select.Option v-for="emp in employeeOptions" :key="emp.employee_id" :value="emp.employee_id">
        {{ emp.name }} ({{ emp.employee_code || emp.employee_id }})
      </Select.Option>
    </a-select>
  </a-form-item>
  <!-- 安全负责人 同理 -->
  ```
- **数据来源**（远程搜索，避免一次性拉全量）：`getEmployeeSelectorList({ limit:100, keyword })` + 防抖 `@search`；打开弹窗时 `ensureEmployeeOptions()` 预载首屏 100 条，并合并当前已选 `manager_id/safety_manager_id`（经 `getEmployeeSelectorBatch` 回显）确保编辑回显不丢失。
- 详情卡片的负责人展示由提示词-115 的 `managerName/safetyManagerName` computed 承担。

## 4. 修改项清单

### 4.1 R1：修复 other/index.vue 数据解包（P0）

**文件**：`安全看板vben/apps/web-antd/src/views/insurance/other/index.vue`

**问题**：
```typescript
// 错误写法（当前代码）
const r = await request.get('/insurance/other', { params: { ...searchForm, ...pagination } });
if (r.code === 0) {                    // r.code 恒 undefined → 条件恒 false
  dataList.value = r.data.list || [];  // r.data 恒 undefined
  total.value = r.data.total || 0;
}
```

**修复**：改为对齐 `responseReturn:'data'` 契约（与 personnel/vehicle 通过 `insurance.ts` 的 `res.list`/`res.total` 一致）：

```typescript
// 正确写法
const r = await request.get('/insurance/other', { params: { ...searchForm, ...pagination } });
dataList.value = r.list || [];
total.value = r.total || 0;
```

同样修复 `fetchStats`：
```typescript
// 错误写法
if (r.code === 0) stats.value = r.data.stats || {};

// 正确写法
stats.value = r.stats || {};
```

> **注意**：修复后改为 try/catch 模式（与 personnel/vehicle 一致），在 catch 中 `message.error`，而非静默忽略。

2. 在 L823 处对 idCard 做脱敏处理。需要先在文件顶部添加 `maskIdCard` 工具函数（或复用已有的）：

### 4.3 R3：personnel 身份证号前端脱敏（P1）

**文件**：`安全看板vben/apps/web-antd/src/views/insurance/personnel/index.vue`

**问题**：表格列 L615 `{ title: '身份证号', dataIndex: 'idCard' }` 和详情抽屉 L379 `{{ currentDetail.idCard || '-' }}` 均明文展示。

**修复**：

在 `<script setup>` 中添加掩码函数：
```typescript
function maskIdCard(idCard: string) {
  if (!idCard || idCard.length < 8) return idCard || '-';
  return idCard.substring(0, 4) + '**********' + idCard.substring(idCard.length - 4);
}
```

表格列改为自定义渲染（在 `bodyCell` 模板中）：
```vue
<template v-else-if="column.key === 'idCard'">
  {{ maskIdCard(record.idCard) }}
</template>
```

详情抽屉改为：
```vue
<DescriptionsItem label="身份证号">{{ maskIdCard(currentDetail.idCard) }}</DescriptionsItem>
```

> **注意**：新增/编辑表单中的身份证号输入框（L270-271）**不脱敏**（编辑时需要看到完整值），仅列表展示和详情抽屉脱敏。

### 4.5 R5：补齐 insurance 各端点 requireRole 鉴权（P1）

**文件**：`server/routes/insurance.js`

**问题**：对照 overage 全部端点已加鉴权，personnel/vehicle/other 大量端点缺鉴权。

**当前鉴权状态**（grep 确认）：
- `/overage/*`（7 个端点）：✅ 全部有 `requireRole`
- `/vehicle/export`：✅ 有
- `/personnel/*`（全部 GET/POST/PUT/DELETE/export/import/batch-renewal/batch-delete/job-type-stats/expiring-soon）：❌ 全部无
- `/vehicle`（GET 列表 + GET stats）：❌ 无
- `/other/*`（全部 GET/POST/PUT/DELETE）：❌ 全部无

**修复**：为以下端点添加 `requireRole('admin', 'safety_manager')`：

**personnel 端点**（所有写操作 + 敏感读）：
- `GET /personnel/export`（R2 已处理）
- `POST /personnel`（新增）
- `PUT /personnel/:id`（编辑）
- `DELETE /personnel/:id`（删除）
- `POST /personnel/import`（导入）
- `POST /personnel/batch-renewal`（批量续保）
- `POST /personnel/batch-delete`（批量删除）
- `GET /personnel/job-type-stats`（统计，含 PII 汇总）
- `GET /personnel/expiring-soon`（临期查询，含 PII）

**vehicle 端点**：
- `GET /vehicle`（列表，含车牌号等敏感信息）
- `GET /vehicle/stats`（统计）

**other 端点**（所有写操作）：
- `POST /other`（新增）
- `PUT /other/:id`（编辑）
- `DELETE /other/:id`（删除）

> **读端点策略**：`GET /personnel`（列表）、`GET /personnel/:id`（详情）、`GET /other`（列表）、`GET /other/:id`（详情）保留仅 `authMiddleware`（登录即可查看），与 emergency 模块的读端点策略一致。但 personnel 列表含身份证号，建议后续提示词讨论是否也对读端点加鉴权。

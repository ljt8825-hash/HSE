### 3.4 修改项 D：模板下载错误处理 — 前端 blob 修复（P2③）

**文件**：`安全看板vben\apps\web-antd\src\api\hse\batch-import.ts`

**downloadTemplate 函数**（约第 275 行）当前使用 `responseType: 'blob'`，后端返回 JSON 错误时仍进入 `.then` 分支。

**修复方案**：检查响应 Content-Type，若为 JSON 则解析错误信息：

```typescript
export async function downloadTemplate(type: string, version = 'v1.0') {
  try {
    const response = await requestClient.get(
      `${BASE}/templates/${type}`,
      {
        params: { version },
        responseType: 'blob',
      },
    );
    
    // 检查是否为错误响应（后端返回 JSON 而非 xlsx）
    if (response.data instanceof Blob && response.data.type.includes('json')) {
      const text = await response.data.text();
      const err = JSON.parse(text);
      throw new Error(err.message || '模板下载失败');
    }
    
    // 正常的文件下载
    const url = window.URL.createObjectURL(response.data);
    const link = document.createElement('a');
    link.href = url;
    link.download = `hse-import-template-${type}-${version}.xlsx`;
    link.click();
    window.URL.revokeObjectURL(url);
    return { success: true };
  } catch (err: any) {
    throw new Error(err.message || '模板下载失败');
  }
}
```

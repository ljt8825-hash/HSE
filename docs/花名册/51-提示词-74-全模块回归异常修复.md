## 1. 修复方案

### 修复 1：应急事件列表接口（前端 1 行）

**文件**：`安全看板vben/apps/web-antd/src/views/emergency/events/index.vue`

**改动**：将请求路径从 `/emergency/events` 改为 `/emergency/events/list`

```js
// 修改前
request.get('/emergency/events', { params })
// 修改后
request.get('/emergency/events/list', { params })
```

**注意**：需先实勘 `index.vue` 确认实际请求代码位置（可能在 `fetchData` / `loadEvents` / `onMounted` 中），精确替换。

### 修复 2：应急模块响应解包统一（前端 5 视图）

**根因**：`request` 客户端配置 `responseReturn:'data'` 返回解包后的内层数据 `{list, total, page, pageSize}`，但应急模块视图仍按信封结构 `r.code === 0 → r.data.list` 取数。

**涉及文件**（`安全看板vben/apps/web-antd/src/views/emergency/` 下）：
- `drills/index.vue` — 演练列表
- `events/index.vue` — 应急事件列表
- `plans/index.vue` — 预案列表
- `teams/index.vue` — 应急队伍
- `materials/index.vue` — 应急物资

**改动模式**（以 drills 为例）：

```js
// 修改前
const r = await request.get('/emergency/drills', { params })
if (r.code === 0) {
  dataList.value = r.data.list
  total.value = r.data.total
}

// 修改后
const r = await request.get('/emergency/drills', { params })
dataList.value = r.list || []
total.value = r.total || 0
```

**执行要求**：逐文件实勘确认实际取数代码，按模式替换，改后确认列表正常渲染。

### 修复 3：/violations 路由白名单（前端 1 处）

**文件**：`安全看板vben/apps/web-antd/src/router/routes/index.ts`

**改动**：在 `dynamicRouteFiles` 白名单中加入 `hse-violations` 模块。

> 注意：需先实勘 `index.ts` 确认白名单数组位置与命名规范，精确插入。同时确认 `/violations` 与 `/site/violation` 的关系（是否冲突或重复），若冲突则保留 `/site/violation` 为主路由，不重复注册。

### 修复 4：档案列表（无需修复）

**判定**：提示词-73 误判为异常。档案功能通过花名册列表「历史」按钮 → `EmployeeHistoryDrawer` 正常提供，无需独立列表页。本修复项**跳过**。

### 修复 5：考核列表端点修正（前端 1 行 + 后端补充路由）

**目标**：确认数据库状态正常，无残留问题。

**检查项**：
1. 所有表行数统计（active vs deleted）
2. 序列值是否正常（无溢出/回退）
3. 活跃连接数与锁等待
4. 最近一次VACUUM/ANALYZE时间
5. 索引膨胀检查

```sql
-- 示例：全表行数统计
SELECT schemaname, relname, n_live_tup, n_dead_tup 
FROM pg_stat_user_tables 
ORDER BY n_live_tup DESC;
```

## 四、异常处理策略

| 异常类型 | 处理策略 |
|----------|----------|
| 页面白屏/报错 | 记录错误堆栈，定位根因（前端/后端/数据），生成修复提示词 |
| 数据不一致 | 对比数据库实际值与前端展示值，定位映射层/API层问题 |
| API异常 | 检查后端日志，确认路由/中间件/数据库连接 |
| 构建失败 | 检查TS类型错误，优先修复，不跳过 |
| 花名册导入匹配失败 | 检查部门/岗位映射规则是否被意外修改 |

**分类标准**：
- 可快速修复（≤30min）→ 本任务内修复，记录修复内容
- 需独立任务 → 评估严重程度，生成修复提示词
- 属已知限制（如残留0行表）→ 记录为"已知"，不阻塞

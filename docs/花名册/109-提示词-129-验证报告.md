## 4. 偏离提示词的适配说明
1. **路由 createTask 调用**：提示词示例改用 `createdBy`，但现有路由传 `user`/`req`、`batchImportService.createTask` 用 `user.username` 作 created_by。为不破坏既有签名，仅新增 `module: module || null`，保留 `user`/`req` 传递。
2. **downloadTemplate 契约**：Vben `responseReturn:'data'` 下 blob 响应直接返回 Blob（非 `{data:Blob}`）。据此在 `downloadTemplate` 内完成下载并返回 `{success:true}`，并同步将 `BatchImportDrawer.handleDownloadTemplate` 简化为"调用即提示成功/失败"，避免把 `{success:true}` 当 Blob 使用。
3. **ModuleType 定义位置**：置于 `BatchImportApi` 命名空间内（与 `ImportType` 同处），index.vue/BatchImportDrawer.vue 无需新增 import 即可用 `BatchImportApi.ModuleType`/字符串；调用侧统一用 `string` 传参。

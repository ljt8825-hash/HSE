# 提示词-115: 部门详情表格动态化与部门员工分页修复

## 背景

在"人员管理 → 组织管理"页面的目视化检查中，发现以下两个问题：

1. **部门详情表格内容未与花名册匹配**：右侧详情卡片中多个字段为空（简称 `-`、所属区域 `-`、所在乡镇 `-`、描述 `-`），编制人数为 0。用户期望这些字段能从花名册中动态获取数据，而非展示静态空值。

2. **部门员工表格只有首页，没有第二页、第三页**：分页组件失效，无论实际有多少条员工数据，翻页按钮始终不可用，只能看到前 10 条。

## 问题一：部门员工分页失效

### 根因分析

`deptEmployeePagination` 响应式对象缺少 `total` 字段（`departments.vue:312-315`）：

```typescript
const deptEmployeePagination = reactive({
  current: 1,
  pageSize: 10,
});
```

Ant Design Vue 的 `a-table` 分页组件需要 `total` 属性来计算总页数。缺少 `total` 时，组件认为总数为 0，永远只显示第 1 页。

同时 `loadDeptEmployees()` 函数（`departments.vue:446-463`）虽然从 API 获取了 `data.total`，但只更新了 `deptEmployeesTotal` 而没有更新 `deptEmployeePagination.total`：

```typescript
deptEmployees.value = data.list || [];
deptEmployeesTotal.value = data.total || 0;
deptEmployeePagination.current = data.page || 1;
deptEmployeePagination.pageSize = data.pageSize || 10;
// 缺少: deptEmployeePagination.total = data.total || 0;
```

### 修复方案

**步骤 1**：在 `deptEmployeePagination` 初始化时添加 `total`、`showSizeChanger` 和 `showTotal`：

```typescript
const deptEmployeePagination = reactive({
  current: 1,
  pageSize: 10,
  total: 0,
  showSizeChanger: true,
  showTotal: (total: number) => `共 ${total} 条`,
});
```

**步骤 2**：在 `loadDeptEmployees()` 中同步更新 `total`：

```typescript
deptEmployeePagination.current = data.page || 1;
deptEmployeePagination.pageSize = data.pageSize || 10;
deptEmployeePagination.total = data.total || 0;  // 新增此行
```

> 注意：`deptEmployeesTotal` 变量（`departments.vue:310`）在模板中还用于显示员工卡片标题中的计数 `({{ ... deptEmployeesTotal }})`，需确保该变量仍然正确赋值。

### 影响范围
- 仅修改 `departments.vue` 第 312-315 行（初始化）和第 456-457 行（数据更新）

## 问题二：部门详情字段动态化

### 根因分析

当前部门详情卡片（`departments.vue:113-153`）展示的全部是 `department` 表的静态字段。这些字段在数据录入阶段未填充，导致：

| 字段 | 当前值 | 根因 |
|------|--------|------|
| 简称 | `-` | `short_name` 为 NULL |
| 所属区域 | `-` | `path` 为空或仅 `/`（且标签语义错误：path 是 ID 层级路径如 `/1/5/12/`，不是"所属区域"） |
| 所在乡镇 | `-` | `township` 为 NULL |
| 编制人数 | `0` | `headcount` 默认值 0（已在提示词-114 中修复为 `-`） |
| 描述 | `-` | `description` 为 NULL |

此外，部门负责人（`manager_id`）和安全负责人（`safety_manager_id`）虽然在 `handleEdit` 中有读取，但详情卡片中**完全没有展示这两个字段**。

### 修复方案

#### 1. 新增"部门负责人"和"安全负责人"展示

在详情卡片中增加两个字段：

```html
<a-descriptions-item label="部门负责人">
  {{ managerName || '-' }}
</a-descriptions-item>
<a-descriptions-item label="安全负责人">
  {{ safetyManagerName || '-' }}
</a-descriptions-item>
```

`managerName` 和 `safetyManagerName` 通过以下方式获取：
- 利用部门员工列表 API（`getDeptEmployees`）返回的数据中匹配 `manager_id` / `safety_manager_id`
- 或：在 `handleSelect` 中选中节点后，如果 `currentDept.manager_id` 存在，从已加载的 `deptEmployees` 列表中查找对应员工姓名
- 或：使用 EmployeeName 组件（`import { EmployeeName } from '#/composables/hse'`）在模板中渲染

**推荐方案**：添加两个 computed 属性，在 `deptEmployees` 中根据 ID 查找姓名：

```typescript
const managerName = computed(() => {
  if (!currentDept.value?.manager_id) return null;
  const emp = deptEmployees.value.find(e => e.id === currentDept.value!.manager_id);
  return emp?.name || null;
});
const safetyManagerName = computed(() => {
  if (!currentDept.value?.safety_manager_id) return null;
  const emp = deptEmployees.value.find(e => e.id === currentDept.value!.safety_manager_id);
  return emp?.name || null;
});
```

> 注意：`deptEmployees` 是分页数据，可能不包含 manager。如果分页数据中找不到，需要额外调用 `getEmployeesByIds` API 批量查询。建议使用 `#/api/hse/employee` 中已有的 `getEmployeesByIds` 函数。

#### 2. 修复"所属区域"标签

`path` 字段存储的是 ID 层级路径（如 `/1/5/12/`），用于数据库祖先/后代查询，不是面向用户的"区域"概念。当前标签"所属区域"语义错误。

**方案**：将标签改为"层级路径"，并使用 `treeData` 递归解析 ID 路径为名称路径（如 `/集团/宁城环卫/宁城街道`）。

在 `handleSelect` 中，基于已加载的 `treeData` 构建名称路径：

```typescript
function buildNamePath(node: EmployeeApi.DeptNode | null): string {
  if (!node) return '-';
  // 从 treeData 中找到从根到当前节点的路径
  const findPath = (nodes: EmployeeApi.DeptNode[], targetId: number, currentPath: string[]): string[] | null => {
    for (const n of nodes) {
      const newPath = [...currentPath, n.name];
      if (n.id === targetId) return newPath;
      if (n.children) {
        const result = findPath(n.children, targetId, newPath);
        if (result) return result;
      }
    }
    return null;
  };
  const names = findPath(treeData.value, node.id, []);
  return names ? names.join(' / ') : node.path || '-';
}
```

然后在详情卡片中：

```html
<a-descriptions-item label="层级路径" :span="2">
  {{ namePath || '-' }}
</a-descriptions-item>
```

#### 3. 为 path 字段更新标签

将原来的：
```html
<a-descriptions-item label="所属区域" :span="2">
  {{ currentDept.path || '-' }}
</a-descriptions-item>
```

改为：
```html
<a-descriptions-item label="层级路径" :span="2">
  {{ namePath || '-' }}
</a-descriptions-item>
```

### 影响范围
- `departments.vue` 模板：新增"部门负责人"和"安全负责人"行，修改"所属区域"为"层级路径"
- `departments.vue` script：新增 `managerName`、`safetyManagerName`、`namePath` computed，新增 `buildNamePath` 辅助函数
- 可能需要从 `departments.vue` 已 import 的 API 中新增 `getEmployeesByIds` 的引用

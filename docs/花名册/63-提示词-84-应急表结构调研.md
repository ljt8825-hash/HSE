# 提示词-84：应急模块表结构调研

> 调研日期：2026-07-31 ｜ 方法：只读 `\d+` / information_schema / pg_constraint 查询
> 范围：emergency_events / emergency_plans / emergency_teams / emergency_materials

---

## 〇、与提示词假设的偏差（重要）

提示词任务2给出的列名与**实际 schema 不符**，已按真实结构适配种子数据：

| 表 | 提示词假设列 | 实际列 | 处理 |
|----|-------------|--------|------|
| emergency_teams | `org_unit_id` / `captain_id` / `member_count` | 无这些列；实为 `leader_id`(bigint) / `leader_name`(varchar) / `member_ids`(bigint[]) | 用 `leader_id`+`leader_name`+`member_ids` |
| emergency_materials | `org_unit_id` | 无 `org_unit_id` | 用 `location`(文本) 记录存放地 |
| emergency_plans | `plan_name` / `plan_type` / `applicable_scope` | 实为 `name` / `type` / `level` | 用真实列名 |

> 真实表结构以 `information_schema` 实测为准，提示词列名仅作语义参考。

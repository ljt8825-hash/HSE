## 4. 孙佳敏专项验证

### 4.1 数据库验证

```sql
SELECT e.employee_code, e.name, ou.org_name, p.name AS position_name, ea.is_current, ea.is_primary
FROM employee e
LEFT JOIN employee_assignment ea ON ea.employee_id = e.id AND ea.is_deleted = false
LEFT JOIN hse_org_unit ou ON ou.id = ea.org_unit_id
LEFT JOIN position p ON p.id = ea.position_id
WHERE e.name = '孙佳敏' AND e.is_deleted = false
ORDER BY ea.is_current DESC;
```

**结果**：

| employee_code | name | org_name | position_name | is_current | is_primary |
|---------------|------|----------|---------------|------------|------------|
| 00271497 | 孙佳敏 | 人力综合部 | **行政综合主管** | **true** | true |
| 00271497 | 孙佳敏 | 人力综合部 | 管理员 | false | true |

当前任职（`is_current=true`）已正确为 **行政综合主管**；旧「管理员」记录保留但标记为非当前。

### 4.2 API 验证

```
GET /api/hse/employee/employees?page=1&pageSize=20&keyword=孙佳敏
```

**结果**：`total=1`，返回记录 `position_name="行政综合主管"`、`dept_name="人力综合部"`、`org_path="/宁津项目公司/人力综合部"`。

前端「员工列表」页面将正确显示孙佳敏职位为 **行政综合主管**。

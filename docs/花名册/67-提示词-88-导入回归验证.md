## 5. 观察项（非阻塞，建议独立修复，不在本次红线范围内）

1. **`/preview` 响应字段名为 `pendingList`**（非 `pending`）：前端调用方需以 `data.pendingList` 取数，避免取到空数组误判。
2. **岗位匹配哨兵不一致（潜在）**：`matchPosition` 在 `rawDept` 含「片区」时将 `cond` 置为 `*片区`，但 DB 中 `employee_position_mapping_rule.condition_dept` 实际值为 `片区`（无星号）。该条件分支不会命中，会回退至 `condition_dept IS NULL` 规则。当前 `司机` 在 片区 / NULL 两种条件下均映射 `1398`（垃圾收运车驾驶员），结果一致故无功能影响；但属隐性不一致，建议后续统一哨兵写法。
3. 既有缺陷 `GET /api/hse/driver-risk-center/drivers` 返回 500（PG DISTINCT/ORDER BY 表达式问题）与本模块无关，已在 API 健康检查报告中按红线记录，建议独立修复。

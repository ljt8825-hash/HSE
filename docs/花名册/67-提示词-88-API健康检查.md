## 4. 已知缺陷：`/api/hse/driver-risk-center/drivers` 返回 500

- **现象**：`GET /api/hse/driver-risk-center/drivers` → HTTP 500。
- **根因**：后端 SQL 在 PostgreSQL 下报 `在查询列表中必须出现SELECT DISTINCT, ORDER BY表达式`（即 `SELECT DISTINCT ... ORDER BY` 列未全部出现在 SELECT 列表 —— 典型 PG 严格性错误），属**服务端既有 SQL 缺陷**。
- **影响范围**：仅"驾驶员风险中心 / 驾驶员列表"子页；同模块的 `/overview`、`/demerit/statistics`、`/accident/statistics` 未在此探针覆盖，但 `overview` 已确认 200。
- **是否本次回归引入**：**否**。该缺陷存在于 `hse-driver-risk-center.js` 既有实现，与花名册导入/数据补录轨道无关。
- **处置（按红线）**：发现即记录与评估，**不修改后端代码**。建议独立修复提示词（定位 `hse-driver-risk-center.js` 中 `drivers` 查询的 `ORDER BY`/`DISTINCT` 列不一致），不在本任务内修复。

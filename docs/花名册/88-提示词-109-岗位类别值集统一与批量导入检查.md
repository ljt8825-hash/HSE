# 提示词-109：岗位类别值集统一 + 批量导入模块检查

## 背景

提示词-108 完成了员工列表检查、部门员工子列表 SQL 修复、统计卡片 camelKeys 修复。同时深入分析了岗位管理模块的筛选问题，发现比提示词-107 记录的更严重：

**P1 级：岗位类别筛选恒空 + 值集持续分裂**

- 前端 `positions.vue` 筛选下拉值为 `管理类/技术类/操作类/辅助类`
- 数据库 `position.job_category` 实际值为 `管理/技术/生产`（+ 8 条 NULL）
- 筛选是**精确比较**（`item.job_category !== searchForm.jobCategory`），选"管理类"永远匹配不到"管理"
- 新增/编辑表单用的也是同一套"XX类"值，每通过 UI 新建一个岗位就写入一个分裂值，越晚统一脏数据越多

本提示词修复该 P1 问题（统一值集），同时检查"人员管理"菜单下最后一个未检查的子模块——**批量导入**。

## 影响范围

| 层级 | 文件 | 改动类型 |
|------|------|---------|
| 前端 | `apps/web-antd/src/views/hse/employee/positions.vue` | 修改筛选下拉和表单下拉值集 |
| 数据库 | `position` 表 | 批量迁移现有值（`管理类`→`管理` 等） |
| 前端 | `apps/web-antd/src/views/hse/employee/batch-import.vue`（或实际路径） | 仅检查 |
| 后端 | `server/routes/hse-employee.js` 批量导入相关端点 | 仅检查 |

> **约束**：仅修复岗位类别值集 + 检查批量导入模块。禁止修改菜单、路由、其他业务模块。

## Task 1：统一岗位类别值集（P1）

### 1.1 策略选择

三选一，推荐 **方案 A**（改动最小，对现有数据破坏最小）：

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **A（推荐）** | 前端改为 `管理/技术/生产/辅助`，数据库已有分裂值回迁 | 与现有数据一致，改动最小 | 需处理 NULL 值 |
| B | 数据库批量迁移为 `管理类/技术类/操作类/辅助类` | 与前端一致 | 需语义映射（操作类↔生产），且需确认业务方认可 |
| C | 引入字典表 | 长期可维护 | 改动大，超出本次范围 |

### 1.2 步骤

#### 步骤 1：数据库迁移

先检查数据库中是否有前端已写入的分裂值：

```sql
SELECT DISTINCT job_category FROM position WHERE is_deleted = false ORDER BY job_category;
```

将分裂值迁移到统一值集（以方案 A 为例）：

```sql
-- 将已知分裂值迁移（如有）
UPDATE position SET job_category = '管理' WHERE job_category = '管理类' AND is_deleted = false;
UPDATE position SET job_category = '技术' WHERE job_category = '技术类' AND is_deleted = false;
UPDATE position SET job_category = '生产' WHERE job_category IN ('操作类', '辅助类') AND is_deleted = false;
```

> **注意**：在执行 UPDATE 前，先 `SELECT` 确认受影响行数，生成迁移前后对比报告。

## Task 2：处理 8 条 NULL job_category（P2）

提示词-108 §3.1 列出了 8 条 `job_category` 为 NULL 的岗位。由于筛选使用 `item.job_category !== searchForm.jobCategory`，NULL 值不参与任何筛选匹配，且通过 `v-if="record.job_category"` 渲染时单元格留空。

### 2.1 处理

在验证报告中列出这 8 条岗位的**建议分类**（见提示词-108 报告），供业务方确认后手动补录。本次不自动修改（需人工确认）。

如需修复，SQL 参考：
```sql
-- 示例（需业务确认后执行）
UPDATE position SET job_category = '管理' WHERE id = 1373 AND is_deleted = false;  -- 乡镇主管
UPDATE position SET job_category = '管理' WHERE id = 1374 AND is_deleted = false;  -- 管理员
UPDATE position SET job_category = '生产' WHERE id = 1375 AND is_deleted = false;  -- 收运车司机
-- ... 其余 5 条
```

5. **模板下载**：模板下载功能是否正常

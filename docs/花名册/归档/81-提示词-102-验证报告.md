## 1. Task 1：前端字段读取方式核对（不改前端）

读取 `安全看板vben/apps/web-antd/src/views/hse/employee-profile/index.vue` 详情 Drawer：

  `employee_code` / `name` / `id_card` / `age` / `phone` / `gender` / `birth_date` / `person_type` / `person_category` / `is_public_welfare` / `status` / `created_at`

  `org_name` / `org_code` / `unit_name` / `unit_type` / `position_name` / `position_code` / `risk_level` / `supervisor_name` / `start_date` / `assignment_status`

核对 `安全看板vben/apps/web-antd/src/api/hse/employee-profile.ts` 类型定义：
- `BasicInfo`：`employee_code / person_type / is_public_welfare` … 均为 **snake_case**
- `CurrentOrg`：`org_name / position_code / start_date` … 均为 **snake_case**

→ **前端与类型均为 snake_case**，与列表页（提示词-101 已修）一致。

## 3. Task 3：修复详情 API 字段映射（Scenario A）

**改动**：移除 `camelKeys()`，直接返回 SQL 结果（SQL 列名本就是 snake_case）。

`server/routes/hse-employee.js`（第 6139 行附近）：

```js
// 修复前
res.json(success(camelKeys({
  basic: emp,
  currentOrg: currentResult.rows.length > 0 ? currentResult.rows[0] : null,
}), '查询成功'));

// 修复后
res.json(success({
  basic: emp,
  currentOrg: currentResult.rows.length > 0 ? currentResult.rows[0] : null,
}, '查询成功'));
```

新增注释说明：SQL 列名本就 snake_case，Drawer 与类型均按 snake_case 读取，套 `camelKeys()` 会键名不匹配导致整列空（与列表页策略一致）。

> 未改动前端、未改动 `/assignments` / `/driver-info` 子接口（它们本就未套 camelKeys，实测 200）。

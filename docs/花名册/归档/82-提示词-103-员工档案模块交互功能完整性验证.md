## Task 3：详情 Drawer 功能验证

### 3.1 基础信息区
- 点击任意员工"详情" → Drawer 弹出
- 确认基础信息区字段完整显示：员工编号、姓名、性别、年龄、出生日期、手机号、身份证号、人员类型、人员分类、是否公益岗、状态、创建时间
- 手机号/身份证号应脱敏展示（`maskPhone`/`maskIdCard` 按 `ENC:` 前缀处理）

### 3.2 组织信息区
- 确认字段完整显示：所属组织、组织编码、作业单元、岗位、岗位编码、风险等级、主管、入职日期、状态
- 对于无运营单位的员工，`unit_name`/`unit_type` 显示 `-` 或空

### 3.3 任职历史 Tab
- 切换到"任职历史" Tab → 确认列表有数据
- 确认列正常显示：组织、作业单元、岗位、开始日期、结束日期、状态
- 确认 `is_current=true` 的记录标记为"当前"

### 3.4 驾驶员信息
- 选择一名驾驶员（如岗位名含"驾驶员"），点击详情
- 确认驾驶员信息能正常展示（或显示"非驾驶员"）

### 3.5 Drawer 关闭与切换
- 关闭 Drawer → 确认关闭
- 再次点击另一员工详情 → 确认 Drawer 重新打开且数据正确
- 快速连续点击不同员工 → 确认无数据错乱

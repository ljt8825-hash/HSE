# 前端接口绑定说明

## 一、概述

本文档详细说明HSE综合驾驶舱前端与后端API的绑定关系，包括接口调用方式、数据结构映射、错误处理等内容。

### 1.1 技术实现

- **请求库**：`@vben/request`（基于Axios封装）
- **API定义文件**：`src/api/hse/cockpit.ts`
- **请求基路径**：由Vben配置的 `apiURL` + `/hse/dashboard`
- **响应格式**：`{ success: boolean, data: T, message: string }`

### 1.2 接口总览

| 序号 | 前端函数 | 后端接口 | 方法 | 页面模块 |
|------|----------|----------|------|----------|
| 1 | `getOverview()` | `/hse/dashboard/overview` | GET | 风险总览 |
| 2 | `getLevelDistribution()` | `/hse/dashboard/level-distribution` | GET | 风险等级分布 |
| 3 | `getRiskTypeAnalysis()` | `/hse/dashboard/risk-type-analysis` | GET | 风险类型分析 |
| 4 | `getRiskTop(limit)` | `/hse/dashboard/risk-top` | GET | 风险TOP排行 |
| 5 | `getRiskTrend(period, metric)` | `/hse/dashboard/risk-trend` | GET | 风险趋势 |
| 6 | `getManagementExecution(days)` | `/hse/dashboard/management-execution` | GET | 管理履职 |
| 7 | `getRiskLevelConfig()` | `/hse/dashboard/risk-level-config` | GET | （备用） |

## 二、接口详细说明

### 2.1 驾驶舱总览接口

**前端函数**：

```typescript
export function getOverview() {
  return requestClient.get<CockpitApi.OverviewData>(`${BASE}/overview`);
}
```

**调用位置**：`views/hse/cockpit/index.vue` → `fetchOverview()`

**请求参数**：无

**返回数据结构**：

```typescript
interface OverviewData {
  totalEmployees: number;           // 员工总数
  evaluatedCount: number;           // 已评估人数
  criticalRiskCount: number;        // 重大风险人数
  highRiskCount: number;            // 较高风险人数
  highRiskRatio: number;            // 高风险占比（%）
  improvementRate: number;          // 风险改善率（%）
  levelDistribution: {              // 等级分布（备用）
    [levelCode: string]: {
      name: string;
      count: number;
      color: string;
    };
  };
  avgScore: number | null;          // 平均积分
}
```

**字段映射**：

| 前端字段 | 后端字段 | 类型转换 | 说明 |
|----------|----------|----------|------|
| totalEmployees | totalEmployees | 直接映射 | 来自employee_assignment统计 |
| evaluatedCount | evaluatedCount | 直接映射 | 来自risk_level_records统计 |
| criticalRiskCount | criticalRiskCount | 直接映射 | level_code='critical'的人数 |
| highRiskCount | highRiskCount | 直接映射 | 重大+较高风险人数合计 |
| highRiskRatio | highRiskRatio | 直接映射 | 高风险人数/已评估人数×100% |
| improvementRate | improvementRate | 直接映射 | 近30天等级下降人数/总变更人数×100% |
| levelDistribution | levelDistribution | 直接映射 | 各等级详情对象 |
| avgScore | avgScore | 直接映射 | 平均积分（当前为null） |

**使用位置**：
- `RiskOverview.vue` - 风险总览6个指标卡片

### 2.2 风险等级分布接口

**前端函数**：

```typescript
export function getLevelDistribution() {
  return requestClient.get<CockpitApi.LevelDistributionData>(`${BASE}/level-distribution`);
}
```

**调用位置**：`views/hse/cockpit/index.vue` → `fetchLevelDistribution()`

**请求参数**：无

**返回数据结构**：

```typescript
interface LevelDistributionData {
  levels: Array<{
    levelCode: string;      // 等级代码: low/medium/high/critical
    levelName: string;      // 等级名称: 低风险/一般风险/较高风险/重大风险
    colorCode: string;      // 颜色代码: #52c41a/#faad14/#fa8c16/#f5222d
    minScore: number;       // 最低分
    maxScore: number;       // 最高分
    count: number;          // 人数
    ratio: number;          // 占比（%）
  }>;
  total: number;             // 总评估人数
}
```

**字段映射**：

| 前端字段 | 后端字段 | 类型转换 | 说明 |
|----------|----------|----------|------|
| levels[].levelCode | levelCode | 直接映射 | 来自risk_level_config.level_code |
| levels[].levelName | levelName | 直接映射 | 来自risk_level_config.level_name |
| levels[].colorCode | colorCode | 直接映射 | 来自risk_level_config.color_code |
| levels[].minScore | minScore | parseFloat | 最低分阈值 |
| levels[].maxScore | maxScore | parseFloat | 最高分阈值 |
| levels[].count | count | parseInt | 该等级人数 |
| levels[].ratio | ratio | parseFloat | 占比，保留2位小数 |
| total | total | 直接计算 | 所有等级人数之和 |

**使用位置**：
- `LevelDistribution.vue` - 环形图数据

**图表配置映射**：

```typescript
// ECharts series.data 映射
data: levels.map(level => ({
  name: level.levelName,
  value: level.count,
  itemStyle: { color: level.colorCode },
  levelCode: level.levelCode,  // 自定义字段，用于点击事件
}))
```

### 2.6 管理履职接口

**前端函数**：

```typescript
export function getManagementExecution(days: number = 30) {
  return requestClient.get<CockpitApi.ManagementExecutionData>(
    `${BASE}/management-execution`,
    { params: { days } }
  );
}
```

**调用位置**：`views/hse/cockpit/index.vue` → `fetchManagementExecution()`

**请求参数**：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| days | number | 30 | 统计天数 |

**返回数据结构**：

```typescript
interface ManagementExecutionData {
  summary: {
    totalInspections: number;       // 总巡查次数
    totalProblems: number;          // 发现问题总数
    completedCount: number;         // 已整改数
    overdueCount: number;           // 逾期数
    problemFoundRate: number;       // 问题发现率（%）
    rectificationRate: number;      // 整改完成率（%）
  };
  execution: {                      // 执行指标
    title: string;
    gridLevels: Array<{
      gridLevel: string;
      actualCount: number;
      expectedCount: number;
      completionRate: number;
    }>;
  };
  quality: {                        // 质量指标
    title: string;
    gridLevels: Array<{
      gridLevel: string;
      totalInspections: number;
      problemCount: number;
      problemFoundRate: number;
    }>;
  };
  closure: {                        // 闭环指标
    title: string;
    gridLevels: Array<{
      gridLevel: string;
      totalProblems: number;
      completedCount: number;
      pendingCount: number;
      overdueCount: number;
      rectificationRate: number;
    }>;
  };
}
```

**前端计算字段**：

巡查完成率（加权平均）在前端计算：

```typescript
const executionRate = computed(() => {
  let totalActual = 0;
  let totalExpected = 0;
  levels.forEach(level => {
    totalActual += level.actualCount || 0;
    totalExpected += level.expectedCount || 0;
  });
  return totalExpected > 0 
    ? parseFloat(((totalActual / totalExpected) * 100).toFixed(2)) 
    : 0;
});
```

**空数据判断条件**：

```typescript
const hasData = computed(() => {
  if (!data?.summary) return false;
  const { totalInspections, totalProblems, completedCount } = data.summary;
  return totalInspections > 0 || totalProblems > 0 || completedCount > 0;
});
```

**重要**：当 `hasData === false` 时，显示"暂无数据"，不显示0%。

**使用位置**：
- `ManagementExecution.vue` - 指标卡片 + 进度条 + 统计

## 三、请求流程

### 3.1 页面初始化加载

```
组件挂载 (onMounted)
  ↓
fetchAllData()
  ├─ fetchOverview()          ── GET /overview
  ├─ fetchLevelDistribution() ── GET /level-distribution
  ├─ fetchRiskTypeAnalysis()  ── GET /risk-type-analysis
  ├─ fetchRiskTop()           ── GET /risk-top?limit=10
  ├─ fetchRiskTrend()         ── GET /risk-trend?period=daily&metric=total
  └─ fetchManagementExecution() ── GET /management-execution?days=30
```

**说明**：6个接口通过 `Promise.all` 并行发起，提升加载速度。

### 3.2 用户交互触发加载

| 交互动作 | 触发函数 | 调用接口 |
|----------|----------|----------|
| 切换趋势周期 | `handlePeriodChange` | `getRiskTrend(period, metric)` |
| 切换趋势指标 | `handleMetricChange` | `getRiskTrend(period, metric)` |

### 3.3 加载状态管理

```typescript
const loading = reactive({
  overview: false,
  levelDistribution: false,
  riskTypeAnalysis: false,
  riskTop: false,
  riskTrend: false,
  managementExecution: false,
});
```

每个模块独立控制loading状态，避免整体闪烁。

## 四、错误处理

### 4.1 错误拦截

`@vben/request` 内置错误拦截器：
- 401: 跳转登录
- 403: 显示无权限
- 500: 显示错误消息

### 4.2 业务错误处理

每个请求函数都有 try-catch：

```typescript
async function fetchOverview() {
  loading.overview = true;
  try {
    overviewData.value = await getOverview();
  } catch (error: any) {
    message.error(error.message || '获取风险总览数据失败');
  } finally {
    loading.overview = false;
  }
}
```

**处理策略**：
- 显示友好的错误提示
- 保持页面其他模块正常显示
- loading状态正确关闭

## 五、权限与数据范围

### 5.1 前端权限控制

- 路由级：`meta.authority` 控制页面访问
- 6种角色可访问：admin, safety_manager, group_leader, department_manager, township_manager, area_manager

### 5.2 后端数据范围

后端根据登录用户的角色和组织权限自动过滤数据：
- 集团领导：全集团数据
- 部门经理：本部门数据
- 乡镇作业中心经理：本乡镇数据
- 片区长：本片区数据
- 管理员：全量数据

前端不需要额外处理，直接展示返回数据即可。

## 六、接口版本兼容

### 6.1 响应格式兼容

前端使用 `@vben/request` 的响应拦截器统一处理：
- 支持 `{ success: true, data: ... }` 格式
- 支持 `{ code: 0, data: ... }` 格式
- 自动提取data字段

### 6.2 字段缺失处理

所有数据字段都有默认值或空值处理：
- 数字默认0
- 数组默认 []
- 对象默认 null
- 颜色有默认值映射

确保后端字段缺失时页面不会崩溃。

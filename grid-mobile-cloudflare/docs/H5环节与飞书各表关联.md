## 5.4 已实现落库细节（2026-09-18 修正后，代码即此口径）

主台账**没有**这些列，写了会被飞书 `1254045 FieldNameNotFound` 拒掉：
`巡查人员ID` / `姓名` / `巡查时间` / `网格` / `问题描述` / `问题类型` / `是否三违` /
`三违行为` / `涉及人员` / `来源` / `client_request_id` / `创建时间` / `提交时间`。

实际写入的列（worker/index.js `handlePatrolSubmit`）：

| 主台账列 | 值 |
|---|---|
| `检查人姓名` | Session 姓名 |
| `网格等级` | Session 网格长等级 |
| `片区\|班组` | 服务端解析的巡查网格 |
| `违章行为` | 三违行为名；非三违 = `无三违行为` |
| `违章人员姓名` | 违章人姓名（**单人**，不是「姓名,职位,班组」串） |
| `描述` | 问题描述 / 巡查结果 |
| `备注` | `巡查人ID:<手机号> · 巡查时间:<YYYY-MM-DD HH:mm> · req:<clientRequestId>` |
| `违章照片` | 附件（type=17），提交时 `photo_tokens` |
| `整改后照片` | 附件，由 `POST /api/mobile/patrol/attach` 事后补挂 |

⚠️ 三个关键约束：

1. **`日期` 是 type=1001 创建时间只读列**，写它会被静默忽略 —— 巡查时间只能落 `备注`。
2. **主台账没有 `client_request_id` 列** → 幂等靠扫 `备注` 里的 `req:<id>` 回溯
   （`storage/index.js findExistingByClientRequestId`）。
3. **「本人记录」判定同样靠 `备注` 里的 `巡查人ID`**（`patrolIsMine`），姓名不参与（重名会串号）。

### 照片链（2026-09-18 打通）

- 现场照片：提交前 `POST /api/mobile/upload`（multipart）→ `file_token` → `body.photo_tokens`。
- 整改后照片：**记录提交之后才拍**，提交时无从得知 → `POST /api/mobile/patrol/attach`
  `{record_id, kind:'rectify', photo_tokens:[...]}` 用飞书 `PUT /records/:id` 局部更新补挂。
- 归属校验：只能补挂 `备注.巡查人ID` == 本人手机号的记录。

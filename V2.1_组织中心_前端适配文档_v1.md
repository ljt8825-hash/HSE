## 一、组织管理页面复用

### 1.1 现有页面分析

现有组织管理页面 [departments.vue](file:///f:/deploy/hse-dashboard/安全看板vben/apps/web-antd/src/views/hse/employee/departments.vue) 使用 `a-tree` 组件展示五级部门树（集团/区域/企业/项目/班组），调用 `getDeptTree()` 获取数据。

**V2.1 适配策略**：通过新增 `useNewModel` 开关参数，在同一页面中切换新旧组织树数据源，不新建页面。

### 1.2 适配方案：组织树数据源切换

在 [departments.vue](file:///f:/deploy/hse-dashboard/安全看板vben/apps/web-antd/src/views/hse/employee/departments.vue) 中增加数据源切换逻辑：

```vue
<script setup lang="ts">
// 新增导入
import { getOrgUnitTree } from '#/api/hse/employee';

// 新模型开关（默认 true，可通过 URL 参数 ?model=legacy 切换）
const useNewModel = ref(
  new URLSearchParams(window.location.search).get('model') !== 'legacy'
);

// 修改 loadTree 函数，支持双数据源
async function loadTree() {
  treeLoading.value = true;
  try {
    if (useNewModel.value) {
      // V2.1 新模型：调用 /org-units/tree
      const data = await getOrgUnitTree({ status: 'active' });
      treeData.value = transformOrgTreeData(data);
    } else {
      // 旧模型：调用 /departments/tree（保留兼容）
      const data = await getDeptTree({ includeInactive: false });
      treeData.value = data;
    }
    filteredTreeData.value = treeData.value;
  } catch {
    // 错误提示已由拦截器处理
  } finally {
    treeLoading.value = false;
  }
}

// V2.1 组织树数据转换（字段名适配）
function transformOrgTreeData(nodes: EmployeeApi.OrgUnitNode[]): EmployeeApi.DeptNode[] {
  return nodes.map(node => ({
    id: node.id,
    dept_code: node.org_code,
    name: node.org_name,
    parent_id: node.parent_id,
    level: node.level,
    path: node.org_path,
    headcount: node.headcount,
    sort_order: node.sort_order,
    status: node.status,
    description: node.description,
    children: node.children ? transformOrgTreeData(node.children) : undefined,
  }));
}
```

### 3.3 组织联动逻辑

```typescript
// 组织树数据
const orgTreeData = ref<EmployeeApi.OrgUnitNode[]>([]);
const orgTreeLoading = ref(false);

// 作业单元选项（根据选中组织联动）
const operationUnitOptions = ref<EmployeeApi.OperationUnitItem[]>([]);
const opUnitLoading = ref(false);

// 岗位列表
const positionOptions = ref<EmployeeApi.PositionItem[]>([]);
const positionLoading = ref(false);

// 上级选项（同组织下的员工）
const supervisorOptions = ref<Array<{ id: number; name: string }>>([]);

// 组织变化时，加载该组织下的作业单元
async function handleOrgChange(orgUnitId: number | undefined) {
  form.value.operation_unit_id = undefined;
  form.value.supervisor_id = undefined;

  if (!orgUnitId) {
    operationUnitOptions.value = [];
    supervisorOptions.value = [];
    return;
  }

  // 加载该组织下的作业单元
  opUnitLoading.value = true;
  try {
    const result = await getOperationUnitList({
      orgUnitId,
      pageSize: 100,
    });
    operationUnitOptions.value = result.list;
  } finally {
    opUnitLoading.value = false;
  }

  // 加载该组织下的员工（作为上级候选）
  try {
    const result = await getEmployeeList({
      orgUnitId,
      pageSize: 200,
      useNewModel: 'true' as any,
    });
    supervisorOptions.value = result.list.map(e => ({
      id: e.id,
      name: e.name,
    }));
  } catch {
    // 忽略错误
  }
}

// 上级搜索过滤
function filterSupervisor(input: string, option: any) {
  return option.name.toLowerCase().includes(input.toLowerCase());
}
```

## 七、回滚策略

### 7.1 参数级回滚（最快）

通过 URL 参数 `?model=legacy` 立即切回旧模型，无需重新部署：

```
https://hse.example.com/hse/employee/index?model=legacy
https://hse.example.com/hse/employee/departments?model=legacy
```

前端代码中的 `useNewModel` 开关会自动读取此参数，所有页面回退到旧数据源。

### 7.2 环境变量级回滚

在 `.env` 中设置环境变量，全局关闭新模型：

```bash
# .env 文件
VITE_USE_NEW_MODEL=false
```

### 7.3 代码级回滚

如果需要完全移除新模型代码：

| 回滚项 | 操作 | 影响 |
|--------|------|------|
| API 文件 | 移除 V2.1 新增的接口函数 | 无影响（旧接口仍在） |
| 员工列表页 | 移除 `useNewModel` 逻辑，恢复固定列 | 无影响 |
| 组织管理页 | 移除 `useNewModel` 逻辑，恢复旧树 | 无影响 |
| 编辑弹窗 | 移除组织关系表单区域 | 无影响 |
| 导入弹窗 | 移除新字段预览列 | 无影响 |

### 7.4 回滚安全保证

| 保证项 | 说明 |
|--------|------|
| 旧接口保留 | 后端 `useNewModel=false` 时走旧逻辑，旧表未删除 |
| 旧组件保留 | `EmployeeEditModal`、`OrgTransferModal` 原有逻辑通过 `v-if` 保留 |
| 数据安全 | 新表数据独立存储，回滚不影响旧表数据 |
| 渐进式切换 | 可逐页面切换，非全量切换 |

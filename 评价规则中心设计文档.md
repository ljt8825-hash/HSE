## 一、规则中心概述

### 1.1 设计目标

建立可配置、可版本化的评价规则中心，实现评价指标、权重、计算方法的灵活配置，支持规则版本管理和审批流程。

### 1.2 规则中心能力

| 能力 | 说明 |
|------|------|
| 规则配置 | 配置评价指标、权重、计算公式 |
| 规则版本管理 | 版本控制、历史回溯、版本切换 |
| 规则审批 | 变更审批、审批流程 |
| 规则测试 | 规则预览、测试数据验证 |
| 规则发布 | 发布新版本、生效切换 |

### 1.3 规则分类

| 规则类型 | 说明 | 示例 |
|----------|------|------|
| 综合评价规则 | 七维度权重配置 | {风险:25%, 整改:20%, ...} |
| 维度计算规则 | 各维度指标计算规则 | 整改完成率计算规则 |
| 等级评定规则 | 分数到等级的映射规则 | A级:≥90分, B级:80-89分 |
| 成熟度判定规则 | L1-L5判定规则 | L3: 65-79分 + 数据完整度≥75% |
| 分类识别规则 | 人员分类识别规则 | 高风险人员识别规则 |
| 建议生成规则 | 改善建议触发规则 | 低分维度触发建议 |

## 四、规则版本管理

### 4.1 版本流程

```
1. 创建新版本
   ├── 复制当前版本作为基础
   ├── 修改规则配置
   └── 提交审批

2. 审批流程
   ├── 提交审批
   ├── 项目公司管理员审批
   ├── 安全管理员审批
   └── 审批通过后生效

3. 版本发布
   ├── 设置生效日期
   ├── 切换为当前生效版本
   └── 保留历史版本

4. 版本回溯
   ├── 查询历史版本
   ├── 对比版本差异
   └── 恢复指定版本
```

### 4.2 版本状态

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| draft | 草稿 | 编辑、删除、提交审批 |
| pending_approval | 待审批 | 撤回、审批 |
| approved | 已审批 | 发布、废弃 |
| active | 生效中 | 查看、废弃 |
| deprecated | 已废弃 | 查看、恢复 |

### 4.3 版本管理API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/hse/rules | GET | 查询规则列表 |
| /api/hse/rules/:code | GET | 查询规则详情 |
| /api/hse/rules | POST | 创建新规则 |
| /api/hse/rules/:code | PUT | 更新规则 |
| /api/hse/rules/:code/versions | GET | 查询版本历史 |
| /api/hse/rules/:code/approve | POST | 审批规则 |
| /api/hse/rules/:code/publish | POST | 发布规则 |
| /api/hse/rules/:code/deprecate | POST | 废弃规则 |
| /api/hse/rules/compare | POST | 对比两个版本 |

## 五、数据库设计

### 5.1 评价规则主表

```sql
CREATE TABLE hse_eval_rule (
    rule_id         BIGSERIAL PRIMARY KEY,
    rule_code       VARCHAR(50) NOT NULL UNIQUE,
    rule_name       VARCHAR(200) NOT NULL,
    rule_type       VARCHAR(30) NOT NULL,
    -- comprehensive / dimension_calculation / grade_assessment
    -- maturity_assessment / category_identification / suggestion_generation
    description     VARCHAR(500),
    current_version VARCHAR(20),
    status          VARCHAR(20) DEFAULT 'draft',
    -- draft / active / deprecated
    created_by      BIGINT,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_rule_code ON hse_eval_rule(rule_code);
CREATE INDEX idx_rule_type ON hse_eval_rule(rule_type);
CREATE INDEX idx_rule_status ON hse_eval_rule(status);
```

### 5.2 评价规则版本表

```sql
CREATE TABLE hse_eval_rule_version (
    version_id      BIGSERIAL PRIMARY KEY,
    rule_id         BIGINT NOT NULL REFERENCES hse_eval_rule(rule_id),
    version         VARCHAR(20) NOT NULL,
    config          JSONB NOT NULL,
    rule_config     JSONB,
    change_log      TEXT,
    -- 本版本的变更说明
    status          VARCHAR(20) DEFAULT 'draft',
    -- draft / pending_approval / approved / active / deprecated
    created_by      BIGINT,
    created_by_name VARCHAR(100),
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    approved_by     BIGINT,
    approved_at     TIMESTAMP,
    effective_date  DATE,
    deprecated_at   DATE
);

CREATE UNIQUE INDEX idx_version_unique ON hse_eval_rule_version(rule_id, version);
CREATE INDEX idx_version_status ON hse_eval_rule_version(status);
```

### 5.3 审批流程表

```sql
CREATE TABLE hse_eval_rule_approval (
    approval_id     BIGSERIAL PRIMARY KEY,
    rule_id         BIGINT NOT NULL REFERENCES hse_eval_rule(rule_id),
    version_id      BIGINT NOT NULL REFERENCES hse_eval_rule_version(version_id),
    approver_id     BIGINT NOT NULL,
    approver_name   VARCHAR(100),
    approver_role   VARCHAR(50),
    -- admin / security_admin
    action          VARCHAR(20) NOT NULL,
    -- approve / reject
    comment         TEXT,
    approved_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_approval_rule ON hse_eval_rule_approval(rule_id, version_id);
```

### 5.4 规则变更记录表

```sql
CREATE TABLE hse_eval_rule_change_log (
    log_id          BIGSERIAL PRIMARY KEY,
    rule_id         BIGINT NOT NULL REFERENCES hse_eval_rule(rule_id),
    version_id      BIGINT,
    change_type     VARCHAR(30),
    -- create / update / approve / publish / deprecate / restore
    old_config      JSONB,
    new_config      JSONB,
    change_summary  TEXT,
    operator_id     BIGINT,
    operator_name   VARCHAR(100),
    changed_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_log_rule ON hse_eval_rule_change_log(rule_id);
CREATE INDEX idx_log_time ON hse_eval_rule_change_log(changed_at);
```

# Speaker Intent — 演讲意图与讲法

> 给演讲者（或下游 TTS / 演讲模式 Agent）的逐页执行脚本。不是逐字稿，是意图 + 情绪 + 关键台词方向。

## 演讲总意图
把一场「AI 能不能从 0 搓出生产级系统」的疑问，变成「能，而且你可以复制，但先避开我这 4 个坑」。全程第一人称、口语、自嘲、有锋芒。目标不是炫技，是让听众离场敢动手、且少踩坑。

## 情绪曲线（与 AST 一致）
```
好奇/共鸣(P1-2) → 期待/惊讶(P3-4) → 代入/紧张(P5-9) → 刺痛/共鸣(P10-13) → 豁然开朗(P14-15) → 兴奋/实用(P16-18) → 鼓舞/号召(P19-20)
```

## 关键台词方向（金句库，可直接用）
- 「如果告诉你，这套系统的前端几乎没我手写一行，你信吗？」
- 「公司要一套 HSE 系统，给的预算是：没有。给的人，是我。」
- 「它得在扫马路的大爷手机上能用，不是在我 4K 屏上好看。」
- 「最贵的那行代码，是删掉的代码。」
- 「一个 js 文件 156KB，AI 自己都快找不着北了。」
- 「我电脑里有个 交通安全风险管理设计-v1.3.md，我自己都忘了哪个是最终版。」
- 「那次『还原官方』，我不是在重构，是在赌命。」
- 「同一个功能，我做了三遍，还都以为自己是第一次做。」
- 「AI 跑得越快，你越需要一个能拉住的缰绳。」
- 「别让一个 AI 又当爹又当妈，分工比选型重要。」
- 「我最早的提示词，现在看像个发脾气的需求文档。」
- 「一个月干完，我一分钱没花在模型订阅上——靠的是轮换，不是氪金。」
- 「我踩的坑，就是你省下的一个月。」
- 「AI 手搓系统的本质，是把你从『写代码的人』变成『定方向的人』。」

## 各页讲法（逐页）

**P1 封面**：站定，先抛钩子句，停顿 2 秒。不要念标题，用「今天讲一个一个月搓出来的真实系统」开场。

**P2 为什么 AI 手搓**：用自嘲语气说资源为 0。左手比「业务要很多」，右手比「人没钱没时间」，制造反差。

**P3 目标**：强调「给一线用」。可举扫马路大爷手机这个具象，让听众笑一下，但记住这是真需求。

**P4 数字墙**：一字一顿报数，最后甩「4 个 AI 工具轮班」。这页是信任锚，语速放慢，让数字落地。

**P5 时间线总览**：手指时间轴从左到右扫，强调「每个节点我都推翻了上一点」——为后面踩坑埋伏笔。

**P6 阶段一 看板期**：轻松，像讲起点很低的故事。展示真实截图 `screenshot_light_initial.png`，说「你看，就是这种土味看板」。

**P7 阶段二 HTML 巨型原型**：语气转向「膨胀的焦虑」。报 156KB 时瞪大眼，制造「危险信号」感。

**P8 阶段三 恢复官方基线**：语气沉一下，这是转折点。「最贵的那行代码是删掉的」——郑重地说。

**P9 阶段四 AI 进化**：回升，带自豪但不飘。「AI 写的不是按钮，是安全结论」。

**P10 踩坑① 副本地狱**：转为调侃式自黑，但让听众后背发凉。堆副本清单时越念越快，制造窒息感。

**P11 踩坑② 没 Git**：严肃，念原文第 14 行。「赌命」那句压低声音。

**P12 踩坑③ 偏离+重复**：无奈笑。「做了三遍还以为是第一次」——这是全场最大共鸣点之一，留白 1 秒。

**P13 踩坑总账**：收束，上升为方法论。「缰绳」金句加重。

**P14 方法论 I 分工**：节奏变轻快，像在教秘籍。三角色用不同手势区分。

**P15 方法论 II 提示词**：展示「提示词也走版本号」的洞察，破除天赋神话。

**P16 白嫖策略（点题）**：全场最兴奋的一页。「一分钱没花」要说得带点得意。明确点出双杠杆。

**P17 实操清单**：实用、冷静，像交操作手册。「额度是可调度资源」。

**P18 复制清单**：号召前奏。「拍下来，周一开始第一步」——指向行动。

**P19 结语 CTA**：放慢，回到人。『我踩的坑，就是你省下的一个月』后停顿。三条 CTA 清晰念出。

**P20 附录**：轻松收尾，欢迎较真。「去翻那几个 md，都在硬盘里」。可留联系方式/群二维码。

## 节奏建议
- 总时长目标 20–30 分钟（每页约 1–1.5 分钟，踩坑页可略长）。
- 钩子页（P1/P4/P8/P16/P19）放慢、留白；过渡页（P5/P9/P13/P18）加快。
- 踩坑三页（P10–12）是情绪谷底，讲完 P13 必须明显「抬升」到方法论，否则听众会丧。

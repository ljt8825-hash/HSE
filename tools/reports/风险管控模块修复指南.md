# 🔧 风险管控模块"一直卡住"问题 - 诊断与修复指南

## 📋 问题症状
点击"风险管控"模块后，页面显示：
```
⏳
正在从数据库加载风险管控数据...
```
**一直卡住，不进入模块界面。**

---

## 🔍 根本原因（3个）

### 原因1：后端服务未启动或端口不匹配
- **前端配置**：`api_client.js` → 连接 `localhost:5001`
- **后端配置**：`server/app.js` → 运行在 `port 3000`
- **结果**：前端连接错误的端口，请求挂起

### 原因2：后端缺少风险管控路由
- `server/routes/` 目录只有 `vehicles.js` 和 `files.js`
- **没有 `risk-control.js` 路由** → 即使后端启动，前端也会收到 404 错误

### 原因3：缺少超时保护
- 前端 `_rcLoadFromBackend()` 使用 `Promise.all()` 但没有超时保护
- 如果后端不可用，TCP 连接超时可能很长（30秒~2分钟）

---

## ✅ 已完成的修复

### 修复1：添加超时保护（`modules/risk-control.js`）
```javascript
// 新增 5 秒超时
var timeoutPromise = new Promise(function(resolve) {
  setTimeout(function() {
    console.warn('[RiskControl] 后端请求超时（5秒），回退到本地数据');
    resolve(null);  // 超时后返回 null，使用本地数据
  }, 5000);
});

_rcBackendPromise = Promise.race([
  Promise.all([...]),
  timeoutPromise
]);
```

### 修复2：改进加载状态提示（`modules/risk-control.js`）
- **0~3秒**：显示"正在连接数据库..."
- **3~6秒**：显示"数据库连接中...（如果后端未启动，将自动使用本地数据）"
- **6秒后**：显示"⚠️ 数据库连接超时"，并提供"刷新重试"按钮

### 修复3：创建后端风险管控路由（`server/routes/risk-control.js`）
- 新增内存存储版本的风险管控路由
- 支持 CRUD 操作
- 支持统计接口（`/stats/all`、`/stats/level`、`/stats/type`）

### 修复4：统一端口配置
- **前端**：`api_client.js` → `localhost:3000`
- **后端**：`server/app.js` → `port 3000`
- **CORS**：允许 `localhost:3000` 和 `127.0.0.1:3000`

### 修复5：修复 CORS 配置（`server/app.js`）
- 开发环境允许所有源访问（避免 `file://` 协议被拦截）
- 生产环境应在 `.env` 中配置 `ALLOWED_ORIGINS`

## 📝 常见问题 FAQ

### Q1：后端启动后，前端仍然卡住？
**可能原因**：
1. 端口不匹配（确认前端 `api_client.js` 中的 `API_BASE` 是否是 `localhost:3000`）
2. CORS 错误（查看浏览器控制台是否有红色错误）
3. 浏览器缓存（按 `Ctrl + Shift + R` 强制刷新）

**解决方法**：
```javascript
// 在浏览器控制台执行，手动设置 API 地址
window.__API_BASE = 'http://localhost:3000/api';
location.reload();  // 刷新页面
```

### Q2：后端启动失败，提示"端口已被占用"？
**解决方法**：
```bash
# 查找占用 3000 端口的进程
netstat -ano | findstr :3000

# 杀死进程（假设 PID 是 1234）
taskkill /PID 1234 /F

# 或者修改端口（编辑 server/.env）
PORT=3001
```

### Q3：MySQL 数据库连接失败？
**解决方法**：
1. 确认 MySQL 服务已启动（`services.msc` 中查看）
2. 修改 `server/.env` 中的数据库密码：
   ```
   DB_PASSWORD=你的真实密码
   ```
3. 或者注释掉数据库连接，使用内存模式（仅用于测试）

### Q4：前端仍然使用本地数据，不连接后端？
**原因**：`_rcApiEnabled` 被设置为 `false`（之前连接失败时）

**解决方法**：
```javascript
// 在浏览器控制台执行
window._rcApiEnabled = true;  // 重新启用后端 API
location.reload();           // 刷新页面
```

# 三违扣分记录 · 档案表导入/导出功能说明

## 1. 需求背景

三级菜单「驾驶员违章记录 → 三违扣分记录」需支持「司机交通安全专项行动档案表.xlsx」的标准格式：

1. **导入**：抓取档案表数据，按驾驶员姓名自动填入各自的违章明细中；
2. **导出**：导出表格格式与该档案表保持一致。

经确认，本功能仅作用于「三违扣分记录」tab，且按「仅保证扣分落库」处理——档案表中的
「违规类型」「违规等级」「违章照片」三列暂不存储。

## 2. 档案表格式

### 档案表 sheet（数据来源）

| 序号 | 日期 | 驾驶员姓名 | 违章类别 | 违章照片 | 违章行为描述 | 违规类型 | 违规等级 | 扣分值 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 2026-08-31 | 杨占刚 | 车辆安全管理——违反劳动纪律 | (图片) | 关闭/遮挡/移动车辆驾驶室内摄像头 | 违反劳动纪律 | 一般违规 | 10分 |

说明：
- 该 Excel 含两个 sheet：`档案表` + `表2扣分标准`；
- `表2扣分标准` 为扣分字典（无驾驶员姓名），导入时自动跳过，不并入数据；
- 违章照片列为内嵌浮动图片（`=DISPIMG(...)`），当前不做抽取与存储。

### 字段映射（导入）

| 档案表列 | 落库字段 | 说明 |
| --- | --- | --- |
| 日期 | violationTime | 违章日期 |
| 驾驶员姓名 | name | 分组依据 |
| 违章类别 | violationType | 违章类别 |
| 违章行为描述 | violationDesc | 违章事由 |
| 扣分值 | demeritPoints | 自动解析数字（"10分"→10） |
| 序号 | seq | 行内序号 |
| 违章照片 / 违规类型 / 违规等级 | （不存储） | 忽略，不影响导入 |

## 3. 代码改动

### 服务端：`server/routes/import.js`

- `driver-three-violation` 模块 `fieldMapping` 新增别名：
  - `'日期' → violationTime`
  - `'违章行为描述' → violationDesc`
  - `'扣分值' → demeritPoints`
- 新增 `excludeSheetPatterns: [/扣分标准|表2/]`，跳过「表2扣分标准」sheet。
- 新增 `driver-three-violation` 下载模板（表头即档案表格式）。

### 前端：`安全看板vben/apps/web-naive/src/views/site/driver/violation/ViolationList.vue`

- `onExport()` 按 `nameOnly` 分支：
  - 三违扣分记录：导出表头 = 序号 / 日期 / 驾驶员姓名 / 违章类别 / 违章照片 / 违章行为描述 / 违规类型 / 违规等级 / 扣分值；
  - 扣分取 `demeritPoints`，日期取 `violationTime`，驾驶员取姓名；
  - 违规类型 / 违规等级 / 违章照片 列导出为空。
- 驾驶证扣分记录 tab 导出维持原格式。

## 4. 使用步骤

1. 进入 「驾驶员违章记录 → 三违扣分记录」 tab；
2. **导入**：点击「导入」→ 选择/上传「司机交通安全专项行动档案表.xlsx」→ 确认；
   - 系统按驾驶员姓名自动归组，每条违章填到对应驾驶员的违章明细（同一驾驶员多行 → 多条明细）；
3. **下载模板**：点击「下载模板」可获取档案表格式的空模板；
4. **导出**：点击「导出」生成「三违扣分记录_YYYYMMDD.xlsx」，格式与档案表一致。

## 5. 验证结论

用原始档案表实测解析脚本结果正确：
- 成功提取 8 条违章并自动按姓名归组（如【杨小林】两条不同日期的记录各成一条明细）；
- 扣分值 "10分" → 10；日期 2026-08-31 / 2026-09-04 正常；
- 「表2扣分标准」sheet 被排除，空白/填充行被自动过滤。

## 6. 已知限制 / 后续可扩展

- 「违规类型」「违规等级」「违章照片」三列当前不存储，导出时为空；
- 如需完整存展示上述三列，需新增数据字段并调整服务端写库与前端表单，可后续单独开发。

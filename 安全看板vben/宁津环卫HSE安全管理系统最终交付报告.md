## 三、架构亮点与合规性

### 3.1 架构亮点

1. **正确的二次开发模式**
   - 所有业务代码在独立目录（views/、api/hse/、router/routes/modules/）
   - 不修改 Vben Admin 官方核心（packages/@core/、packages/effects/）
   - 通过 `import.meta.glob` 动态加载路由和 i18n

2. **统一的组件体系**
   - 页面容器：Vben `Page` 组件（20/20页面）
   - 统计卡片：统一 `HseStatCard` 组件（Card + Statistic + 图标）
   - 图标：`@vben/icons` 的 `IconifyIcon`（统一 lucide 图标集）
   - 表格/表单/弹窗/抽屉：Ant Design Vue 官方组件

3. **主题与深色模式**
   - 所有颜色使用 CSS 变量（`hsl(var(--border))`、`hsl(var(--foreground))` 等）
   - 零硬编码颜色值
   - 深色模式自动适配

4. **Mock 降级机制**
   - 所有 API 调用使用 try/catch
   - 失败时自动降级到内置 Mock 数据
   - 前端可完全独立运行

5. **表单校验**
   - 所有 P2 模块 CRUD 表单配置了完整校验规则
   - 必填、字符长度、数值范围、手机号格式

6. **交互统一**
   - 删除操作全部使用 Popconfirm
   - 非删除确认操作使用 Modal.confirm
   - CRUD 流程一致：Modal 表单 → 提交 → 刷新列表

### 3.2 合规性检查

| TypeScript 严格模式 | ✅ | 全量类型定义 |

## 四、部署与运维建议

### 4.1 部署架构

```
                    ┌─────────────┐
                    │   Nginx     │  端口 80/443
                    │  静态+代理   │
                    └──────┬──────┘
                           │
            ┌──────────────┴──────────────┐
            │                             │
    ┌───────▼───────┐            ┌────────▼────────┐
    │  前端静态资源   │            │   后端 API      │
    │  dist/        │            │  端口 5666      │
    └───────────────┘            └─────────────────┘
```

### 4.2 部署步骤

```bash
# 1. 构建前端
cd 安全看板vben/apps/web-antd
pnpm build

# 2. 复制 dist/ 到服务器
scp -r dist/ user@server:/var/www/hse-dashboard/

# 3. 配置 Nginx（见用户操作手册）

# 4. 启动后端服务
cd server && npm run start

# 5. 验证
curl http://your-domain.com
```

## 二、登录与首页

## 三、告警中心

**路径**: 侧边栏 → 告警中心

### 功能说明
实时展示安全告警信息，支持批量处置和详情查看。

### 操作指南

#### 查看告警
- 页面顶部显示4个统计卡片：告警总数、严重告警、待处理、已解决
- 下方表格展示告警列表，包含标题、级别、状态、来源、发生时间等

#### 筛选告警
- **关键词**: 输入告警标题或描述关键词
- **级别**: 选择严重/高危/中危/低危/提示
- **状态**: 选择待处理/处理中/已关闭
- **时间范围**: 选择日期范围
- 点击「重置」清除所有筛选条件

#### 批量处置
1. 在表格中勾选需要处置的告警（可多选）
2. 点击右上角「批量处置」按钮
3. 在弹窗中填写处置备注
4. 点击「确认」完成批量处置

#### 单条处置
- 点击告警行的「处置」按钮
- 在弹窗中填写处置备注并确认

#### 查看详情
- 点击告警行的「查看」按钮
- 在右侧抽屉中查看完整告警信息

## 五、系统管理

### 用户管理
**路径**: 侧边栏 → 系统管理 → 用户管理

- **新增用户**: 点击「新增用户」→ 填写用户名、姓名、邮箱、手机号、部门 → 提交

- **重置密码**: 点击「重置密码」→ 确认操作
- **删除用户**: 点击「删除」→ 确认删除

### 角色管理
**路径**: 侧边栏 → 系统管理 → 角色管理

- **新增角色**: 填写角色编码、名称、描述 → 提交
- **权限配置**: 点击「权限配置」→ 在抽屉中勾选菜单权限 → 保存
- **启用/禁用**: 切换角色状态

## 八、隐患管理

**路径**: 侧边栏 → 隐患管理

### 功能说明
隐患排查整改全流程管理，支持年/月筛选和统计分析。

### 操作指南

#### 统计概览
- 顶部4个卡片：隐患总数、待整改、整改中、已完成

#### 筛选隐患
- **关键词**: 搜索隐患标题/描述
- **年份**: 选择年份筛选（如2025年）
- **月份**: 选择月份筛选（1-12月）
- **等级**: 重大/较大/一般/低
- **状态**: 待整改/整改中/已完成
- **分类/区域**: 按隐患分类或发现区域筛选

#### 新增隐患
1. 点击「新增隐患」
2. 填写隐患标题（必填，3-100字符）
3. 选择等级、分类、区域
4. 填写发现日期、上报人
5. 填写隐患描述
6. 点击「确认」提交

#### 完成整改
- 点击隐患行的「完成」按钮
- 确认完成操作

## 九、人员保险管理

**路径**: 侧边栏 → 保险管理 → 人员保险

### 功能说明
管理环卫人员保险信息，支持批量续保、多视图展示和高危工种分类。

### 三种视图模式

#### 列表视图
- 以表格形式展示所有人员保险信息
- 支持按关键词、部门、保险状态、高危工种筛选

#### 分类视图
- 按高危工种分类展示人员
- 5大高危工种分类：
  - **司机**（驾驶员、押运员、跟车员）
  - **转运站**（中转站、垃圾站、压缩站）
  - **高空作业**（登高、外墙、路灯、亮化）
  - **市政井下**（井下、窨井、下水道、化粪池、有限空间）
  - **其他特种**（电工、焊工、叉车、起重机）

#### 日历视图
- 以日历形式展示保单到期情况
- 快速查看即将到期的保单

### 批量续保
1. 在列表中勾选需要续保的人员（可多选）
2. 点击「批量续保」按钮
3. 在弹窗中填写新的保险起期、到期日期、保费
4. 填写续保备注
5. 点击「确认」完成批量续保

### 单条续保
- 点击人员行的「续保」按钮
- 填写新到期日期和保费
- 确认续保

### Tab分类
- **全部人员**: 显示所有人员
- **高危人员**: 仅显示高危工种人员
- **即将到期**: 显示30天内到期的人员
- **已过期**: 显示保单已过期的人员

## 十七、常见问题解答

### Q1: 页面打开后数据为空？
**A**: 系统在无法连接后端API时会自动降级到Mock数据。如果页面完全空白，请检查浏览器控制台是否有 JavaScript 错误，并尝试清除浏览器缓存后刷新。

### Q2: 如何切换深色模式？
**A**: 点击页面右上角的设置（齿轮）图标，在偏好设置面板中找到「主题模式」，选择「深色」即可。所有页面已支持深色模式自动适配。

### Q3: 批量操作时无法勾选多条数据？
**A**: 请确保点击的是表格第一列的复选框。如果复选框不可见，可能是表格列宽不够，尝试缩小筛选区域或调整浏览器窗口大小。

### Q4: 表单提交时提示校验错误？
**A**: 系统已为所有CRUD表单添加了校验规则。请确保：
- 标题类字段已填写且达到最小字符数要求
- 必填的下拉选择已选择
- 数字类字段填写了有效数值
- 手机号字段符合格式要求（11位数字，1开头）

### Q5: 如何导出数据？
**A**: 数据导出功能正在开发中，当前版本暂不支持。后续版本将支持 Excel/CSV 格式导出。

### Q6: 忘记密码怎么办？
**A**: 请联系系统管理员，在「用户管理」页面点击「重置密码」按钮为您重置。

### Q7: 告警中心的批量处置和隐患的批量操作有什么区别？
**A**: 
- 告警中心：勾选多条告警 → 批量处置 → 统一关闭
- 隐患管理：当前支持单条完成整改，批量操作功能在开发中
- 人员保险：勾选多条人员 → 批量续保 → 统一更新保单到期日

### Q8: 高危工种是如何自动分类的？
**A**: 系统根据人员的岗位/工种名称自动匹配高危分类。例如，岗位包含"司机"或"驾驶员"的自动归类为"司机"高危工种。支持5大类：司机、转运站、高空作业、市政井下、其他特种。

### Q9: 系统支持哪些浏览器？
**A**: 推荐使用 Chrome 90+、Firefox 88+、Edge 90+ 或 Safari 14+。不支持 IE 浏览器。

### Q10: 如何查看操作日志？
**A**: 导航至「安全审计 → 审计日志」，可查看所有系统操作记录，支持按操作人、类型、模块和时间范围筛选。

## 十八、部署说明

### 开发环境

```bash
# 1. 安装依赖
cd 安全看板vben
pnpm install

# 2. 启动前端开发服务
cd apps/web-antd
pnpm dev

# 3. 访问 http://localhost:5173
```

### 生产环境

```bash
# 1. 构建生产版本
cd apps/web-antd
pnpm build

# 2. 构建产物在 dist/ 目录
# 3. 将 dist/ 部署到 Web 服务器（如 Nginx）
```

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /path/to/dist;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api/ {
        proxy_pass http://backend-server:5666/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    location ~* \.(js|css|png|jpg|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### 环境变量

| 变量 | 说明 | 默认值 |
|-----|------|-------|
| `VITE_PORT` | 开发服务端口 | 5173 |
| `VITE_GLOB_API_URL` | API基础路径 | /api |
| `VITE_NITRO_MOCK` | 是否启用Mock服务 | false |

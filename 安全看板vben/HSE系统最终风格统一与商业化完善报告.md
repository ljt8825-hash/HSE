## 六、部署与交付建议

### 6.1 部署架构建议

```
                    ┌─────────────┐
                    │   Nginx     │  (静态资源托管 + API代理)
                    │  (端口 80)  │
                    └──────┬──────┘
                           │
            ┌──────────────┴──────────────┐
            │                             │
    ┌───────▼───────┐            ┌────────▼────────┐
    │  前端静态资源   │            │   后端 API      │
    │  (dist/)      │            │  (端口 5666)    │
    └───────────────┘            └─────────────────┘
```

### 6.2 环境变量配置

**生产环境 (.env.production)：**
```env
VITE_BASE=/
VITE_GLOB_API_URL=/api
VITE_COMPRESS=gzip
VITE_PWA=false
VITE_ROUTER_HISTORY=hash
```

### 6.3 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name hse.ningjin.gov.cn;
    
    root /var/www/hse-dashboard;
    index index.html;
    
    # 前端路由 fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API 代理
    location /api/ {
        proxy_pass http://localhost:5666/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

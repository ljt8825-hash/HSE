# 项目安全周工作总结生成工具使用说明

## 📁 文件说明

| 文件名 | 说明 |
|--------|------|
| `generate_weekly_summary.py` | 主程序脚本 |
| `项目安全周工作总结使用说明.md` | 本文档 |
| `乡镇人员名单（微信）.xlsx` | 人员信息数据 |
| `拍照巡检 AI 识别.xlsx` | 巡检记录数据 |

## 🚀 快速开始

### 1. 生成本地报告（立即可以使用）

直接运行以下命令：

```bash
python generate_weekly_summary.py
```

脚本会自动从本地 Excel 文件读取数据，生成周工作总结。

### 2. 连接飞书多维表格（需要先配置）

配置完成后，脚本可以直接从飞书多维表格读取数据：

1. 【检查任务计划】表
2. 【三维检查记录表】表
3. 【检查人员信息】表

## 📋 报告内容说明

生成的报告包含以下三个固定板块：

### 一、各级网格长履职完成情况

按 **一级网格长**、**二级网格长**、**三级网格长** 分组展示：

```
🟢【网格等级-姓名】
  🎯 本周目标：计划检查X次
  🟢 实际完成：实际完成X次
  📋 完成记录：
    • 日期 - 地点
  💡 亮点：...
```

**状态符号说明：**
- 🔴 超额完成
- 🟢 正常完成
- 🟡 未完成

### 二、司机酒驾测试和车辆检查情况

- 酒精检测数值和合格状态
- 车辆检查完成状态

### 三、本周隐患排查治理情况

1. 按日期分组的新增隐患明细
2. 隐患统计（已整改/整改中/未整改/无需整改）
3. 高频隐患类型提示

## 🔗 飞书多维表格集成

### 前置准备

1. 安装 Node.js
2. 安装飞书 CLI：
   ```bash
   npm install -g @larksuite/cli
   ```
3. 配置飞书 CLI：
   ```bash
   lark-cli config init --new
   ```
4. 授权多维表格访问：
   ```bash
   lark-cli auth login --domain base
   ```

### 飞书表格结构要求

#### 【检查人员信息】表

建议包含以下字段：
- 姓名
- 网格等级（一级/二级/三级）
- 乡镇/区域
- 岗位/职责
- 微信名

#### 【检查任务计划】表

建议包含以下字段：
- 姓名
- 计划检查频次（每周）
- 网格等级
- 岗位职责
- 检查区域

#### 【三维检查记录表】表

建议包含以下字段：
- 检查日期
- 检查人
- 检查地点/内容
- 三违行为（是/否）
- 三违详情
- 隐患问题
- 隐患状态
- 照片（附件）
- 酒驾测试记录
- 车辆检查记录

### 使用飞书数据生成报告

运行脚本后，按提示输入三个表格的 Base Token：

```
【检查任务计划】Base Token：xxxx
【三维检查记录表】Base Token：xxxx
【检查人员信息】Base Token：xxxx
```

## ⚙️ 自定义配置

### 修改项目名称

编辑 `generate_weekly_summary.py`，找到：

```python
generate_weekly_summary(project_name="宁津", ...)
```

将 `"宁津"` 改为您的项目名称。

### 修改计划检查频次

在 `load_data_from_excel()` 函数中修改：

```python
planned_frequency = 3  # 改为您需要的数字
```

## 📝 常见问题

### Q: 如何只生成本地报告，不连接飞书？

A: 直接运行脚本，在提示输入 Base Token 时直接回车即可。

### Q: 报告保存到哪里了？

A: 保存在当前目录，文件名格式为：`项目安全周工作总结_YYYY年MM月DD日.txt`

### Q: 如何调整统计周期？

A: 当前脚本自动按"本周一至本周日"统计。如需修改，可以编辑 `get_week_date_range()` 函数。

### Q: 飞书表格字段名不一样怎么办？

A: 需要修改 `fetch_data_from_feishu()` 函数中的字段映射逻辑，或者在飞书中调整字段名称。

# Node.js 和飞书 CLI 快速安装指南

## 🚀 方法一：手动安装（推荐）

### 第1步：下载 Node.js

1. 访问 Node.js 官网：https://nodejs.org/
2. 点击下载 **LTS 版本**（长期支持版，更稳定）
3. 下载 Windows `.msi` 安装包

### 第2步：安装 Node.js

1. 运行下载的 `.msi` 安装包
2. **重要**：在安装过程中勾选 "Add to PATH" 选项
3. 完成安装

### 第3步：重启终端或电脑

### 第4步：验证安装

打开新的 PowerShell 终端，运行：
```powershell
node --version
npm --version
```

### 第5步：安装飞书 CLI

```powershell
npm install -g @larksuite/cli
```

### 第6步：配置飞书 CLI

```powershell
lark-cli config init --new
```

按提示输入：
- App ID: `<FEISHU_APP_ID>`
- App Secret: [您的App Secret]

```powershell
lark-cli auth login --domain base
```

## 📝 方法二：分步命令安装

如果您想直接在终端中执行，请按顺序运行：

### 1. 下载 Node.js 安装包
```powershell
# 下载到临时目录
Invoke-WebRequest -Uri "https://nodejs.org/dist/v24.14.0/node-v24.14.0-x64.msi" -OutFile "$env:TEMP\nodejs-installer.msi" -UseBasicParsing
```

### 2. 运行安装程序
```powershell
Start-Process "$env:TEMP\nodejs-installer.msi"
```

### 3. 在安装向导中勾选 "Add to PATH" 并完成安装

### 4. 重启终端后运行
```powershell
# 验证 Node.js
node --version
npm --version

# 安装飞书 CLI
npm install -g @larksuite/cli

# 初始化配置
lark-cli config init --new

# 授权访问
lark-cli auth login --domain base
```

## ❓ 遇到问题？

### 如果 `node` 命令不识别
- 确保重启了终端
- 或者重启电脑
- 确保安装时勾选了 "Add to PATH"

### 如果下载慢
- 可以使用国内镜像：https://npmmirror.com/

## 🚀 步骤 2：导入 Excel 文件

### 方法 A：使用飞书官方导入功能

1. 在飞书多维表格页面，点击右上角的 **"..."**（更多选项）

2. 在弹出菜单中，选择 **"导入"** 或 **"导入 Excel/CSV"**

3. 点击 **"选择文件"**

4. 导航到以下位置并选择文件：
   ```
   C:\Users\honey\Desktop\三违\新建文件夹\宁津项目三违检查清单.xlsx
   ```

5. 选择要导入的工作表（5个工作表都可以导入）：
   - 三违检查记录表
   - 检查任务计划
   - 检查人员信息
   - 数据源表
   - 检查记录

6. 配置导入选项：
   - ✅ 保留第一行作为表头
   - ✅ 自动创建字段
   - ✅ 导入到新表格或现有表格

7. 点击 **"导入"** 或 **"开始导入"**

---

### 方法 B：复制粘贴（推荐用于小数据）

1. 打开 Excel 文件

2. 选择要导入的数据（包括表头）

3. 按 `Ctrl+C` 复制

4. 在飞书多维表格中，选择要粘贴的起始单元格

5. 按 `Ctrl+V` 粘贴

6. 确认字段对应关系

## 📋 工作表说明

Excel 文件包含 5 个工作表：

### 1. 三违检查记录表（12 条）
- 主要记录表，记录三违检查情况
- 字段：乡镇、姓名、三违单号、图片内容、三违行为等

### 2. 检查任务计划（59 条）
- 任务计划记录
- 字段：检查任务、乡镇作业中心经理、检查人、检查周期等

### 3. 检查人员信息（59 条）
- 人员信息表
- 字段：负责检查计划、姓名、网格长级别等

### 4. 数据源表（59 条）
- 辅助数据表

### 5. 检查记录（7 条）
- 历史检查记录

---

## 💡 建议的导入顺序

建议按以下顺序导入：

1. **检查人员信息** - 先导入人员基础数据
2. **检查任务计划** - 再导入任务计划
3. **数据源表** - 导入辅助数据
4. **三违检查记录表** - 导入主记录表
5. **检查记录** - 最后导入历史记录

---

## ✅ 验证导入成功

导入完成后，检查以下内容：

1. 记录数量是否正确
2. 字段名是否完整
3. 数据格式是否正确
4. 图片链接是否保留（如果有）

---

## 📞 遇到问题？

如果导入过程中遇到问题：
- 检查是否有足够的权限
- 确保 Excel 文件没有损坏
- 尝试单个工作表导入，而不是全部导入

# 飞书多维表格同步指南

## 一、环境准备

### 1. 安装 Node.js
Node.js 已经安装完成，需要**重启终端**或**重启电脑**以使环境变量生效。

### 2. 安装飞书 CLI
```bash
npm install -g @larksuite/cli
```

## 二、飞书 CLI 配置步骤

### 步骤 1：初始化配置
在终端运行：
```bash
lark-cli config init --new
```
按提示输入您的 **App ID** 和 **App Secret**（从飞书开放平台获取）。

您的 App ID：`<FEISHU_APP_ID>`（从环境变量读取）

### 步骤 2：授权多维表格访问
```bash
lark-cli auth login --domain base
```
这将打开浏览器让您授权访问飞书多维表格。

## 三、导入 Excel 到飞书多维表格

### 导入"乡镇人员名单"
```bash
lark-cli drive +import --type bitable --file "乡镇人员名单（微信）.xlsx" --title "乡镇人员名单"
```

### 导入"拍照巡检 AI 识别"
```bash
lark-cli drive +import --type bitable --file "拍照巡检 AI 识别.xlsx" --title "拍照巡检 AI 识别"
```

导入成功后，会返回多维表格的 **base_token**，请保存这个 token 备用。

## 四、使用自动同步脚本

### 1. 生成报告（已可用）
直接运行：
```bash
python generate_custom_report.py
```

### 2. 完整同步（配置好飞书 CLI 后使用）
```bash
python sync_to_feishu_base.py
```

## 五、飞书多维表格常用命令

### 查看 Base 信息
```bash
lark-cli base +base-get --base-token <您的base_token>
```

### 列出表
```bash
lark-cli base +table-list --base-token <您的base_token>
```

### 查看字段结构
```bash
lark-cli base +field-list --base-token <您的base_token> --table-name "<表名>"
```

### 读取记录
```bash
lark-cli base +record-list --base-token <您的base_token> --table-name "<表名>" --limit 200
```

## 六、常见问题

### 问题 1：提示找不到 node/npm 命令
解决：重启终端或重启电脑，让 Node.js 环境变量生效。

### 问题 2：权限不足
解决：确保您在飞书开放平台已开通了 bitable 相关权限，然后重新运行：
```bash
lark-cli auth login --domain base
```

### 问题 3：导入 Excel 失败
解决：检查 Excel 文件格式，确保第一行是表头。

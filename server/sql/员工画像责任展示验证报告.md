# 员工画像责任展示验证报告

## 一、责任体系概述

责任数据来自 `hse_responsibility` 表，责任类型分为三类：

| 责任类型 | 说明 | 展示字段 |
|----------|------|----------|
| `grid_leader` | 网格长责任 | 责任类型、网格等级、网格角色、巡查频次 |
| `production_manager` | 生产管理责任 | 仅责任类型 |
| `none` | 无责任 | 显示"非责任岗位" |

## 二、展示规则验证

### 2.1 grid_leader 展示规则

**规则**：必须展示责任类型、网格等级、网格角色、巡查频次。

**巡查频次来源**：责任配置表（`hse_responsibility.inspection_frequency`）。

**验证结果**：

| 检查项 | 测试1（二级网格长） | 测试2（三级网格长） |
|--------|---------------------|---------------------|
| 责任类型 | ✅ grid_leader | ✅ grid_leader |
| 网格等级 | ✅ grid3 | ✅ grid4 |
| 网格角色 | ✅ 二级网格长 | ✅ 三级网格长 |
| 巡查频次 | ✅ 1次/1天 | ✅ 1次/1天 |

### 2.2 production_manager 展示规则

**规则**：仅展示"生产管理责任"，不展示网格等级、网格角色、巡查频次。

**验证结果**：

| 检查项 | 测试3（片区长） |
|--------|-----------------|
| 责任类型 | ✅ production_manager |
| 网格等级 | ✅ 未返回（undefined） |
| 网格角色 | ✅ 未返回（undefined） |
| 巡查频次 | ✅ 未返回（undefined） |

### 2.3 none 展示规则

**规则**：显示"该员工岗位不属于安全责任岗位"。

**验证结果**：

| 检查项 | 测试4（驾驶员） |
|--------|-----------------|
| 责任类型 | ✅ null |
| 页面展示 | ✅ "非责任岗位" Empty 状态 |

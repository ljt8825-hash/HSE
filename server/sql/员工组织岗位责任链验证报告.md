# 员工组织岗位责任链验证报告

## 一、验证目标

验证完整的生产关系链：

```
员工（employee）
  ↓ 组织关联
组织（hse_org_unit）
  ↓ 作业单元关联
作业单元（hse_operation_unit）
  ↓ 岗位关联
岗位（position）
  ↓ 责任生成
责任（hse_responsibility）
```

确认每个环节的数据完整性和关联正确性。

## 四、链路关联正确性验证

### 4.1 员工→组织→岗位链路

```sql
-- 验证：每个员工都有组织和岗位
SELECT
  COUNT(*) FILTER (WHERE er.org_unit_id IS NOT NULL) as has_org,
  COUNT(*) FILTER (WHERE er.position_id IS NOT NULL) as has_position,
  COUNT(*) FILTER (WHERE er.org_unit_id IS NOT NULL AND er.position_id IS NOT NULL) as has_both,
  COUNT(*) as total
FROM hse_employee_relation er
WHERE er.is_current = true AND er.is_deleted = false;
```

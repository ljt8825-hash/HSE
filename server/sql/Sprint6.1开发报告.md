# Sprint6.1 开发报告

## 一、开发概述

Sprint6.1 员工HSE风险画像中心开发，基于Sprint6.0基础数据底座，实现员工综合风险画像。通过6类风险维度的规则评分，对员工进行定量风险评估与等级划分，支持风险趋势分析与重点管控。

---

## 二、开发内容

### 1. 数据库

- **2张新表**：
  - `hse_risk_scoring_config`：评分配置表，存储6条维度评分规则
  - `hse_employee_risk_snapshot`：员工风险快照表，存储评分结果
- **1个聚合视图**：`v_employee_risk_profile`，跨表聚合员工多维风险数据
- **6条评分配置**：三违风险、培训风险、事故风险、隐患责任风险、交通安全风险、网格巡查责任风险

### 2. 后端API

8个接口，统一路径前缀 `/api/hse/risk-profile`：

| 接口 | 方法 | 功能 |
|------|------|------|
| / | GET | 获取风险画像列表（分页、筛选、排序） |
| /:employeeId | GET | 获取单个员工风险画像详情 |
| /statistics | GET | 风险统计概览 |
| /dimension/:dimension | GET | 按维度分析 |
| /trend/:employeeId | GET | 员工风险趋势 |
| /calculate | POST | 触发全量评分计算 |
| /calculate/:employeeId | POST | 触发单个员工评分计算 |
| /export | GET | 导出风险画像数据 |

### 3. 前端页面

- **RiskProfile.vue**：风险画像主页面，含列表、统计、详情、趋势展示
- **API封装**：`hse-risk-profile.ts`，封装全部8个后端接口调用

### 4. 路由注册

- 前端路由已注册至HSE模块菜单下

## 五、评分计算示例

以保洁员**刘文武**为例：

| 维度 | 原始指标 | 维度评分 | 权重 | 加权得分 |
|------|----------|----------|------|----------|
| 三违风险 | 1次 | 80分 | 0.30 | 24.0 |
| 培训风险 | 0% | 20分 | 0.20 | 4.0 |
| 事故风险 | 0次 | 100分 | 0.25 | 25.0 |
| 隐患责任风险 | 0次 | 100分 | 0.15 | 15.0 |
| 交通安全风险 | N/A | -1（不适用） | - | 不参与 |
| 网格巡查风险 | N/A | -1（不适用） | - | 不参与 |

**计算过程：**

```
total_score = (24.0 + 4.0 + 25.0 + 15.0) / (0.30 + 0.20 + 0.25 + 0.15)
            = 68.0 / 0.90
            = 75.6 ≈ 76分
```

**风险等级**：中风险（medium，60-79分区间）

3. 保存映射规则，避免下次导入再次异常

## 三、班组无法确认分析（软异常）

### 3.1 总体情况

班组无法确认共 **121** 条，占总记录数的 **85.2%**。

> **重要说明：** 班组无法确认属于"软异常"，不影响员工主数据、组织关系和岗位关系的导入，仅影响 `hse_operation_unit`（作业单元）的关联。员工仍然可以正常导入，只是作业单元字段为空，后续可补充。

### 3.2 原因分析

作业单元匹配率低的主要原因：

1. **作业单元初始化数据有限**：当前系统中初始化的作业单元数量较少，主要覆盖了车辆作业单元
2. **班组命名不规范**：Excel中的班组名称（如"人工班组"、"保洁组"、"挂桶组"、"管理层"）与系统中的作业单元名称不直接对应
3. **作业单元映射规则缺失**：尚未建立班组名称到作业单元的映射规则
4. **作业单元类型推断覆盖不全**：仅驾驶员岗位能通过类型推断匹配到车辆作业单元

### 3.3 各场景班组匹配情况

| 岗位/场景 | 人数 | 作业单元匹配数 | 匹配率 |
|-----------|------|---------------|--------|
| 驾驶员 | 20 | 20 | 100% |
| 乡镇主管 | 12 | 0 | 0% |
| 人工班长 | 24 | 0 | 0% |
| 片区长 | 6 | 0 | 0% |
| 保洁员 | 50 | 0 | 0% |
| 挂桶员 | 15 | 0 | 0% |
| 转运站操作员 | 8 | 0 | 0% |

### 3.4 改进建议

1. **完善作业单元初始化数据**：
   - 各乡镇作业中心：创建对应的人工班组、保洁组、挂桶组作业单元
   - 各转运站：创建转运站作业单元
   - 环卫作业中心：创建各片区作业单元

2. **建立班组-作业单元映射规则**：
   - "人工班组" → 对应乡镇的人工班组作业单元
   - "保洁组" → 对应乡镇的保洁作业单元
   - "挂桶组" → 对应乡镇的挂桶作业单元
   - "管理层" → 不关联作业单元（管理岗）

3. **增强作业单元匹配逻辑**：
   - 支持按组织+岗位组合推断作业单元
   - 支持班组名称模糊匹配

## 四、异常处理流程

### 4.1 异常进入待确认表

所有异常记录均已写入 `employee_import_pending` 表，状态为 `pending`（待人工确认）。

### 4.2 人工确认操作

1. 在"花名册导入-待确认"页面查看异常列表
2. 对每条异常记录进行处理：
   - **组织不匹配**：选择正确的组织，保存映射规则
   - **岗位不匹配**：选择正确的岗位，保存别名映射
   - **岗位歧义**：从多个候选中选择正确的岗位
   - **班组不确定**：选择正确的作业单元
   - **基础数据错误**：修正数据后重新导入

3. 确认后系统自动：
   - 更新员工组织/岗位/作业单元关系
   - 生成/更新责任记录
   - 保存映射规则（下次自动匹配）

## 五、预防措施建议

### 5.1 数据质量提升

1. **Excel模板标准化**：提供标准导入模板，包含字段说明和格式要求
2. **数据校验前置**：导入前先进行格式校验，提前发现基础数据错误
3. **身份证号校验**：增加身份证号校验码验证，减少格式错误

### 5.2 映射规则完善

1. **定期收集别名**：从每次导入的异常中提取新的组织/岗位别名
2. **建立映射规则库**：持续积累映射规则，提高自动匹配率
3. **部门-岗位组合映射**：支持"部门+职位"的组合映射，解决"经理"类歧义

### 5.3 作业单元匹配优化

1. **批量初始化作业单元**：按组织层级批量创建作业单元
2. **作业单元命名规范**：统一作业单元命名规则，便于自动匹配
3. **班组-作业单元映射表**：建立专门的映射表，支持灵活配置

## 六、结论

本次导入异常率 **3.5%**（5/142），处于较低水平，主要异常为：
- 基础数据错误（测试数据，非真实业务数据）
- 个别组织/岗位名称不匹配

班组无法确认（121条）属于软异常，不影响核心导入流程，后续可通过完善作业单元映射规则逐步解决。

**整体评估：导入流程稳定，异常处理机制完备，可投入生产使用。**

| **乡镇主管** | 乡镇作业中心经理 | grid_leader | grid3 | 二级网格长 | 79 |

### 2.2 区分逻辑

三个岗位名称虽然相似，但通过 `source_position` 精确匹配机制确保不混淆：

```
Excel职位 = "人工片区长"
  → 精确匹配规则[5] → 乡镇作业中心经理 → grid_leader / grid3

Excel职位 = "片区长"
  → 精确匹配规则[11] → 环卫作业中心片区长 → production_manager

Excel职位 = "乡镇主管"
  → 精确匹配规则[4] → 乡镇作业中心经理 → grid_leader / grid3
```

**关键区分点：**
- "人工片区长" ≠ "片区长" — 前者是乡镇人工管理岗，后者是环卫作业中心管理岗
- "人工片区长"和"乡镇主管"都映射到"乡镇作业中心经理"，因为它们在实际业务中是同一岗位的不同称呼
- "片区长"映射到"环卫作业中心片区长"，责任类型为 production_manager

## 六、匹配优先级机制

### 6.1 岗位匹配优先级

1. **映射规则精确匹配**（按 match_priority 降序）
   - 带条件规则（condition_dept）：检查部门是否包含条件值
   - 无条件规则：直接匹配
2. **岗位别名匹配**
3. **岗位名称精确匹配**

### 6.2 优先级数值说明

| 优先级范围 | 说明 |
|-----------|------|
| 100-80 | 核心管理岗（项目总经理、部门经理、乡镇作业中心经理） |
| 79-60 | 别名映射岗（乡镇主管、人工片区长、人工班长、副经理、片区长） |
| 59-40 | 非责任岗位（保洁员、挂桶员等） |
| 39-20 | 驾驶员、操作员类 |
| 19-1 | 职能岗位（安全、文员、会计等） |

# 员工风险画像基础页面开发说明

## 一、页面概述

员工风险画像基础页面，路径为 `/hse/risk-profile/employee`。该页面用于展示员工 HSE 基础画像信息，暂不包含风险评分计算。

## 二、页面结构

### 1. 员工基础信息卡

展示员工个人基础信息，包括：

- 姓名
- 工号
- 性别
- 手机号
- 身份证脱敏

### 2. 组织岗位卡

展示员工所属组织和岗位信息，包括：

- 所属组织
- 组织类型
- 作业单元
- 作业单元类型
- 标准岗位
- 岗位别名

### 3. 责任画像卡

根据员工责任类型动态展示责任信息。

### 4. 风险指标占位区域

展示六类风险维度，当前标记为建设中：

- 作业风险
- 行为风险
- 培训风险
- 健康风险
- 违章风险
- 事故风险

## 三、责任展示逻辑

### 网格长责任

当 `responsibility_type` 为 `grid_leader` 时显示：

- 责任类型标签：网格长责任
- 网格等级：二级网格 / 三级网格长
- 网格角色
- 巡查频次

### 生产管理责任

当 `responsibility_type` 为 `production_manager` 时显示：

- 生产管理责任标签
- 说明文字
- 不显示网格等级

### 非责任岗位

当 `responsibility_type` 为 `none` 或 `responsibility` 为 `null` 时：

- 显示空状态提示
- 不展示责任模块详情

## 四、交互

- 页面提供员工 ID 输入框
- 用户输入员工 ID 后点击查询按钮
- 页面调用后端接口 `GET /api/hse/risk-profile/employee/{employeeId}` 加载画像数据
- 根据返回数据渲染各信息卡片

## 五、限制遵守

- 未修改 `employee` / `employee_assignment` / `hse_responsibility`
- 未新增人员表
- 未新增依赖
- 未修改权限框架

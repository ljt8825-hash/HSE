# 风险指标计算规则

## 一、评分模型概述

- **评分方式**：规则评分（非AI自动评分），基于明确阈值分级
- **维度数量**：6个风险维度，按适用性参与计算
- **权重分配**：各维度固定权重，加权平均计算总分
- **总分范围**：0-100分
- **风险等级划分**：
  - 低风险（low）：80-100分
  - 中风险（medium）：60-79分
  - 高风险（high）：40-59分
  - 极高风险（critical）：0-39分

---

## 二、各维度计算规则

### 1. 三违风险（权重30%）

| 项目 | 说明 |
|------|------|
| **指标** | 近12个月三违次数 |
| **数据来源** | `violations`表，按姓名+乡镇匹配员工 |
| **适用范围** | 全部员工 |

**评分规则：**

| 三违次数 | 评分 |
|----------|------|
| 0次 | 100分 |
| 1次 | 80分 |
| 2-3次 | 60分 |
| 4-5次 | 40分 |
| 6次以上 | 20分 |

---

### 2. 培训风险（权重20%）

| 项目 | 说明 |
|------|------|
| **指标** | 培训完成率 |
| **数据来源** | `employee_training_status`表 |
| **适用范围** | 全部员工 |

**评分规则：**

| 培训完成率 | 评分 |
|------------|------|
| 100% | 100分 |
| 80%-99% | 80分 |
| 60%-79% | 60分 |
| 40%-59% | 40分 |
| <40% | 20分 |

---

### 3. 事故风险（权重25%）

| 项目 | 说明 |
|------|------|
| **指标** | 事故次数 |
| **数据来源** | `accidents`表，按姓名或`personnel_id`匹配员工 |
| **适用范围** | 全部员工 |

**事故分类：**
- 生产安全事故
- 交通事故
- 环境污染事故

**评分规则：**

| 事故次数 | 评分 |
|----------|------|
| 0次 | 100分 |
| 1次 | 70分 |
| 2次 | 40分 |
| 3次以上 | 10分 |

---

### 4. 隐患责任风险（权重15%）

| 项目 | 说明 |
|------|------|
| **指标** | 责任隐患次数 |
| **数据来源** | `hazard_record`表，按`employee_id`或`responsible_id`匹配员工 |
| **适用范围** | 全部员工 |

**评分规则：**

| 责任隐患次数 | 评分 |
|--------------|------|
| 0次 | 100分 |
| 1-2次 | 70分 |
| 3-5次 | 40分 |
| 6次以上 | 10分 |

---

### 5. 交通安全风险（权重10%，仅驾驶员）

| 项目 | 说明 |
|------|------|
| **指标** | 交通违法次数 |
| **数据来源** | `violations`表中交通类 + `accidents`中交通事故类 |
| **适用岗位** | 垃圾转运车驾驶员、垃圾收运车驾驶员、吸污车驾驶员 |
| **非驾驶员** | 此维度不参与评分 |

**评分规则：**

| 交通违法次数 | 评分 |
|--------------|------|
| 0次 | 100分 |
| 1次 | 70分 |
| 2-3次 | 40分 |
| 4次以上 | 10分 |

> **注意**：非驾驶员员工该维度标记为不适用（-1分），不参与加权计算。

---

### 6. 网格巡查责任风险（权重10%，仅grid_leader）

| 项目 | 说明 |
|------|------|
| **指标** | 巡查完成率 |
| **数据来源** | `grid_areas`表`completion_rate`字段 |
| **适用责任类型** | `grid_leader` |
| **非grid_leader** | 此维度不参与评分 |

**评分规则：**

| 巡查完成率 | 评分 |
|------------|------|
| 100% | 100分 |
| 80%-99% | 80分 |
| 60%-79% | 60分 |
| 40%-59% | 40分 |
| <40% | 20分 |

> **注意**：非grid_leader员工该维度标记为不适用（-1分），不参与加权计算。

## 三、评分计算公式

```
total_score = Σ(dimension_score × dimension_weight) / Σ(applicable_dimension_weight)
```

**计算规则：**
- 只计算适用维度的加权得分之和
- 不适用维度（评分为-1）不参与分子和分母计算
- 分母为所有适用维度的权重之和（非1.0）

**示例计算：**

某员工适用4个维度（三违、培训、事故、隐患），交通和巡查不适用：

```
total_score = (三违分×0.30 + 培训分×0.20 + 事故分×0.25 + 隐患分×0.15) / (0.30+0.20+0.25+0.15)
            = (三违分×0.30 + 培训分×0.20 + 事故分×0.25 + 隐患分×0.15) / 0.90
```

## 四、风险等级划分

| 等级 | 标识 | 分数范围 | 含义 |
|------|------|----------|------|
| 低风险 | low | 80-100分 | 员工HSE表现良好，风险可控 |
| 中风险 | medium | 60-79分 | 存在一定风险，需关注改善 |
| 高风险 | high | 40-59分 | 风险较高，需重点管控 |
| 极高风险 | critical | 0-39分 | 风险极高，需立即干预 |

---

## 五、评分快照

每次计算完成后，将评分结果存入 `hse_employee_risk_snapshot` 表，包含以下字段：

- 员工ID
- 各维度原始指标值
- 各维度评分
- 总分
- 风险等级
- 计算时间

**用途：**
- 支持历史趋势分析，追踪员工风险变化
- 支持批量统计，生成部门/岗位风险分布报告
- 支持时间维度的风险对比，评估管控措施效果

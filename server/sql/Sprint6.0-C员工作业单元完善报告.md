## 三、作业单元映射规则

### 3.1 映射规则表设计

新建 `employee_operation_unit_mapping_rule` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| source_dept | VARCHAR(255) | Excel所属部门 |
| source_position | VARCHAR(255) | Excel职位 |
| target_unit_id | BIGINT | 目标作业单元ID |
| target_unit_name | VARCHAR(255) | 目标作业单元名称 |
| target_unit_type | VARCHAR(50) | 目标作业单元类型 |
| match_priority | INT | 匹配优先级 |
| status | VARCHAR(20) | 状态 |

### 3.2 映射规则统计

| 规则类型 | 规则数 | 匹配优先级 |
|----------|--------|-----------|
| 班组精确匹配 → cleaning_team | 51 | 100 |
| 车队 → center_vehicle_team | 1 | 95 |

| 片区+收运辅助工 → collection_team | 12 | 88 |
| 片区+中转站管理员 → transfer_station | 10 | 85 |

## 四、导入匹配逻辑优化

### 4.1 四级优先级匹配

| 优先级 | 匹配方式 | 说明 |
|--------|---------|------|
| 第一优先 | 部门精确匹配 | source_dept完全匹配，source_position为空 |
| 第二优先 | 部门+岗位组合 | source_dept和source_position都匹配 |
| 第三优先 | 岗位推断 | 根据岗位名称推断作业单元类型 |
| 第四优先 | 组织推断 | 按组织查找同类型作业单元 |

### 4.2 岗位匹配优化

修正"司机"岗位的条件匹配：

| 原始职位 | 部门条件 | 目标岗位 | 说明 |
|----------|---------|----------|------|
| 司机 | 车队 | 垃圾转运车驾驶员 | 修正（原误为收运车驾驶员） |
| 司机 | 片区 | 垃圾收运车驾驶员 | 新增 |
| 中转站管理员 | - | 转运站操作员 | 新增 |
